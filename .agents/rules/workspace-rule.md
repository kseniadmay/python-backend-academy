# Запрет технических кодов и номеров в UI (Clean Human UI Invariant)

- **Никогда не использовать технические номера карточек, конспектов и т.д. в интерфейсе пользователя**:
  - СТРОГО ЗАПРЕЩЕНО выводить в пользовательском интерфейсе служебные технические коды и идентификаторы (`К-001`, `Ф-001`, `К-конспекты`, `Ф-карточки`, `Ф-xxx`, `К-*`, `Ф-*`, технические коды юнитов вида `Юнит 1.1`, `Юнит X.Y`, `1.1`, UUID, raw slug, машинные коды заметок).
  - Пользователю показываются исключительно понятные человеческие названия тем («Базовый синтаксис»), смысловые заголовки и естественные номера («Карточка 1 из 10», «Урок 1: Базовый синтаксис», «Урок 1 из 9»).
  - Вся внутренняя техническая номенклатура базы знаний (`К-*`, `Ф-*`, ID юнитов `X.Y`) остаётся строго под капотом (в data-атрибутах, стейте и коде движка).
