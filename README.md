Автономная интерактивная образовательная платформа и практическая лабораторная среда для интенсивной подготовки **Junior+ Python Backend Developer**.  
Проект объединяет доказательную педагогику **Khan Academy**, философию **Coddy** (3D-тропа обучения, Single Dominant CTA) и hands-on кодинг в браузере без необходимости локальной установки Python.  
Поддерживает двустороннюю синхронизацию прогресса между ПК и мобильными устройствами через облачный REST API на Node.js и PostgreSQL.

## Live Demo

**Онлайн-платформа:**  
https://python-backend-academy.onrender.com

### 1. Локальный запуск (Десктоп)
Дважды кликните по файлу `academy.html` или откройте его в Google Chrome / Яндекс.Браузере. Платформа полностью автономна и работает прямо из локальной папки.

### 2. Мобильный доступ (Смартфон / Планшет)
Запустите командный файл в корне репозитория:
```cmd
.\start_mobile.cmd
```
Скрипт автоматически запустит локальный сервер синхронизации, определит IP-адрес домашней сети, поднимет защищённый туннель Cloudflare и выведет в консоль QR-код для моментального входа со смартфона.  
*(Для удобства в корне также сохранён ярлык `Запустить_с_Телефона.bat`).*

## Стек технологий

- Python 3.13 (стандартная библиотека, 0 сторонних pip-зависимостей)
- Исполнение Python в браузере: Brython WebAssembly / Pyodide (Python 3.13)
- Клиентское ядро: Vanilla JavaScript (ES6+), HTML5 Semantic, CSS3 Custom Properties («Вечерний Обсидиан»)
- Интерфейс и редакторы: Monaco Cloud IDE + Hermetic Fallback Editor (<15 КБ)
- Офлайн и PWA: Service Worker Cache API, Web App Manifest (100% автономная работа без интернета)
- Интервальное повторение: Адаптивный алгоритм SuperMemo-2 (SRS) с 4 градациями XP
- Бэкенд синхронизации: Node.js 20+, Express/HTTP REST API
- Базы данных: PostgreSQL (Neon Cloud) / локальный JSON (`data/progress_sync.json`)
- Звук и голос: Web Audio API (процедурный синтезатор звуков) + Web Speech Synthesis API
- Тестирование и верификация: Chrome DevTools Protocol (CDP), AST-анализ, pixel-diff сьют

## Возможности

### Основные функции

- **3D-Тропа обучения (Home = Journey)**: единый маршрут из 42 учебных дней и 28 навыков с плавной кривой Безье, автоматическим центрированием на активном уроке и popover-инспекцией тем.  
_Реализация:_ кастомный SVG-рендерер, CSS Spring Physics, Single Dominant CTA (`#/path`)

- **Студия кода и тренажёр IDE**: 401 практическая задача с тестами в реальном времени, консольным терминалом, подсветкой синтаксиса и горячими клавишами (`Ctrl+Enter`).  
_Реализация:_ Monaco Editor / Hermetic Fallback Editor + Brython WASM (`#/practice`)

- **Интерактивные микро-конспекты**: порционные шаги теории на 5–10 минут с визуализацией потоков данных (I/O Flow) и индексной анатомией структур данных.  
_Реализация:_ Markdown AST парсер, чистая типографика Onest без тяжелых рамок (`#/python/skill/...`)

- **Флешкарты интервального повторения**: 3D-переворот карточек, всплывающие шпаргалки кода, горячие клавиши (Пробел / 1..4) и начисление опыта (+2/+5/+10 XP).  
_Реализация:_ алгоритм SuperMemo-2 (SRS), CSS 3D Transforms, Web Audio API (`#/cards`)

- **Аттестация и экзамены модулей**: рубежные тестирования по 7 ключевым направлениям бэкенда с проходным порогом 75% и детальным разбором решений.  
_Реализация:_ модульные модальные окна, автоматический аудит ответов

- **Мок-интервью**: симуляция технических скринингов и архитектурных секций собеседования Junior+ Backend.  
_Реализация:_ сократический диалоговый агент, 4-уровневый динамический скаффолдинг подсказок (`#/mock`)

### Системные возможности

- **Двусторонняя дельта-синхронизация (ПК ↔ Смартфон)**: непрерывное сохранение решённых задач, черновиков кода и карточек памяти между устройствами.  
_Реализация:_ Node.js REST API (`scripts/server.js`) + Neon Cloud PostgreSQL / Local JSON

- **Автономный офлайн-режим (PWA)**: полноценная работа платформы в режиме полета (чтение теории, повторение карточек и кодинг).  
_Реализация:_ Service Worker Cache API (`sw.js`) + PWA Manifest (`manifest.json`)

- **Голосовой компаньон**: чтение теории и формулировок задач вслух с естественной интонацией прямо во время изучения.  
_Реализация:_ Web Speech Synthesis API с фонетической адаптацией IT-терминологии

- **Звуковая геймификация**: процедурный синтез приятных звуков клика, успешной компиляции, ошибки и получения ачивок.  
_Реализация:_ процедурный Web Audio API синтезатор без внешних аудиофайлов

- **Конвейер верификации (100% PASS)**: непрерывный сквозной контроль качества и предотвращение регрессий.  
_Реализация:_ `verify_all.py` (DOM-инварианты, PWA, Headless Chrome, 401 задача IDE, pixel-diff)

## Endpoints и маршруты

### Серверный REST API (`scripts/server.js`)

`GET  /healthz` – проверка работоспособности сервиса (Health check)  
`GET  /api/sync` – чтение сохранённого бандла прогресса (XP, решённые задачи, карточки)  
`POST /api/sync` – дельта-сохранение прогресса с защитой от рассинхронизации (HTTP 409 Conflict)  
`GET  /api/bug-report` – получение очереди замечаний мобильного интерфейса  
`POST /api/bug-report` – отправка замечания или баг-репорта со смартфона  

### Клиентские маршруты платформы (SPA)

`#/path` – 3D-тропа обучения (главный экран, 42 дня, 28 навыков)  
`#/python` – трек Python Core (теория, карточки, задачи)  
`#/web` – трек Web & HTTP (протоколы, сокеты, REST)  
`#/backend` – трек Backend (FastAPI, Django, асинхронность)  
`#/algorithms` – трек Алгоритмы и структуры данных  
`#/databases` – трек Базы данных и PostgreSQL  
`#/architecture` – трек Архитектура и Clean Architecture  
`#/infra` – трек Инфраструктура и Docker  
`#/practice` – тренажёр IDE с 401 задачей и автотестами  
`#/cards` – интервальное повторение флешкарт (SRS)  
`#/mock` – симулятор технических собеседований с Сократом  

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/kseniadmay/python-backend-academy.git
cd python-backend-academy
```

### 2. Запуск в браузере (Автономно)

Платформа полностью герметична и не требует обязательного сервера:
- **Windows**: Дважды кликните по файлу `academy.html` или откройте его в браузере.
- **Через встроенный веб-сервер Python**:
```bash
python -m http.server 8080
```
Затем перейдите по адресу: [http://localhost:8080/academy.html#/](http://localhost:8080/academy.html#/)

### 3. Запуск с доступом со смартфона / планшета

```powershell
.\start_mobile.cmd
```
*(Либо через ярлык `.\Запустить_с_Телефона.bat`).*  
В терминале сгенерируется QR-код и ссылка Cloudflare Tunnel для мгновенного подключения мобильного устройства.

### 4. Настройка переменных окружения

Создайте файл `.env` на основе шаблона:
```bash
cp .env.example .env
```
Задайте переменные при необходимости подключения облачной базы данных (`DATABASE_URL`) и защиты синхронизации (`SYNC_TOKEN`).

### 5. Запуск сервера синхронизации Node.js

```bash
# Установка зависимостей Node.js
npm install

# Запуск сервера синхронизации
npm start
```
По умолчанию сервер запустится на порту `8080` и будет сохранять прогресс в `data/progress_sync.json` (или в PostgreSQL при наличии `DATABASE_URL`).

### 6. Сборка монолита из базы знаний (при внесении правок)

```bash
python scripts/assemble_academy.py
```

## Ключевые решения

- **Исполнение кода Python в браузере (Brython WASM)**: обучающийся решает 401 задачу без необходимости разворачивать локальное окружение Python на ПК или смартфоне
- **100% герметичный офлайн-режим (Service Worker Cache API)**: платформа полностью сохраняет работоспособность в авиарежиме и без доступа к сети
- **Двусторонняя дельта-синхронизация с защитой от конфликтов**: прогресс надёжно синхронизируется между компьютером и телефоном с определением версий (HTTP 409 Conflict)
- **Канонический Single Source of Truth интерфейса**: утверждённый эталон в `Эталоны/` и строгий 6-этапный конвейер верификации исключают визуальные и логические регрессии
- **Процедурный синтез звука и речи (Web Audio / Web Speech API)**: звуковые эффекты и озвучка теории генерируются процедурно без тяжёлых MP3-файлов и сетевого оверхеда

```
               │                               │

┌─────────────────────────────┐ ┌─────────────────────────────┐
│     Офлайн-кэш (sw.js)      │ │   Движок кода в браузере    │
│   Hermetic Service Worker   │ │     (Brython / Pyodide)     │
└──────────────┬──────────────┘ └─────────────────────────────┘
               │ HTTPS (дельта-синхронизация /api/sync)
               ▼
┌─────────────────────────────┐
│   Сервер синхронизации      │
│      (scripts/server.js)    │
└──────────────┬──────────────┘
               │
       ┌───────┴───────┐
       ▼               ▼
┌─────────────┐ ┌─────────────┐
│  Локальный  │ │ Облачная БД │
│  JSON (dev) │ │  (Neon PG)  │
└─────────────┘ └─────────────┘
```

**Компоненты:**
- **academy.html** — единое SPA-приложение, объединяющее навигацию, редактор и базу знаний
- **Service Worker (`sw.js`)** — перехватывает сетевые запросы и обеспечивает полную работоспособность без интернета
- **Brython Runtime** — компилирует и исполняет код задач Python прямо в песочнице браузера
- **Node.js Sync Server (`scripts/server.js`)** — REST API для обмена прогрессом между телефоном и настольным компьютером
- **PostgreSQL / JSON** — надёжное персистентное хранилище решённых задач и накопленного XP
