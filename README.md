## О платформе

Платформа позволяет изучать бэкенд на Python без необходимости устанавливать и настраивать локальное окружение:

- **Тренажёр с тестами в браузере**: 401 практическая задача с моментальной проверкой решений через WebAssembly (Brython 3.13).
- **Короткие конспекты**: 238 практических тем, сфокусированных на реальных задачах и вопросах технических собеседований.
- **Интервальное повторение**: 287 тематических колод карточек (алгоритм SuperMemo-2) для закрепления синтаксиса и алгоритмов.
- **Синхронизация прогресса**: бэкенд на FastAPI сохраняет прогресс, решённые задачи и черновики между компьютером и телефоном.
- **Автономный режим (PWA)**: приложение работает без интернета прямо из файла или через Service Worker.

| Направления | Учебных дней | Задач в тренажёре | Конспектов | Колод карточек |
| :---: | :---: | :---: | :---: | :---: |
| **7 модулей** | **42 дня** | **401 задача** | **238 тем** | **287 колод** |

## Быстрый старт

### Вариант 1. Сервер FastAPI (рекомендуется)
```cmd
.\start_fastapi.cmd
```
*Или через консоль:* `python -m backend.run`  
- Интерфейс: [http://127.0.0.1:8080](http://127.0.0.1:8080)
- Документация Swagger: [http://127.0.0.1:8080/docs](http://127.0.0.1:8080/docs)
- Спецификация ReDoc: [http://127.0.0.1:8080/redoc](http://127.0.0.1:8080/redoc)

### Вариант 2. Запуск со смартфона или планшета
```cmd
.\start_mobile.cmd
```
Скрипт определяет IP-адрес в локальной сети, открывает защищённый туннель Cloudflare и показывает QR-код для подключения.

### Вариант 3. Автономный запуск в браузере
Откройте файл `academy.html` в браузере или запустите локальный сервер:
```bash
python -m http.server 8080
```
Затем перейдите по адресу: [http://localhost:8080/academy.html#/](http://localhost:8080/academy.html#/)

## Программа

1. **Python Core**: модель памяти, типы данных, изменяемость, итераторы, генераторы, ООП и аннотации типов.
2. **Web и протоколы**: HTTP/HTTPS, WebSockets, сокеты, заголовки, TCP/UDP и принципы REST API.
3. **Бэкенд и API**: FastAPI, Django, асинхронный Python (`asyncio`), валидация с Pydantic V2.
4. **Алгоритмы и структуры данных**: оценка сложности Big-O, бинарный поиск, списки, деревья, графы.
5. **Базы данных**: PostgreSQL, транзакции, уровни изоляции, B-Tree индексы, работа с ORM.
6. **Архитектура**: чистая архитектура, принципы SOLID, паттерны проектирования, 12-Factor App.
7. **Инфраструктура**: Docker, сборка образов, CI/CD, очереди задач Celery, Redis и мониторинг.

## API

Сервер предоставляет REST API с автодокументацией в Swagger (`/docs`):

| Метод | Эндпоинт | Назначение |
| :--- | :--- | :--- |
| `GET` | `/api/v1/health` | Проверка состояния сервиса |
| `GET` / `POST` | `/api/v1/sync` | Получение и сохранение прогресса пользователя |
| `GET` | `/api/v1/content/summary` | Сводка: количество модулей, задач и тем |
| `GET` | `/api/v1/content/modules` | Список модулей программы и матрица навыков |
| `GET` | `/api/v1/content/tasks` | Список практических задач с фильтрацией по уровню и теме |
| `GET` | `/api/v1/content/search` | Поиск по конспектам и задачам (`?q=...`) |
| `POST` | `/api/v1/feedback` | Отправка отзывов и сообщений об ошибках |

## Структура репозитория

```text
Python_Backend_Academy/
├── academy.html                 # Автономное приложение платформы
├── start_fastapi.cmd            # Запуск бэкенда FastAPI для Windows
├── start_mobile.cmd             # Запуск с мобильным доступом
├── verify_all.py                # Скрипт сквозного тестирования
│
├── backend/                     # Бэкенд на FastAPI
│   ├── run.py                   # Точка входа Uvicorn
│   ├── app/                     # Исходный код: core, schemas, services, api
│   └── tests/                   # Тесты API
│
├── frontend/                    # Модульный интерфейс
│   ├── css/                     # Стили компонентов
│   ├── dist/bundle.css          # Собранный бандл стилей
│   └── js/                      # Логика клиента (api.js, state.js)
│
├── data/content/                # База контента: задачи, конспекты, карточки
├── scripts/build.py             # Сборщик ассетов и проверка данных
└── tests/                       # Регрессионные тесты интерфейса
```

## Тестирование

```bash
# Сборка ассетов и проверка целостности данных:
python scripts/build.py

# Тесты REST API:
python -m unittest discover backend/tests

# Быстрая проверка платформы:
python verify_all.py --quick

# Полный прогон всех тестов и 401 задачи:
python verify_all.py
```
