## 🚀 Быстрый запуск и верификация

### 1. Верификация платформы (6-этапный конвейер)
```powershell
# Через Python:
python .\verify_all.py --quick
# или через npm:
npm run verify
# Полный прогон (с 401 задачей IDE и visual diff):
npm run verify:full
```

### 2. Запуск локального сервера и синхронизации
```powershell
npm start
# или запуск с мобильным туннелем:
.\Запустить_с_Телефона.bat
```

### 2. Сквозной аудит всех тестовых скриптов (87/87 PASS)
Параллельный запуск всех тестовых, проверочных и аудиторских скриптов:
```powershell
python .\scripts\audit_pipeline.py
```

### 3. Установка Git Pre-Commit хука
Защита от случайных синтаксических ошибок в JS, Python и JSON перед коммитом:
```powershell
python .\scripts\install_hooks.py
```

### 4. Открытие платформы в браузере
Дважды кликните по файлу `academy.html` или откройте его в Google Chrome:
```powershell
Start-Process "chrome.exe" (Resolve-Path ".\academy.html")
```

### 5. Автоматизированная проверка PWA и оффлайн-режима
```powershell
node .\scripts\test_pwa_offline.js
```

### 6. Пересборка проекта и синхронизация облака
```powershell
python .\scripts\assemble_academy.py
```

## ☁️ Синхронизация прогресса ПК ↔ телефон через интернет

Чтобы синхронизация работала при выключенном ПК, приложение и API должны быть размещены в облаке. Подготовлены конфигурация Render и PostgreSQL-хранилище; локальный режим по-прежнему сохраняет прогресс в `data/progress_sync.json`.

### Первичная настройка (Render + Neon)

1. Создайте проект PostgreSQL в [Neon](https://console.neon.tech/) и скопируйте connection string (`DATABASE_URL`). Бесплатная база может приостанавливать вычислитель при простое, но включается при новом запросе.
2. В [Render](https://dashboard.render.com/) подключите GitHub-репозиторий `kseniadmay/python-backend-academy` как Blueprint и выберите корневой `render.yaml`.
3. Для `DATABASE_URL` вставьте строку подключения Neon. Для `SYNC_TOKEN` задайте длинный случайный код. Не публикуйте эти значения и не вставляйте их в исходники.
4. После успешной сборки откройте выданный адрес `https://…onrender.com/academy.html#/` и используйте его на ПК и телефоне. При первом обращении приложение попросит код синхронизации; введите тот же `SYNC_TOKEN` на обоих устройствах.
5. Чтобы перенести уже накопленный прогресс, на каждом устройстве экспортируйте JSON в старой версии приложения, затем откройте «🔄 Контекст» на облачной версии и импортируйте файл. Импорт сливает данные, поэтому повторите его отдельно для телефона и ПК.

Клиент хранит код только в `localStorage` своего браузера. Состояние курса, статусы IDE и черновики передаются по HTTPS в PostgreSQL Neon. API отклоняет запросы без правильного кода. `/healthz` используется Render для проверки доступности сервиса.

Бесплатный веб-сервис Render засыпает после 15 минут без запросов; первое открытие после простоя может занимать около минуты. Бесплатный compute Neon также засыпает в простое и автоматически просыпается при обращении. При открытии телефона без ПК сайт всё равно доступен в Render, прогресс попадёт в Neon и синхронизируется с ПК при следующем открытии.

### Локальная разработка

```powershell
npm install
$env:PBA_PORT = "8080"
npm start
```

Если `DATABASE_URL` не задан, API использует локальный JSON-файл. Для локального или облачного режима с авторизацией установите `SYNC_TOKEN` и введите тот же код в браузере.
