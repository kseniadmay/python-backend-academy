# 🏆 Канонические эталоны интерфейса платформы (Single Source of Truth)

Директория `standards/` хранит исполняемый эталон вёрстки `standards.html` и базовые визуальные снимки экранов **Python Backend Academy**.

> [!IMPORTANT]
> **Единый свод правил стиля, цветов, типографики, бусин и актуальных визуальных спецификаций** перенесён в корневой документ [`../DESIGN.md`](../DESIGN.md) (чтобы не дублировать детали компонентов).

---

## Состав файлов в `standards/`

- **`standards.html`** — полный интерактивный SPA-эталон, побайтово синхронизированный с [`../academy.html`](../academy.html).
- **`theory_reader_baseline.png`** — базовый снимок экрана конспекта (актуальный канон подачи без рамки в Book Mode и без запуска кода в теории описан в [`../DESIGN.md § 3.2, § 5.3`](../DESIGN.md)).
- **`video_frames/`** (`frame_001.png` .. `frame_014.png`) — раскадровка интерактивных флеш-карточек (актуальный канон изумрудной оборотной грани и однострочных 100% Solid Hex кнопок `Не знаю / Частично / Помню / Легко` — в [`../DESIGN.md § 6.3`](../DESIGN.md)).
- **`practice_task_baseline.png`** — базовый снимок тренажёра практики Zen IDE (сократический дифф и мобильный Sticky Anchor — в [`../DESIGN.md § 6.4`](../DESIGN.md)).
- **`milestone_exam_modal_baseline.png`** — базовый снимок стартовой модалки рубежного теста (актуальное правило на 8–12 вопросов — в [`../PROJECT_CONTEXT.md § 1.12`](../PROJECT_CONTEXT.md)).

## Команды верификации эталона (запускать только после утверждения экрана)

- `node tests/test_pravki_spec.js` — проверка спецификаций эталонов
- `python scripts/verify_academy.py` — побайтовая идентичность с `academy.html`, синтаксис JS и рендеринг
- `python verify_all.py --quick` — конвейер верификации данных и кода
