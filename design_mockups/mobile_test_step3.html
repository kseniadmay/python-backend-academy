Как Python находит ключ за один шаг?

Вместо проверки всех элементов по очереди, функция hash() мгновенно превращает строку в номер ячейки памяти.

PYTHON 3.13 ▶ Тапни для запуска
key = "user_id"
bucket = hash(key) % 8
print(f"Ячейка #{bucket}")
✓ Вывод: Ячейка #5 (0.0001 мс)
💡 Суть: Поиск в словаре из 10 элементов и из 10 миллионов занимает одинаковое время — O(1).

Какая встроенная функция Python вычисляет числовой хеш неизменяемого ключа?

idx = hash(key) % 16
print(idx)
