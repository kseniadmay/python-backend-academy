🎨 Варианты карточек разделов на тропе (#/path)

Сравнение 3 концепций оформления разделителей глав по дизайн-системе платформы (бордо / изумруд / янтарь, матовое стекло, «Вечерний Обсидиан»).
ВАРИАНТ А
Широкая стеклянная карточка-портал

Полноширинная карточка из матового стекла на всю ширину тропы с сегментами прогресса.

  • Полоса сегментов пройденных юнитов главы
  • Янтарная 3D-кнопка «ПЕРЕЙТИ К РАЗДЕЛУ ➔» справа
  • Не прерывает восприятие прогресса
ВАРИАНТ Б
Компактная парящая плашка

Ультра-компактная стеклянная пилюля с иконкой раздела, парящая над тропой.

  • Высота всего ~52px (минимум визуального шума)
  • Круглая светящаяся эмблема языка/темы слева
  • Компактная кнопка «ОБЗОР ➔»
ВАРИАНТ В (КАНОНИЧЕСКИЙ CODDY)
Карточка-портал в стиле Coddy v1

Центрированная карточка прямо по оси тропы с золотым гексагоном номера раздела.

  • 100% совпадение со стилем кадра v1 из Coddy
  • Золотой 3D-гексагон с номером раздела (1..7)
  • Крупная изумрудная 3D-кнопка внизу карточки

📍 Где размещать карточки: 1-й вариант (все 7) vs 2-й вариант (только между главами)

ВАРИАНТ 1 (РЕКОМЕНДУЕМЫЙ)
Все 7 разделов (включая Раздел 1 в самом верху)

Тропа открывается золотым порталом Раздела 1. Все главы оформлены абсолютно единообразно.

  • Единая визуальная логика для каждого раздела курса
  • Студент сразу видит «Раздел 1: Python Core» прямо на старте тропы
  • Устраняется пустота в начале пути
ВАРИАНТ 2
Только между главами (начиная со 2-го раздела)

Тропа сразу начинается с ноды Юнита 1.1, а карточка появляется только при переходе к Разделу 2.

  • Меньше элементов на первом экране (сразу нода 1.1)
  • Карточка работает строго как «ворота перехода на следующий уровень»
  • Верхний баннер отвечает за первый раздел
