K-003: Срезы в Python (slice)

Срез (синтаксис lst[start:stop:step]) позволяет извлекать подстроки и подсписки. В Python срез всегда создаёт новый объект — поверхностную копию (shallow copy) элементов, оставляя исходную коллекцию неизменной.

# Пример базового среза numbers = [10, 20, 30, 40, 50] subset = numbers[1:4] # [20, 30, 40] reversed_lst = numbers[::-1] # [50, 40, 30, 20, 10]

Если шаг отрицательный, обход выполняется справа налево, а значения по умолчанию для start и stop меняются местами.
