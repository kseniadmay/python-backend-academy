Словари в Python хранят пары ключ–значение. В отличие от списка, поиск по ключу не перебирает элементы по очереди.
Например, вот как выглядят корзины хеш-таблицы в памяти для словаря users:
КорзинаХешКлюч : Значение
#1841921"alice" : 28
#5391045"bob" : 34
Но что происходит, когда в словаре миллион ключей? Функция hash() за один шаг вычисляет номер корзины:
bucket = hash("bob") % 8
# Мгновенный переход к корзине #5 за O(1)

Почему изменяемый список [1, 2] нельзя сделать ключом словаря?

Потому что список занимает слишком много памяти в RAM
При изменении списка изменится его хеш, и элемент потеряется в старой корзине
В словаре ключами могут быть только строки str
✓ Правильно! (Ответ уровня Senior) ⚑

Именно этот ответ ждут на техническом скрининге: мутация ключа ломает инвариант хеш-таблицы.
