В чём разница между shallow copy и deepcopy при работе со вложенными списками?

Двухфакторный поиск анаграмм в потоке

Реализуйте функцию group_anagrams(words: list[str]) -> list[list[str]], группирующую анаграммы за оптимальное асимптотическое время без квадратичных вложенных циклов.

⚡ Контракт задачи O(N · K log K)
Вход (words) ["eat", "tea", "tan", "ate", "nat", "bat"]
➔
Ожидание [["eat","tea","ate"], ...]
💡 Сократовская подсказка L1 (Концепция)
Подумайте, какой неизменяемый инвариант объединяет все перестановки одного и того же слова, чтобы использовать его как ключ хэш-таблицы?
solution.py CPython 3.13 / Brython
from collections import defaultdict def group_anagrams(words: list[str]) -> list[list[str]]: groups = defaultdict(list) for w in words: key = "".join(sorted(w)) groups[key].append(w) return list(groups.values())

Срезы (Slicing)

Отрицательный шаг step < 0 переворачивает направление. s[::-1] разворачивает последовательность без изменения оригинала.
