1. Что делает директива `from __future__ import annotations` (PEP 563)? >> Откладывает вычисление аннотаций до момента обращения к ним; позволяет использовать forward references и синтаксис Python 3.10+ в более ранних версиях
2. Какой PEP ввёл аннотации типов? >> PEP 484
3. Для кого предназначена информация в аннотациях? >> Для разработчика, IDE и статических анализаторов типов
4. Как называется концепция аннотаций подчёркивающая их рекомендательный характер? >> Type hints (подсказки типов)
5. Бросает ли Python ошибку при несовпадении типа с аннотацией? >> Нет; аннотации не проверяются в runtime
6. Где хранятся аннотации функции во время выполнения? >> В атрибуте `__annotations__` ; доступны как словарь `{'param': type, 'return': type}`
7. Как аннотировать аргумент `name` как строку? >> `def func(name: str):`
8. Являются ли аннотации строгими ограничениями? >> Нет; только подсказки
9. Каким символом указывается тип возвращаемого значения? >> `->` ; например `def func() -> int:`
10. Как указать что аргумент может быть `int` или `str` ? >> `Union[int, str]` из `typing` ; в Python 3.10+ можно `int | str`
11. Что произойдёт при вызове `add('hello', 'world')` если аргументы аннотированы как `int` ? >> Python выполнит без ошибки и вернёт `'helloworld'`
12. Как указать что аргумент может быть `int` или `None` ? >> `Optional[int]` из `typing` ; в Python 3.10+ можно `int | None`
13. Какой линтер выполняет статическую проверку типов? >> `mypy` ; анализирует код без его запуска и выявляет несоответствия аннотациям
14. Пример аннотации переменной `age` как `int` со значением `25` ? >> `age: int = 25`
