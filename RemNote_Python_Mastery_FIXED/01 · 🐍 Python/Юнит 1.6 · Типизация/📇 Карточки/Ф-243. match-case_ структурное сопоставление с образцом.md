1. С какой версии Python доступен match-case? >> С Python 3.10 (PEP 634).
2. Чем match-case отличается от switch в других языках? >> Умеет не только сравнивать значение, но и разбирать структуру объекта (кортежи, словари, атрибуты класса) прямо в условии.
3. Что делает case _: в match-case? >> Случай по умолчанию, аналог else.
4. Что делает `case (0, y):`? >> Проверяет, что это кортеж из двух элементов с первым равным 0, и одновременно извлекает второй элемент в переменную y.
5. Что такое guard-условие в match-case? >> Дополнительный if после паттерна, проверяемый только при структурном совпадении.
6. Может ли case проверять структуру словаря по ключам? >> Да: case {"type": "click", "x": x} — проверяет наличие ключей и извлекает значения.
7. Что делает `case [x, y, *rest]:` при сопоставлении со списком? >> Проверяет, что список содержит минимум 2 элемента, извлекает первые два в x, y, а остаток — в rest.
8. Может ли match-case сопоставлять по типу без извлечения атрибутов, например `case int():`? >> Да, просто проверит, что значение — экземпляр int.
9. Что делает `case str() | bytes():` в одном case? >> Сопоставление с несколькими альтернативными типами через |, аналогично isinstance с кортежем типов.
10. Является ли match-case заменой полноценного switch из C-подобных языков? >> Частично — он мощнее (структурное сопоставление), но для простого сравнения значений if/elif работает так же и не требует Python 3.10+.
11. Что произойдёт, если ни один case не совпал и нет case _? >> match просто ничего не выполнит — прохождение блока завершится без ошибки, аналогично if без else.
12. Может ли case содержать несколько guard-условий подряд через and? >> Да: case int(x) if x > 0 and x < 100: — обычное булево выражение после if.
13. Что произойдёт при `case Point(x=0, y=0):` для объекта, у которого нет атрибута y? >> AttributeError не будет — case просто не совпадёт с этим паттерном и перейдёт к следующему case.
14. Можно ли захватить весь объект целиком вместе со структурным сопоставлением через as? >> Да: case Point(x=0, y=0) as origin: — origin будет содержать весь объект при совпадении.
