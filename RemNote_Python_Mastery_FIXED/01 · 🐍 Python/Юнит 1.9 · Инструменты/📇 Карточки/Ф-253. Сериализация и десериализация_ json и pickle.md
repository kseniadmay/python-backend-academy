1. В чём главное различие json и pickle? >> json — текстовый, языконезависимый, ограниченный простыми типами; pickle — бинарный, Python-специфичный, сериализует почти любой объект.
2. Чем json.dumps() отличается от json.dump()? >> dumps() работает со строкой, dump() пишет сразу в файловый объект.
3. Почему pickle.loads() опасен на данных из недоверенного источника? >> Может выполнить произвольный код при десериализации (arbitrary code execution).
4. Может ли json сериализовать datetime "из коробки"? >> Нет, нужен кастомный encoder через параметр default в json.dumps().
5. Когда уместен pickle, а когда json? >> pickle — только для доверенных внутренних данных одной Python-системы; json — для API, конфигов, любого обмена между системами.
6. Какие типы Python json.dumps() не может сериализовать без кастомного encoder? >> Множества (set), datetime, объекты пользовательских классов, Decimal.
7. Во что превращается Python None при сериализации в JSON? >> null.
8. Во что превращается Python True/False при сериализации в JSON? >> true/false (нижний регистр).
9. Что делает параметр indent в json.dumps(data, indent=2)? >> Форматирует вывод с отступами для читаемости человеком, вместо компактной однострочной записи.
10. Может ли pickle сериализовать функции и лямбды? >> Обычные именованные функции — да (по ссылке на модуль), lambda — нет, pickle не умеет их сериализовать.
11. Что нужно проверить перед pickle.loads() данных из сети? >> Что источник данных полностью доверенный — иначе это уязвимость выполнения произвольного кода.
12. Что вернёт json.loads('null')? >> None.
13. Можно ли сериализовать вложенные структуры (список словарей) через json.dumps()? >> Да, json нативно поддерживает произвольную вложенность списков и словарей.
14. Что произойдёт при json.dumps() объекта с циклической ссылкой? >> ValueError: Circular reference detected — json не умеет сериализовать циклы, в отличие от pickle.
15. Какой протокол (версию) pickle использовать для максимальной эффективности в современном Python? >> pickle.HIGHEST_PROTOCOL — автоматически выбирает самый новый доступный протокол.
