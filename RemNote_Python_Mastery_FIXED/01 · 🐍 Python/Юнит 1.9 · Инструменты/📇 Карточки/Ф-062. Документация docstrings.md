1. Что такое docstring в Python? >> Строковый литерал в первой строке модуля, класса или функции; становится значением атрибута `__doc__` объекта
2. Что рекомендуется описывать в docstring модуля? >> Назначение модуля, внешние интеграции, примеры импорта и использования
3. Через какой атрибут доступен docstring объекта? >> `obj.__doc__` ; также доступен через `help(obj)`
4. Для чего используется `pdoc` ? >> Простая автоматическая генерация HTML-документации из docstrings без сложной настройки
5. Как запустить локальный сервер документации mkdocs? >> `mkdocs serve` ; изменения отображаются в браузере в реальном времени
6. Что такое `pydocstyle` ? >> Линтер, проверяющий соответствие docstrings стандарту PEP 257; не исправляет автоматически, только находит несоответствия
7. Можно ли в docstring документировать возвращаемые значения и исключения? >> Да; это стандартная практика во всех стилях: секции `Returns` , `Raises` в Google/NumPy, `:returns:` и `:raises:` в Sphinx Style
8. Где располагается docstring модуля? >> В самой первой строке файла, до импортов
9. Что такое mkdocs? >> Современная альтернатива Sphinx: генерирует сайт документации из Markdown-файлов
10. Что такое doctest? >> Исполняемые примеры кода внутри docstring; оформляются как интерактивная сессия Python ( `>>>` )
11. Какой пакет нужен для интеграции docstrings в mkdocs? >> `mkdocstrings` ; устанавливается: `pip install mkdocs mkdocstrings`
12. Как запустить `pydocstyle` ? >> `pydocstyle myapp/`
13. Как инициализировать проект Sphinx? >> `sphinx-quickstart docs/`
14. Какой PEP регулирует соглашения по написанию docstrings? >> PEP 257
15. Где располагается docstring класса? >> В первой строке сразу после заголовка `class`
16. Какие три основных стиля docstrings существуют в Python? >> Google Style (наиболее читаемый, популярный), NumPy Style (многословный, для научного сообщества), Sphinx/reStructuredText Style (для генерации документации Sphinx)
17. Является ли docstring частью исполняемого кода? >> Нет; это метаданные для документации и инструментов; на логику программы не влияет
18. Как создать HTML-документацию пакета через pdoc? >> `pdoc mypackage --html`
19. Чем Google Style docstring отличается от NumPy Style на практике? >> Google Style компактнее: секции начинаются с отступа; NumPy Style использует подчёркивание заголовков ( `Args\n----` ) и многословнее – удобен для научных библиотек с большим числом параметров
20. Как собрать HTML-документацию Sphinx? >> `sphinx-build -b html docs/ docs/_build/` ; флаг `-b` задаёт формат сборки
21. Для чего используется Sphinx? >> Генерация документации в форматах HTML, PDF и др. из docstrings и `.rst` -файлов
22. Как запустить doctests через pytest? >> `pytest --doctest-modules`
23. Как запустить doctest через стандартный модуль? >> `python -m doctest mymodule.py`
