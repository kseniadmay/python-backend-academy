## Зачем нужны регулярные выражения

**Регулярное выражение** – язык для описания шаблонов в тексте: "найди то, что выглядит как email", "проверь, что строка состоит только из цифр", "замени все пробелы на подчёркивания". В Python это модуль стандартной библиотеки **`re`**. Регулярки избыточны для простых операций (для них хватает `str.split()`, `str.replace()`, `in`) – их сила в гибких, вариативных шаблонах, которые обычными строковыми методами описать неудобно или невозможно.

---

## Основные функции модуля re

```python
import re

text = 'Свяжитесь со мной: alex@example.com или на +7 999 123-45-67'

match = re.search(r'\w+@\w+\.\w+', text)
print(match.group())  # 'alex@example.com'

numbers = re.findall(r'\d+', text)
print(numbers)  # ['7', '999', '123', '45', '67']

print(re.match(r'Свяжитесь', text))  # Match – совпадает с началом
print(re.match(r'alex', text))  # None – не с начала строки

clean = re.sub(r'\d', '#', text)
print(clean)  # цифры телефона заменены на '#'

parts = re.split(r'[,;]\s*', 'a, b; c,d')
print(parts)  # ['a', 'b', 'c', 'd']
```

---

## Ключевые спецсимволы

`.` – любой символ, кроме перевода строки. `\d` – цифра, `\D` – не цифра. `\w` – буква/цифра/подчёркивание, `\W` – всё остальное. `\s` – пробельный символ. `*` – 0 или больше повторений. `+` – 1 или больше. `?` – 0 или 1 (необязательный элемент). `{n,m}` – от n до m повторений. `^`/`$` – начало/конец строки. `[abc]` – один из перечисленных символов. `()` – группа, `(?:...)` – группа без захвата (не попадает в результат).

## Группы захвата

```python
pattern = r'(\w+)@(\w+)\.(\w+)'
match = re.search(pattern, 'alex@example.com')
print(match.group(0))  # 'alex@example.com' – вся строка совпадения
print(match.group(1))  # 'alex' – первая группа
print(match.group(2))  # 'example' – вторая группа
print(match.groups())  # ('alex', 'example', 'com')

pattern = r'(?P<user>\w+)@(?P<domain>\w+\.\w+)'
match = re.search(pattern, 'alex@example.com')
print(match.group('user'))  # 'alex'
print(match.group('domain'))  # 'example.com'
```

---

## Жадные vs ленивые квантификаторы

По умолчанию `*` и `+` **жадные** – захватывают максимально возможное количество символов. Добавление `?` после них делает квантификатор **ленивым** – минимально возможное совпадение.

```python
text = '<b>жирный</b> и <i>курсив</i>'

print(re.findall(r'<.+>', text))  # ['<b>жирный</b> и <i>курсив</i>'] – жадный,
print(re.findall(r'<.+?>', text))  # ['<b>', '</b>', '<i>', '</i>'] – ленивый,
```

## Компиляция паттерна для многократного использования

```python
email_pattern = re.compile(r'\w+@\w+\.\w+')

for text in ['контакт: a@b.com', 'почта: c@d.org']:
    match = email_pattern.search(text)
    if match:
        print(match.group())  # по очереди: 'a@b.com', затем 'c@d.org'
```

`re.compile()` заранее компилирует шаблон в объект – если один и тот же паттерн применяется много раз (например, в цикле по большому набору строк), это быстрее, чем передавать строку шаблона в `re.search()` каждый раз заново.

---

## Когда использовать

Регулярки уместны для валидации формата (email, телефон, почтовый индекс), извлечения структурированных фрагментов из неструктурированного текста (парсинг логов), гибкой замены по шаблону. Когда задача сводится к точной подстроке или разбиению по фиксированному символу – обычные строковые методы (`in`, `str.split(',')`, `str.replace()`) читаются проще и работают быстрее, и предпочтительнее регулярки.
