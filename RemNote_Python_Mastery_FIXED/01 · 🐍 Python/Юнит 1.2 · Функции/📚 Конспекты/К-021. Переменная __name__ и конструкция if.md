## Что такое `__name__`

В каждом Python-файле автоматически создаётся переменная **`__name__`**. Её значение зависит от того, как именно этот файл используется в текущей сессии.

Если файл запускается напрямую – `python my_module.py` – интерпретатор присваивает `__name__` значение `'__main__'`. Если файл импортируется в другой скрипт – `import my_module` – переменная получает имя модуля, то есть строку `'my_module'`.

Это позволяет файлу знать свою роль: он является точкой входа или просто предоставляет инструменты другому файлу.

---

## Зачем нужна проверка `if __name__ == '__main__'`

При импорте модуля Python выполняет весь код верхнего уровня в этом файле. Если там есть вызовы функций, `print`, запуск логики – всё это выполнится в момент импорта. Это почти всегда нежелательно.

```python

def calculate(x):
    return x * 2

result = calculate(5)
print(result)  # Выведет 10 даже когда другой файл просто импортирует utils
```

Конструкция `if __name__ == '__main__'` – это фильтр: код внутри выполняется только при прямом запуске файла и полностью игнорируется при импорте.

```python

def calculate(x):
    return x * 2

if __name__ == '__main__':
    result = calculate(5)
    print(result)  # Выведет 10 только при python utils.py
```

## Практический пример

```python

def greet():
    print('Hello!')

print(f'__name__ = {__name__}')  # '__name__ = __main__' (при прямом запуске)

if __name__ == '__main__':
    greet()  # напечатает: 'Hello!' (только при прямом запуске)
```

При прямом запуске: `__name__ = __main__`, затем `Hello!`. При импорте из другого файла: `__name__ = my_module` – и `greet()` не вызывается.

---

## Где это применяется

В реальных проектах блок `if __name__ == '__main__'` используют в нескольких сценариях. Первый – **точка входа**: запуск основной логики приложения. Второй – **быстрая проверка**: тестовые вызовы функций прямо в файле, которые не мешают другим файлам при импорте. Третий – **CLI-скрипты**: файл может работать и как импортируемый модуль, и как самостоятельная утилита.

В production-коде точку входа обычно выносят в отдельный файл `main.py` или `__main__.py` – последний позволяет запускать пакет как `python -m my_package`.

---

## Главное правило

Определения – функции, классы, константы – располагаются на верхнем уровне файла и доступны при импорте. Всё, что является запуском логики – вызовы, вывод, инициализация – должно находиться внутри `if __name__ == '__main__'`. Это делает файл безопасным для импорта и предсказуемым для тех, кто будет использовать его как модуль.
