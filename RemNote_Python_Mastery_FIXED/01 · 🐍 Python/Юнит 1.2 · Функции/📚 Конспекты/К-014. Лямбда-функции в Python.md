## Что такое lambda

**`lambda`** – это способ создать анонимную функцию в одном выражении, без `def` и без имени. Результат – обычный объект функции, который можно вызвать, передать как аргумент или сохранить в переменную.

```python
square = lambda x: x ** 2
print(square(5))  # 25

add = lambda a, b: a + b
print(add(2, 3))  # 5
```

---

## Синтаксис и ограничения

`lambda аргументы: выражение`. Тело лямбды – **ровно одно выражение**, а не набор инструкций: внутри нельзя написать `if/else` в виде оператора, циклы, `return`, множественные строки. Условие можно выразить только через тернарный оператор:

```python
classify = lambda n: 'even' if n % 2 == 0 else 'odd'
print(classify(7))  # 'odd'
```

Если логика не помещается в одно выражение – это сигнал использовать обычную функцию через `def`.

---

## Главный сценарий – функция-ключ

Лямбды почти никогда не используются сами по себе с присваиванием в переменную (для этого есть `def` – так рекомендует PEP 8). Их основная область применения – быть **аргументом** для функций высшего порядка, которым нужен короткий одноразовый callback.

```python
users = [
    {'name': 'Alice', 'age': 30},
    {'name': 'Bob', 'age': 25},
]

users_sorted = sorted(users, key=lambda u: u['age'])
print(users_sorted)  # сначала Bob (25), потом Alice (30)

evens = list(filter(lambda x: x % 2 == 0, range(10)))
print(evens)  # [0, 2, 4, 6, 8]

squares = list(map(lambda x: x ** 2, range(5)))
print(squares)  # [0, 1, 4, 9, 16]
```

`key=` в `sorted()`, `max()`, `min()` – самый частый повод написать `lambda`: не нужно объявлять отдельную именованную функцию ради одной строки логики.

---

## Почему PEP 8 не рекомендует `f = lambda: ...`

```python
f = lambda x: x * 2

def f(x):
    return x * 2
```

Обе формы эквивалентны по поведению, но у обычной функции есть осмысленное имя в трейсбеке при ошибке (`f`), а у лямбды, присвоенной переменной, `__name__` всё равно останется `'<lambda>'` – это усложняет отладку. Присваивание лямбды переменной не даёт никакого выигрыша перед `def`, а из читаемости – вычитает.

---

## Ловушка: лямбда и замыкание в цикле

Лямбда захватывает переменную, а не её значение на момент создания – та же ловушка, что и с обычными вложенными функциями в цикле (см. тему про замыкания). `[lambda: i for i in range(3)]` даст три функции, возвращающие одно и то же последнее значение `i`, если не зафиксировать его через аргумент по умолчанию `lambda i=i: i`.

---

## Когда использовать

Лямбда уместна для короткой, очевидной логики внутри `sorted`, `filter`, `map`, `key=`, GUI-колбэков одной строкой. Как только тело просит вторую строку, условие в виде оператора или подробное имя для читаемости – это сигнал переходить на `def`.
