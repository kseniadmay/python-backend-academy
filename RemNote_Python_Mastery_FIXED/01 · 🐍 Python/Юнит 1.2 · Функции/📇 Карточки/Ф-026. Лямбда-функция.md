1. Сколько аргументов может принимать lambda-функция в Python и какие есть ограничения на её тело? >> Любое количество, включая ноль; `lambda: 42` – валидная лямбда без аргументов
2. Какое главное ограничение накладывается на тело lambda-функции в Python? Как использовать условия внутри lambda? >> Только одно выражение; инструкции ( `if-else` как statement, `for` , `return` , аннотации типов) недопустимы
3. Что выведет следующий код с lambda-функцией: `square = lambda x: x ** 2; print(square(5))` ? >> `25`
4. Может ли лямбда занимать несколько строк? >> Нет, только одна строка
5. Что является приоритетом при выборе между `lambda` и `def` ? >> Читаемость кода
6. Какую роль играет `u` в `lambda u: u['age']` ? >> Входной аргумент, представляющий текущий элемент списка – словарь с ключами `name` и `age`
7. Как называются функции, создаваемые через `lambda` ? >> Анонимные функции
8. `sorted(users, key=lambda u: u['age'])` – для чего используется лямбда? >> Определяет правило сортировки: извлекает значение `'age'` из каждого словаря для сравнения
9. Когда предпочтительно использовать лямбду? >> Для коротких вспомогательных функций на месте: в `sorted()` , `map()` , `filter()`
10. Где располагается лямбда в вызове `sorted()` ? >> Передаётся как значение именованного параметра `key`
11. В какой параметр `sorted()` обычно передаётся лямбда? >> `key`
12. Чем количество аргументов лямбды отличается от количества выражений в теле? >> Аргументов может быть любое количество; тело – строго одно выражение
13. Нужно ли писать `return` в лямбда-функции? >> Нет; результат выражения возвращается неявно; явный `return` выбросит `SyntaxError`
14. Что такое лямбда-функция в Python? >> Анонимная функция, объявляемая в одну строку через ключевое слово `lambda` ; содержит только одно выражение, результат которого возвращается неявно
15. Какое ключевое слово создаёт анонимную функцию? >> `lambda`
16. Почему лямбда не подходит для сложной логики? >> Ограничение на одно выражение и отсутствие имени снижают читаемость; PEP 8 рекомендует использовать `def`
