1. Можно ли передать в map() несколько итерируемых объектов? Как это работает? >> Да; `map(func, iter1, iter2)` передаёт в `func` по одному элементу из каждого; останавливается по самому короткому
2. Для чего в Python используется list(map(...)) или list(filter(...))? >> Для явного преобразования итератора в список
3. Что вернёт следующее выражение с `filter()`: `list(filter(lambda x: x > 2, [1, 2, 3, 4]))` ? >> `[3, 4]`
4. К какому количеству элементов `map()` применяет функцию? >> К каждому элементу
5. Для чего используется `filter(func, iterable)` ? >> Фильтрует элементы, оставляя только те, для которых функция возвращает `True`
6. `list(map(str, [1, 2, 3]))` – результат? >> `['1', '2', '3']`
7. Как `filter()` обрабатывает элементы, для которых условие ложно? >> Исключает их из результирующего итератора
8. Когда `map()` предпочтительнее list comprehension? >> Когда передаётся уже существующая именованная функция: `map(str, lst)` лаконичнее чем `[str(x) for x in lst]`
9. Что возвращает `map()` ? >> Итератор; для получения списка нужно явно вызвать `list(map(...))`
10. `list(map(lambda x: x**2, [1, 2, 3]))` – результат? >> `[1, 4, 9]`
11. Каково назначение `map(func, iterable)` ? >> Применяет функцию к каждому элементу итерируемого объекта и возвращает итератор результатов
12. Какая конструкция считается более читаемой альтернативой `map()` и `filter()` ? >> List comprehensions; `[x**2 for x in lst]` вместо `map(lambda x: x**2, lst)`
13. Что произойдёт если передать `None` вместо функции в `filter()` ? >> `filter(None, iterable)` оставит только истинные ( `truthy` ) элементы; эквивалент `filter(bool, iterable)`
14. Возвращают ли `map()` и `filter()` `list` ? >> Нет, оба возвращают итераторы
