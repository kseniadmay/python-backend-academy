1. На что ссылается параметр cls в @classmethod и чем он отличается от self? >> На сам класс; позволяет обращаться к атрибутам и методам класса, а не экземпляра
2. Можно ли вызывать `@classmethod` без создания экземпляра класса? Как передаётся аргумент `cls` ? >> Да: `User.show_count()` ; `cls` Python передаёт автоматически
3. Как декоратор `@property` позволяет создать атрибут только для чтения (read-only)? Что произойдёт при попытке записи? >> Да; без определения сеттера присваивание выбросит `AttributeError`
4. Как объявить геттер и сеттер с помощью декоратора `@property` ? >> Через `@<имя>.setter` ; обязательно наличие базового `@property` ; без него сеттер не работает
5. В чём синтаксическая и архитектурная разница между методом с `@property` и обычным методом? >> `@property` вызывается без скобок ( `c.area` ); обычный метод – со скобками ( `c.area()` )
6. Для каких свойств используется `@property` ? >> Для вычисляемых свойств и контроля доступа к атрибутам
7. Для чего часто применяется `@classmethod` ? >> Для создания альтернативных конструкторов: `User.from_dict(data)` , `Date.from_string('2024-01-15')`
8. Как `@property` помогает инкапсуляции? >> Скрывает внутреннюю реализацию за простым интерфейсом атрибута; позволяет добавить валидацию без изменения внешнего API
9. В чём отличие `@classmethod` от обычного метода? >> Обычный метод получает `self` (экземпляр); `@classmethod` получает `cls` (класс)
10. Когда использовать `@classmethod` вместо обычного метода? >> Когда методу нужно работать с состоянием класса или создавать экземпляры класса
11. Что позволяет делать `@property` ? >> Обращаться к методу как к атрибуту без скобок; скрывает реализацию за простым интерфейсом
12. Что такое `@staticmethod` ? >> Декоратор для метода, не получающего ни `self` , ни `cls` ; ведёт себя как обычная функция внутри пространства имён класса
13. Что такое `@classmethod` ? >> Декоратор, превращающий метод в метод класса; первым аргументом получает `cls` – ссылку на сам класс, а не на экземпляр
14. Может ли `@staticmethod` изменять атрибуты экземпляра или класса? >> Нет; не получает ни `self` , ни `cls`
15. Какое преимущество даёт `@staticmethod` перед функцией вне класса? >> Логическую группировку: функция находится внутри пространства имён класса, куда относится по смыслу
16. Какова основная цель декораторов в Python? >> Изменение или расширение поведения функций и методов без изменения их исходного кода
17. Что произойдёт при вызове `c.area()` со скобками если `area` – `@property` ? >> `c.area` вернёт число; попытка вызвать число как функцию `()` выбросит `TypeError: 'float' object is not callable`
18. Какие обязательные аргументы получает `@staticmethod` ? >> Никаких; ни `self` , ни `cls`
19. Какой идентификатор используется для первого аргумента `@classmethod` ? >> `cls`
20. Когда использовать `@staticmethod` ? >> Когда нужна вспомогательная функция, логически связанная с классом, но не использующая состояние ни объекта, ни класса
21. Что означает `_` перед именем атрибута? >> Соглашение: атрибут защищённый (внутренний); технического ограничения доступа нет
