1. Какая переменная захватывается замыканием в функции `multiplier`: `def make_multiplier(n):; def multiplier(x):; return x * n; return multiplier` ? >> Аргумент `n` из внешней функции `make_multiplier`
2. Что выведет следующий код с замыканием: `def make_multiplier(n):; def multiplier(x):; return x * n; return multiplier; f = make_multiplier(2); print(f(10))` ? >> `20`
3. Почему возникает ловушка замыкания в цикле `[lambda: i for i in range(3)]` и как она работает? >> Захватить текущее значение через аргумент по умолчанию: `lambda i=i: i`
4. Что вернёт следующее выражение со значением аргумента по умолчанию в lambda: `[f() for f in [lambda i=i: i for i in range(3)]]` ? >> `[0, 1, 2]`
5. Чему равно значение `i` при вызове лямбд из списка `[lambda: i for i in range(3)]` ? >> `2` – последнее значение после завершения цикла
6. Что выведет следующий код с замыканием: `def make_multiplier(n):; def multiplier(x):; return x * n; return multiplier; times3 = make_multiplier(3); print(times3(5))` ? >> `15`
7. Почему все функции в `[lambda: i for i in range(3)]` возвращают `2` ? >> Все захватывают одну и ту же переменную `i` ; к моменту вызова цикл завершён и `i == 2`
8. Почему конструкция `lambda i=i: i` решает проблему позднего связывания в цикле? >> Значение аргумента по умолчанию вычисляется и фиксируется в момент создания функции, а не в момент вызова
9. Что возвращает функция `make_multiplier(n)` и как работает замыкание: `def make_multiplier(n):; def multiplier(x):; return x * n; return multiplier` ? >> Вложенную функцию `multiplier` с захваченным `n`
10. Что вернёт генератор списка функций при их немедленном вызове: `funcs = [lambda: i for i in range(3)]; print([f() for f in funcs])` ? >> `[2, 2, 2]`
11. Как `nonlocal` связан с замыканиями? >> `nonlocal` позволяет вложенной функции не только читать, но и изменять переменную из охватывающей области; без него присваивание создаст новую локальную переменную
12. На каком механизме работают декораторы в Python? >> На замыканиях
13. Как диагностировать захваченные переменные замыкания? >> Через атрибут `__closure__` : `f.__closure__` возвращает кортеж `cell` -объектов с захваченными значениями
14. Что такое замыкание ( `closure` ) в Python? >> Функция, которая запоминает переменные из охватывающей области видимости и сохраняет доступ к ним после завершения внешней функции
15. Что происходит с переменной внешней функции после её завершения, если на неё ссылается замыкание? >> Переменная сохраняется в памяти – сборщик мусора не удаляет её, пока существует замыкание
16. Что такое фабричная функция? >> Функция, создающая и возвращающая другие функции, настраивая их поведение через замыкания
17. Что именно хранит замыкание: значение переменной или ссылку? >> Ссылку на переменную; это и является причиной ловушки в циклах
18. Какую область видимости запоминает замыкание? >> Охватывающую ( `Enclosing` ) – уровень E в LEGB
19. Как называется удержание переменных внешней области видимости в памяти? >> Захват переменных ( `capture` )
