1. Сколько уровней вложенности функций требуется для создания декоратора, принимающего аргументы? Как они устроены? >> Три: внешняя функция принимает аргументы декоратора, средняя – `func` , внутренняя – `wrapper`
2. В каком порядке применяются и выполняются стекированные декораторы: `@decorator_one; @decorator_two; def func():; pass` ? >> Снизу вверх: ближайший к функции – первый; `@A \n @B \n def f` эквивалентно `f = A(B(f))`
3. Что выведет вызов `greet()` , если к функции применён параметризованный декоратор `@repeat(3)`: `@repeat(3); def greet():; print('Hello'); greet()` ? >> Вызывает `greet` три раза подряд
4. Как устроен декоратор для замера времени выполнения функции ( `@timer` ): `import time; from functools import wraps; def timer(func):; @wraps(func); def wrapper(*args, **kwargs):; start = time.perf_counter(); result = func(*args, **kwargs); elapsed = time.perf_counter() - start; print(f'{func.__name__} took {elapsed:.4f}s'); return result; return wrapper` ? >> `start = time.time()` вызывается перед вызовом оригинальной функции
5. Можно ли применять несколько декораторов к одной функции? Как они взаимодействуют? >> Да; декораторы стекируются и применяются снизу вверх: `@A` над `@B` – сначала применяется `B` , затем `A`
6. Как функция `wrapper` в параметризованном декораторе `@repeat(n)` обращается к значению `n` ? >> Через замыкание: `n` захватывается из области видимости внешней функции
7. Как передать параметры в декоратор (например, `@my_decorator(timeout=10)` )? >> `@my_dec(10)`
8. Что произойдёт с атрибутом `__name__` декорированной функции, если забыть `@functools.wraps` ? >> Примет значение `'wrapper'` вместо имени оригинальной функции
9. Влияет ли применение декоратора на синтаксис вызова декорированной функции со стороны вызывающего кода? >> Нет; функция вызывается так же как без декоратора
10. Что принимает средняя (вторая по вложенности) функция в параметризованном декораторе? >> Оригинальную функцию `func`
11. Что принимает внешняя функция в `repeat(n)` ? >> Аргумент декоратора – количество повторений `n`
12. Назовите примеры использования декораторов >> Логирование, замер времени, кэширование, проверка прав доступа, retry-логика
13. Зачем внутри `wrapper` вызывается оригинальная функция? >> Чтобы выполнить её логику и получить результат
14. Что должен возвращать `wrapper` ? >> Результат вызова оригинальной функции
15. Какую задачу решает `@wraps(func)` ? >> Сохраняет метаданные оригинальной функции: `__name__` , `__doc__` и другие атрибуты
16. Что такое декоратор в Python? >> Функция, принимающая другую функцию, дополняющая её логикой и возвращающая новую функцию
17. Что принимает `wrapper` чтобы работать с любой функцией? >> `*args` и `**kwargs`
18. Для чего используются декораторы? >> Для добавления поведения функции без изменения её исходного кода
19. Может ли декоратор изменить возвращаемое значение? >> Да; `wrapper` полностью контролирует что возвращается вызывающему коду
20. Когда нужны три уровня вложенности? >> Когда декоратор принимает собственные аргументы: `@repeat(3)`
21. Какой символ указывает на применение декоратора? >> `@`
22. Из какого модуля импортируется `@wraps` ? >> `functools`
23. Что произойдёт если `wrapper` не возвращает `result` ? >> Функция всегда будет возвращать `None`
24. Является ли `@wraps` обязательным? >> Нет, но это стандартная практика; без него теряются метаданные функции
25. Чему эквивалентен `@decorator` над `func` ? >> `func = decorator(func)`
