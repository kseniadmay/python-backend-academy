1. Что произойдёт, если объявить `global x` внутри функции, когда переменная `x` ещё не существовала в глобальной области? >> Python создаст переменную `x` в глобальной области при первом присваивании
2. При `def outer():; x = 10; def inner():`: Какое значение выведет `print(x)` после выполнения `inner()` ? >> `11`
3. При `def outer():; x = 10; def inner():`: Для чего используется `nonlocal x` во вложенной функции `inner` ? >> Чтобы получить доступ на изменение переменной `x` , объявленной в охватывающей функции `outer`
4. Что такое `global` в Python? >> Инструкция, заставляющая функцию работать с переменной из глобального пространства имён вместо создания локальной
5. На какую область видимости указывает `nonlocal` ? >> На ближайшую охватывающую область видимости (Enclosing в LEGB)
6. Где применяется ключевое слово `nonlocal` ? >> Во вложенных функциях для изменения переменных из охватывающей (но не глобальной) области видимости
7. Как `global` влияет на создание локальных переменных? >> Предотвращает создание локальной переменной, перенаправляя обращение к существующей глобальной
8. Что такое `nonlocal` в Python? >> Инструкция для изменения переменных в ближайшей охватывающей области видимости вложенной функции
9. Допускает ли `nonlocal` обращение к переменным из глобальной области видимости? >> Нет, для этого используется `global`
10. Верно ли, что `nonlocal` ищет переменную в самой дальней охватывающей области? >> Нет, поиск происходит в ближайшей охватывающей области
11. По какому порядку Python ищет переменную при обращении к ней? >> LEGB: Local -> Enclosing -> Global -> Built-in
12. Какую инструкцию необходимо использовать внутри функции, чтобы переменная ссылалась на глобальную область видимости? >> `global`
