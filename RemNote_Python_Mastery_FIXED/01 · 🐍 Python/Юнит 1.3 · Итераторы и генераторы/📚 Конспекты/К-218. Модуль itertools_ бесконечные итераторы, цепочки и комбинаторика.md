## Зачем нужен itertools

Модуль **`itertools`** — это стандартная библиотека быстрых (реализованных на C) строительных блоков для работы с итераторами. Главное преимущество всех функций `itertools` — **ленивость** и память **$O(1)$**: они вычисляют элементы по одному на лету, не создавая гигантских промежуточных списков в оперативной памяти.

## Бесконечные итераторы: count, cycle, repeat

Эти итераторы никогда не заканчиваются сами по себе, поэтому при переборе их всегда ограничивают через `islice`, `zip` или `break`:

```python
from itertools import count, cycle, repeat, islice

# count(start=0, step=1) — бесконечный арифметический счётчик
ids = count(start=100, step=5)
print(list(islice(ids, 4)))  # [100, 105, 110, 115]

# cycle(iterable) — бесконечно крутит последовательность по кругу (например, round-robin воркеров)
workers = cycle(["worker-1", "worker-2", "worker-3"])
tasks = ["t1", "t2", "t3", "t4"]
print(list(zip(tasks, workers)))
# [('t1', 'worker-1'), ('t2', 'worker-2'), ('t3', 'worker-3'), ('t4', 'worker-1')]

# repeat(elem, times=None) — повторяет один и тот же объект (выгодно по памяти)
print(list(repeat("ping", 3)))  # ['ping', 'ping', 'ping']
```

## Объединение и фильтрация потоков: chain, islice, takewhile, dropwhile

**`chain(*iterables)`** и **`chain.from_iterable(iterable)`** последовательно склеивают несколько итерируемых объектов в один плоский поток **без копирования** данных в новый список (в отличие от `list1 + list2`):

```python
from itertools import chain, islice, takewhile, dropwhile

# Выравнивание (flatten) двумерного списка за O(1) дополнительной памяти
matrix = [[1, 2], [3, 4], [5, 6]]
flat = list(chain.from_iterable(matrix))  # [1, 2, 3, 4, 5, 6]

# islice(iterable, start, stop[, step]) — срез по любому генератору/итератору
# (обычный срез gen[10:20] на генераторе вызовет TypeError!)
gen = (x * x for x in range(1000))
print(list(islice(gen, 2, 6)))  # [4, 9, 16, 25]

# takewhile берёт элементы, пока условие истинно (до первого False!)
# dropwhile пропускает элементы, пока условие истинно, а затем отдаёт ВСЁ оставшееся
nums = [1, 3, 5, 2, 4, 7]
print(list(takewhile(lambda x: x < 5, nums)))  # [1, 3]
print(list(dropwhile(lambda x: x < 5, nums)))  # [5, 2, 4, 7]
```

## Группировка и нарезка батчами: groupby и batched

**`groupby(iterable, key=None)`** группирует элементы по значению ключа, но имеет **главную ловушку собеседований**: он объединяет **только соседние (подряд идущие)** элементы с одинаковым ключом — точно как утилита `uniq` в Linux! Поэтому перед вызовом `groupby` данные **обязательно нужно отсортировать** по тому же ключу `key`:

```python
from itertools import groupby

orders = [
    {"status": "paid", "id": 1},
    {"status": "new", "id": 2},
    {"status": "paid", "id": 3},
]

# 1. Сортируем по тому же ключу! Без этого 'paid' распадётся на две разные группы
orders_sorted = sorted(orders, key=lambda x: x["status"])

# 2. Группируем (вложенный итератор group нужно материализовать сразу на шаге цикла)
grouped = {
    status: list(group)
    for status, group in groupby(orders_sorted, key=lambda x: x["status"])
}
```

Вторая тонкость `groupby`: возвращаемые подитераторы `group` разделяют общий базовый итератор. Если перейти к следующей итерации внешнего цикла, не сохранив предыдущий `group` в `list(group)`, данные прошлой группы будут потеряны.

Начиная с Python 3.12, в стандартной библиотеке появилась функция **`itertools.batched(iterable, n)`**, которая разбивает поток данных на кортежи длиной до `n` элементов — идеально для пакетной вставки (`bulk_insert`) в базу данных или отправки запросов чанками. В более ранних версиях Python батчинг реализуют через цикл с `islice(it, n)`.

## Комбинаторика: product, permutations, combinations

Комбинаторные функции заменяют вложенные циклы и рекурсивный перебор вариантов:

```python
from itertools import product, permutations, combinations, combinations_with_replacement

# product — декартово произведение (эквивалент вложенных циклов for x in A: for y in B)
print(list(product([1, 2], ["a", "b"])))
# [(1, 'a'), (1, 'b'), (2, 'a'), (2, 'b')]

# permutations(iterable, r=None) — перестановки: порядок ВАЖЕН, (1, 2) и (2, 1) — разные
print(list(permutations("AB", 2)))  # [('A', 'B'), ('B', 'A')]

# combinations(iterable, r) — сочетания без повторений: порядок НЕ важен, только ('A', 'B')
print(list(combinations("ABC", 2)))  # [('A', 'B'), ('A', 'C'), ('B', 'C')]

# combinations_with_replacement — сочетания с повторениями элементов
print(list(combinations_with_replacement("AB", 2)))  # [('A', 'A'), ('A', 'B'), ('B', 'B')]
```

## Накопление и разветвление: accumulate и tee

**`accumulate(iterable, func=operator.add)`** возвращает итератор накопленных (префиксных) сумм или результатов любой бинарной функции (например, бегущего максимума `accumulate(nums, max)`).

**`tee(iterable, n=2)`** создаёт `n` независимых итераторов из одного исходного. Но важно помнить о расходе памяти: если один из клонов `tee` ушёл далеко вперёд, а второй стоит на месте, все промежуточные элементы буферизуются в памяти. Поэтому `tee` эффективен только тогда, когда все ветки потребляются примерно синхронно.
