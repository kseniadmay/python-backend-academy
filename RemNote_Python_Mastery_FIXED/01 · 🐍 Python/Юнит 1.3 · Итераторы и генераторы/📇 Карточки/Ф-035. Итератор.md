1. Что вернёт второй вызов `next(it)` для `it = iter([1, 2, 3])` ? >> `2`
2. В чём разница между протоколом Iterable и протоколом Iterator на уровне магических методов? >> `iterable` реализует только `__iter__()` ; итератор реализует оба метода: `__iter__()` и `__next__()`
3. Что возвращает вызов `iter(my_list)` для обычного списка? >> Объект-итератор типа `list_iterator`
4. Что такое итератор (Iterator) в Python и какие методы он обязан реализовывать? >> Объект, реализующий протокол итерации через `__iter__()` и `__next__()`
5. Является ли итератор исчерпаемым объектом? Можно ли запустить итерацию по нему повторно? >> Да; после прохода по всем элементам итератор нельзя перемотать назад; `iterable` можно итерировать заново
6. Что происходит в `__next__()` когда элементы закончились? >> Выбрасывается `StopIteration`
7. Что вернёт третий `next(it)` для `iter([1, 2, 3, 4])` ? >> `3`
8. Какие два метода обязан реализовать итератор? >> `__iter__()` и `__next__()`
9. Какая функция получает следующее значение из итератора? >> `next()`
10. Что вернёт первый `next(it)` для `iter([1, 2, 3])` ? >> `1`
11. Как называется объект с `__iter__()` , но без `__next__()` ? >> Итерируемый объект ( `iterable` )
12. Какова функция `__next__()` ? >> Возвращает следующий элемент последовательности; при исчерпании выбрасывает `StopIteration`
13. В чём ключевое практическое отличие итератора от списка? >> Итератор ленивый: генерирует элементы по одному по запросу, не хранит все в памяти; список хранит все элементы сразу
14. Где инициализируются начальные значения состояния в собственном итераторе? >> В методе `__init__`
15. Что вернёт четвёртый `next(it)` для `iter([1, 2, 3])` ? >> Выбросит `StopIteration`
16. Что возвращает `__iter__()` у итератора? >> Сам объект ( `self` )
17. Как превратить итерируемый объект в итератор? >> `iter(obj)`
18. К какой категории относится стандартный список? >> Итерируемый объект ( `iterable` ); при вызове `iter(list)` создаётся отдельный итератор
