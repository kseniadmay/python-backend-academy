1. Какова главная задача контекстного менеджера ( `with` ) и что подразумевается под управлением ресурсами? >> Управление ресурсами: гарантированное получение и освобождение независимо от исключений
2. Что должен вернуть метод `__enter__` контекстного менеджера, чтобы значение было доступно в блоке `as target` ? >> Ссылку на нужный объект; часто `self` , но может быть и другой объект
3. Что должен вернуть метод `__exit__` контекстного менеджера, чтобы подавить возникшее внутри блока `with` исключение? >> `True` ; если вернуть `False` или `None` – исключение распространяется дальше
4. Как устроен контекстный менеджер на основе генератора с декоратором `@contextlib.contextmanager` ? >> После завершения блока `with` ; аналог `__exit__`
5. Самый частый пример контекстного менеджера? >> Работа с файлами через `open()`
6. Какие три аргумента получает `__exit__` при исключении? >> `exc_type` , `exc_val` , `exc_tb` – тип, значение и traceback исключения; при нормальном выходе все три равны `None`
7. Как получить доступ к объекту возвращаемому `__enter__` ? >> Через ключевое слово `as` : `with open('file') as f`
8. Какой декоратор упрощает создание контекстных менеджеров? >> `@contextmanager` из модуля `contextlib`
9. Из какого модуля импортируется `@contextmanager` ? >> `contextlib`
10. Что происходит с файлом после завершения `with open()` ? >> Закрывается автоматически; `__exit__` вызывает `file.close()`
11. В какой момент вызывается `__enter__` ? >> При входе в блок `with`
12. Что получает `__exit__` если блок завершился без ошибки? >> `None, None, None`
13. Как ведёт себя контекстный менеджер при исключении внутри `with` ? >> Всё равно гарантирует освобождение ресурса через `__exit__`
14. Какое преимущество даёт `@contextmanager` перед классом? >> Более лаконичный способ без реализации `__enter__` и `__exit__` вручную
15. Через какие два метода реализуется протокол контекстного менеджера? >> `__enter__` и `__exit__`
16. Что происходит в месте `yield` внутри `@contextmanager` -функции? >> Выполняется тело блока `with` ; значение после `yield` передаётся через `as`
17. Какая часть кода отвечает за вход при `@contextmanager` ? >> Весь код до `yield`
18. В какой момент вызывается `__exit__` ? >> При выходе из блока `with` ; всегда, даже при исключении
