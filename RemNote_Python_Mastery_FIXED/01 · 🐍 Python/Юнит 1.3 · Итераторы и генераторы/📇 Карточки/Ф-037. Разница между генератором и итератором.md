1. Что делает конструкция `yield from iterable` в генераторах? >> Делегирование итерации вложенному итерируемому объекту; `yield from iterable` эквивалентно `for x in iterable: yield x` , но эффективнее
2. Два основных вида генераторов в Python? >> Генераторная функция ( `yield` ) и генераторное выражение ( `(x for x in ...)` )
3. Какие скобки используются для генераторного выражения? >> Круглые `()`
4. Если в генераторной функции три `yield` , сколько раз можно вызвать `next()` ? >> Три раза; четвёртый вызов выбросит `StopIteration`
5. В чём преимущество генератора перед ручной реализацией итератора? >> Меньше кода, автоматическое управление состоянием, встроенная обработка `StopIteration`
6. Что произойдёт при вызове `next()` на исчерпанном генераторе? >> `StopIteration`
7. В чём концепция ленивых вычислений в генераторах? >> Значения вычисляются по одному по запросу и не хранятся в памяти
8. Является ли генератор итератором? >> Да; генератор реализует оба метода `__iter__()` и `__next__()` автоматически
9. Что отличает генераторную функцию от обычной? >> Наличие ключевого слова `yield`
10. Какую задачу упрощает генератор? >> Создание итератора без ручной реализации `__iter__` и `__next__`
11. Что вернёт первый `next()` для генератора с `yield 1` , `yield 2` , `yield 3` ? >> `1` ; генератор останавливается на первом `yield` и возвращает его значение. `def gen():; yield 1; yield 2; yield 3; g = gen(); print(next(g)) # 1`
12. С чем схожи генераторные выражения по синтаксису? >> Со списковыми включениями; разница – круглые скобки вместо квадратных
13. Какое внутреннее состояние сохраняет генераторная функция между вызовами `next()` ? >> Локальные переменные, позицию выполнения и стек вызовов – генератор замораживается на `yield` и продолжает с того же места
14. Что возвращает вызов генераторной функции? >> Объект-генератор; тело функции при этом не выполняется
15. Почему `sum([x for x in range(10**7)])` менее эффективно чем `sum(x for x in range(10**7))` ? >> Список создаёт все элементы в памяти сразу; генератор вычисляет по одному
16. В каком случае генератор критически важен? >> При работе с большими объёмами данных, которые не помещаются в память целиком
17. Вычисляются ли все значения генераторного выражения сразу? >> Нет; значения вычисляются лениво по мере запроса
18. Когда начинает выполняться код генераторной функции? >> Только при первом вызове `next()`
19. Что хранится в `gen` после `gen = (x**2 for x in range(10))` ? >> Объект-генератор; вычисления не произведены
