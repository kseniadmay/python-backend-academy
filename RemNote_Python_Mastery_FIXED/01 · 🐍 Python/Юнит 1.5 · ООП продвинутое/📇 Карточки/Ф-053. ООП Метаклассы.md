1. Для чего Django ORM использует метаклассы в моделях ( `models.Model` )? >> Для реализации ORM-маппинга: автоматического преобразования атрибутов класса в поля таблицы базы данных
2. Что должен возвращать метод __new__ в метаклассе и как он вызывается? >> `super().__new__(mcs, name, bases, namespace)`
3. Что содержит параметр namespace в методе __new__ метакласса? >> Словарь с атрибутами и методами класса
4. Что представляет собой параметр name в сигнатуре __new__ метакласса? >> Строковое имя создаваемого класса
5. Что содержит параметр bases в __new__ метакласса? >> Кортеж родительских классов создаваемого класса
6. Каковы современные и более простые альтернативы метаклассам в Python для кастомизации создания классов? >> Декораторы классов
7. Что такое конфликт метаклассов ( `TypeError: metaclass conflict` ) и как он решается? >> Ошибка `TypeError: metaclass conflict` при наследовании от классов с разными метаклассами; решается созданием общего метакласса, наследующего оба
8. Когда выполняется код в `__new__` метакласса? >> В момент парсинга определения класса, не при создании экземпляра
9. Насколько часто метаклассы применяются на практике? >> Редко; большинство задач решается декораторами классов или `__init_subclass__`
10. Что вернёт `type(MyClass)` без явного метакласса? >> `<class 'type'>`
11. Верно ли что классы в Python сами являются объектами? >> Да; класс – объект типа `type` ; поэтому к классам применимы те же операции что и к обычным объектам
12. Какой класс является базовым метаклассом? >> `type`
13. Каков результат `type(str)` ? >> `<class 'type'>`
14. От какого класса наследуется собственный метакласс? >> `type`
15. Каким синтаксисом указывается метакласс? >> `class MyClass(metaclass=Meta):`
16. Что такое метакласс в Python? >> Класс, определяющий правила создания других классов; класс классов
17. К какому типу относятся все стандартные классы ( `int` , `str` )? >> `type`
18. Что такое `__init_subclass__` ? >> Метод класса, вызываемый автоматически при создании подкласса; более простая альтернатива метаклассам для большинства задач
19. Какой встроенный механизм является более простой альтернативой метаклассам? >> `__init_subclass__`
20. В какой момент метакласс модифицирует класс? >> В момент определения класса (при парсинге), не при создании экземпляра
21. Что такое `mcs` в `__new__(mcs, name, bases, namespace)` ? >> Ссылка на сам метакласс; аналог `cls` в обычном классе
22. Какой магический метод чаще всего переопределяется в метаклассе? >> `__new__`
23. Какая функция позволяет проверить метакласс объекта? >> `type()`
