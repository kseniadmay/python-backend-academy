1. Какой метод вызовется при `D().hello()` , если метод `hello` определён и в `B` , и в `C`: `class A:; def hello(self): return 'A'; class B(A):; def hello(self): return 'B'; class C(A):; def hello(self): return 'C'; class D(B, C):; pass` ? >> Метод из `B` – он первый в MRO после `D`
2. В чём разница между вызовом метода `ClassName.mro()` и обращением к атрибуту `ClassName.__mro__` ? >> Для отладки и предсказания пути поиска методов при множественном наследовании
3. Через какой атрибут класса можно получить цепочку MRO (Method Resolution Order)? >> `ClassName.__mro__`
4. Что произойдёт, если построить противоречивую иерархию классов (невозможный MRO)? >> Python выбросит `TypeError: Cannot create a consistent method resolution order (MRO)` ; например при `class D(A, B)` и `class E(B, A)` одновременно
5. Как работает поиск метода в MRO (C3-линеаризация), если метод есть в C и A, но отсутствует в D и B? >> Из `C` – следующий в MRO после `B`
6. Какой класс всегда последний в цепочке MRO? >> `object`
7. Почему `super()` в `B(A)` не вызывает `A` сразу при множественном наследовании? >> Между `B` и `A` в MRO могут стоять другие классы; `super()` следует по MRO, а не по прямой иерархии
8. Что определяет порядок перечисления родителей в `D(B, C)` ? >> Приоритет поиска методов: левый родитель имеет приоритет над правым
9. На что ссылается `super()` ? >> На следующий класс в цепочке MRO, а не на прямого родителя
10. Как называется процесс выстраивания классов в последовательную цепочку? >> Линеаризация
11. Какой класс стоит первым в MRO? >> Сам класс
12. В какой ситуации знание MRO особенно важно? >> При множественном наследовании и использовании `super()`
13. Что сохранится в `result = super().hello()` в `B` при MRO `D → B → C → A` ? >> Результат `hello()` из `C`
14. Через какой метод вывести MRO? >> `ClassName.mro()`
15. Какую структуру возвращает `__mro__` ? >> `tuple` классов в порядке поиска
16. Какой алгоритм используется в Python для построения цепочки MRO (Method Resolution Order)? Каковы его свойства? >> C3-линеаризация
17. Верно ли что `super()` ищет в классе указанном после `class` ? >> Нет; `super()` следует строго по MRO
18. К какому классу обратится `super()` в `B` если MRO: `D → B → C → A` ? >> К `C`
19. Что означает MRO? >> Method Resolution Order – порядок разрешения методов при поиске атрибутов в иерархии классов
20. Порядок MRO для `D(B, C)` где `B(A)` и `C(A)` ? >> `D → B → C → A → object`
21. Что такое кооперативное наследование? >> Паттерн при котором каждый класс в цепочке вызывает `super()` , обеспечивая корректный проход по всему MRO
