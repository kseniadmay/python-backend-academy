1. Перечислите основные встроенные типы-последовательности (Sequence) в Python. Является ли `int` последовательностью? >> `str` , `list` , `tuple` , `range` , `bytes` , `bytearray`
2. Как называется операция получения подмножества элементов по диапазону индексов? >> Срез ( `slicing` ); синтаксис `[start:stop:step]`
3. Какая характеристика позволяет называть структуру данных последовательностью? >> Упорядоченность, поддержка индексации по целому числу и протокол `__len__` + `__getitem__`
4. Что такое последовательность в Python? >> Упорядоченная коллекция объектов с доступом по целочисленному индексу, поддерживающая `len()` , срезы и итерацию
5. Какой оператор выполняет конкатенацию последовательностей? >> `+` ; работает только между объектами одного типа: `[1] + [2]` – корректно, `[1] + (2,)` – выбросит `TypeError`
6. Какая операция позволяет последовательно перебирать все элементы коллекции? >> Итерация (цикл `for ... in ...`); любая последовательность реализует протокол итерации через метод `__iter__` (или `__getitem__`), что позволяет обходить её элементы в цикле `for` или генераторах
7. Какую функцию использовать для определения количества элементов последовательности? >> `len()`
8. Какой оператор проверяет наличие элемента в последовательности? >> `in` ; возвращает `True` или `False`
9. Являются ли `bytes` и `bytearray` последовательностями? >> Да; `bytes` – неизменяемая последовательность байт, `bytearray` – изменяемая
10. К какому типу коллекций относится `range` ? >> К последовательностям; при этом `range` – ленивый объект, не хранящий все элементы в памяти
