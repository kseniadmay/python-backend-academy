1. Почему использование классов и внедрения зависимостей (Dependency Injection) предпочтительнее глобальных переменных? >> Инкапсулируют состояние; делают зависимости явными через конструктор
2. Почему GIL не защищает от состояний гонки (Race Conditions) при изменении глобальных переменных в разных потоках? >> GIL защищает от одновременного выполнения байткода, но не делает составные операции ( `+=` , `append` ) атомарными
3. К чему приводит использование глобальных переменных в плане зависимостей? >> Создают неявные скрытые зависимости; зависимость не видна в сигнатуре функции
4. Как называется паттерн передачи зависимостей через аргументы вместо глобального состояния? >> Dependency injection; зависимости передаются явно, что упрощает тестирование и замену компонентов
5. Главная причина осторожного использования глобальных переменных? >> Создают скрытые связи, затрудняющие отладку, тестирование и понимание кода
6. Где объявляется глобальная переменная? >> На уровне модуля; вне всех функций и классов
7. Как глобальные переменные влияют на тестирование? >> Усложняют изоляцию функции; требуют сброса глобального состояния между тестами
8. Почему глобальные переменные затрудняют понимание кода? >> Внешнее состояние функции не отображается в её сигнатуре; нужно читать всё тело
9. Что нужно сделать чтобы изменить глобальную переменную внутри функции? >> Явно объявить через `global`
10. Как передавать данные вместо глобальных переменных? >> Через аргументы функции
11. Что использовать для хранения состояния вместо глобальных переменных? >> Классы; инкапсулируют состояние и ограничивают область его видимости
12. Каким функциям доступна глобальная переменная? >> Любой функции данного модуля для чтения; для изменения нужен `global`
13. Какая проблема возникает с глобальными переменными в многопоточной среде? >> Конкурентный доступ нескольких потоков вызывает race condition; требуется синхронизация через `Lock`
14. Когда переменные на уровне модуля считаются приемлемыми? >> Как неизменяемые константы или конфигурация: `MAX_RETRIES = 3` , `DB_URL = '...'`
15. Какое правило именования применяется к константам? >> `UPPER_CASE` : `MAX_RETRIES` , `DB_URL`
16. Почему `state = []` на уровне модуля – плохая практика? >> Создаёт изменяемое глобальное состояние; любая функция может неожиданно изменить его
