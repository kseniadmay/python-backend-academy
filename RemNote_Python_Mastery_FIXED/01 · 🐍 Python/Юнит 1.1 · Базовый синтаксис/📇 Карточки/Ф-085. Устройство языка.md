1. Что такое байткод в CPython и почему виртуальную машину Python называют стековой? >> Байткод – промежуточное представление кода, в которое компилируется исходный текст ( `.py` ) перед исполнением. Машину называют стековой (а не регистровой), потому что её инструкции работают со стеком
2. Какая система типизации используется в языке Python? Что означают понятия 'динамическая' и 'строгая'? >> Динамическая строгая типизация: типы переменных определяются в `runtime` , но неявное приведение типов не производится
3. Какая реализация Python считается эталонной (референсной) и в какой момент создаются файлы `.pyc` в `__pycache__`? >> Эталонной реализацией является `CPython` (написана на C); файлы `.pyc` с байткодом создаются в `__pycache__` при импорте модуля, если кэш отсутствует или исходный `.py`-файл изменился
4. Какую последовательность преобразований проходит код Python перед выполнением в CPython? >> Исходный код проходит лексический анализ и парсинг, превращаясь в AST (Abstract Syntax Tree); затем компилируется в байткод, который исполняется виртуальной машиной CPython
5. Что содержат файлы с расширением `.pyc` ? >> Скомпилированный байткод вместе с метаданными: магическим числом версии Python и меткой для проверки актуальности кэша
6. В какие файлы и директории Python компилирует исходный код? >> В файлы `.pyc` , которые хранятся в директории `__pycache__` (начиная с Python 3.2)
7. Как определяется Python с точки зрения назначения? >> Язык общего назначения
8. Компилируется ли код Python напрямую в машинный код перед выполнением? >> Нет, он компилируется в байткод
9. К какому уровню языков программирования относится Python? >> Очень высокоуровневый: Python абстрагирует управление памятью, типами и многим другим
10. Что такое `CPython` и из каких основных компонентов он состоит? >> Эталонная реализация Python, написанная на языке C; состоит из компилятора в байткод и виртуальной машины, которая этот байткод исполняет
11. Что именно исполняет виртуальная машина CPython? >> Байткод
12. Почему с точки зрения разработчика Python считается интерпретируемым языком? >> Технически Python компилирует исходный код в байткод автоматически при запуске, без явного шага компиляции для разработчика; поэтому исторически его называют интерпретируемым – но точнее: компилируемо-интерпретируемым; байткод затем исполняется виртуальной машиной CPython
