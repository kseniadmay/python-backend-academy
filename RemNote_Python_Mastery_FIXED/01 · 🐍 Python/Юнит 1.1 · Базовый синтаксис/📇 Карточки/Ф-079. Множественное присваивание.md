1. Как присвоить значение `0` сразу трём переменным в одну строку? >> `a = b = c = 0`
2. Чему будут равны все три переменные после `a = b = c = 0`? >> `0`
3. Чем опасна цепочка присваивания с изменяемым объектом `a = b = c = []`? >> Все три переменные указывают на один и тот же объект списка в памяти; изменение через `a.append(1)` изменит и `b`, и `c`
4. Каким синтаксисом в Python можно обменять значения переменных `x` и `y` без временной переменной? >> `x, y = y, x`
5. Для чего в Python используется конструкция `x, y = y, x`? >> Для обмена значениями между двумя переменными без временной переменной
6. Как называется механизм присваивания `x, y = 1, 2` и как он работает? >> Распаковка кортежа (tuple unpacking)
7. Какое значение получит `x` при выполнении `x, y = 1, 2`? >> `1`
8. Какое значение получит `y` при выполнении `x, y = 1, 2`? >> `2`
9. Что произойдёт при `x, y = 1, 2`? >> Множественное присваивание по позициям: `x` получит `1`, `y` получит `2`, за один проход.
10. Какой символ используется для разделения имён переменных и значений при распаковке? >> Запятая `,`
11. Какими способами можно присвоить значения нескольким переменным одновременно? >> Цепочка присваивания `a = b = c = 0` или позиционная распаковка `x, y = 1, 2`
