1. Где на практике применяется `frozenset` ? >> Как ключ словаря, элемент множества, константная коллекция уникальных значений, защищённая от случайного изменения
2. Можно ли добавить `frozenset` как элемент обычного `set` ? Почему обычный `set` добавить нельзя? >> Да, благодаря хешируемости; обычный `set` внутри `set` добавить нельзя
3. При `d = {frozenset([1, 2]): 'value'}`: Корректно ли это выражение? >> Да, `frozenset` – валидный ключ словаря
4. Можно ли использовать `frozenset` как ключ словаря? >> Да, благодаря хешируемости
5. Что такое `frozenset` в Python? >> Неизменяемое ( `immutable` ) множество: содержит уникальные элементы, но не допускает изменений после создания
6. Каково главное отличие `frozenset` от `set` после инициализации? >> В `frozenset` нельзя добавлять или удалять элементы
7. Каким важным свойством обладает `frozenset` ? >> Хешируемостью ( `hashable` ): реализует `__hash__()` , что делает его пригодным для использования как ключ словаря или элемент `set`
8. Можно ли удалять элементы из `frozenset` после создания? >> Нет, любые операции изменения состава запрещены
9. Почему `set` нельзя использовать как ключ словаря, а `frozenset` можно? >> `set` изменяемый и не реализует `__hash__()` ; `frozenset` неизменяемый и хешируемый
10. К чему приведёт попытка вызвать `.add()` у `frozenset` ? >> `AttributeError: 'frozenset' object has no attribute 'add'` – метод просто отсутствует у типа
11. Как создать `frozenset` из списка `[1, 2, 3]` ? >> `frozenset([1, 2, 3])`
