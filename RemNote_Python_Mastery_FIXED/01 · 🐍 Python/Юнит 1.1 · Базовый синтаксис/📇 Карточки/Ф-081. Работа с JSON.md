1. Что делает параметр sort_keys=True в функции json.dumps() и зачем он нужен? >> Сортирует ключи словаря по алфавиту; полезно для детерминированного вывода и сравнения JSON
2. Что происходит с целочисленными ключами словаря при сериализации в JSON ( `json.dumps` )? >> Преобразуются в строки: `{1: 'a'}` → `{"1": "a"}` ; при десериализации обратно станут строками – ловушка потери типа
3. Что возвращает вызов `json.loads('{"key": 123}')` ? >> Словарь `{'key': 123}`
4. Какие типы вызывают `TypeError` при стандартной сериализации? >> `datetime` , `set` , кастомные классы
5. В чём разница между `dump` и `dumps` ? >> `dump` работает с файловым объектом; `dumps` возвращает строку
6. Метод для преобразования объекта Python в JSON-строку? >> `json.dumps()`
7. В какой формат преобразуется `True` при сериализации? >> `true` (нижний регистр)
8. Поддерживает ли JSON тип `datetime` ? >> Нет; выбросит `TypeError` ; нужен кастомный encoder или предварительное преобразование в строку
9. Что означает суффикс `s` в `dumps` и `loads` ? >> Работа со строками ( `string` )
10. Что нужно для сериализации неподдерживаемых типов? >> Кастомный `JSONEncoder` с переопределённым методом `default()`
11. Параметр для красивого форматирования в `dumps` ? >> `indent` ; например `json.dumps(data, indent=4)`
12. Можно ли напрямую сериализовать `set` в JSON? >> Нет; выбросит `TypeError`
13. Режим открытия файла для `json.dump()` ? >> `'w'`
14. Метод для чтения из JSON-файла? >> `json.load()`
15. В чём разница между `load` и `loads` ? >> `load` читает из файлового объекта; `loads` принимает строку
16. Какая структура Python соответствует объекту JSON `{}` ? >> Словарь ( `dict` )
17. В какой тип преобразуется `tuple` при сериализации? >> В список ( `list` ); при десериализации кортеж не восстанавливается
18. Требует ли JSON сторонних библиотек? >> Нет; входит в стандартную библиотеку Python
19. Режим открытия файла для `json.load()` ? >> `'r'`
20. Кодировка при открытии файла для JSON с кириллицей? >> `utf-8`
21. Является ли JSON языконезависимым форматом? >> Да; поддерживается практически всеми языками
22. На синтаксисе какого языка основан JSON? >> JavaScript
23. Что вернёт `json.dumps({'active': True})` ? >> `'{"active": true}'`
24. Является ли JSON человекочитаемым? >> Да
25. Какой параметр установить `False` чтобы кириллица отображалась корректно? >> `ensure_ascii=False`
26. Метод для десериализации JSON-строки в объект Python? >> `json.loads()`
27. Стандартная кодировка для обмена JSON? >> UTF-8
28. Как расшифровывается JSON? >> JavaScript Object Notation
29. Что вернёт `json.dumps((1, 2, 3))` ? >> `'[1, 2, 3]'`
30. Что возвращает `json.dump()` ? >> `None` ; данные записываются в файл
31. Что делает `ensure_ascii=False` ? >> Позволяет записывать символы как есть без `\uXXXX` escape-последовательностей
32. Для чего JSON стал стандартом? >> REST API, конфигурационные файлы, обмен данными между сервисами
33. Метод для записи в JSON-файл? >> `json.dump()`
34. В каком формате хранятся ключи в JSON? >> Всегда строки в двойных кавычках
