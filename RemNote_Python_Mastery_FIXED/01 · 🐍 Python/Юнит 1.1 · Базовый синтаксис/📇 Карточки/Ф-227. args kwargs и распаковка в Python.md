1. Что делает `*args` в сигнатуре функции? >> Собирает все лишние позиционные аргументы в кортеж (tuple).
2. Что делает `**kwargs` в сигнатуре функции? >> Собирает все лишние именованные аргументы в словарь (dict).
3. Какой порядок параметров правильный в сигнатуре функции с *args и **kwargs? >> def f(a, b, *args, c, **kwargs) — позиционные, затем *args, затем keyword-only, затем **kwargs.
4. Что делает `*` при вызове функции: `f(*my_list)`? >> Распаковывает список в отдельные позиционные аргументы вызова.
5. Что делает `**` при вызове функции: `f(**my_dict)`? >> Распаковывает словарь в отдельные именованные аргументы вызова.
6. Зачем нужны *args/**kwargs в декораторах? >> Чтобы декоратор мог прозрачно прокидывать любые аргументы в обёрнутую функцию, не зная её сигнатуру заранее.
7. Что означает `first, *middle, last = [1,2,3,4,5]`? >> first=1, middle=[2,3,4], last=5 — распаковка с сбором "остатка" через звёздочку.
8. Что произойдёт при `{**defaults, **overrides}`, если ключи совпадают? >> Значение из overrides (последнего распакованного словаря) перезапишет значение из defaults.
9. Можно ли поменять местами значения двух переменных без временной переменной? >> Да: a, b = b, a — работает через распаковку кортежа.
10. Обязательно ли называть параметры именно args и kwargs? >> Нет, это соглашение; важны символы * и **, а не имена.
11. Что произойдёт при вызове f(1, 2, x=3), если сигнатура def f(a, b, *, x)? >> x — keyword-only параметр (после *), обязан передаваться по имени; вызов сработает корректно, x=3.
12. Можно ли распаковать генератор через *? >> Да, любой итерируемый объект, не только список или кортеж.
13. Что произойдёт при f(*[1,2], *[3,4])? >> Оба списка распакуются в единый набор позиционных аргументов: f(1, 2, 3, 4).
14. Как объявить функцию, принимающую ТОЛЬКО именованные аргументы? >> def f(*, a, b): — звёздочка без имени запрещает позиционную передачу всего, что после неё.
15. Что означает / в сигнатуре def f(a, b, /, c)? >> a и b — позиционно-только параметры (нельзя передать по имени), начиная с Python 3.8.
16. В каком порядке Python заполняет *args при смешанном вызове f(1, 2, 3, key=4)? >> Сначала обычные позиционные по порядку определения, остаток уходит в *args, key вне сигнатуры — в **kwargs.
17. Что вернёт dict(**{'a':1}, **{'b':2})? >> {'a': 1, 'b': 2} — распаковка двух словарей в конструктор dict.
18. Эквивалентны ли *args при вызове и при определении функции? >> Нет, семантика противоположна: при определении — собирает, при вызове — распаковывает.
19. Что произойдёт при попытке передать два значения для одного параметра: f(1, a=1) для def f(a)? >> TypeError: got multiple values for argument 'a' — позиционное и именованное значение конфликтуют.
20. Может ли **kwargs содержать ключи, не являющиеся строками? >> Нет, ключи словаря kwargs всегда строки — это ограничение синтаксиса вызова функций.
21. Что произойдёт при def f(a, *args, b): f(1, 2, 3)? >> TypeError: f() missing 1 required keyword-only argument: 'b' — b обязан передаваться по имени, позиционные не заполнят его.
22. Как объединить два кортежа через распаковку в один? >> (*t1, *t2) — например (*[1,2], *[3,4]) даст (1,2,3,4).
23. Эквивалентны ли dict(a=1, b=2) и {'a':1, 'b':2}? >> Да, dict() с именованными аргументами создаёт тот же словарь.
