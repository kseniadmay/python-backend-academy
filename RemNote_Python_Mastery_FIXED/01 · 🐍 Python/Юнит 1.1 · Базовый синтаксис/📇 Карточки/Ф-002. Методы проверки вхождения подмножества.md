1. Даны `a = (1, 2, 3, 4, 5)` и `b = (2, 3)` . Как проверить, что все элементы `b` входят в `a` , через `all()` ? >> `all(x in a for x in b)`
2. В чём разница между методом `set.issubset()` и оператором `<=` ? >> Да, для объектов `set` они функционально идентичны; разница в том, что `.issubset()` принимает любой итерируемый объект, а `<=` требует `set` с обеих сторон
3. Что вернёт `set(b).issubset(set(a))` для `a = (1, 2, 3, 4, 5)` и `b = (2, 3)` ? >> `True`
4. Почему проверка `all(x in a for x in b)` работает точнее `set(b).issubset(set(a))` при наличии дубликатов? >> При работе с дублирующимися элементами: `set()` удаляет дубли, поэтому `set([2,2]).issubset(set([1,2,3]))` вернёт `True` , хотя `b` содержит два элемента `2` , а в `a` он один
5. Как работает встроенная функция `all()` ? Приведите пример проверки списка условий. >> `all()`
6. Какую операцию нужно выполнить с кортежем перед `.issubset()` ? >> Преобразовать в `set` через `set()`
7. Как проверить, является ли один кортеж подмножеством другого через методы множеств? >> `set(b).issubset(set(a))` – преобразовать оба в `set` и использовать `.issubset()`
8. `all(x in a for x in b)` – какой тип возвращает функция? >> `bool` ; в данном случае `True`
9. Что делает выражение `x in a for x in b` внутри `all()` ? >> Создаёт генератор, проверяющий наличие каждого элемента `x` из `b` в `a` ; `all()` вернёт `True` только если все проверки истинны
10. Почему `set()` может быть менее точным при работе с дублями? >> `set()` удаляет все повторяющиеся элементы, теряя информацию о количестве вхождений
11. Какой оператор эквивалентен `.issubset()` ? >> `<=` ; `set(b) <= set(a)`
12. `set([1, 2]) <= set([1, 2, 3])` – результат? >> `True`
