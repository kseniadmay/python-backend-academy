Какие основные принципы ООП поддерживает Python и чем декларативный стиль отличается от императивного? >> Python полностью поддерживает инкапсуляцию, наследование и полиморфизм; императивный стиль описывает **как** выполнить задачу (пошагово), а декларативный — **что** нужно получить (например, `sum(x for x in data if x > 0)`)
2. Какие встроенные инструменты Python относятся к функциональной парадигме программирования? >> `map` и `filter` – инструменты функционального стиля: функции высшего порядка, принимающие `callable` как аргумент
3. К какой парадигме программирования относится использование `list comprehensions` в Python? >> К функциональному стилю; запись выглядит декларативно, но реализована императивно
4. На чём делается акцент в императивном стиле программирования? >> На явном описании шагов и порядка выполнения задачи; императивный стиль описывает как, декларативный – что
5. Какие основные парадигмы и стили поддерживает Python, помимо императивного? >> ООП, функциональный стиль (функции высшего порядка, `map` , `filter` , `functools` ), процедурный стиль; отдельные конструкции имитируют декларативную запись, но реализованы императивно
6. Какая парадигма программирования является основной для языка Python? >> Python базируется на императивной модели выполнения, при этом поддерживает ООП и функциональный стиль
7. Что характеризует Python с точки зрения поддержки различных стилей написания кода? >> Мультипарадигменный язык программирования
