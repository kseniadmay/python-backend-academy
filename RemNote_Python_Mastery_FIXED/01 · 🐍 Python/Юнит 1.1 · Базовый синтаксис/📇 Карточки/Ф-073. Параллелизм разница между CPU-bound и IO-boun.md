1. Почему модуль `multiprocessing` эффективен для CPU-bound вычислений, а `threading` – нет? >> Каждый процесс имеет свой GIL; достигается настоящий параллелизм на нескольких ядрах
2. Преимущество `asyncio` для I/O-bound? >> Один поток эффективно управляет тысячами ожиданий без накладных расходов на создание потоков и процессов
3. Что такое CPU-bound задача? >> Задача ограниченная мощностью процессора; время тратится на вычисления, а не на ожидание
4. Какой высокоуровневый API упрощает работу с `multiprocessing` ? >> `ProcessPoolExecutor` из `concurrent.futures` ; аналог `ThreadPoolExecutor` для процессов
5. Что происходит с GIL во время I/O операций? >> Освобождается; другие потоки могут выполняться в это время
6. К какому типу относится машинное обучение? >> CPU-bound
7. Почему GIL не является проблемой для I/O-bound задач? >> Во время ожидания I/O Python освобождает GIL; другие потоки могут работать в это время
8. Что НЕ является I/O-bound: HTTP-запрос, SQL-запрос, инвертирование матрицы? >> Инвертирование матрицы – CPU-bound
9. Что такое настоящий параллелизм? >> Одновременное выполнение инструкций на разных ядрах процессора
10. Три примера CPU-bound задач? >> Математические операции, сортировка больших данных, обработка изображений
11. Что использовать для CPU-bound в Python? >> `multiprocessing`
12. На что тратится время в CPU-bound задачах? >> На интенсивные вычисления
13. Что такое I/O-bound задача? >> Задача ограниченная скоростью операций ввода-вывода; программа большую часть времени ожидает
14. Что делать если задача одновременно CPU-bound и I/O-bound? >> Разделить: CPU-bound часть отдать `multiprocessing` , I/O-bound – `asyncio` или `threading`
15. Основные источники задержек в I/O-bound? >> Сетевые запросы, чтение/запись файлов, запросы к базам данных
16. Что будет быстрее с `multiprocessing` : поиск простых чисел или скачивание файлов? >> Поиск простых чисел; скачивание файлов – I/O-bound, для него эффективнее `threading` / `asyncio`
17. Является ли обращение к БД CPU-bound? >> Нет; это I/O-bound
18. Что лучше для парсинга миллионов строк? >> `multiprocessing`
19. Что использовать для I/O-bound в Python? >> `threading` или `asyncio`
20. Почему `threading` не подходит для CPU-bound? >> GIL не даёт потокам выполняться параллельно на разных ядрах
