1. При `d = {'a': 1, 'b': 2, 'c': 3}`: Что вернёт `list(d.keys())` ? >> `['a', 'b', 'c']`
2. Как преобразовать объект `dict_keys` в список? >> `list(d.keys())`
3. Почему результат вызова `dict.keys()` , `dict.values()` и `dict.items()` называют представлением (view), а не списком? >> Он отражает изменения словаря в реальном времени: если словарь изменился, `view` покажет актуальные данные без повторного вызова
4. Гарантирован ли порядок ключей в `dict_keys` ? >> Да, начиная с Python 3.7 словари сохраняют порядок вставки
5. В каком виде возвращаются элементы внутри `dict_items` ? >> В виде кортежей `(ключ, значение)`
6. Что возвращает метод `.values()` ? >> Динамическое представление ( `dict_values` view) всех значений словаря
7. Что возвращает метод `.keys()` ? >> Динамическое представление ( `dict_keys` view) ключей словаря, а не их копию
8. Как выглядит прямой перебор ключей словаря `d` в цикле `for` ? >> `for key in d:` – итерация по словарю напрямую равнозначна итерации по `.keys()`
9. Как перебрать ключи и значения словаря одновременно? >> `for key, value in d.items():` – распаковка кортежей из `.items()`
10. Что возвращает метод `.items()` ? >> Динамическое представление ( `dict_items` view) пар ключ-значение в виде кортежей
