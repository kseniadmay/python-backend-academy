1. Является ли `tuple` изменяемым типом? >> Нет
2. Является ли `list` изменяемым типом? >> Да
3. Для каких коллекций чаще применяется `list` ? >> Для однородных изменяемых коллекций одного типа данных
4. Какая структура работает быстрее: `list` или `tuple` ? >> `tuple` ; особенно заметно при создании и итерации – CPython оптимизирует кортежи как статические структуры
5. Какая структура занимает меньше памяти: `list` или `tuple` ? >> `tuple` ; `list` хранит дополнительный буфер для будущих элементов, `tuple` – нет
6. В каком виде функциям рекомендуется возвращать несколько значений? >> В виде `tuple` ; Python делает это автоматически при `return a, b`
7. Можно ли использовать `list` в качестве ключа словаря? >> Нет; `list` – изменяемый и нехешируемый тип, попытка выбросит `TypeError`
8. О чём сигнализирует использование `tuple` другому разработчику? >> О том, что данные в этой коллекции не должны изменяться
9. Какой тип подходит для хранения координат объекта? >> `tuple` ; координаты – фиксированный набор данных, изменение которого нежелательно
10. Почему `tuple` считается более безопасным для передачи данных? >> Гарантирует защиту от случайного изменения данных
11. Можно ли удалить элемент из `tuple` после создания? >> Нет
12. Для каких наборов данных предпочтителен `tuple` ? >> Для фиксированных наборов, часто разнородных данных: координаты, возвращаемые значения функций
13. Какое принципиальное отличие между `list` и `tuple` ? >> `list` – изменяемый ( `mutable` ), `tuple` – неизменяемый ( `immutable` )
14. Основное применение `list` >> Изменяемые коллекции однородных данных
15. Можно ли добавить элементы в `tuple` после создания? >> Нет; любая операция над кортежем создаёт новый объект
16. Какое свойство `tuple` позволяет использовать его в качестве ключа словаря? >> Хешируемость; неизменяемые типы как правило хешируемы, но `tuple` содержащий `list` ключом быть не может
17. Основное применение `tuple` >> Фиксированные наборы разнородных данных; ключи словарей; возврат нескольких значений из функции
18. Можно ли заменить элемент `tuple` после создания? >> Нет; попытка присвоения `t[0] = x` выбросит `TypeError`
