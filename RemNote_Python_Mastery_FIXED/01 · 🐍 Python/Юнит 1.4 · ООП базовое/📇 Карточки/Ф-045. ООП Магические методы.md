1. Что происходит с методом `__hash__` класса, если в нём переопределить метод `__eq__` ? Почему? >> Python автоматически устанавливает `__hash__ = None` ; объект становится нехешируемым и не может быть ключом словаря или элементом `set`
2. Какую функцию вызывает `__str__` ? >> `str()` ; также вызывается при `print(obj)`
3. Какой метод вызывается при `a + b` ? >> `a.__add__(b)` ; `a` – получатель, `b` – правый операнд
4. Могут ли магические методы существовать без двойных подчёркиваний? >> Нет; двойные подчёркивания с обеих сторон – обязательная часть определения
5. Является ли `__init__` обязательным? >> Нет; без него объект создаётся без атрибутов экземпляра; `__new__` всё равно будет вызван
6. Что передаётся аргументом в `__add__(self, b)` ? >> Правый операнд `b`
7. В чём разница между `__str__` и `__repr__` ? >> `__str__` – читаемое представление для пользователя; `__repr__` – однозначное представление для разработчика и отладки; если `__str__` не определён, Python использует `__repr__`
8. Какой метод вызывается при `len(obj)` ? >> `__len__`
9. Как называются методы, обрамлённые двойным подчёркиванием? >> Магические методы или dunder-методы
10. Какой метод нужен для инициализации атрибутов объекта? >> `__init__`
11. Как вызываются магические методы? >> Автоматически интерпретатором; можно вызвать вручную, но это не принято
12. Как реализована перегрузка операторов в Python? >> Через определение магических методов: `__add__` , `__mul__` , `__lt__` и др.
13. Какая операция вызывает `__eq__` ? >> Оператор `==`
14. Что означает наличие `__` в начале и конце имени метода? >> Принадлежность к категории магических методов – зарезервированных интерпретатором Python
15. Почему `__init__` редко вызывают вручную? >> Он запускается автоматически при создании экземпляра через `__new__`
16. От чего произошло название dunder? >> Double Underscore – двойное подчёркивание
17. Что произойдёт при вызове `len()` для объекта без `__len__` ? >> `TypeError: object of type '...' has no len()`
18. Какой метод нужно переопределить чтобы изменить логику сложения объектов? >> `__add__`
19. Для чего предназначены магические методы? >> Для взаимодействия объектов со встроенными операторами и функциями Python; вызываются интерпретатором автоматически
