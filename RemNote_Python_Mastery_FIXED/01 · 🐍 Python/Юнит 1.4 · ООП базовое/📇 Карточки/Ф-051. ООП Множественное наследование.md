1. Если `Duck` наследует `Flyable` и `Swimmable` , какие методы доступны объекту `Duck` ? >> Оба: `fly()` из `Flyable` и `swim()` из `Swimmable`
2. Как называется возможность наследоваться от нескольких классов одновременно? >> Множественное наследование
3. Какая основная проблема множественного наследования? >> Конфликты при одинаковых именах методов в разных родителях – проблема ромбовидного наследования
4. Как синтаксически оформляется множественное наследование `Duck` от `Flyable` и `Swimmable` ? >> `class Duck(Flyable, Swimmable):`
5. Что такое проблема ромба (diamond problem)? >> Ситуация когда два родительских класса наследуют один общий класс; возникает неоднозначность какой метод вызывать
6. В чём отличие Python от Java и C# в контексте наследования? >> Python поддерживает множественное наследование; Java и C# – нет (используют интерфейсы как альтернативу)
7. По какому алгоритму Python вычисляет MRO? >> C3-линеаризация; гарантирует предсказуемый и согласованный порядок разрешения методов
8. Чем определяется порядок разрешения конфликтов имён методов? >> MRO
9. Какую задачу выполняет MRO? >> Определяет приоритетность вызова методов при их совпадении в нескольких родителях; устраняет неоднозначность
10. Что такое MRO? >> Method Resolution Order – порядок поиска атрибутов и методов в иерархии классов при множественном наследовании
11. Как посмотреть MRO конкретного класса? >> `ClassName.__mro__` или `ClassName.mro()` ; возвращает кортеж классов в порядке поиска
12. Почему важно использовать `super()` при множественном наследовании? >> `super()` следует MRO и корректно передаёт вызов по цепочке; прямой вызов `ParentClass.method(self)` нарушает порядок MRO
