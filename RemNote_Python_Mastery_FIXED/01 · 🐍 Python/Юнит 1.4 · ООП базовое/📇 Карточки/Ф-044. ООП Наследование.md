1. Что произойдёт, если не вызвать `super().__init__()` в конструкторе дочернего класса? >> Атрибуты родительского класса не будут инициализированы; обращение к ним вызовет `AttributeError`
2. Почему класс `Dog` имеет доступ к `self.name` , хотя он не объявлялся напрямую в его `__init__`: `class Animal:; def __init__(self, name):; self.name = name; class Dog(Animal):; def __init__(self, name, breed):; super().__init__(name); self.breed = breed` ? >> `Dog.__init__` вызывает `super().__init__()` , который инициализирует `self.name` в `Animal.__init__` ; без этого вызова `self.name` был бы недоступен
3. Может ли `Dog` переопределить метод `speak` родителя? >> Да; Python будет использовать метод `Dog` , а не `Animal`
4. Как называется изменение метода родителя в дочернем классе? >> Переопределение (override)
5. Зачем использовать наследование вместо копирования кода? >> Переиспользование, единая точка изменений, упрощение поддержки
6. Может ли дочерний класс иметь методы которых нет в родительском? >> Да; дочерний класс может расширять функциональность родителя
7. Как называется класс который получает атрибуты от другого? >> Дочерний класс (subclass)
8. Как в Python указывается родительский класс? >> Имя родителя записывается в скобках: `class Dog(Animal):`
9. В каком порядке Python ищет метод при наследовании? >> По MRO (Method Resolution Order): сначала в текущем классе, затем по цепочке родителей до `object`
10. Зачем использовать `super()` в дочернем классе? >> Для вызова метода родительского класса; особенно важно в `__init__` : `super().__init__()` инициализирует атрибуты родителя
11. Как называется механизм при котором один класс получает атрибуты и методы другого? >> Наследование
12. Получает ли дочерний класс все методы родительского автоматически? >> Да; если метод не переопределён, Python ищет его в родительском классе по MRO
13. Что происходит с функциональностью родителя при расширении дочерним классом? >> Родительские методы остаются доступны; дочерний добавляет новые возможности поверх существующих
14. Какую основную возможность даёт наследование? >> Переиспользование кода и расширение функциональности без дублирования
15. Как называется класс чьи атрибуты передаются другому? >> Родительский класс (superclass, base class)
