1. Как функция `isinstance()` работает с абстрактными базовыми классами ( `abc.ABC` )? >> Да; если класс реализует нужные методы и зарегистрирован через `ABC` , `isinstance` вернёт `True` даже без явного наследования
2. Какую функцию использовать для проверки является ли объект экземпляром класса или подкласса? >> `isinstance(obj, cls)`
3. Что общего у `isinstance` и `issubclass` ? >> Обе возвращают `bool` и учитывают иерархию наследования
4. Что вернёт `issubclass(Dog, Animal)` если `Dog` наследует `Animal` ? >> `True`
5. Какая функция проверяет является ли один класс производным от другого? >> `issubclass(cls1, cls2)`
6. Почему `isinstance(True, int)` возвращает `True` ? >> `bool` наследует от `int` ; `True` и `False` – экземпляры обоих классов
7. Какая проверка вернёт `False` для объекта подкласса при сравнении с базовым классом? >> `type(obj) == BaseClass`
8. Каков результат `isinstance(True, int)` ? >> `True` ; `bool` является подклассом `int`
9. Какая функция принимает объект первым аргументом? >> `isinstance`
10. Для чего используется кортеж во втором аргументе `isinstance` ? >> Для проверки принадлежности объекта к любому из перечисленных классов
11. Что можно передать вторым аргументом `isinstance` для проверки на несколько классов? >> Кортеж классов: `isinstance(obj, (list, tuple))`
12. Каков результат `isinstance([], (list, tuple))` ? >> `True`
13. Является ли класс подклассом самого себя? >> Да; `issubclass(bool, bool)` → `True` ; каждый класс считается подклассом себя самого
14. Каков результат `issubclass(bool, int)` ? >> `True`
15. Какая функция принимает исключительно классы обоими аргументами? >> `issubclass` ; передача экземпляра вместо класса выбросит `TypeError`
16. Каков результат `isinstance([], list)` ? >> `True`
17. В чём преимущество `isinstance` перед `type(obj) == cls` ? >> Учитывает иерархию наследования; `type()` возвращает точный тип без учёта родителей
