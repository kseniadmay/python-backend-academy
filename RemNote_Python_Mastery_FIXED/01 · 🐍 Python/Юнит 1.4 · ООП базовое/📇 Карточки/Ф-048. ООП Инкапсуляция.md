1. Как получить доступ к приватному атрибуту `__pin` класса `BankAccount` напрямую? Что такое Name Mangling? >> `account._BankAccount__pin`
2. Что является главной целью инкапсуляции? >> Безопасное управление внутренним состоянием объекта без нарушения его целостности
3. Для чего используется `@property` в контексте инкапсуляции? >> Позволяет контролировать чтение и запись атрибута через методы, скрывая внутреннюю реализацию за интерфейсом атрибута
4. Через что осуществляется доступ к состоянию объекта при инкапсуляции? >> Через публичный интерфейс: методы и `@property`
5. С какой целью применяется name mangling? >> Для защиты от случайного переопределения атрибута в подклассах, а не для настоящей приватности
6. Какая ошибка возникнет при прямом обращении к `account.__pin` вне класса? >> `AttributeError` ; Python не находит атрибут с таким именем – он сохранён под изменённым именем
7. Какой префикс указывает на псевдоприватность атрибута? >> Двойное подчёркивание: `__pin`
8. Что такое инкапсуляция? >> Сокрытие внутреннего состояния объекта и ограничение доступа к нему через публичный интерфейс
9. Как реализуется контроль доступа в Python? >> Соглашениями об именовании; жёстких ограничений на уровне языка нет
10. Как называется механизм автоматического изменения имени атрибута начинающегося с `__` ? >> Name mangling (искажение имён)
11. Как называются атрибуты доступные всем без ограничений? >> Публичные ( `public` ): без префикса
12. В какое имя преобразуется `__pin` в классе `BankAccount` ? >> `_BankAccount__pin`
13. Что означает одиночное подчёркивание в конце имени: `name_` ? >> Соглашение для избежания конфликта с зарезервированным именем Python: `class_` , `type_` , `id_`
14. Почему `account._balance` работает несмотря на защищённость? >> Python не блокирует доступ к атрибутам с одним подчёркиванием на уровне интерпретатора
15. Обеспечивает ли name mangling настоящую приватность? >> Нет; доступ возможен через преобразованное имя `_ClassName__attr`
16. Что означает «не трогай снаружи» для защищённых атрибутов? >> Атрибут технически доступен, но его изменение вне класса или подкласса считается нарушением контракта
17. Как обозначается защищённый атрибут? >> Одно подчёркивание: `_balance` ; соглашение «не трогай снаружи», технически доступен
