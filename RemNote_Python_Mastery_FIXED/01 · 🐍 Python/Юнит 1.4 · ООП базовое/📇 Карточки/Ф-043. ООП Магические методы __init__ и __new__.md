1. Зачем в методе `__new__` вызывать `super().__new__(cls)` ? >> Делегирует создание экземпляра родительскому классу; стандартный способ создать объект внутри переопределённого `__new__`
2. Как реализовать паттерн Singleton через магический метод `__new__` ? >> Возвращает уже существующий экземпляр из кэша вместо создания нового: `if cls._instance is None: cls._instance = super().__new__(cls)`
3. Что обязан вернуть метод `__new__` , чтобы процесс создания объекта продолжился вызовом `__init__` ? >> Новый экземпляр класса; обычно через `super().__new__(cls)`
4. Какую задачу выполняет `__init__` ? >> Инициализирует уже созданный экземпляр: заполняет атрибутами и настраивает состояние
5. Почему `__new__` называют истинным конструктором? >> Именно он создаёт и возвращает новый экземпляр; `__init__` лишь настраивает уже существующий объект
6. Какой первый аргумент принимает `__new__` ? >> `cls` – ссылка на сам класс
7. Какую задачу выполняет `__new__` ? >> Создаёт и возвращает новый экземпляр класса; вызывается до `__init__`
8. Какой первый аргумент принимает `__init__` ? >> `self` – уже созданный экземпляр
9. Всегда ли вызывается `__new__` даже без явного определения? >> Да; вызывается автоматически при каждом создании объекта
10. Чья реализация `__new__` используется если он не переопределён? >> `object.__new__` – базовая реализация
11. Что произойдёт если в `__new__` забыть `return` ? >> Метод неявно вернёт `None` ; `__init__` не будет вызван
12. Какой метод вызывается первым при создании объекта? >> `__new__`
13. Является ли `__init__` обязательным для создания объекта? >> Нет; память выделяется в `__new__` ; `__init__` только настраивает состояние
14. Какой метод вызывается вторым? >> `__init__`
15. Может ли `__new__` вернуть объект другого класса? >> Да; в этом случае `__init__` текущего класса не будет вызван
16. Разница между `__new__` и `__init__` ? >> `__new__` создаёт объект и возвращает его; `__init__` инициализирует уже созданный объект атрибутами
17. Будет ли вызван `__init__` , если `__new__` вернёт `None` ? >> Нет; `__init__` вызывается только если `__new__` вернул экземпляр того же класса
18. В чём разница между `cls` и `self` ? >> `cls` – это сам класс; `self` – конкретный экземпляр этого класса
19. В каком порядке Python ищет `__new__` если он не найден в текущем классе? >> По MRO вверх по иерархии наследования до `object`
20. В каких случаях переопределяют `__new__` ? >> При наследовании от `immutable` -типов ( `str` , `int` , `tuple` ), реализации паттерна Singleton, управлении кэшированием объектов
21. Почему `__new__` нужен при наследовании от `immutable` -типов? >> Их значение фиксируется при создании; изменить его в `__init__` уже невозможно
