1. Что такое `self` в Python? >> Ссылка на текущий экземпляр класса; первый параметр любого метода экземпляра
2. Как `self` влияет на хранение данных в разных экземплярах? >> Связывает атрибуты с конкретным объектом; каждый экземпляр хранит свои данные отдельно
3. Каким по счёту аргументом Python передаёт экземпляр в метод? >> Первым
4. Является ли `self` зарезервированным ключевым словом? >> Нет; это общепринятое соглашение; технически можно использовать любое имя, но это нарушает PEP 8 и читаемость
5. В чём разница между атрибутом экземпляра и атрибутом класса? >> Атрибут экземпляра задаётся через `self.attr` – уникален для каждого объекта; атрибут класса задаётся на уровне класса – общий для всех экземпляров
6. Что произойдёт при вызове метода через класс напрямую: `Dog.bark(d)` ? >> Корректный вызов; `self` нужно передать явно – здесь это `d` ; эквивалентно `d.bark()`
7. Что обозначает `self.name` в `self.name = name` ? >> Атрибут конкретного экземпляра класса
8. К чему получает доступ метод через `self` ? >> К атрибутам и методам конкретного экземпляра
9. Как `self` предотвращает смешивание данных между экземплярами? >> Связывает каждый атрибут с конкретным объектом в памяти; `dog1.name` и `dog2.name` – независимые атрибуты
10. Для чего используется `self` в `__init__` ? >> Для инициализации атрибутов создаваемого экземпляра
11. На что ссылается `self` : на класс или на объект? >> На конкретный экземпляр (объект)
12. Нужно ли явно передавать `self` при вызове `d.bark()` ? >> Нет; Python подставляет объект `d` автоматически как первый аргумент
