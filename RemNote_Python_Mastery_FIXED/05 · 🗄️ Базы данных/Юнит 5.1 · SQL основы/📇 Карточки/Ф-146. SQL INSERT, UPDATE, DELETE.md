1. К какому типу команд относится `TRUNCATE` ? >> DDL (Data Definition Language) в большинстве СУБД – не DML; это отличает его от `DELETE` и влияет на поведение в транзакциях
2. Запрос для архивации сотрудников старше 60 лет? >> `INSERT INTO employees_archive SELECT * FROM employees WHERE age > 60`
3. Какая SQL-команда добавляет новые строки в таблицу? >> `INSERT`
4. Какое из средств удаления работает построчно? >> `DELETE` – обрабатывает и логирует каждую строку отдельно
5. `WHERE` для удаления записи с `id = 42` ? >> `WHERE id = 42`
6. Как в `SET` разделяются несколько пар «столбец = значение»? >> Запятой: `SET salary = salary * 1.1, updated_at = NOW()`
7. Какой оператор использовать в `UPDATE WHERE` для фильтрации по двум условиям одновременно? >> `AND`
8. Какое ключевое слово в `UPDATE` задаёт новые значения столбцов? >> `SET`
9. Синтаксис добавления одной строки в таблицу `employees` ? >> `INSERT INTO employees (name, age) VALUES ('Alice', 30)`
10. Какая команда удаляет строки из таблицы? >> `DELETE`
11. `WHERE` для удаления записей с `last_login` раньше 1 января 2022? >> `WHERE last_login < '2022-01-01'`
12. Что произойдёт при `DELETE FROM temp_table` без `WHERE` ? >> Удалятся все строки таблицы `temp_table` ; структура таблицы сохранится
13. Фрагмент `SET` для повышения зарплаты на 10%? >> `SET salary = salary * 1.1`
14. В чём преимущество `DELETE` перед `TRUNCATE` с точки зрения транзакций? >> `DELETE` всегда можно откатить через `ROLLBACK` ; `TRUNCATE` в MySQL – нет
15. Какая команда удаляет все строки быстрее, чем `DELETE` ? >> `TRUNCATE TABLE`
16. Что выполнит `UPDATE employees SET salary = 95000 WHERE id = 42` ? >> Установит зарплату 95000 сотруднику с `id = 42`
17. Удаляет ли `TRUNCATE` структуру таблицы? >> Нет, только данные; столбцы, индексы и ограничения сохраняются
18. Можно ли откатить `TRUNCATE` ? >> Зависит от СУБД: в PostgreSQL `TRUNCATE` транзакционен и откатывается через `ROLLBACK` ; в MySQL `TRUNCATE` – DDL-команда и не откатывается
19. Почему при `DELETE` критически важно указывать `WHERE` ? >> Без `WHERE` удалятся все строки таблицы
20. К какому типу DML-команд относятся `INSERT` , `UPDATE` , `DELETE` ? >> DML (Data Manipulation Language) – команды манипулирования данными
21. Почему `TRUNCATE` быстрее `DELETE` при очистке большой таблицы? >> `TRUNCATE` сбрасывает данные массово без построчного логирования, `DELETE` логирует каждую строку
22. Какая команда предпочтительна для быстрой очистки временной таблицы? >> `TRUNCATE TABLE temp_table`
23. Какое ключевое слово после которого перечисляются значения для вставки? >> `VALUES`
24. Какая команда изменяет данные в существующих записях? >> `UPDATE`
25. Что произойдёт при `UPDATE` без `WHERE` ? >> Обновятся все строки в таблице – одна из самых опасных ошибок в DML
26. Какая конструкция вставляет данные, полученные из другой таблицы? >> `INSERT INTO ... SELECT` : не использует `VALUES` , данные берутся из результата `SELECT`
27. Как в одной команде `INSERT` добавить сразу несколько строк? >> Перечислить наборы значений в скобках через запятую: `VALUES (1, 'a'), (2, 'b'), (3, 'c')`
