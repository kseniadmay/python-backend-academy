1. Какая системная константа подставляет текущую дату и время? >> `CURRENT_TIMESTAMP`
2. Как называется столбец, ссылающийся на `id` другой таблицы? >> Внешний ключ (Foreign Key)
3. Какое ключевое слово в PostgreSQL создаёт автоинкрементный целочисленный столбец? >> `SERIAL` ; в PostgreSQL 10+ предпочтительна стандартная альтернатива: `GENERATED ALWAYS AS IDENTITY`
4. Какое ключевое слово используется для именования ограничений? >> `CONSTRAINT` : `CONSTRAINT chk_salary CHECK (salary >= 0)`
5. Команда для добавления столбца `phone` в таблицу `employees` ? >> `ALTER TABLE employees ADD COLUMN phone VARCHAR(20)`
6. Какое ключевое слово обозначает ссылочную целостность между таблицами? >> `REFERENCES`
7. Как создать ссылку на первичный ключ другой таблицы? >> `REFERENCES` : `department_id INTEGER REFERENCES departments(id)`
8. Команда для создания индекса `idx_department` по столбцу `department_id` ? >> `CREATE INDEX idx_department ON employees(department_id)`
9. Какой тип данных хранит точные денежные значения? >> `DECIMAL` или `NUMERIC` (синонимы в PostgreSQL)
10. Чем `GENERATED ALWAYS AS IDENTITY` лучше `SERIAL` ? >> Это SQL-стандарт (ISO), в отличие от `SERIAL` – расширения PostgreSQL; даёт больший контроль и переносимость
11. Что произойдёт при `CREATE TABLE` , если таблица уже есть и `IF NOT EXISTS` не указан? >> Ошибка
12. Какое ключевое слово задаёт значение столбца по умолчанию? >> `DEFAULT`
13. Какой тип данных использовать для строк переменной длины до 100 символов? >> `VARCHAR(100)`
14. Какая команда создаёт новую таблицу в базе данных? >> `CREATE TABLE`
15. Команда для переименования столбца `name` в `full_name` ? >> `ALTER TABLE employees RENAME COLUMN name TO full_name`
16. В `DECIMAL(10, 2)` – что означает 10 и что означает 2? >> 10 – общее количество цифр (точность); 2 – знаков после запятой
17. Какое ограничение запрещает `NULL` в столбце? >> `NOT NULL`
18. Какое ограничение делает столбец уникальным идентификатором строки? >> `PRIMARY KEY`
19. Является ли `DROP TABLE` необратимой операцией? >> В большинстве СУБД (MySQL) – да; в PostgreSQL `DROP TABLE` внутри транзакции можно откатить через `ROLLBACK`
20. Что означает `DEFAULT 0` в определении столбца `salary` ? >> При вставке строки без явного значения `salary` будет установлено `0`
21. Какая команда изменяет структуру уже существующей таблицы? >> `ALTER TABLE`
22. Какое ключевое слово задаёт условие проверки допустимых значений? >> `CHECK` : `CHECK (age >= 18)`
23. Зачем давать ограничению имя через `CONSTRAINT` ? >> Чтобы можно было ссылаться на него по имени при `ALTER TABLE DROP CONSTRAINT`
24. Как называется тип связи, устанавливаемый через `REFERENCES departments(id)` в таблице сотрудников? >> «Многие к одному»: много сотрудников могут ссылаться на один отдел
25. Как добавить именованное ограничение `CHECK` в существующую таблицу? >> `ALTER TABLE employees ADD CONSTRAINT chk_salary CHECK (salary >= 0)`
26. Что описывается внутри скобок в `CREATE TABLE employees (...)` ? >> Список столбцов с их типами данных и ограничениями
27. Зачем нужны индексы в базе данных? >> Для ускорения поиска и выборки данных; без индекса СУБД выполняет полный перебор строк
28. Что описывает `CHECK (age >= 18)` ? >> Бизнес-правило, ограничивающее допустимый диапазон: возраст должен быть не менее 18
29. Какой тип данных использовать для хранения даты и времени создания записи? >> `TIMESTAMP`
30. Команда для удаления базы данных `mydb` ? >> `DROP DATABASE mydb`
31. Что делает `CASCADE` в `DROP TABLE departments CASCADE` ? >> Удаляет таблицу и все зависимые объекты: ограничения внешних ключей в других таблицах, ссылающихся на `departments`
32. Какая команда полностью удаляет таблицу со всеми данными? >> `DROP TABLE`
33. Команда для удаления столбца `phone` из таблицы `employees` ? >> `ALTER TABLE employees DROP COLUMN phone`
34. Что такое ссылочная целостность? >> Гарантия, что значение внешнего ключа соответствует существующей записи в связанной таблице
35. Команда для изменения типа столбца `salary` на `NUMERIC(12, 2)` ? >> `ALTER TABLE employees ALTER COLUMN salary TYPE NUMERIC(12, 2)`
36. Если задано `email VARCHAR(150) UNIQUE` , можно ли добавить двух сотрудников с одинаковым `email` ? >> Нет – нарушение ограничения уникальности, СУБД вернёт ошибку
37. Как избежать ошибки при создании таблицы, которая уже существует? >> `CREATE TABLE IF NOT EXISTS employees (...)`
38. Каков результат `RENAME COLUMN name TO full_name` ? >> Столбец `name` будет переименован в `full_name` ; данные сохранятся
39. Команда для удаления индекса `idx_department` ? >> `DROP INDEX idx_department`
40. Что `PRIMARY KEY` объединяет в себе из других ограничений? >> `UNIQUE` + `NOT NULL`
41. Какой тип данных использовать для хранения возраста или счётчиков? >> `INTEGER`
42. Какое ограничение требует уникальности всех значений в столбце? >> `UNIQUE`
43. Какая команда удаляет всю базу данных? >> `DROP DATABASE`
44. Может ли одна таблица содержать несколько ограничений `UNIQUE` ? >> Да, уникальными можно сделать несколько разных столбцов или комбинаций столбцов
45. Как избежать ошибки при `DROP TABLE` , если таблица может не существовать? >> `DROP TABLE IF EXISTS employees`
46. К какому разделу SQL относятся `CREATE` , `ALTER` и `DROP` ? >> DDL (Data Definition Language) – язык определения данных
