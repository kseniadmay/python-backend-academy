1. Когда предпочтительнее SQL? >> Строгая консистентность и транзакции (финансы, медицина); сложные `JOIN` по многим таблицам; стабильная схема
2. Почему polyglot persistence популярен? >> Каждая БД оптимизирована для своего сценария; нет универсальной БД, одинаково хорошей для всего
3. Поддерживают ли NoSQL БД транзакции? >> Зависит от конкретной БД; MongoDB поддерживает с версии 4.0; Redis имеет транзакции через `MULTI/EXEC` ; Cassandra – ограниченно; строгого ACID нет везде
4. Как данные организованы в реляционных (SQL) БД? >> Таблицы со строгой фиксированной схемой, связанные через внешние ключи и `JOIN`
5. Какой тип масштабирования характерен для SQL БД? >> Вертикальное: увеличение мощности одного сервера (CPU, RAM)
6. Какую модель консистентности обеспечивают реляционные БД? >> Сильная консистентность (strong consistency); все узлы видят одинаковые данные немедленно
7. Что такое polyglot persistence? >> Одновременное использование БД разных типов в одной системе; например, PostgreSQL + Redis: первый для основных данных, второй для кэша и очередей
8. Как реализуются связи в NoSQL БД? >> Через денормализацию (вложенные документы) или ссылки (аналог FK без принудительной проверки)
9. Для каких задач лучше подходит Neo4j? >> Графовые паттерны доступа: социальные сети, рекомендательные системы, анализ связей
10. Что объединяет все NoSQL БД? >> Отказ от табличной модели; гибкая или отсутствующая схема; горизонтальное масштабирование; собственный API вместо SQL
11. Что такое eventual consistency? >> Данные в конечном счёте станут согласованными на всех узлах, но не обязательно немедленно; типично для NoSQL
12. Какой тип масштабирования характерен для NoSQL БД? >> Горизонтальное: добавление новых серверов в кластер (sharding)
13. Когда предпочтительнее NoSQL? >> Гибкая или неизвестная заранее схема; огромные объёмы с горизонтальным масштабированием; высокая скорость записи важнее строгой консистентности
14. Для каких задач лучше Cassandra/ClickHouse? >> Колоночные БД: аналитика по большим объёмам данных, временные ряды, OLAP-запросы
15. Какие четыре типа NoSQL БД существуют? >> Документоориентированные (MongoDB); ключ-значение (Redis); колоночные (Cassandra, ClickHouse); графовые (Neo4j)
