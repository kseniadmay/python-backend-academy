1. Что означает TTL в контексте Redis? >> Time To Live – время жизни ключа в секундах; по истечении ключ удаляется автоматически
2. Как называется ситуация, когда данных в кэше нет? >> Cache miss (промах)
3. Какая библиотека интегрирует Redis с Django cache framework? >> `django-redis`
4. Из какого модуля Django импортируется объект `cache` ? >> `from django.core.cache import cache`
5. Команда для получения среза Sorted Set по позиции? >> `r.zrange('key', start, end)` – в redis-py 4.0+; аргумент `rev=True` для убывания, `withscores=True` для включения score
6. Формат строки `LOCATION` для подключения к Redis в Django? >> `"redis://127.0.0.1:6379/1"` (число в конце – номер БД Redis, от 0 до 15)
7. Команда Redis для удаления ключа? >> `r.delete('key')`
8. Как вернуть значение по умолчанию при отсутствии ключа? >> `cache.get('key', default={})`
9. Метод Django Cache API для получения нескольких значений? >> `cache.get_many(['k1', 'k2'])`
10. Какую библиотеку импортировать для работы с Redis в Python? >> `redis` (пакет `redis-py` ): `import redis`
11. Команда для проверки членства в Set? >> `r.sismember('key', member)`
12. Метод Django Cache API для массовой записи? >> `cache.set_many({'k1': v1, 'k2': v2})`
13. Какая структура Redis ранжирует элементы по числовому значению? >> Sorted Set (упорядоченное множество)
14. Какой `BACKEND` указать для `django-redis` ? >> `"django_redis.cache.RedisCache"`
15. Как установить TTL для уже существующего ключа? >> `r.expire('key', seconds)`
16. Как установить TTL при записи ключа? >> Через аргумент `ex` : `r.set('key', 'value', ex=3600)`
17. Какая структура Redis хранит объект как набор полей «ключ-значение»? >> Hash (хэш)
18. Где физически хранятся данные в Redis? >> В оперативной памяти (RAM), что обеспечивает высокую скорость
19. Команда для добавления элемента в Set? >> `r.sadd('key', member)`
20. Каков типичный порядок времени выполнения операций в Redis? >> Микросекунды
21. В каком файле Django настраивается `CACHES` ? >> `settings.py`
22. Какой порт использует Redis по умолчанию? >> `6379`
23. Что такое политика вытеснения (eviction policy) в Redis? >> Правило, определяющее, какие ключи удалять при нехватке памяти; задаётся параметром `maxmemory-policy` в конфиге
24. Что возвращает `r.ttl('key')` , если ключ не существует? >> `-2`
25. Команда Redis для записи строкового значения по ключу? >> `r.set('key', 'value')`
26. Какое время ответа даёт Redis при попадании в кэш (cache hit)? >> Менее 1 мс
27. В каком формате хранить сложные объекты (словари, списки) в Redis? >> В виде JSON-строки через `json.dumps(obj)` при записи и `json.loads()` при чтении
28. Перед какими источниками данных Redis используется как кэш? >> Перед медленными источниками: PostgreSQL, MongoDB, внешние API
29. Команда для получения одного поля из Hash? >> `r.hget('key', 'field')`
30. Опишите последовательность при cache miss? >> Приложение обращается в Redis → получает miss → запрашивает данные в БД → сохраняет в Redis → возвращает ответ
31. Какая структура Redis подходит для хранения уникальных идентификаторов (например, онлайн-пользователей)? >> Set (множество)
32. Как Redis сохраняет данные на диск (персистентность)? >> Два механизма: RDB (периодические снапшоты) и AOF (лог каждой операции); можно использовать оба одновременно
33. Что такое Redis с точки зрения хранения данных? >> In-memory хранилище данных структур (строки, хэши, списки, множества, sorted sets)
34. Команда для получения всех полей и значений из Hash? >> `r.hgetall('key')`
35. Каков диапазон времени ответа PostgreSQL без кэша? >> 10–100 мс
36. Что определяет параметр `TIMEOUT` в настройках кэша Django? >> TTL по умолчанию для всех записей в секундах
37. Для чего в `django-redis` используется `CLIENT_CLASS` ? >> Для указания класса клиента; по умолчанию `django_redis.client.DefaultClient`
38. Команда Redis для проверки существования ключа? >> `r.exists('key')` – возвращает `1` если ключ есть, `0` если нет
39. Команда Redis для чтения значения по ключу? >> `r.get('key')`
40. Как снижается нагрузка на БД при 95% cache hit rate при 1000 запросов/сек? >> До БД доходит только 50 запросов вместо 1000
41. Как называется ситуация, когда данные успешно получены из кэша? >> Cache hit (попадание)
42. Команда для добавления элемента в Sorted Set? >> `r.zadd('key', {'member': score})`
43. Назовите основные политики вытеснения Redis? >> `noeviction` (ошибка при заполнении), `allkeys-lru` (удаляет наименее используемые из всех), `volatile-lru` (только среди ключей с TTL), `allkeys-lfu` (по частоте использования)
44. Что возвращает `r.ttl('key')` , если у ключа нет TTL? >> `-1`
45. Что возвращает `zrange` с `withscores=True` ? >> Список кортежей `(member, score)` вместо только имён элементов
46. Команда для записи нескольких полей в Hash? >> `r.hset('key', mapping={'field1': 'val1', 'field2': 'val2'})`
47. Что вернёт `cache.get('key')` , если ключа нет в кэше? >> `None`
48. За что отвечает параметр `decode_responses=True` в `redis.Redis()` ? >> За автоматическое декодирование ответов из байтов в строки Python
