1. Что такое паттерн Unit of Work? >> Накапливает все изменения объектов и применяет их одним пакетом при `commit()` ; обеспечивает атомарность операций
2. Что описывают классы, наследующие от `Base` ? >> Структуру таблиц БД: имя таблицы ( `__tablename__` ), колонки и их типы, связи
3. Какие функции используются для сложных фильтров? >> `and_()` – логическое И; `or_()` – логическое ИЛИ; импортируются из `sqlalchemy`
4. Для чего используется `ForeignKey` в моделях? >> Создаёт внешний ключ – связь колонки с первичным ключом другой таблицы
5. Основные типы данных SQLAlchemy? >> `Integer` , `String` , `Boolean` , `DateTime` , `Float` , `Text` , `JSON` ; импортируются из `sqlalchemy`
6. Что такое `Session` в SQLAlchemy? >> Основной инструмент взаимодействия с БД; отслеживает изменения объектов и управляет транзакциями по паттерну Unit of Work
7. Как работает `.where()` в `select()` ? >> Аналог `WHERE` в SQL; принимает условия: `User.age > 25` , `User.name == "Alice"` , `and_(...)` , `or_(...)`
8. Что такое `stmt` в контексте SQLAlchemy? >> Объект-инструкция, описывающий будущий SQL-запрос; передаётся в `session.execute(stmt)` для выполнения
9. Является ли `session.query()` рекомендуемым способом в SQLAlchemy 2.0? >> Нет; `session.query()` помечен как legacy; предпочтителен `select()` + `session.execute()`
10. Что делает `.scalars()` после `execute()` ? >> Извлекает чистые объекты моделей вместо строк-кортежей; без него получите `Row` -объекты
11. Что такое SQLAlchemy ORM? >> Высокоуровневый интерфейс; таблицы описываются как Python-классы; работа ведётся с объектами, а не SQL-строками
12. Что такое SQLAlchemy Core? >> Низкоуровневый SQL-конструктор; позволяет строить запросы программно без привязки к Python-классам
13. Как создать фабрику сессий? >> `Session = sessionmaker(bind=engine)` ; затем `with Session() as session:`
14. Когда объекту присваивается сгенерированный БД первичный ключ? >> После `session.commit()` ; до этого `id` может быть `None`
15. Что такое `create_engine` ? >> Создаёт движок – соединение с БД на основе URL; `create_engine("postgresql://user:pass@localhost/mydb")`
16. Почему сессию нужно использовать через контекстный менеджер? >> Гарантирует автоматическое закрытие и возврат ресурсов даже при ошибках
17. В чём разница между `session.add()` и `session.commit()` ? >> `add()` регистрирует объект в сессии (в памяти); `commit()` физически записывает все изменения в БД и подтверждает транзакцию
18. Что вернёт `scalars()` без `.all()` ? >> `ScalarResult` – итератор, не список; для списка нужен `.all()`
19. Как выполнить запрос в SQLAlchemy 2.0+? >> `stmt = select(User).where(User.age > 25)` ; `result = session.execute(stmt).scalars().all()`
20. Что такое SQLAlchemy? >> Самая популярная ORM-библиотека для Python; состоит из двух уровней: Core (SQL-конструктор) и ORM (работа с объектами)
21. Какая функция создаёт базовый класс для моделей? >> `declarative_base()` ; все модели наследуются от `Base`
