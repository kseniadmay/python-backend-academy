1. Какую задачу выполняет `ROW_NUMBER()` ? >> Присваивает каждой строке в окне уникальный порядковый номер без пропусков и повторений
2. Что такое «окно» в контексте оконных функций SQL? >> Набор строк, связанных с текущей строкой, на основе которых производится вычисление
3. Список зарплат `(100, 100, 50)` – что вернёт `DENSE_RANK()` для значения 50? >> `2` (`DENSE_RANK` не пропускает ранги после ничьей: `1, 1, 2`)
4. `PARTITION BY` разбивает данные на группы, внутри которых функция применяется независимо – верно? >> Да, это основное назначение `PARTITION BY`
5. Почему результат оконной функции нельзя фильтровать в `WHERE` того же запроса? >> Оконные функции вычисляются после `WHERE` ; на момент фильтрации их результат ещё не доступен
6. Для чего используется `LEAD()` ? >> Для получения значения из следующей строки окна без `SELF JOIN`
7. Как правильно отфильтровать строки по результату оконной функции? >> Обернуть в подзапрос или CTE: `WITH cte AS (SELECT ..., ROW_NUMBER() OVER(...) AS rn FROM ...) SELECT * FROM cte WHERE rn <= 3`
8. Что вернут `LAG()` и `LEAD()` для первой и последней строки окна соответственно? >> `NULL` – соседняя строка отсутствует
9. Что такое `NTILE(n)` ? >> Разбивает строки окна на `n` примерно равных групп; возвращает номер группы для каждой строки
10. Как `ROW_NUMBER()` обрабатывает строки с одинаковыми значениями в `ORDER BY` ? >> Присваивает им разные номера; порядок между равными строками не детерминирован
11. Возможны ли пропуски в нумерации при `ROW_NUMBER()` ? >> Нет, нумерация всегда последовательна без пропусков
12. Как с помощью `SUM()` вычислить накопительную сумму? >> `SUM(salary) OVER (ORDER BY date)` – по умолчанию фрейм `RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW`
13. Влияет ли оконная функция в `SELECT` на группировку в `GROUP BY` ? >> Нет; оконные функции и `GROUP BY` работают на разных уровнях обработки запроса
14. Какие аргументы принимает `LAG(column, n, default)` ? >> `column` – столбец; `n` – смещение (по умолчанию 1); `default` – значение вместо `NULL` , если строки нет
15. Код `SELECT name, SUM(salary) OVER() FROM employees` – что вернёт `SUM(salary) OVER()` ? >> Общую сумму зарплат всех сотрудников в каждой строке результата
16. Если двум строкам присвоен ранг 2 функцией `DENSE_RANK()` , какой ранг получит следующая строка? >> `3` (`DENSE_RANK` нумерует плотно без пропусков)
17. Если `PARTITION BY` указывает поле отдела – когда сбрасывается счётчик `ROW_NUMBER()` ? >> При переходе к каждому новому отделу
18. Какое ключевое слово указывает, что функция является оконной? >> `OVER`
19. Как изменяется количество строк при использовании оконных функций? >> Не изменяется – строки не группируются
20. Если двум строкам присвоен ранг 2 функцией `RANK()` , какой ранг получит следующая строка? >> `4` (`RANK` пропускает 3-е место после двух строк на 2-м месте)
21. Что является аргументом `NTILE` ? >> Целое число – количество групп для разбивки
22. Какая функция лучше всего подходит для пагинации данных? >> `ROW_NUMBER()`
23. Назначение `PARTITION BY` в оконной функции? >> Разбивает данные на независимые группы (окна); функция применяется внутри каждой группы отдельно
24. Список зарплат `(100, 100, 50)` – что вернёт `RANK()` для значения 50? >> `3` (после двух первых мест `1, 1` второе место пропускается)
25. Как называются функции, вычисляющие агрегаты или номера строк без свёртки выборки? >> Оконные функции (window functions)
26. Роль `ORDER BY` внутри `OVER()` ? >> Определяет порядок строк внутри окна для корректного расчёта; особенно важен для ранжирующих и навигационных функций
27. Что такое фрейм окна ( `ROWS` / `RANGE` )? >> Уточнение границ набора строк внутри окна: `ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW` – физические строки; `RANGE` – логические (по значению); важно при наличии дубликатов в `ORDER BY`
28. В чём главное отличие оконных функций от `GROUP BY` ? >> Оконные функции не схлопывают строки; каждая исходная строка сохраняется в результате
29. Какая последовательность рангов `(1, 2, 2, 4)` характерна для какой функции? >> `RANK()`
30. Что такое `DENSE_RANK()` ? >> Функция ранжирования с одинаковым рангом для дубликатов без пропуска последующих номеров; количество рангов равно количеству уникальных значений
31. В чём преимущество `LAG` / `LEAD` перед `SELF JOIN` ? >> Проще синтаксис и выше производительность при доступе к соседним строкам
32. Для разделения клиентов на 10 децилей по объёму покупок какую функцию использовать? >> `NTILE(10)`
33. Каков базовый синтаксис оконной функции? >> `ФУНКЦИЯ() OVER (PARTITION BY ... ORDER BY ...)`
34. Как `RANK()` обрабатывает строки с одинаковыми значениями? >> Присваивает одинаковый ранг; следующий ранг пропускается на количество дубликатов
35. Что произойдёт, если в `OVER()` не указать `PARTITION BY` ? >> Функция применяется ко всей таблице как к одному окну
36. Какая последовательность рангов `(1, 2, 2, 3)` характерна для какой функции? >> `DENSE_RANK()`
37. Если в компании 100 человек и используется `NTILE(4)` , сколько человек в каждой группе? >> 25; при неравномерном делении (например, 101 человек) первые группы получают на одного больше
38. В чём отличие `DENSE_RANK()` от `RANK()` ? >> `DENSE_RANK()` не создаёт пропусков: после двух строк с рангом 2 следует ранг 3
39. Что произойдёт с результатом `ROW_NUMBER()` , если убрать `ORDER BY` из `OVER()` ? >> Нумерация будет произведена в произвольном (недетерминированном) порядке
40. Для чего используется `LAG()` ? >> Для получения значения из предыдущей строки окна без `SELF JOIN`
41. Если нужен Топ-3 сотрудника по зарплате в каждом отделе, какое условие использовать? >> `WHERE rn <= 3` во внешнем запросе или CTE, где `rn = ROW_NUMBER() OVER (PARTITION BY dept ORDER BY salary DESC)`
42. Что такое `RANK()` ? >> Функция ранжирования, присваивающая одинаковый ранг дубликатам с пропуском последующих номеров
43. Каким будет результат `RANK()` для набора `(10, 10, 10, 5)` ? >> `1, 1, 1, 4`
44. `ROW_NUMBER() OVER (PARTITION BY dept ORDER BY sal DESC)` – что получит самый высокооплачиваемый в отделе? >> `1` (первый номер в своём окне `dept` при сортировке по убыванию зарплаты)
