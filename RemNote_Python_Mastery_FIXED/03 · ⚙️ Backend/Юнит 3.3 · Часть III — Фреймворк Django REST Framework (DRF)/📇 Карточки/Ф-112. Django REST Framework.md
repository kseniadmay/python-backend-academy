1. Какие ключевые глобальные параметры настраиваются в словаре REST_FRAMEWORK в settings.py? >> `DEFAULT_AUTHENTICATION_CLASSES` ; `DEFAULT_PERMISSION_CLASSES` ; `DEFAULT_PAGINATION_CLASS` ; `PAGE_SIZE`
2. Как стандартные действия (actions) в ModelViewSet DRF соответствуют HTTP-методам и URL? >> `GET /articles/` → `list` ; `POST /articles/` → `create` ; `GET /articles/{id}/` → `retrieve` ; `PUT /articles/{id}/` → `update` ; `DELETE /articles/{id}/` → `destroy`
3. Что входит в `permissions.SAFE_METHODS` ? >> `GET` , `HEAD` , `OPTIONS`
4. Для чего `read_only=True` в поле сериализатора? >> Поле только для чтения; не принимается при `POST` / `PUT` ; не проходит валидацию при записи
5. Что такое `source` в поле сериализатора? >> Указывает, откуда брать данные: `source='author.username'` – атрибут связанной модели
6. Какой базовый класс использовать для полного CRUD? >> `viewsets.ModelViewSet`
7. Чем `ModelViewSet` удобнее ручного написания `APIView` ? >> Автоматически реализует весь CRUD; Router генерирует URL; меньше boilerplate-кода
8. От какого базового класса наследуются кастомные классы разрешений (Permissions) в DRF и какие методы они переопределяют? >> `permissions.BasePermission` ; переопределяется `has_permission()` и/или `has_object_permission()`
9. От какого класса наследуется `ModelSerializer` ? >> `serializers.ModelSerializer` ; автоматически генерирует поля на основе модели
10. Что объединяют в себе классы ViewSet в Django REST Framework (DRF)? >> Логику связанных представлений: `list` , `create` , `retrieve` , `update` , `destroy` в одном классе
11. Что произойдёт при `PUT /articles/1/` от анонима с `IsAuthenticatedOrReadOnly` ? >> Запрос отклонён с кодом 403 Forbidden
12. Что делает `JWTAuthentication` ? >> Обрабатывает JWT-токены из заголовка `Authorization: Bearer <token>`
13. Что происходит при вызове router.register('articles', ArticleViewSet) в DRF? >> Генерирует полный набор URL для ресурса `articles` на основе методов ViewSet
14. Как называется переменная настроек DRF в `settings.py` ? >> `REST_FRAMEWORK`
15. Что делает `IsAuthenticatedOrReadOnly` ? >> Анонимным разрешает только безопасные методы (GET, HEAD, OPTIONS); авторизованным – всё
16. Каким декоратором создаются нестандартные действия в ViewSet? >> `@action` ; `from rest_framework.decorators import action`
17. Если `permission_classes` не указан в ViewSet, что применяется? >> `DEFAULT_PERMISSION_CLASSES` из `settings.py`
18. Чем `has_object_permission` отличается от `has_permission` ? >> `has_permission` – проверка доступа к view; `has_object_permission` – проверка доступа к конкретному объекту
19. Что регулирует `PAGE_SIZE` в `REST_FRAMEWORK` ? >> Количество объектов на одной странице при пагинации
20. Каково основное назначение сериализаторов в DRF? >> Преобразование Python/Django-объектов в JSON и обратно; валидация входящих данных
21. Какие атрибуты обязательны для `ModelViewSet` ? >> `queryset` – набор данных; `serializer_class` – сериализатор; `permission_classes` – опционально
