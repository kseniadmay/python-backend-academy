1. В чём основная задача View при обработке запроса? >> Обработка запроса и получение данных через Model с последующей передачей в Template
2. Где в Django MTV определяется как данные будут представлены пользователю? >> В Template
3. Какому компоненту MVC функционально соответствует View в Django? >> Controller (Контроллер)
4. Какая составляющая MTV отвечает за рендеринг? >> Template
5. Почему Django View считается контроллером? >> Он связывает запрос пользователя, данные из модели и логику шаблона
6. Что является результатом работы Template после рендеринга? >> HTML-код
7. Что возвращает View при разработке API? >> JSON напрямую, без использования Template
8. От какого компонента Template получает контекст для рендеринга? >> View (Представление)
9. Какой компонент следует сразу за URL dispatcher? >> View
10. За какой аспект работы с информацией отвечает Model? >> Взаимодействие с данными
11. Кто является инициатором запроса к Model в архитектуре Django? >> View
12. Ключевое отличие MVC от MTV в контексте управления Model и View? >> В MVC ими управляет Controller; в Django – View
13. Какой компонент MTV отвечает за описание структуры данных и бизнес-логику? >> Model (Модель)
14. Вариацией какого классического паттерна является MTV? >> MVC (Model-View-Controller)
15. Каков формат взаимодействия View и Template? >> Передача контекста ( `context` ) – словаря с данными для шаблона
16. Что такое контекст во взаимодействии View и Template? >> Словарь данных, который View формирует и передаёт в шаблон для отображения; может содержать данные из запроса, БД или вычислений
17. Куда View передаёт данные полученные от Model? >> В Template
18. Почему в Django говорят что Controller и View слиты? >> View сам запрашивает данные у модели и передаёт их в шаблон
19. Что следует сразу после получения данных из Model? >> Передача данных в Template
20. Какая составляющая MTV отвечает за маршрутизацию? >> URL dispatcher
21. Обязателен ли Template для работы View? >> Нет; View может вернуть JSON без Template
22. Какому элементу реляционной БД соответствует класс модели в Django? >> Таблице; экземпляр модели соответствует строке (записи)
23. Какой компонент MTV представляет собой HTML-файл с логикой отображения? >> Template (Шаблон)
24. Если View возвращает JSON напрямую, какая часть MTV исключается? >> Template
25. Как расшифровывается MTV? >> Model-Template-View
26. Какой элемент стоит первым на пути HTTP-запроса перед View? >> URL dispatcher (маршрутизатор)
