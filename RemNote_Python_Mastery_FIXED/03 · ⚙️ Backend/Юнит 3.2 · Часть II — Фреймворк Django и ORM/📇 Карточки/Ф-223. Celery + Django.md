1. Какой командой в терминале запускается планировщик периодических задач Celery Beat? >> `celery -A myproject beat -l info`
2. Как в crontab Celery ограничить выполнение периодической задачи только будними днями (пн–пт)? >> `day_of_week='mon-fri'` внутри `crontab`
3. Как с помощью celery.schedules.crontab настроить запуск периодической задачи ежедневно в 03:00 ночи? >> `schedule=crontab(hour=3, minute=0)`
4. Какой параметр в Celery ограничивает максимальное количество повторных попыток выполнения упавшей задачи? >> `max_retries`
5. Как Flower получает данные о задачах? >> Подключается к брокеру или бэкенду результатов и отслеживает события выполнения
6. В каком словаре в `settings.py` описывается расписание задач? >> `CELERY_BEAT_SCHEDULE`
7. Как правильно инициировать перезапуск задачи Celery при перехвате исключения? >> `raise self.retry(exc=exc)` внутри `except`
8. За что отвечает аргумент `eta` в `apply_async` ? >> Определяет точное время ( `datetime` ) когда задача должна выполниться
9. Какую основную проблему Django решает Celery? >> Позволяет выполнять длительные операции асинхронно, не блокируя ответ пользователю
10. Какая строка в `celery.py` загружает настройки из `settings.py` ? >> `app.config_from_object('django.conf:settings', namespace='CELERY')`
11. Почему `result.get()` без `timeout` не рекомендуется в Django? >> Блокирует поток до получения результата, сводя на нет преимущества асинхронности
12. Что такое Брокер в архитектуре Celery? >> Хранилище задач ожидающих обработки воркерами (Redis, RabbitMQ)
13. Что представляет собой Воркер (Worker) в Celery? >> Отдельный процесс, извлекающий задачи из брокера и выполняющий их
14. Для чего в настройках указывается `CELERY_TIMEZONE` ? >> Для корректной работы Celery Beat в соответствии с локальным временем
15. Как передать именованные аргументы (kwargs) в задачу Celery через метод apply_async? >> `task.apply_async(kwargs={'key': 'value'})`
16. Какой инструмент используется для логирования внутри задач? >> `get_task_logger` из `celery.utils.log`
17. Что такое Flower? >> Веб-инструмент для мониторинга задач и воркеров Celery в реальном времени
18. Что меняет `bind=True` в `@shared_task` ? >> Передаёт экземпляр задачи первым аргументом `self` ; даёт доступ к `self.retry()`
19. Зачем в файле celery.py вызывается os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'myproject.settings')? >> Указывает Celery какой файл настроек Django использовать
20. Какую роль играет `app.autodiscover_tasks()` ? >> Автоматически ищет файлы `tasks.py` во всех установленных приложениях Django
21. Чем отличается передача аргументов в `delay()` и `apply_async()` ? >> В `delay()` – напрямую; в `apply_async()` – через `args=[...]` или `kwargs={...}`
22. Где должен располагаться файл `celery.py` в проекте Django? >> В папке проекта рядом с `settings.py`
23. Какая настройка в settings.py указывает Celery адрес подключения к брокеру сообщений? >> `CELERY_BROKER_URL`
24. Что означает флаг `-l info` при запуске Celery? >> Устанавливает уровень логирования `INFO`
25. Какую функцию выполняет параметр CELERY_RESULT_BACKEND и когда его можно отключить? >> Где Celery хранит результаты выполнения и статусы задач
26. Для чего используется `.apply_async()` вместо `.delay()` ? >> Для расширенной настройки: задержка, точное время запуска, приоритет
27. Зачем в `__init__.py` пакета проекта импортируется `celery_app` ? >> Гарантирует загрузку приложения Celery при старте Django; делает `@shared_task` доступным
28. В каком формате задается URL подключения к Redis в настройках Celery? >> `redis://localhost:6379/0`
29. Как получить результат задачи в основном коде? >> Вызвать `.get()` у объекта результата возвращённого `.delay()` или `.apply_async()`
30. Команда для запуска воркера Celery? >> `celery -A myproject worker -l info`
31. Почему в задачи Celery категорически рекомендуется передавать ID объекта (int/UUID), а не сам экземпляр Django-модели? >> Данные в БД могут измениться к моменту выполнения; воркер получает актуальный объект по ID
32. Как настроить автоматический повтор задачи через 60 секунд? >> `default_retry_delay=60` в декораторе задачи
33. В чем преимущество использования @shared_task вместо app.task в приложениях Django? >> Позволяет создавать задачи без импорта конкретного экземпляра приложения Celery
34. Почему рекомендуется `namespace='CELERY'` в `app.config_from_object` ? >> Celery будет искать только настройки с префиксом `CELERY_` в `settings.py`
35. Что такое Celery в контексте веб-разработки? >> Распределённая очередь задач для выполнения кода в фоновом режиме или по расписанию
36. В чём разница между прямым вызовом и `.delay()` ? >> Прямой вызов – синхронный; `.delay()` отправляет задачу в очередь и немедленно возвращает управление
37. Как вынести тяжелую операцию (например, генерацию PDF на 30 сек) в фоновый режим с помощью Celery? >> Оформить как `@shared_task` и вызвать через `.delay()`
38. Что произойдёт с задачей если воркер не запущен после `.delay()` ? >> Задача останется в очереди брокера до запуска воркера
39. Как передать аргументы через `.delay()` ? >> `task_name.delay(arg1, arg2)` – как в обычной функции
40. Как отложить выполнение задачи на 10 минут через `apply_async` ? >> `task.apply_async(countdown=600)`
41. Как в Celery Beat настроить периодическую задачу с простым интервалом (каждые 5 минут) без использования crontab? >> `schedule=300.0` – количество секунд
42. Что такое Celery Beat? >> Планировщик, отправляющий задачи в очередь по расписанию – аналог cron
43. Что произойдёт при `result.get(timeout=10)` если задача не завершится за 10 секунд? >> Celery выбросит `TimeoutError`
