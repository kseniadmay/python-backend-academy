1. Что произойдет, если в `APIRouter` не указать параметр `prefix` ? >> Пути считаются от корня если иное не задано при подключении в `main.py`
2. Зачем эндпоинт объявляют через `async def` , а не через обычный `def` , в FastAPI? >> Чтобы неблокирующе выполнять операции ввода-вывода
3. Что происходит со значением параметра пути, если указать `user_id: int` ? >> Оно приводится (валидируется) к типу `int`

5. Каково основное назначение `APIRouter` в FastAPI? >> Разбивка большого приложения на отдельные модули для обеспечения структурированности
6. В какой структуре описываются дополнительные ответы в `APIRouter` ? >> В словаре ( `dict` )
7. Что определяет параметр `prefix` в `APIRouter` ? >> Строку с которой начинаются пути всех эндпоинтов роутера
8. Какой путь у `GET /` в роутере `users` если `prefix="/users"` ? >> `/users/`
9. Каким методом подключаются роутеры к приложению? >> `app.include_router()`
10. Из какого модуля импортируется `APIRouter` ? >> `from fastapi import APIRouter`
11. Где отображаются `title` и `version` из `FastAPI(title="My API", version="1.0.0")` ? >> В заголовке автоматически сгенерированной Swagger/ReDoc документации
12. Для чего используется параметр `tags` в `APIRouter` ? >> Для логической группировки эндпоинтов в Swagger-документации
13. Какое ключевое слово используется перед `db.users.all()` внутри `async` -функции? >> `await`
14. Как FastAPI определяет, что аргумент функции `user_id` является параметром пути (Path Parameter)? >> По совпадению имени переменной в функции и в строке пути `{user_id}`
15. Откуда импортируется `Depends` для использования в роутере? >> `from fastapi import Depends`
16. В каком файле создаётся основной экземпляр приложения FastAPI? >> `main.py`
17. Если подключено три роутера, сколько раз вызывается `include_router` ? >> Три раза
18. Как импортировать роутер из `routers/users.py` ? >> `from routers import users`
19. Какое имя обычно присваивается переменной `APIRouter` в файлах роутеров? >> `router`
20. Какой HTTP-метод применяется для частичного обновления? >> `PATCH`
21. Какой инструмент Flask является аналогом `APIRouter` ? >> `Blueprint`
22. К какому тегу в Swagger относится `list_orders` если в `orders.py` задано `tags=["orders"]` ? >> `orders`

29. Какой HTTP-метод используется для создания пользователя? >> `POST`
