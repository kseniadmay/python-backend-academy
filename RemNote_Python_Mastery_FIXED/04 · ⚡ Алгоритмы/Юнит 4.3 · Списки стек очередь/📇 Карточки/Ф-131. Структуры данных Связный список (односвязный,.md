1. Главное отличие DLL от SLL? >> Каждый узел указывает и на следующий, и на предыдущий
2. Почему удаление из конца SLL – $O(n)$ ? >> Нужно пройти весь список чтобы найти предпоследний узел и обновить его `next`
3. Сложность вставки в конец DLL (с `tail` )? >> $O(1)$
4. Как реализован встроенный `list` в Python? >> Как динамический массив (contiguous block of memory), не связный список
5. Сложность поиска в SLL и DLL? >> $O(n)$
6. Чему равен `next` у последнего узла? >> `None`
7. Что такое связный список? >> Последовательность узлов, где каждый содержит данные и указатель(и) на соседние узлы
8. Что изменится в поиске при переходе с SLL на DLL? >> Ничего – поиск остаётся $O(n)$ в обоих случаях
9. Сложность вставки в конец SLL с `tail` ? >> $O(1)$
10. Сложность вставки в начало SLL и DLL? >> $O(1)$
11. Три атрибута узла DLL? >> `val` , `next` , `prev`
12. Сложность удаления из начала SLL и DLL? >> $O(1)$
13. Может ли SLL удалять из конца за $O(1)$ ? >> Нет – даже с `tail` нет доступа к предпоследнему узлу без перебора
14. Какая структура Python реализована на основе двусвязного списка? >> `collections.deque` – двусторонняя очередь, даёт $O(1)$ добавление и удаление с обоих концов
15. Куда указывает узел в SLL? >> Только на следующий
16. Роль атрибута `head` ? >> Указатель на первый узел списка
17. Сложность доступа по индексу в SLL и DLL? >> $O(n)$
18. Почему доступ по индексу $O(n)$ ? >> Нет прямой адресации: нужно перебирать узлы по цепочке от `head`
19. Чему равен `prev` у первого узла DLL? >> `None`
20. Что такое Node? >> Элемент связного списка: данные и ссылки на соседние узлы
21. Чему равен `head` при инициализации пустого списка? >> `None`
22. Сложность вставки в конец SLL без `tail` ? >> $O(n)$ – нужно дойти до последнего узла
23. Из чего состоит узел односвязного списка (SLL)? >> Данные ( `val` ) и указатель на следующий узел ( `next` )
24. Как располагаются элементы связного списка в памяти? >> Не подряд – в произвольных местах; узлы связаны ссылками, а не физическим соседством
25. Сложность удаления из конца DLL (с `tail` )? >> $O(1)$ – через `tail.prev` сразу доступен предпоследний узел
