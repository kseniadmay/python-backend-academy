1. Когда движется левая граница в `min_subarray_len` ? >> Когда условие выполнено ( `window_sum >= target` ) – сжимаем окно, пытаясь найти меньшую длину
2. Когда движется правая граница в `min_subarray_len` ? >> Всегда – правая граница расширяет окно; когда сумма ≥ target, обновляем ответ и сжимаем слева
3. Ограничение скользящего окна? >> Только непрерывные подпоследовательности
4. Принцип `reverse_array` через два указателя? >> Указатели с обоих концов меняют элементы местами и движутся к центру
5. Как обновляется сумма окна при сдвиге? >> `window_sum = window_sum - arr[i - k] + arr[i]` – убрать ушедший, добавить новый
6. Тип окна для longest unique substring? >> Переменного размера
7. Три применения двух указателей? >> Поиск пар в отсортированных массивах, проверка палиндрома, слияние двух массивов
8. Принцип `is_palindrome` через два указателя? >> Указатели с обоих концов движутся навстречу; сравнивают символы до пересечения
9. Память базовых реализаций двух указателей? >> $O(1)$
10. Что хранит `char_index` в `longest_unique_substring` ? >> Последний встреченный индекс каждого символа
11. Для каких массивов применяется метод двух указателей? >> Отсортированных или при поиске пар с заданным условием
12. Что если массив не отсортирован? >> Сначала отсортировать $O(n \log n)$ ; итоговая сложность $O(n \log n)$
13. Что делает быстрый указатель в `remove_duplicates` ? >> Сканирует массив в поисках уникальных элементов
14. Почему важно `max(left, ...)` при обновлении левой границы? >> Без `max` `left` может прыгнуть назад если символ встречался до начала текущего окна
15. Сложность `max_sum_subarray` через sliding window? >> $O(n)$
16. Что такое скользящее окно (Sliding Window)? >> Подмассив фиксированного или переменного размера, перемещающийся по данным за один проход
17. Для чего sliding window в потоковых данных? >> Поддержание актуальных метрик по последним $N$ событиям без пересчёта с нуля
18. Что такое техника двух указателей? >> Два индекса перемещаются по массиву в определённом направлении для решения задачи за один проход
19. Что делать с `left` если символ уже встречался в окне? >> `left = max(left, char_index[s[right]] + 1)` – `max` защищает от смещения `left` назад за пределы текущего окна
20. Задачи для окна переменного размера? >> Длиннейшая/кратчайшая подпоследовательность с условием (уникальные символы, сумма ≥ target)
21. Что решают техники Two Pointers и Sliding Window по сложности? >> Снижают $O(n^2)$ до $O(n)$ за счёт избегания вложенных циклов
22. Задачи для окна фиксированного размера? >> Максимальная/минимальная сумма, среднее внутри окна заданной длины
23. Сложность поиска пары с суммой через два указателя? >> $O(n)$ при уже отсортированном массиве
24. Что делает медленный указатель в `remove_duplicates` ? >> Указывает позицию для записи следующего уникального элемента
