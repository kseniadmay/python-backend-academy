1. Два главных преимущества массивов? >> Быстрый доступ по индексу $O(1)$ и хорошая локальность данных (cache-friendly)
2. Сложность `append` в амортизированном смысле? >> $O(1)$
3. Почему поиск по значению не быстрее $O(n)$ ? >> Без сортировки нужно проверить каждый элемент последовательно
4. Есть ли встроенные статические массивы в Python? >> Нет; для однотипных данных используют `array.array` , для числовых вычислений – `numpy`
5. Что является динамическим массивом в Python? >> `list`
6. Меняется ли размер статического массива? >> Нет, задаётся при создании
7. Сложность вставки в начало или середину? >> $O(n)$
8. В чём разница между `len()` списка и его реальной ёмкостью (capacity)? >> `len()` возвращает количество элементов; ёмкость – фактически выделенных слотов под указатели, всегда ≥ `len()` ; посмотреть можно через `sys.getsizeof`
9. Сложность удаления из начала или середины? >> $O(n)$
10. Два основных недостатка динамических массивов? >> Медленная вставка/удаление в середине $O(n)$ и затраты на копирование при расширении
11. Сложность доступа по индексу? >> $O(1)$
12. Что такое статический массив? >> Фиксированная последовательность элементов одного типа в непрерывном блоке памяти; размер задаётся при создании и не меняется
13. Сложность удаления последнего элемента ( `pop()` )? >> $O(1)$
14. Сложность изменения значения по индексу? >> $O(1)$
15. Адрес элемента `[3]` если `base=100` и `int = 4` байта? >> 112
16. Является ли копирование при расширении бесплатным? >> Нет, $O(n)$ ; но происходит редко – логарифмически от числа операций
17. Почему доступ по индексу $O(1)$ ? >> Элементы расположены в памяти подряд; адрес вычисляется по формуле без перебора
18. Всегда ли `append` $O(1)$ ? >> Нет; при расширении массива – $O(n)$ , но в амортизированном смысле $O(1)$
19. Что происходит при заполнении динамического массива? >> Выделяется новый блок памяти большего размера, все элементы копируются туда
20. Формула вычисления адреса элемента? >> `base_address + index × element_size`
21. Сложность поиска по значению? >> $O(n)$
22. Что такое динамический массив? >> Массив, способный изменять размер в процессе работы за счёт перевыделения памяти
23. Адрес элемента `[1]` если `base=100` и `int = 4` байта? >> 104
24. Что такое амортизированная сложность? >> Среднее время одной операции, усреднённое по длинной последовательности операций
25. Почему вставка в начало $O(n)$ ? >> Все элементы правее позиции вставки сдвигаются на одну позицию вправо
26. Во сколько раз растёт блок памяти при расширении `list` в CPython? >> Примерно в 1.125 раза по формуле `new = old + (old >> 3) + 6` ; на практике говорят «в 1.5–2 раза» – допустимое упрощение
27. Что возвращает `sys.getsizeof()` для списка? >> Размер в байтах самого объекта `list` : структура + массив указателей на элементы; размер объектов, на которые указывают ссылки, не учитывается
