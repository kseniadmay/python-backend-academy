1. Упростите $O(500)$ ? >> $O(1)$
2. Упростите $O(n + \log n)$ ? >> $O(n)$
3. Как упрощается $O(n² + n)$ ? >> $O(n²)$ ; выбирается доминирующий член с наибольшей скоростью роста
4. Полный порядок возрастания сложностей? >> $O(1) < O(\log n) < O(n) < O(n \log n) < O(n²) < O(2^n) < O(n!)$
5. Упростите $O(3n²)$ ? >> $O(n²)$
6. Что описывает нотация Big O? >> Как растёт время выполнения или потребление памяти алгоритма в зависимости от размера входных данных
7. Сколько операций для $O(n)$ при $n=1000$ ? >> 1 000
8. Почему Big O не измеряет время в секундах? >> Время зависит от железа; Big O оценивает масштабируемость алгоритма независимо от оборудования
9. Как называется $O(n²)$ ? >> Квадратичная сложность; возникает при вложенных циклах
10. Как называется $O(2^n)$ ? >> Экспоненциальная сложность; характерна для полного перебора подмножеств
11. Сколько операций для $O(n²)$ при $n=1000$ ? >> 1 000 000
12. Упростите $O(2n)$ ? >> $O(n)$
13. Какой сценарий обычно описывает Big O? >> Худший случай (worst case)
14. Почему константы в Big O отбрасываются? >> Важна только скорость роста при больших n, а не абсолютные значения
15. Как называется $O(n)$ ? >> Линейная сложность; растёт пропорционально размеру входных данных
16. Как называется $O(\log n)$ ? >> Логарифмическая сложность; типична для бинарного поиска
17. Что произойдёт с $O(n²)$ , если данных в 10 раз больше? >> Время увеличится в 100 раз
18. $O(n)$ или $O(n \log n)$ – что медленнее? >> $O(n \log n)$
19. Сложность алгоритма с вложенным циклом (например, пузырьковая сортировка)? >> $O(n²)$
20. Как называется $O(1)$ ? >> Константная сложность; время выполнения не зависит от размера данных
21. $O(2^n)$ или $O(n!)$ – что растёт быстрее? >> $O(n!)$
22. Сколько операций для $O(\log n)$ при $n=1000$ ? >> ~10
23. Сложность алгоритма, проходящего по массиву один раз? >> $O(n)$
24. Как называется $O(n \log n)$ ? >> Линейно-логарифмическая сложность; характерна для эффективных алгоритмов сортировки (merge sort, quicksort в среднем)
25. Сложность бинарного поиска? >> $O(\log n)$ ; на каждом шаге отбрасывается половина оставшихся элементов
26. $O(2^n)$ или $O(n²)$ – что быстрее? >> $O(n²)$
27. Как называется $O(n!)$ ? >> Факториальная сложность; характерна для перебора всех перестановок
