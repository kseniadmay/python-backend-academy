# 🪆 К-122. Рекурсия (Recursion): стек вызовов, декомпозиция и переполнение стека

> **Ментальная модель — «Русская матрёшка и цепочка поручений»**:
> Чтобы узнать, сколько матрёшек внутри большой куклы, вы открываете внешнюю матрёшку и задаёте **тот же самый вопрос** матрёшке поменьше, пока не дойдёте до самой маленькой цельной фигурки, которая не открывается (**Базовый случай / Base Case** — ответ `1`). После этого ответы складываются в обратном порядке от маленькой к большой (**раскрутка стека вызовов**).

---

## 1. Два обязательных компонента любой рекурсии

Любая корректная рекурсивная функция обязана содержать:
1. **Базовый случай (Base Case / Условие выхода)** — простейший вход, для которого ответ известен сразу без новых рекурсивных вызовов (например, `n <= 1` или `node is None`). Без базового случая рекурсия бесконечна!
2. **Рекурсивный шаг (Recursive Step)** — сведение задачи к **строго меньшей** подзадаче того же типа, приближающей аргументы к базовому случаю (`n - 1`, `n // 2`, `node.left`).

```text
Жизненный цикл стека вызовов (Call Stack) при вычислении factorial(3):

Фаза 1: Погружение (Push кадров в стек)          Фаза 2: Возврат и вычисление (Pop кадров)
+-----------------------------------+            +-----------------------------------+
| Кадр 3: factorial(1) -> Base Case!|  ======>   | Возвращает 1                      |
| Кадр 2: factorial(2) ждёт f(1)    |            | Вычисляет 2 * 1 = 2               |
| Кадр 1: factorial(3) ждёт f(2)    |            | Вычисляет 3 * 2 = 6 (ИТОГ)        |
+-----------------------------------+            +-----------------------------------+
```

## 2. Стек вызовов (Call Stack), `RecursionError` и TCO в Python

Каждый рекурсивный вызов выделяет в оперативной памяти новый **стековый кадр (Stack Frame)**, хранящий локальные переменные и точку возврата.
Поэтому **пространственная сложность рекурсии всегда не меньше максимальной глубины дерева вызовов $O(\text{depth})$**!

- **Лимит глубины в CPython**: по умолчанию `sys.getrecursionlimit()` равен **$1000$** кадров. При превышении выбрасывается исключение **`RecursionError: maximum recursion depth exceeded`** (защита от аварийного падения C-стека `Stack Overflow`).
- **Есть ли в Python оптимизация хвостовой рекурсии (Tail Call Optimization, TCO)?**
  **Нет!** Гвидо ван Россум сознательно отказался от TCO в CPython, чтобы не искажать трассировки стека (`Traceback`) при отладке. Поэтому любую глубокую линейную рекурсию в Python следует переписывать через **обычный цикл `while`/`for` или явный стек `list`**.

| Тип рекурсии | Глубина стека (Space) | Время (Time) | Пример |
| :--- | :--- | :--- | :--- |
| **Линейная** (`f(n)` вызывает `f(n-1)`) | $O(n)$ | $O(n)$ | Факториал, сумма списка |
| **Логарифмическая** (`f(n)` вызывает `f(n//2)`) | **$O(\log n)$** | **$O(\log n)$** | Быстрое возведение в степень, бинарный поиск |
| **Разветвлённая по дереву** (`f(left)` + `f(right)`) | **$O(h)$** (высота дерева) | $O(n)$ | Обход бинарного дерева, `maxDepth` |
| **Древовидная с перекрытием без кэша** (`f(n-1) + f(n-2)`) | $O(n)$ | **$O(2^n)$ (катастрофа!)** | Наивный Фибоначчи без мемоизации |

> **Junior vs Senior**:
> - **Junior**: Использует рекурсию для простого линейного прохода по списку из $50\,000$ элементов или поднимает `sys.setrecursionlimit(100_000)`, рискуя уронить процесс сегфолтом операционной системы.
> - **Senior**: Применяет рекурсию там, где структура данных сама рекурсивна и имеет логарифмическую глубину (деревья, графы, парсинг вложенного JSON, `Divide & Conquer`), а для глубоких графов или линейных цепочек переходит к **итеративному алгоритму с явным стеком `stack = [root]`**.

```python
from typing import Any

# 1. Где рекурсия идеальна: обход произвольно вложенного JSON-словаря / списка
def sum_nested_numbers(data: Any) -> int:
    """Суммирует все числа на любой глубине вложенности словарей и списков."""
    if isinstance(data, int):          # Базовый случай: само число
        return data
    if isinstance(data, list):         # Рекурсивный шаг по элементам списка
        return sum(sum_nested_numbers(item) for item in data)
    if isinstance(data, dict):         # Рекурсивный шаг по значениям словаря
        return sum(sum_nested_numbers(val) for val in data.values())
    return 0

# 2. Замена глубокой рекурсии на итеративный цикл за O(1) памяти (защита от RecursionError)
def factorial_iterative(n: int) -> int:
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result

payload = {"a": 10, "b": [20, {"c": 30, "d": [40, 50]}], "meta": "ok"}
print("Сумма чисел во вложенном JSON:", sum_nested_numbers(payload))
print("Итеративный факториал 6! за O(1) памяти:", factorial_iterative(6))
```
