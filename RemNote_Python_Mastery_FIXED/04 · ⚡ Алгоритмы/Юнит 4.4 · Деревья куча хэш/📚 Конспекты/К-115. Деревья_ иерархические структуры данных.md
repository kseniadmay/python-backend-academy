# 🌳 К-115. Деревья (Trees): бинарное дерево, обходы (DFS/BFS) и дерево поиска (BST)

> **Ментальная модель — «Генеалогическое древо и игра Больше/Меньше»**:
> - **Дерево (Tree)** — это связный ациклический граф с выделенной вершиной — **корнем (Root)**. В отличие от реальных деревьев, в информатике корень рисуют **сверху**, а **листья (Leaves)** — узлы без потомков — **снизу**.
> - **Бинарное дерево поиска (Binary Search Tree, BST)** устроено как телефонный справочник с развилками: в каждом узле **все** значения в левом поддереве строго меньше узла, а **все** значения в правом поддереве — строго больше!

---

## 1. Терминология и виды бинарных деревьев

- **Бинарное дерево (Binary Tree)** — дерево, в котором у каждого узла не более двух потомков: `left` и `right`.
- **Глубина узла (Depth)** — число рёбер от корня до этого узла (глубина корня $= 0$).
- **Высота дерева (Height / `maxDepth`)** — максимальное число узлов (или рёбер) на пути от корня до самого дальнего листа.
- **Сбалансированное дерево (Balanced Tree — AVL, Red-Black Tree)** — дерево, в котором высоты левого и правого поддеревьев любого узла отличаются не более чем на $1$. Его высота гарантированно равна **$h = O(\log n)$**.
- **Вырожденное дерево (Degenerate / Skewed Tree)** — дерево, в которое элементы вставляли в уже отсортированном порядке (`1 -> 2 -> 3 -> 4`). Оно превращается в обычный связный список с высотой **$h = O(n)$**!

```text
Сбалансированное BST (высота O(log n)):          Вырожденное BST (вставка 1, 2, 3, 4 -> высота O(n)):

            [ 8 ]  <-- Корень (Root)                     [ 1 ]
           /     \                                          \
        [ 3 ]   [ 10 ]                                     [ 2 ]
        /   \        \                                         \
     [ 1 ] [ 6 ]    [ 14 ]  <-- Листья (Leaves)               [ 3 ]
                                                                  \
                                                                 [ 4 ]
```

## 2. Четыре канонических обхода дерева (Tree Traversals)

Пусть дано дерево с корнем `8`, левым поддеревом `(3: 1, 6)` и правым `(10: -, 14)`:

| Вид обхода | Порядок посещения | Результат на примере выше | Главное применение |
| :--- | :--- | :--- | :--- |
| **Pre-order (Прямой DFS)** | **Корень** $\to$ Лево $\to$ Право | `8, 3, 1, 6, 10, 14` | Клонирование и сериализация структуры дерева |
| **In-order (Симметричный DFS)** | Лево $\to$ **Корень** $\to$ Право | `1, 3, 6, 8, 10, 14` | В **BST** выдаёт элементы в **строго отсортированном порядке**! |
| **Post-order (Обратный DFS)** | Лево $\to$ Право $\to$ **Корень** | `1, 6, 3, 14, 10, 8` | Подсчёт высоты/размера поддеревьев, удаление дерева снизу вверх |
| **Level-order (Поуровневый BFS)** | Уровень $0 \to 1 \to 2 \dots$ (через `deque`) | `8`, затем `3, 10`, затем `1, 6, 14` | Поиск кратчайшего пути от корня, послойная печать |

## 3. Бинарное дерево поиска (BST) и ловушка валидации

Инвариант **BST**: для **каждого** узла `node` все ключи в его левом поддереве строго меньше `node.val`, а все ключи в правом поддереве — строго больше `node.val`.

> **Junior vs Senior**:
> - **Junior**: Проверяет валидность BST локально: `node.left.val < node.val < node.right.val`. Этот код ошибочно признает валидным дерево с корнем `10`, у которого справа стоит `15`, а слева от `15` — узел `6` (хотя `6 < 10`, и узел `6` не имеет права находиться в правом поддереве десятки!).
> - **Senior**: Передаёт при рекурсивном спуске **допустимый интервал `(low, high)`**: при шаге влево верхняя граница сужается до `(low, node.val)`, а при шаге вправо нижняя граница сужается до `(node.val, high)`. Либо проверяет, что `In-order` обход строго возрастает.

```python
from __future__ import annotations
from collections import deque

class TreeNode:
    def __init__(self, val: int, left: TreeNode | None = None, right: TreeNode | None = None) -> None:
        self.val = val
        self.left = left
        self.right = right

def insert_bst(root: TreeNode | None, val: int) -> TreeNode:
    """Вставка в BST за O(h), где h — высота дерева."""
    if root is None:
        return TreeNode(val)
    if val < root.val:
        root.left = insert_bst(root.left, val)
    elif val > root.val:
        root.right = insert_bst(root.right, val)
    return root

def inorder_dfs(root: TreeNode | None) -> list[int]:
    """Симметричный обход (Лево -> Корень -> Право): для BST возвращает отсортированный список."""
    if root is None:
        return []
    return inorder_dfs(root.left) + [root.val] + inorder_dfs(root.right)

def is_valid_bst(root: TreeNode | None, low: float = float("-inf"), high: float = float("inf")) -> bool:
    """Строгая проверка инварианта BST через сужение границ (low, high) за O(n)."""
    if root is None:
        return True
    if not (low < root.val < high):
        return False
    return is_valid_bst(root.left, low, root.val) and is_valid_bst(root.right, root.val, high)

def level_order_bfs(root: TreeNode | None) -> list[list[int]]:
    """Поуровневый обход (BFS) с использованием очереди deque за O(n)."""
    if root is None:
        return []
    levels: list[list[int]] = []
    q: deque[TreeNode] = deque([root])
    while q:
        level_vals: list[int] = []
        for _ in range(len(q)):
            node = q.popleft()
            level_vals.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        levels.append(level_vals)
    return levels

bst_root: TreeNode | None = None
for v in [8, 3, 10, 1, 6, 14]:
    bst_root = insert_bst(bst_root, v)

print("In-order обход BST (всегда отсортирован):", inorder_dfs(bst_root))
print("Level-order (по уровням):", level_order_bfs(bst_root))
print("Дерево является валидным BST:", is_valid_bst(bst_root))
```
