1. Что вернёт `db1 is db2` для Singleton? >> `True` ; оба указывают на один объект в памяти
2. Чем Singleton отличается от обычной глобальной переменной? >> Singleton контролирует создание через класс и предоставляет одну точку доступа; глобальная переменная – просто переменная без ограничений на создание объектов
3. Какие объекты целесообразно реализовывать как Singleton? >> Подключение к БД, пул соединений, конфигурация приложения, логгер; объекты с разделяемыми ресурсами, существующими в единственном числе
4. Что такое ленивая инициализация в контексте Singleton? >> Экземпляр создаётся не при старте программы, а при первом обращении к нему
5. Как сделать Singleton потокобезопасным? >> Использовать `threading.Lock()` : блокировать `_lock` перед проверкой `_instance` ; применять паттерн double-checked locking
6. К какому типу паттернов относится Singleton? >> Порождающие (Creational); управляет созданием объектов
7. Почему Singleton усложняет unit-тестирование? >> Глобальное состояние сохраняется между тестами; трудно изолировать тест; сложно подменить мок-объектом
8. Какая проблема возникает у стандартного Singleton в многопоточной среде? >> Два потока могут одновременно пройти проверку `if _instance is None` и создать два разных экземпляра
9. В чём самый «питоничный» способ реализации Singleton? >> Использование модуля: Python импортирует модуль один раз, все последующие импорты возвращают один и тот же объект
10. Что такое паттерн Singleton? >> Порождающий паттерн, гарантирующий существование ровно одного экземпляра класса и предоставляющий глобальную точку доступа к нему
11. Почему модуль Python является Singleton? >> При первом импорте модуль инициализируется и кэшируется в `sys.modules` ; повторные импорты возвращают тот же объект
12. Как хранится ссылка на единственный экземпляр в реализации через `__new__` ? >> В атрибуте класса `_instance` ; подчёркивание обозначает внутреннее (protected) использование
13. Какой принцип SOLID нарушает Singleton? >> SRP (Single Responsibility Principle): класс одновременно выполняет свои функции и управляет собственным жизненным циклом
14. Какие минусы у Singleton? >> Глобальное состояние усложняет тестирование; скрытые зависимости; нарушение SRP; сложность в многопоточной среде
15. Как реализовать Singleton через `__new__` в Python? >> Переопределить `__new__` : если `_instance is None` – создать и сохранить в `cls._instance` ; иначе вернуть существующий
