## 1. Паттерн Strategy (Стратегия): меняем «мозги» алгоритма на лету

> **Ментальная модель — «Построение маршрута в навигаторе»**:
> Вы ставите точку `А` (дом) и точку `Б` (офис). Навигатор (`Context`) умеет рисовать карту и вести по маршруту, но **алгоритм расчёта пути (`Strategy`)** вы переключаете одной кнопкой: `🚗 На автомобиле` (по шоссе с учётом пробок), `🚶 Пешком` (через дворы и парки) или `🚇 На метро` (по станциям). Сам навигатор при переключении кнопки не переписывается — он просто вызывает метод `.build_route(a, b)` у выбранной стратегии!

**Strategy (Стратегия)** — поведенческий паттерн проектирования, который выделяет семейство алгоритмов в отдельные классы (или функции) с единым интерфейсом и позволяет подменять их во время выполнения программы (в рантайме) независимо от клиента (`Context`).

```text
Структура паттерна Strategy:

  +------------------------------+          +----------------------------------+
  |      ShippingCalculator      |          |      <<ShippingStrategy>>        |
  |          (Context)           | -------> | + calculate_cost(weight_kg) -> int|
  | - strategy: ShippingStrategy |          +----------------------------------+
  | + set_strategy(s)            |                   ^        ^        ^
  | + checkout(weight_kg)        |                   |        |        |
  +------------------------------+          CourierStrategy  Post   PickupPoint
```

## 2. Чем Strategy отличается от Factory и от обычного `if/elif`?

Новички часто спрашивают: *«В чём разница между Factory (Фабрикой) и Strategy (Стратегией)?»*

| Характеристика | Паттерн Factory (Порождающий) | Паттерн Strategy (Поведенческий) |
| :--- | :--- | :--- |
| **Главная цель** | **Создать** подходящий объект и вернуть его клиенту | **Выполнить алгоритм** расчёта/действия и позволить менять его на лету |
| **Момент работы** | В момент **инициализации** (`notifier = factory.create("sms")`) | В момент **выполнения бизнес-логики** (`cart.set_discount_strategy(VipDiscount())`) |
| **Как они работают вместе?** | Фабрика часто создаёт нужную Стратегию по строке из JSON-запроса (`strategy = PricingFactory.get(req.tariff)`) | Контекст (`Order`) принимает созданную стратегию и вызывает `strategy.calculate(order)` |

## 3. Классическая ООП-Стратегия vs Функциональная Стратегия в Python

В языках вроде Java стратегия всегда требует создания интерфейса и отдельных классов. В Python у нас есть два инструмента:
1. **Функциональная стратегия (`Callable`)**: если у алгоритма нет внутреннего состояния (только вход $\to$ выход), стратегией может быть обычная функция, переданная как аргумент!
2. **Объектная стратегия (`Protocol` / `@dataclass`)**: если стратегия хранит собственные настройки (например, `FixedDiscount(min_total=1000, discount_rub=300)` или `LoyaltyBonusStrategy(user_points=450)`), её оформляют как класс.

> **Junior vs Senior**:
> - **Junior**: Пишет функцию `calculate_price(total, promo_type, vip_level, is_black_friday, bonus_points)` на 150 строк из вложенных `if/elif/else`. При добавлении новой акции ломаются старые скидки.
> - **Senior**: Выносит каждое правило ценообразования в изолированную `PricingStrategy`. Каждая стратегия покрывается 3 строками модульного теста, а при необходимости стратегии комбинируются в цепочку (`CompositeStrategy`).

## 4. Практикум: переключение стратегий расчёта доставки и скидок в рантайме

```python
from dataclasses import dataclass
from typing import Protocol

class DiscountStrategy(Protocol):
    def apply(self, subtotal: float) -> float: ...

@dataclass(frozen=True)
class NoDiscount:
    def apply(self, subtotal: float) -> float:
        return subtotal

@dataclass(frozen=True)
class PercentDiscount:
    percent: float
    def apply(self, subtotal: float) -> float:
        return round(subtotal * (1.0 - self.percent / 100.0), 2)

@dataclass(frozen=True)
class ThresholdDiscount:
    threshold: float
    discount_amount: float
    def apply(self, subtotal: float) -> float:
        return max(0.0, subtotal - self.discount_amount) if subtotal >= self.threshold else subtotal

class ShoppingCart:
    def __init__(self, strategy: DiscountStrategy | None = None) -> None:
        self._items: list[float] = []
        self._strategy: DiscountStrategy = strategy or NoDiscount()

    def add_item(self, price: float) -> None:
        self._items.append(price)

    def set_discount_strategy(self, strategy: DiscountStrategy) -> None:
        self._strategy = strategy

    def total(self) -> float:
        return self._strategy.apply(sum(self._items))

cart = ShoppingCart()
cart.add_item(1200.0)
cart.add_item(800.0)
print("Без скидки:", cart.total())

cart.set_discount_strategy(PercentDiscount(15))
print("Со скидкой 15%:", cart.total())

cart.set_discount_strategy(ThresholdDiscount(threshold=1500.0, discount_amount=400.0))
print("По купону -400 руб. от 1500:", cart.total())
```
