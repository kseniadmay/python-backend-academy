1. Как применить изменения в `~/.bashrc` без перезапуска терминала? >> `source ~/.bashrc` или `. ~/.bashrc`
2. Какая переменная содержит имя текущего пользователя? >> `$USER` (стандартная переменная окружения Unix/Linux с логином активного пользователя)
3. Какая переменная возвращает путь к текущей рабочей директории? >> `$PWD` ; обновляется автоматически при каждом `cd`
4. Как проверить, успешно ли выполнилась предыдущая команда? >> `echo $?` ; если вывод `0` – команда завершилась успешно
5. Какая переменная хранит путь к текущей оболочке? >> `$SHELL` (например, `/bin/bash` или `/bin/zsh` — путь к командному интерпретатору пользователя)
6. Как вывести значение переменной `HOME` на экран? >> `echo $HOME`
7. Как вывести значение конкретной переменной `PATH` без `echo` ? >> `printenv PATH`
8. Почему `.env` -файл не следует коммитить в репозиторий? >> Он содержит секреты (ключи API, пароли, DSN БД); его добавляют в `.gitignore` и хранят отдельно
9. Что произойдёт, если добавить директорию в `PATH` без `export` ? >> Изменение останется локальным в текущей оболочке и не передастся дочерним процессам
10. Как передать переменную окружения только одному запуску команды? >> `MY_VAR=test python script.py` ; переменная существует только на время этой команды и не попадает в текущую сессию
11. Какая переменная хранит PID текущего процесса оболочки? >> `$$` ; например `echo $$` выведет PID текущего bash/zsh
12. Где будет доступна переменная, установленная через `export MY_VAR=test` ? >> В текущей сессии и всех порождённых ею дочерних процессах; после закрытия терминала – исчезнет
13. Какая переменная хранит путь к домашней директории текущего пользователя? >> `$HOME` (например, `/home/username` или `/root` в Linux)
14. Чем переменная окружения отличается от переменной оболочки? >> Переменная оболочки видна только в текущем shell-процессе; переменная окружения ( `export` ) передаётся дочерним процессам как часть их окружения
15. Для чего предназначена переменная `PATH` ? >> Содержит список директорий через `:` , в которых shell ищет исполняемые файлы; позволяет запускать программы без указания полного пути
16. Как загрузить переменные из `.env` -файла в текущую сессию bash вручную? >> `export $(grep -v '^#' .env | xargs)` ; `xargs` читает строки и передаёт их в `export`
17. Какая команда делает переменную доступной в дочерних процессах? >> `export MY_VAR=hello` ; переменная становится частью окружения (environment), а не только локальной переменной shell
18. Какая команда выводит список всех переменных окружения текущей сессии? >> `env` ; также можно использовать `printenv` без аргументов
19. В какой файл добавляют `export` для постоянного сохранения переменных в bash? >> `~/.bashrc` – для интерактивных non-login сессий; `~/.bash_profile` или `~/.profile` – для login-сессий
20. Что содержит переменная `$?` ? >> Код возврата последней выполненной команды; `0` – успех, любое другое значение – ошибка
21. Какой символ ставится перед именем переменной для получения её значения в shell? >> `$` ; например `echo $HOME`
22. Как загрузить `.env` -файл в Python-приложении? >> `python-dotenv` : `from dotenv import load_dotenv; load_dotenv()` – загружает переменные в `os.environ` ; переменные, уже установленные в окружении, по умолчанию не перезаписываются
23. Какова область видимости переменной, созданной командой `MY_VAR=hello` ? >> Только текущая оболочка; дочерние процессы и скрипты её не видят
