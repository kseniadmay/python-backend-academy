1. Как перейти в домашнюю директорию пользователя? >> `cd ~` или просто `cd` без аргументов
2. Какой флаг `grep` выводит только количество найденных совпадений? >> `-c` (count — выводит только число совпавших строк)
3. Какой флаг `grep` включает поиск без учёта регистра? >> `-i` (ignore-case — ищет и строчные, и заглавные буквы)
4. Как рекурсивно сменить владельца всего каталога `/var/www/` на `www-data` ? >> `chown -R www-data:www-data /var/www/`
5. Как объединить вывод двух файлов в терминале? >> `cat file1.txt file2.txt`
6. Какой аргумент `find` ограничивает поиск только обычными файлами? >> `-type f` ; для директорий – `-type d`
7. Какой флаг `cp` сохраняет атрибуты файла (права, дата, владелец)? >> `-p` (preserve — сохраняет метаданные, права доступа и временные метки)
8. Как создать новую директорию `mydir` ? >> `mkdir mydir`
9. Какая команда выводит полный путь к текущей рабочей директории? >> `pwd` (print working directory — показывает абсолютный путь от корня `/`)
10. Какая команда используется и для перемещения, и для переименования файлов? >> `mv` ; переименование – это перемещение в тот же каталог с новым именем
11. Какой флаг `chmod` применяет изменения рекурсивно ко всей директории? >> `-R` (recursive — обходит все вложенные папки и файлы)
12. Какой флаг `ls` делает размер файлов удобочитаемым (KB, MB, GB)? >> `-h` ; обычно используется в связке `ls -lh`
13. Какой флаг `ls` показывает подробную информацию (права, владелец, размер, дата)? >> `-l` (long listing format — табличный вывод прав, владельца, размера и времени)
14. Как найти файлы, изменённые за последние 24 часа? >> `find . -mtime -1`
15. Какая команда меняет владельца и группу файла? >> `chown` (change owner — например, `chown user:group file.txt`)
16. Как перейти в директорию `/var/log` по абсолютному пути? >> `cd /var/log`
17. Как сменить владельца `file.txt` на `user` и группу на `group` ? >> `chown user:group file.txt`
18. Какая команда изменяет права доступа к файлу или директории? >> `chmod` (change mode — например, `chmod 755 script.sh` или `chmod +x script.sh`)
19. Как вывести строки, которые НЕ содержат шаблон (инвертированный поиск)? >> `grep -v "шаблон" file`
20. Какой флаг `mkdir` позволяет создать цепочку вложенных директорий? >> `-p` ; например `mkdir -p a/b/c` создаст все промежуточные папки
21. Как автоматически удалить все `.pyc` -файлы через `find` ? >> `find . -name "*.pyc" -delete`
22. Какая команда используется для поиска строк по шаблону внутри файлов? >> `grep` (фильтрует текстовый поток или файлы по регулярному выражению)
23. Как вернуться на один уровень выше в дереве директорий? >> `cd ..` (две точки `..` обозначают родительский каталог)
24. Какой флаг `cp` нужен для рекурсивного копирования директории? >> `-r` (или `-R` — копирует саму папку и всё дерево файлов внутри неё)
25. Какая команда используется для поиска файлов и директорий по различным критериям? >> `find` (ищет объекты в дереве каталогов по имени `-name`, типу `-type`, размеру `-size` и дате)
26. Что означают права `644` ( `rw-r--r--` )? >> Владелец: `rw-` ; группа и остальные: `r--` ; типичные права для обычных файлов
27. Какой флаг `rm` запрашивает подтверждение перед удалением каждого файла? >> `-i` (interactive — спрашивает `y/n` перед каждым удалением)
28. Чем `rm -rf /` отличается от `rm -rf ./` ? >> `rm -rf /` рекурсивно удаляет корневую файловую систему (уничтожает систему); `rm -rf ./` удаляет только текущую директорию – принципиальная ловушка при опечатке
29. Как выполнить рекурсивный поиск слова `TODO` во всех файлах директории `src/` ? >> `grep -r "TODO" src/`
30. Какая команда выводит содержимое файла в терминал? >> `cat file.txt`
31. Какой флаг `grep` показывает номера строк с совпадениями? >> `-n` (line-number — печатает номер строки в файле перед каждым совпадением)
32. Как переименовать `old_name.txt` в `new_name.txt` ? >> `mv old_name.txt new_name.txt`
33. Что делает флаг `-f` в команде `rm` ? >> Принудительно удаляет файлы без запроса подтверждения; `rm -rf` – рекурсивно и без подтверждения; опасная комбинация
34. Как отобразить скрытые файлы вместе с подробной информацией? >> `ls -la` ; флаг `-a` включает файлы, начинающиеся с точки
35. Как рекурсивно удалить директорию со всем содержимым? >> `rm -r mydir/`
36. Как вернуться в предыдущую рабочую директорию? >> `cd -` ; удобно для переключения между двумя директориями
37. Что означают права `755` ( `rwxr-xr-x` )? >> Владелец: `rwx` ; группа: `r-x` ; остальные: `r-x` ; типичные права для исполняемых файлов и директорий
38. Какой флаг `grep` включает расширенные регулярные выражения? >> `-E` ; позволяет использовать `|` , `+` , `?` , `{n}` без экранирования
39. Как скопировать `file.txt` в `backup.txt` ? >> `cp file.txt backup.txt`
40. Как перейти в корневой каталог системы? >> `cd /` (слэш `/` — это корень всей файловой иерархии Linux)
41. Какой флаг `cat` добавляет номера строк к выводу? >> `-n` (нумерует все выводимые строки по порядку, начиная с 1)
42. Как найти все файлы с расширением `.log` в `/var/log` ? >> `find /var/log -name "*.log"`
43. Как добавить право на выполнение файлу `script.sh` , не затрагивая остальные права? >> `chmod +x script.sh`
44. Какая команда выводит список файлов и директорий в текущем каталоге? >> `ls` (list — перечисляет содержимое выбранной или текущей директории)
45. Что означают цифры в числовом представлении прав доступа? >> `4` – чтение (r), `2` – запись (w), `1` – выполнение (x); права суммируются: `7=rwx` , `6=rw` , `5=rx` , `4=r`
46. Как найти файлы размером более 10 МБ? >> `find . -size +10M`
47. Как удалить файл `file.txt` ? >> `rm file.txt`
