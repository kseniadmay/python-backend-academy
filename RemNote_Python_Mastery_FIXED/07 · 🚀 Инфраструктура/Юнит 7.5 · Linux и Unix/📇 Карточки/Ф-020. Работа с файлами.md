1. Как посмотреть суммарный размер директории `/var/log` ? >> `du -sh /var/log`
2. Как в реальном времени просматривать лог, фильтруя только строки с `ERROR` ? >> `tail -f app.log | grep ERROR`
3. Как посмотреть размер каждого объекта в текущей директории? >> `du -sh *`
4. Что делает флаг `-h` в `df` и `du` ? >> Выводит размеры в читаемом формате: KB, MB, GB
5. Какие клавиши перемещают вперёд при просмотре в `less` ? >> `пробел` или `f`
6. Как вырезать строку в `nano` ? >> `Ctrl+K` (вставить вырезанную строку обратно — `Ctrl+U`)
7. Для чего используется `wc` ? >> Подсчёт строк ( `-l` ), слов ( `-w` ) и байт ( `-c` ) в файле или потоке
8. Как сохранить файл в `nano` ? >> `Ctrl+O` , затем подтвердить `Enter`
9. Как перейти в начало файла в `vim` ? >> `gg` (две строчные `g` в Normal-режиме мгновенно переносят курсор на первую строку)
10. Какой флаг `sort` сортирует числа по значению, а не лексикографически? >> `-n` ; без него `10` окажется перед `9`
11. Какая клавиша выходит из `less` ? >> `q` (quit — закрывает просмотрщик и возвращает в терминал)
12. Как сохранить и выйти из `vim` одной командой? >> `:wq` или `ZZ`
13. Как выйти из `vim` ? >> `:q` ; если есть несохранённые изменения – `:q!` для выхода без сохранения
14. Как просмотреть первые 20 строк файла `file.txt` ? >> `head -n 20 file.txt`
15. Для чего используется `uniq` ? >> Удаляет или считает повторяющиеся соседние строки
16. Как вывести последние 50 строк файла `file.txt` ? >> `tail -n 50 file.txt`
17. Как перейти в конец файла в `less` ? >> `G` ; в начало – `g`
18. Как войти в режим Insert в `vim` ? >> `i` – вставка перед курсором; `a` – после курсора; выйти из Insert – `Esc`
19. Как подсчитать количество строк в файле? >> `wc -l file.txt`
20. Какая команда по умолчанию выводит первые 10 строк файла? >> `head` (без аргумента `-n` показывает ровно первые 10 строк)
21. Как запустить поиск по шаблону внутри `less` ? >> `/pattern` ; `n` – следующее совпадение, `N` – предыдущее
22. Какой флаг `sort` выводит только уникальные строки? >> `-u` ; эквивалент `sort | uniq`
23. Для чего используется `du` ? >> Оценивает объём, занятый конкретными файлами и директориями
24. Какое обязательное условие для корректной работы `uniq` ? >> Входные данные должны быть отсортированы; `uniq` сравнивает только соседние строки
25. Как войти в режим Visual в `vim` ? >> `v` (для построчного выделения — `V`, для блочного — `Ctrl+V`)
26. Какие три основных режима работы в `vim` ? >> Normal (навигация и команды), Insert (ввод текста), Visual (выделение); между режимами переключаются явно
27. Что делает `uniq -c` ? >> Выводит каждую уникальную строку с количеством её повторений
28. Для чего используется флаг `-f` в `tail` ? >> Отслеживает изменения файла в реальном времени (follow); удобно для мониторинга логов – не завершается, а ждёт новых строк
29. Как подсчитать количество байт в файле? >> `wc -c file.txt`
30. Для чего используется `df` ? >> Показывает использование дискового пространства смонтированными разделами
31. Для чего используется `sort` ? >> Сортировка строк файла; по умолчанию лексикографическая
32. Как перейти в конец файла в `vim` ? >> `G` (заглавная `Shift+G` в Normal-режиме переносит курсор на последнюю строку)
33. Как скопировать строку в `vim` ? >> `yy` (yank); вставить – `p`
34. Как удалить текущую строку в `vim` ? >> `dd` ; удалённая строка помещается в буфер и может быть вставлена через `p`
35. Как найти текст в `nano` ? >> `Ctrl+W` (Where Is — открывает строку поиска внизу экрана)
36. Как сохранить файл в `vim` ? >> `:w` (в Normal-режиме)
37. В чём основное преимущество `less` перед `more` ? >> `less` поддерживает навигацию в обе стороны, поиск по шаблону и не загружает файл целиком в память; `more` только вперёд
38. Чем `df` отличается от `du` ? >> `df` показывает свободное/занятое место на разделах целиком; `du` – фактический размер конкретных файлов и директорий
39. Какая команда по умолчанию выводит последние 10 строк файла? >> `tail` (без аргумента `-n` показывает ровно последние 10 строк)
40. Как выйти из `nano` ? >> `Ctrl+X` ; если есть несохранённые изменения, предложит сохранить
41. Какая клавиша перемещает назад в `less` ? >> `b` (back — пролистывает на один экран вверх/назад)
42. Какой текстовый редактор считается наиболее простым для начинающих? >> `nano` ; подсказки по горячим клавишам отображаются прямо в интерфейсе
43. Как заменить все вхождения `old` на `new` во всём файле в `vim` ? >> `:%s/old/new/g`
