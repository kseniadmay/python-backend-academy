1. Команда для просмотра списка всех локальных веток? >> `git branch` ; текущая ветка отмечена символом `*`
2. Что делает флаг `-c` в команде `git switch -c feature/auth` ? >> Создаёт новую ветку (от англ. create) и переключается на неё
3. Команда для принудительного удаления неслитой ветки? >> `git branch -D feature/auth` ; эквивалент `--delete --force` ; удаляет ветку независимо от статуса слияния
4. Что делает флаг `-b` в команде `git checkout -b feature/auth` ? >> Создаёт новую ветку перед переключением; без него `checkout` на несуществующую ветку завершится ошибкой
5. Копирует ли Git файлы проекта при создании новой ветки? >> Нет; создаётся только новый указатель (~41 байт), поэтому создание ветки в Git практически мгновенно и не зависит от размера репозитория
6. При каком условии `git branch -d feature/auth` удалит ветку? >> Только если ветка полностью слита (merged) в текущую ветку или её upstream; иначе Git выдаст ошибку
7. Как создать ветку `feature/auth` и сразу переключиться на неё (способ до Git 2.23)? >> `git checkout -b feature/auth`
8. Что происходит с `HEAD` при переключении ветки? >> `HEAD` начинает указывать на новую ветку; при следующем коммите именно эта ветка сдвинется вперёд
9. Базовая команда для создания ветки `feature/auth` без переключения на неё? >> `git branch feature/auth`
10. Как переименовать ветку с `old-name` на `new-name` ? >> `git branch -m old-name new-name` ; если вы уже на переименовываемой ветке, достаточно `git branch -m new-name`
11. Что такое detached HEAD? >> Состояние, при котором `HEAD` указывает напрямую на коммит, а не на ветку; новые коммиты в этом состоянии не принадлежат ни одной ветке и могут быть потеряны после переключения
12. Что представляет собой ветка в Git с технической точки зрения? >> Лёгкий указатель (файл в `.git/refs/heads/` ) на конкретный SHA-1 коммита; при новом коммите указатель автоматически смещается вперёд
13. Как переключиться на существующую ветку `main` (способ с Git 2.23+)? >> `git switch main`
14. Как просмотреть все ветки, включая remote-tracking? >> `git branch -a` ; remote-tracking ветки отображаются с префиксом `remotes/origin/`
15. Как просмотреть список веток вместе с их последними коммитами? >> `git branch -v`
16. Как удалить ветку `feature/auth` в удалённом репозитории `origin` ? >> `git push origin --delete feature/auth`
17. Как переключиться на существующую ветку `main` (старый способ)? >> `git checkout main`
18. Как создать ветку `feature/auth` и сразу переключиться на неё (способ с Git 2.23+)? >> `git switch -c feature/auth`
