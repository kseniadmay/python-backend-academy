1. Что такое метрики в контексте мониторинга? >> Числовые измерения состояния системы во времени; отвечают на вопрос «как система работает прямо сейчас»
2. Как удобнее всего собирать метрики для каждого запроса в Django? >> Через Middleware; функция `get_response` передаёт управление следующему слою и возвращает ответ, время которого замеряется
3. Что такое scraping в Prometheus? >> Периодический опрос эндпоинтов приложений для сбора актуальных значений метрик
4. Что делает `counter.inc()` без аргумента? >> Увеличивает счётчик на 1
5. Что даёт параметр `buckets` при создании `Histogram` ? >> Определяет границы интервалов для распределения значений; нужно выбирать бакеты под реальный диапазон измеряемых величин
6. Что такое тип метрики `Gauge` ? >> Текущее значение, которое может как расти, так и уменьшаться; отражает состояние системы в моменте
7. Что такое методология USE? >> Utilization (использование), Saturation (насыщение), Errors (ошибки); применяется для мониторинга инфраструктурных ресурсов (CPU, память, диск)
8. Чем метрики отличаются от логов? >> Логи описывают конкретные события («что именно случилось»); метрики – агрегированное числовое состояние системы («как она работает»)
9. Что такое «три столпа observability»? >> Логи (что произошло), Метрики (как работает система), Трейсинг (путь конкретного запроса)
10. Какие методы доступны для `Gauge` ? >> `.inc()` , `.dec()` , `.set(value)`
11. Что такое тип метрики `Histogram` ? >> Распределение значений по заранее определённым интервалам (бакетам); позволяет вычислять перцентили (p50, p95, p99)
12. Можно ли использовать `Counter` для текущего количества свободных мест на парковке? >> Нет; это значение может уменьшаться – нужен `Gauge`
13. Как инкрементировать метрику с конкретными значениями лейблов? >> `counter.labels(method="GET", status_code="200").inc()`
14. В чём разница между техническими и бизнес-метриками? >> Технические описывают работу системы (latency, error rate, CPU); бизнес-метрики – эффективность продукта (выручка, созданные заказы, брошенные корзины)
15. Что такое лейблы (labels) в Prometheus? >> Дополнительные измерения для фильтрации и группировки метрик; например, `method="GET"` , `status_code="200"`
16. Для чего чаще всего используют `Histogram` ? >> Измерение времени ответа (latency); позволяет понять, что 95% запросов укладываются в X секунд
17. Популярные инструменты для распределённого трейсинга? >> Jaeger, Zipkin, Sentry (с поддержкой трейсинга)
18. Что такое методология RED? >> Rate (количество запросов), Errors (ошибки), Duration (время ответа); применяется для мониторинга сервисов и приложений
19. Что такое тип метрики `Counter` ? >> Монотонно возрастающий счётчик; значение может только увеличиваться или оставаться неизменным; при перезапуске приложения сбрасывается в 0
20. Как запустить HTTP-сервер для скрапинга метрик Prometheus? >> `start_http_server(port)` из `prometheus_client` ; Prometheus забирает данные с эндпоинта `/metrics`
21. Как называется официальная Python-библиотека для Prometheus? >> `prometheus-client`
22. Можно ли использовать разные наборы ключей лейблов в одном объекте метрики? >> Нет; набор ключей фиксируется при создании объекта
23. Какой стандартный стек для работы с метриками? >> Prometheus (сбор и хранение) + Grafana (визуализация и алерты)
24. Для чего в Grafana используются Alerting-правила? >> Автоматическое уведомление при выходе метрик за допустимые пределы; интегрируется со Slack, PagerDuty, email
25. Примеры метрик типа `Gauge` ? >> Количество активных соединений, использование RAM, загрузка CPU, размер очереди Celery, свободное место на диске
26. Что произойдёт при перезапуске приложения с локальным `Counter` ? >> Значение сбросится в 0; Prometheus отслеживает разницу между скрапингами, поэтому кратковременный провал не потеряет данные
27. Что такое трейсинг? >> Отслеживание пути конкретного запроса через все сервисы системы; показывает где и сколько времени тратится
28. Какой из «трёх столпов» лучше подходит для поиска трендов? >> Метрики; они агрегированы во времени и позволяют строить графики и алерты
29. Примеры метрик типа `Counter` ? >> Общее количество HTTP-запросов, количество ошибок, количество зарегистрированных пользователей ( `users_registered_total` ), общая выручка ( `orders_revenue_total` )
