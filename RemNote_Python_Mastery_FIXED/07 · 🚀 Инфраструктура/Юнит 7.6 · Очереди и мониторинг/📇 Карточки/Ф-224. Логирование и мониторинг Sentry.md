1. Почему важно устанавливать `send_default_pii=False` ? >> Предотвращает отправку персональных данных (пароли, токены, PII) в Sentry; нарушение может повлечь проблемы с GDPR
2. Что должна вернуть `before_send` , чтобы отправить событие без изменений? >> `event` (сам словарь события без модификаций или с очищенными секретными полями)
3. Что обнаруживает Performance мониторинг Sentry? >> Медленные запросы и проблемы N+1 к БД; показывает waterfall транзакции с разбивкой по времени операций
4. За что отвечает параметр `environment` в конфигурации Sentry? >> Разделяет события по окружениям ( `production` , `staging` , `development` ); позволяет фильтровать ошибки в UI
5. Что такое PII в контексте Sentry? >> Personally Identifiable Information – персональные идентификационные данные; их нельзя отправлять в Sentry без явного согласия пользователя
6. Какая функция инициализирует Sentry? >> `sentry_sdk.init()` ; вызывается один раз при старте приложения, обычно в `settings.py`
7. Какую информацию Sentry собирает автоматически при ошибке? >> Стек вызовов со значениями локальных переменных, данные HTTP-запроса (headers, params, body), данные пользователя и окружение
8. Что такое Breadcrumbs в Sentry? >> Хронологическая лента событий, предшествовавших ошибке; помогает воспроизвести путь пользователя
9. Как добавить хлебную крошку? >> `sentry_sdk.add_breadcrumb(category="auth", message="Пользователь вошёл", level="info")`
10. Чем теги ( `set_tag` ) отличаются от контекста ( `set_context` ) в Sentry? >> Теги индексируются и доступны для поиска и фильтрации в UI; контекст отображается только в деталях конкретного события
11. Какие интеграции Sentry используются для Django и Celery? >> `DjangoIntegration()` – перехват исключений Django; `CeleryIntegration()` – мониторинг ошибок в фоновых задачах
12. Что должна вернуть `before_send` , чтобы заблокировать отправку события? >> `None` (возврат `None` отменяет отправку события в Sentry, экономя квоту на ожидаемых исключениях)
13. Как Sentry помогает справляться с потоком одинаковых ошибок? >> Автоматически группирует похожие события в одну Issue по fingerprint стека вызовов
14. В чём главное преимущество Sentry в production? >> Об ошибке становится известно до того, как пользователь успеет пожаловаться; метрика затронутых пользователей показывает масштаб проблемы
15. Для чего используется `RedisIntegration()` в Sentry? >> Отслеживание медленных запросов к Redis
16. Что даёт параметр `release` в Sentry? >> Привязывает ошибки к конкретной версии приложения (формат: `myapp@1.2.3` ); помогает определить, в каком релизе появилась проблема
17. Как отправить текстовое уведомление в Sentry? >> `sentry_sdk.capture_message("текст", level="warning")` ; по умолчанию уровень `info`
18. Что определяет параметр `dsn` в `sentry_sdk.init()` ? >> Data Source Name – уникальный адрес проекта в Sentry, по которому SDK отправляет события
19. Каково основное назначение Sentry? >> Автоматический перехват исключений, сбор контекста ошибки и мониторинг производительности в production-приложениях
20. Где в аргументах `before_send` содержится информация об исключении? >> В параметре `hint` ; `hint["exc_info"]` – кортеж `(тип, исключение, traceback)`
21. Как отправить исключение в Sentry вручную? >> `sentry_sdk.capture_exception(e)` внутри блока `except`
22. Для чего используется `SqlalchemyIntegration()` ? >> Мониторинг производительности SQL-запросов; помогает обнаруживать N+1 и медленные запросы
23. Как передать информацию о пользователе в Sentry? >> `sentry_sdk.set_user({"id": 42, "email": "user@example.com", "username": "alice"})`
24. Для чего используется `before_send` ? >> Функция-хук для фильтрации или модификации событий перед отправкой; если возвращает `None` – событие не отправляется
25. Как установить Sentry SDK для Python? >> `pip install sentry-sdk`
26. Для чего используют `set_tag("payment_provider", "stripe")` ? >> Для фильтрации ошибок по платёжному провайдеру в интерфейсе Sentry
27. Что означает `traces_sample_rate=0.1` ? >> Данные о производительности (трейсы) собираются для 10% запросов; значение `1.0` – для всех, что дорого в production
