1. Что означает `.` в конце команды `docker build` ? >> Указывает на директорию build context; Docker CLI упакует её содержимое и отправит daemon
2. За что отвечает флаг `-t` в команде `docker build` ? >> Задаёт имя и тег создаваемого образа
3. Как расшифровывается флаг `-i` в `-it` ? >> Interactive – держит stdin открытым
4. Какая команда удаляет Docker-образ? >> `docker rmi myapp:1.0`
5. Команда для просмотра всех локальных Docker-образов? >> `docker images`
6. В чём разница между bind mount и named volume в Docker? >> Bind mount ( `-v /host/path:/app/data` ) монтирует конкретную директорию хоста; named volume ( `-v myvolume:/app/data` ) управляется Docker и не зависит от пути хоста – предпочтителен для данных в production
7. Как отслеживать логи контейнера в реальном времени? >> `docker logs -f my-container` ( `-f` = follow)
8. Какая команда отправляет локальный образ в удалённый реестр? >> `docker push myuser/myapp:1.0`
9. Какая команда выводит логи контейнера? >> `docker logs my-container`
10. Команда для удаления конкретного контейнера? >> `docker rm my-container`
11. В команде `docker run -e DEBUG=true` , что произойдёт в контейнере? >> Будет установлена переменная окружения `DEBUG` со значением `true`
12. В команде `docker run -v /data:/app/data` , что является путём внутри контейнера? >> `/app/data` (после двоеточия)
13. Как передать несколько переменных окружения из файла при запуске контейнера? >> `docker run --env-file .env myapp` ; удобнее чем перечислять `-e` для каждой переменной
14. Какая команда выполняет корректную (graceful) остановку контейнера? >> `docker stop my-container` – отправляет `SIGTERM` , ждёт 10 секунд (по умолчанию), затем отправляет `SIGKILL`
15. Команда для просмотра запущенных контейнеров? >> `docker ps`
16. Какие флаги необходимы для запуска контейнера в интерактивном режиме с терминалом? >> `-it` : `-i` (interactive, держит stdin открытым) + `-t` (TTY, выделяет виртуальный терминал)
17. Зачем нужна команда `docker tag` перед `docker push` ? >> Добавляет тег с именем пользователя или адресом реестра: `docker tag myapp:1.0 myuser/myapp:1.0`
18. Какая команда скачивает образ из реестра? >> `docker pull python:3.11-slim`
19. Как увидеть все контейнеры, включая остановленные? >> `docker ps -a`
20. Какая команда позволяет выполнить команду в уже работающем контейнере? >> `docker exec` : `docker exec my-container python manage.py migrate`
21. Как удалить все остановленные контейнеры одной командой? >> `docker rm $(docker ps -aq)` – работает на Linux/macOS; контейнеры должны быть остановлены, иначе добавить флаг `-f`
22. Можно ли командой `docker rm` удалить запущенный контейнер? >> Нет, нужно сначала остановить контейнер или использовать флаг `-f` (force)
23. Какой флаг используется для запуска контейнера в фоновом режиме? >> `-d` (detached)
24. В синтаксисе `-p 8080:8000` , какой порт относится к хост-машине? >> 8080 (первое число); формат: `-p хост:контейнер`
25. Что делает флаг `--rm` при запуске контейнера? >> Автоматически удаляет контейнер после его остановки; удобно для одноразовых задач и отладки
26. Какая команда запускает контейнер на основе образа `myapp` ? >> `docker run myapp`
27. Какая команда запускает bash-сессию внутри нового контейнера `myapp` ? >> `docker run -it myapp bash`
28. Что делает `docker system prune` ? >> Удаляет все остановленные контейнеры, неиспользуемые сети, висячие образы и кэш сборки; с флагом `-a` – также все образы без запущенных контейнеров
29. Как смонтировать директорию хоста `/host/path` в `/app/data` контейнера? >> `docker run -v /host/path:/app/data myapp`
30. Каким флагом в `docker run` передаётся переменная окружения? >> `-e` : `docker run -e DEBUG=true myapp`
31. Как вывести только последние 100 строк логов? >> `docker logs --tail 100 my-container`
32. Какой сигнал отправляет `docker stop` и что происходит при истечении таймаута? >> Сначала `SIGTERM` (приложение может завершиться корректно); если не остановилось за 10 секунд – принудительный `SIGKILL`
33. Что выводит `docker inspect my-container` ? >> Подробные метаданные объекта в JSON: сетевые настройки, смонтированные тома, переменные окружения, статус, конфигурацию и т.д.
34. Что возвращает `docker ps -aq` ? >> Только ID всех контейнеров (включая остановленные); флаг `-q` (quiet) убирает всё кроме ID
35. С помощью какой опции контейнеру присваивается пользовательское имя? >> `--name` : `docker run --name my-container myapp`
36. Какая команда немедленно завершает работу контейнера? >> `docker kill my-container` – отправляет `SIGKILL` без ожидания
37. Какая команда используется для сборки Docker-образа из текущей директории? >> `docker build -t имя:тег .`
38. Как войти в bash-терминал уже запущенного контейнера? >> `docker exec -it my-container bash`
39. С помощью какого флага указывается путь к нестандартному Dockerfile? >> `-f` : `docker build -t имя -f Dockerfile.prod .`
40. Что делает `docker tag myapp:1.0 myuser/myapp:1.0` ? >> Создаёт новое имя (алиас) для того же образа; данные не копируются, оба тега указывают на один и тот же image ID
41. Как настроить проброс порта 8080 хоста на порт 8000 контейнера? >> `docker run -p 8080:8000 myapp`
42. Как расшифровывается флаг `-t` в `-it` ? >> TTY – выделяет виртуальный терминал
43. На каком порту приложение должно слушать внутри контейнера при `-p 8080:8000` ? >> На порту 8000 (второе число – порт контейнера)
