Все переменные в Python — это указатели

В Python переменная не хранит значение сама. Она лишь держит ссылку (указатель в памяти) на объект в куче (heap). Оператор = никогда не копирует данные — он лишь связывает имя с адресом объекта.

Посмотрим на реальном примере в терминале. Когда мы пишем b = a, никакого второго списка не создаётся:

PYTHON 3.13 ⟷ SCROLL (PEP 8) 
def check_transaction(conn, account_id: int):
    # Проверяем уровень изоляции перед блокировкой записи
    with conn.cursor() as cur:
        cur.execute("SELECT balance, status FROM accounts WHERE id = %s FOR UPDATE", (account_id,))
        acc = cur.fetchone()
        if not acc or acc['status'] != 'active':
            raise AccountBlockedError(f"Счёт {account_id} заблокирован")
    return acc
⚠️ Ловушка на собеседовании: Дефолтный аргумент def fn(val=[]) вычисляется ровно один раз при загрузке модуля! Все последующие вызовы делят один и тот же список.
