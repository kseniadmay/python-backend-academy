## Стандарт OpenAPI: спецификация API как код

**OpenAPI Specification (OAS)** — открытый стандарт описания REST API в машинночитаемом формате (JSON или YAML).

- **Swagger vs OpenAPI:** исторически проект назывался Swagger. В 2015 году спецификация была передана фонду Linux Foundation под именем **OpenAPI**, а слово Swagger закрепилось за семейством инструментов (Swagger UI, Swagger Editor).
- **Единый источник истины (Single Source of Truth):** схема OpenAPI документирует пути, параметры, форматы пейлоадов и статус-коды. По ней автоматически генерируются UI-документация, клиентские SDK и мок-серверы.

## Анатомия спецификации OpenAPI

Ключевые секции документа OpenAPI 3.0:

```yaml
openapi: 3.0.3
info:
  title: Users API
  version: 1.0.0
paths:
  /users/{id}:
    get:
      summary: Получить пользователя по ID
      parameters:
        - name: id
          in: path
          required: true
          schema:
            type: integer
      responses:
        '200':
          description: Успех
          content:
            application/json:
              schema:
                $ref: '#/components/User'
components:
  schemas:
    User:
      type: object
      properties:
        id: {type: integer}
        name: {type: string}
```

Директива `$ref` исключает дублирование, связывая эндпоинты с описанием модели в блоке `components/schemas`.

## Декларативная автогенерация в FastAPI

FastAPI генерирует схему OpenAPI автоматически на лету на основе аннотаций типов Python и моделей Pydantic:

```python
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI(
    title="Store API", version="1.0"
)

class Item(BaseModel):
    name: str = Field(..., max_length=50)
    price: float = Field(..., gt=0)

@app.post("/items", status_code=201)
def create_item(item: Item):
    return item
```

- Из коробки доступны интерактивные интерфейсы:
  * Swagger UI по адресу `http://localhost:8000/docs`;
  * ReDoc по адресу `http://localhost:8000/redoc`.

## Практическая ценность: кодогенерация и контракты

1. **Автогенерация SDK (`openapi-generator`):** фронтенд-команда генерирует готовый TypeScript/Axios клиент одной командой:
   `openapi-generator-cli generate -i openapi.json -g typescript-axios`
2. **Контрактное тестирование (Contract Testing):** валидация того, что ответы бэкенда в тестах на 100% совпадают со схемой (библиотека `schemathesis`).
3. **Мокирование (Mock Servers):** фронтендеры могут начать разработку интерфейса на базе Prism-мок-сервера до того, как бэкенд напишет первую строчку логики.
