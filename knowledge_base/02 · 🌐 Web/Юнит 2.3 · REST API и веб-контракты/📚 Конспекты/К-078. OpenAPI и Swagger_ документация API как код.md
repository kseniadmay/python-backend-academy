## Стандарт OpenAPI: спецификация API как код

**OpenAPI Specification (OAS)** — открытый стандарт описания REST API в машинночитаемом виде (JSON или YAML).

- **Swagger vs OpenAPI:** до 2015 года проект назывался Swagger; затем спецификацию передали Linux Foundation под именем **OpenAPI**, а Swagger остался именем UI-инструментов (*Swagger UI*, *Swagger Editor*).
- **Единый источник истины:** схема OpenAPI фиксирует эндпоинты, параметры, тела и статус-коды, позволяя автоматически генерировать документацию, SDK и моки.

## Анатомия спецификации OpenAPI

Ключевые секции документа OpenAPI 3.0 описывают метаданные, маршруты (`paths`) и переиспользуемые модели (`components`):

```yaml
openapi: 3.0.3
info:
  title: Users API
  version: 1.0.0
paths:
  /users/{id}:
    get:
      summary: Получить по ID
      parameters:
        - name: id
          in: path
          required: true
          schema: {type: integer}
      responses:
        '200':
          description: Успех
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/User'
components:
  schemas:
    User:
      type: object
      properties:
        id: {type: integer}
        name: {type: string}
```

Директива `$ref` избавляет от дублирования моделей по разным маршрутам.

## Декларативная автогенерация в FastAPI

FastAPI строит схему OpenAPI автоматически на основе аннотаций типов Python и моделей Pydantic:

```python
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI(title='Store API')

class Item(BaseModel):
    name: str = Field(..., max_length=50)
    price: float = Field(..., gt=0)

@app.post('/items', status_code=201)
def create_item(item: Item):
    return item
```

Из коробки приложение сразу поднимает два интерактивных интерфейса документации:

- **Swagger UI** по адресу `http://localhost:8000/docs`;
- **ReDoc** по адресу `http://localhost:8000/redoc`.

## Практическая ценность: кодогенерация и контракты

Машинночитаемая схема превращает документацию в рабочий инструмент всей команды.

**Автогенерация клиентских SDK (`openapi-generator`):** фронтенд генерирует типизированного клиента одной командой прямо из схемы API:

```bash
openapi-generator-cli generate \
  -i openapi.json \
  -g typescript-axios
```

- **Контрактное тестирование:** утилиты вроде `schemathesis` автоматически проверяют, совпадают ли ответы бэкенда со схемой.
- **Мок-серверы:** с помощью инструментов вроде Prism фронтенд начинает разработку ещё до готовности логики на сервере.
