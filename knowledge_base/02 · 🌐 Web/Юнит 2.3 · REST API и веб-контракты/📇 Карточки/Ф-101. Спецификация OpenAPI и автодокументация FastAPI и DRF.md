1. Какую библиотеку использовать для OpenAPI в Django REST Framework? >> `drf-spectacular` ; устанавливается через `pip install drf-spectacular`
2. С какого поля начинается YAML-файл OpenAPI? >> `openapi: "3.0.0"` (или актуальная версия)
3. Как сгруппировать эндпоинты в Swagger UI? >> Передать список строк в параметр `tags` декоратора; эндпоинты с одинаковым тегом группируются в UI
4. Как задокументировать ответы с ошибками (400, 404) в FastAPI? >> Использовать словарь в параметре `responses` : `responses={404: {"description": "Not found"}}`
5. На основе чего FastAPI автоматически генерирует OpenAPI-спецификацию? >> Аннотаций типов Python и моделей Pydantic; `BaseModel` автоматически превращается в JSON Schema
6. Как ограничить path-параметр `id` значением ≥ 1? >> `Path(ge=1)` (greater or equal)
7. Что такое `$ref` в OpenAPI? >> Ссылка на переиспользуемый компонент: `$ref: '#/components/schemas/Order'`
8. Как подключить `drf-spectacular` к DRF? >> В `settings.py` установить `DEFAULT_SCHEMA_CLASS = "drf_spectacular.openapi.AutoSchema"`
9. В чём разница между OpenAPI и Swagger? >> OpenAPI – спецификация (стандарт); Swagger – набор инструментов для работы с ней (UI, Codegen, Editor)
10. Чем отличаются параметры `summary` и `description` в декораторе FastAPI? >> `summary` – краткое название операции в Swagger UI; `description` – подробное описание с поддержкой Markdown
11. Какие возможности даёт OpenAPI/Swagger? >> Интерактивная документация, валидация данных на основе схем, генерация клиентского кода
12. Для чего используется `components/schemas` ? >> Определение переиспользуемых схем объектов; на них ссылаются через `$ref`
13. Во что преобразуются модели Pydantic в документации FastAPI? >> В JSON Schema; отображаются в Swagger UI и `/openapi.json`
14. За что отвечает `response_model` в декораторе эндпоинта FastAPI? >> Определяет модель Pydantic для валидации и документирования ответа; поля, не входящие в модель, фильтруются из ответа
15. Как описать Bearer JWT-аутентификацию в OpenAPI? >> В `components/securitySchemes` : `type: http` , `scheme: bearer` , `bearerFormat: JWT` ; глобально применить через корневую секцию `security`
16. Как указать в YAML, что параметр находится в строке запроса? >> `in: query` в описании параметра
17. Где в YAML описываются эндпоинты и HTTP-методы? >> В секции `paths`
18. Как ограничить строковый параметр набором фиксированных значений в YAML? >> Ключевое слово `enum` : `enum: [pending, paid, cancelled]`
19. Что такое стандарт OpenAPI? >> Стандарт описания REST API в формате YAML или JSON; определяет эндпоинты, параметры, схемы данных, коды ответов и аутентификацию
20. Для чего используется секция `servers` ? >> Перечисляет базовые URL-адреса, на которых развёрнуто API
21. Как пометить поле Pydantic как необязательное? >> `field: Optional[str] = None` ; в Pydantic v2 также `field: str | None = None`
22. Как указать в YAML, что эндпоинт возвращает массив объектов? >> `type: array` + `items: $ref: '#/components/schemas/Order'`
23. Как расширить схему конкретного DRF-эндпоинта? >> Декоратором `@extend_schema` из `drf_spectacular.utils`
24. Что произойдёт при `raise HTTPException(status_code=404)` в FastAPI? >> FastAPI вернёт JSON-ответ с кодом 404; исключение фиксируется в схеме OpenAPI автоматически
25. Что описывается в секции `info` YAML-спецификации? >> Метаданные API: `title` , `version` , `description`
26. Чем отличается `in: path` от `in: query` в OpenAPI? >> `in: path` – параметр является частью URL ( `/orders/{id}` ), обязателен всегда; `in: query` – передаётся после `?` , может быть опциональным
27. Какой класс Pydantic используется для добавления описания и примеров к полям? >> `Field` ; параметры `description` , `example` , `min_length` , `ge` , `le` и др.
28. По каким адресам доступна документация FastAPI? >> `/docs` – Swagger UI; `/redoc` – ReDoc; `/openapi.json` – сырая спецификация
29. Для чего используются классы `Path` и `Query` в FastAPI? >> `Path` – документирование и валидация path-параметров; `Query` – query-параметров; поддерживают `ge` , `le` , `min_length` , `description`
30. Что делает параметр `status_code` в декораторе FastAPI? >> Задаёт HTTP-статус успешного ответа (например, `201` для создания ресурса)
