1. Что такое HTTP статус-код 418 I'm a teapot? >> Шуточный статус-код из RFC 2324; сервер отказывается варить кофе потому что он чайник; существует в стандарте официально
2. Что означает HTTP статус-код 502 Bad Gateway и почему он возникает? >> Шлюз не получил корректный ответ от upstream-сервера
3. Почему ошибка 502 Bad Gateway часто возникает в связке Nginx + Gunicorn/Django? >> Nginx выступает шлюзом и не получает ответа от приложения Django
4. В чем разница между HTTP статус-кодами редиректов 302 Found, 303 See Other и 307 Temporary Redirect? >> Временный редирект; большинство браузеров меняют `POST` на `GET`
5. Для чего используется `422 Unprocessable Entity` ? >> Запрос синтаксически корректен, но данные не проходят валидацию или нарушают бизнес-правила
6. Что означает `405 Method Not Allowed` ? >> Ресурс существует, но указанный метод для него не разрешён
7. Какой код возвращается после успешного создания ресурса? >> `201 Created`
8. Что означает `503 Service Unavailable` ? >> Сервис недоступен из-за перегрузки или технического обслуживания
9. Какой код при превышении лимита запросов? >> `429 Too Many Requests`
10. Самый частый код при успешном запросе? >> `200 OK`
11. Что означает `301 Moved Permanently` ? >> Постоянный редирект; браузеры кэшируют и впредь используют новый URL без запроса старого
12. Какая категория используется для редиректов? >> `3xx`
13. Какая категория указывает на ошибки клиента? >> `4xx`
14. Что означает `100 Continue` ? >> Указание клиенту продолжать отправку тела запроса
15. Что означает `404 Not Found` ? >> Ресурс не найден
16. Какой код если `GET` к эндпоинту поддерживающему только `POST` ? >> `405 Method Not Allowed`
17. Что означает `204 No Content` ? >> Запрос выполнен успешно, тело ответа отсутствует
18. Что означает `504 Gateway Timeout` ? >> Шлюз не дождался ответа от upstream-сервера за отведённое время
19. Какая категория указывает на ошибки сервера? >> `5xx`
20. Что означает `304 Not Modified` ? >> Кэшированная версия актуальна; тело ответа отсутствует
21. Для чего используется `206 Partial Content` ? >> Для range-запросов; клиент запрашивает диапазон байтов; используется при стриминге и дозагрузке файлов
22. В чём разница `502` и `504` ? >> `502` – шлюз получил некорректный ответ; `504` – шлюз не дождался ответа за отведённое время (таймаут)
23. Какой код при повторной регистрации с существующим email? >> `409 Conflict`
24. Если сервер перегружен – наиболее вероятный `5xx` ? >> `503 Service Unavailable`
25. Что означает `401 Unauthorized` ? >> Требуется аутентификация; «Кто ты?»
26. Какой заголовок сопровождает `201 Created` ? >> `Location` – URL созданного ресурса
27. Что означает `403 Forbidden` ? >> Аутентификация пройдена, но доступ запрещён; «Я знаю кто ты, но тебе нельзя»
28. Какая категория статус-кодов обозначает успех? >> `2xx`
29. Что означает `409 Conflict` ? >> Конфликт с текущим состоянием ресурса; например, дублирование уникальной записи
30. Что означает `500 Internal Server Error` ? >> Непредвиденная ошибка на стороне сервера
31. В чём разница `307` / `308` от `302` / `301` ? >> `307` / `308` сохраняют метод запроса; `POST` не меняется на `GET`
32. В чём разница `401` и `403` ? >> `401` – нет аутентификации; `403` – нет авторизации
33. Что означает `400 Bad Request` ? >> Сервер не может обработать запрос из-за синтаксической ошибки; отличие от `422` : `400` – «не понимаю запрос», `422` – «понимаю, но данные логически неверны»
34. После каких методов часто возвращается `204` ? >> `DELETE` , `PUT` , `PATCH`
35. Какая категория является информационной? >> `1xx` ; редко встречается на практике
