1. Какую фундаментальную проблему Head-of-Line (HoL) Blocking НЕ решает протокол HTTP/2? >> Head-of-Line Blocking на уровне TCP: потеря одного пакета блокирует все потоки в соединении
2. Что такое HTTP/3 и как протокол QUIC решает проблему TCP Head-of-Line Blocking? >> HTTP/3 использует протокол QUIC вместо TCP; QUIC работает поверх UDP и устраняет TCP Head-of-Line Blocking; каждый поток независим на транспортном уровне
3. Как алгоритм сжатия HPACK в HTTP/2 оптимизирует передачу заголовков? >> Кэширует заголовки; при повторном запросе передаёт только изменения
4. Главная проблема производительности HTTP/1.1? >> Head-of-Line Blocking: следующий запрос ждёт завершения предыдущего в том же соединении
5. В чём ключевое различие форматов HTTP/1.1 и HTTP/2? >> HTTP/1.1 – текстовый протокол; HTTP/2 – бинарный
6. Сколько TCP-соединений использует HTTP/2? >> Одно на домен
7. Для каких страниц HTTP/2 даёт наибольший прирост скорости? >> Для страниц с большим количеством мелких ресурсов
8. Как называются независимые логические каналы в HTTP/2? >> Потоки (streams)
9. Как браузеры обходят Head-of-Line Blocking в HTTP/1.1? >> Открывают 6–8 параллельных TCP-соединений на домен; накладные расходы высоки
10. Является ли Server Push обязательным? >> Нет; сервер решает по своей логике; клиент может отказаться
11. Что такое Server Push в HTTP/2? >> Сервер отправляет ресурсы до явного запроса клиента; пример: CSS и JS вместе с HTML
12. В каком году HTTP/1.1 стал стандартом? >> 1997
13. Что передаётся в HTTP/2 вместо текстовых строк? >> Бинарные фреймы
14. Как называется алгоритм сжатия заголовков в HTTP/2? >> HPACK
15. Как изменяется анализ трафика при переходе на HTTP/2? >> Усложняется; бинарные данные нельзя прочитать без специального декодировщика
16. Что является основным драйвером производительности HTTP/2 при загрузке множества JS-файлов? >> Мультиплексирование
17. Что эффективнее в HTTP/2: один большой файл или много мелких? >> Много мелких становятся почти так же эффективны; мультиплексирование устраняет очереди ожидания
18. В каком году утверждён HTTP/2? >> 2015
19. В каком формате передаются заголовки в HTTP/1.1? >> Текстовом; при каждом запросе полностью
20. Влияют ли задержки в одном потоке HTTP/2 на другие? >> Нет на уровне HTTP; но на уровне TCP блокировка всё ещё возможна (TCP Head-of-Line Blocking)
21. Преимущество бинарного формата HTTP/2? >> Эффективнее и надёжнее парсить; исключает ошибки интерпретации текста
22. Требование браузеров для HTTP/2? >> Обязательное TLS (HTTPS)
23. Какая технология HTTP/2 решает Head-of-Line Blocking на уровне HTTP? >> Мультиплексирование; множество запросов и ответов передаются параллельно в одном TCP-соединении
24. Что такое приоритеты в HTTP/2? >> Клиент указывает важность конкретных потоков; сервер учитывает при отправке
25. Преимущество текстового формата HTTP/1.1? >> Легко читать без специальных инструментов
