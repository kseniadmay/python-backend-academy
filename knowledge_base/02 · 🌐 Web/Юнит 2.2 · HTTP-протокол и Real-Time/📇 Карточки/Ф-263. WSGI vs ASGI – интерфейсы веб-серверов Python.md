1. Зачем вообще нужны стандарты WSGI и ASGI между веб-сервером и Python-фреймворком? >> Они задают единый контракт взаимодействия между сервером приложений (`Gunicorn`, `Uvicorn`) и фреймворком (`Django`, `Flask`, `FastAPI`), позволяя менять сервер без переписывания кода приложения
2. Как расшифровываются WSGI и ASGI и в каких PEP/спецификациях они описаны? >> WSGI — Web Server Gateway Interface (PEP 333 / PEP 3333, синхронный стандарт); ASGI — Asynchronous Server Gateway Interface (асинхронный наследник WSGI)
3. Какова сигнатура WSGI-приложения в Python? >> `def app(environ, start_response):` — синхронная вызываемая функция, принимающая словарь переменных окружения запроса `environ` и колбэк `start_response`, и возвращающая итерируемое тело ответа
4. Какова сигнатура ASGI-приложения в Python? >> `async def app(scope, receive, send):` — корутина, принимающая словарь метаданных соединения `scope` (тип `http`, `websocket` или `lifespan`) и две асинхронные очереди сообщений `receive` и `send`
5. Почему классический WSGI не поддерживает WebSocket и HTTP/2 Server Push? >> WSGI жёстко привязан к циклу «один синхронный входной запрос — один синхронный выходной ответ» и блокирует рабочий поток до полного возврата ответа
6. Какие фреймворки работают по стандарту WSGI, а какие — по ASGI? >> WSGI: `Flask`, классический `Django`; ASGI: `FastAPI`, `Starlette`, `Litestar`, `Django` (начиная с 3.0+ и `Django Channels`), `Quart`
7. Назовите популярные WSGI- и ASGI-серверы в продакшене. >> WSGI-серверы: `Gunicorn`, `uWSGI`, `Waitress`; ASGI-серверы: `Uvicorn`, `Hypercorn`, `Daphne`, `Granian`
8. Зачем в продакшене часто запускают связку `Gunicorn` + `UvicornWorker` (`gunicorn -k uvicorn.workers.UvicornWorker`)? >> `Gunicorn` выступает как надёжный менеджер процессов (Process Manager): запускает несколько процессов по числу ядер CPU и перезапускает упавшие воркеры, а внутри каждого процесса работает быстрый асинхронный цикл `Uvicorn`
9. Зачем перед `Gunicorn` / `Uvicorn` в продакшене ставят Reverse Proxy (`Nginx`, `Caddy`, `Cloudflare`)? >> Для терминации TLS/SSL, защиты от медленных клиентов (Slowloris), раздачи статики, сжатия `gzip`/`brotli`, балансировки нагрузки между процессами и ограничения частоты запросов (Rate Limiting)
10. Что такое `scope['type'] == 'lifespan'` в спецификации ASGI? >> Специальный канал событий запуска (`lifespan.startup`) и остановки (`lifespan.shutdown`) приложения, позволяющий инициализировать и закрывать пулы соединений к БД и кэшу
11. Что произойдёт, если в обычном WSGI-сервере с 4 потоками все 4 запроса зависнут на внешнем HTTP-вызове по 10 секунд? >> Все 4 рабочих потока заблокируются, и сервер на 10 секунд перестанет принимать любые новые запросы от других пользователей
12. Как `Uvicorn` добивается высокой скорости работы Event Loop в Python? >> Он использует `uvloop` (быструю обёртку над C-библиотекой `libuv` вместо стандартного цикла `asyncio`) и `httptools` (C-парсер HTTP)
