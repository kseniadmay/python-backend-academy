1. Как правильно реализовать асинхронную зависимость для сессии базы данных SQLAlchemy в FastAPI с гарантированным закрытием сессии? >> `async def get_db(): async with AsyncSession() as session: yield session` + `db: AsyncSession = Depends(get_db)`
2. Что инициализируют в `lifespan` ? >> Соединения с БД, Redis, пул соединений – ресурсы живущие всё время работы приложения
3. Какую библиотеку использовать для асинхронного PostgreSQL? >> `asyncpg` или SQLAlchemy async; не `psycopg2` – синхронный
4. Что произойдет и что вернет эндпоинт FastAPI, если забыть написать await перед вызовом асинхронной функции? >> Объект корутины вместо результата – распространённая ловушка
5. Какую библиотеку использовать для асинхронных HTTP-запросов? >> `aiohttp` или `httpx` ; не `requests` – синхронный
6. Где FastAPI выполняет `def` (sync) эндпоинты? >> В пуле потоков (threadpool) чтобы не блокировать event loop
7. Основное правило `async def` ? >> Никогда не вызывать блокирующие I/O операции; только `await` -совместимые корутины
8. На какой библиотеке построен FastAPI? >> `Starlette` (async-фреймворк) + `Pydantic` (валидация)
9. Что такое `lifespan` в FastAPI? >> Механизм выполнения кода при старте и завершении приложения; код до `yield` – startup, после – shutdown
10. Что делает `asyncio.gather()` ? >> Запускает несколько корутин параллельно; общее время = $\max(t_1, t_2, \ldots, t_n)$ ; эффективнее последовательных `await`
11. Что произойдёт при `time.sleep(5)` внутри `async def` ? >> Event loop заблокируется на 5 секунд для всех запросов; нужно `await asyncio.sleep(5)`
12. Как подключить `lifespan` к FastAPI? >> `@asynccontextmanager` + `yield` ; передать в `app = FastAPI(lifespan=lifespan)`
13. Почему нельзя использовать `requests` в `async def` ? >> Синхронная библиотека блокирует event loop; использовать `aiohttp` или `httpx`
14. Для чего `yield` в асинхронной зависимости? >> Передаёт ресурс в эндпоинт; после завершения запроса выполняется код после `yield` (cleanup)
15. Спасает ли объявление эндпоинта через обычный `def` (Thread Pool) от тяжёлых CPU-bound вычислений на Python? >> Нет! Потоки Thread Pool живут в том же процессе и делят общий GIL с потоком Event Loop; для тяжёлых CPU-задач нужен `ProcessPoolExecutor` или фоновая очередь (`Celery` / `Dramatiq`)
16. Когда в FastAPI использовать `async def`, а когда обычный `def`? >> `async def` – для неблокирующего асинхронного I/O (`asyncpg`, `httpx.AsyncClient`); обычный `def` – для синхронного блокирующего I/O (`requests`, синхронный ORM, файлы), который выполняется в Thread Pool и отпускает GIL на время ожидания
17. Где FastAPI выполняет `async def` эндпоинты? >> В event loop; `await` передаёт управление обратно loop – другие запросы обрабатываются параллельно
