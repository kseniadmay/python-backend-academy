1. Что такое `ThreadPoolExecutor` из модуля `concurrent.futures` и каковы его преимущества? >> Высокоуровневый API из `concurrent.futures` ; управляет пулом потоков; удобнее `threading` для большинства задач
2. Как GIL влияет на выполнение Python-потоков на современных многоядерных процессорах? >> Не позволяет нескольким потокам одновременно выполнять Python-байткод; только один поток активен в каждый момент
3. Для чего используется метод `.join()` у объектов потоков `threading.Thread` ? >> Блокирует основной поток до завершения дочернего потока или процесса
4. Основной недостаток процессов? >> Тяжелее потоков: больше памяти, медленный запуск, сложный обмен данными
5. Насколько потоки ресурсозатратны? >> Лёгковесные по сравнению с процессами
6. Что такое CPU-bound задачи? >> Задачи ограниченные вычислительной мощностью процессора: математика, шифрование, обработка данных
7. Какой механизм даёт настоящий параллелизм на нескольких ядрах? >> `multiprocessing`
8. Когда `threading` не даст прироста скорости? >> При CPU-bound задачах из-за GIL
9. Метод для запуска потока или процесса? >> `.start()`
10. Три способа обмена данными между процессами? >> Очереди ( `Queue` ), каналы ( `Pipe` ), разделяемая память ( `shared memory` )
11. Что выбрать для I/O-bound задач? >> `threading` или `asyncio`
12. Как GIL соотносится с несколькими процессами? >> У каждого процесса свой GIL; настоящий параллелизм достигается
13. Что такое многопоточность? >> Несколько потоков исполнения внутри одного процесса с общей памятью
14. Как потоки взаимодействуют с памятью? >> Разделяют общую память процесса
15. В чём суть многопроцессности? >> Создание нескольких отдельных независимых процессов с изолированной памятью
16. Сколько потоков могут одновременно выполнять Python-код? >> Только один в каждый момент времени
17. Модуль для работы с процессами? >> `multiprocessing`
18. Что такое `asyncio` ? >> Библиотека для асинхронного программирования через корутины; один поток, кооперативная многозадачность; идеален для I/O-bound задач с большим количеством соединений
19. Что выбрать для CPU-bound задач? >> `multiprocessing`
20. Что такое I/O-bound задачи? >> Задачи ограниченные скоростью ввода-вывода: сеть, диск, БД
21. Модуль для работы с потоками? >> `threading`
