1. В каком порядке завершатся асинхронные задачи A(2с), B(1с), C(3с) при одновременном запуске в `asyncio.gather()` ? >> B finished → A finished → C finished
2. В каком порядке располагаются результаты в списке `results` после выполнения `results = await asyncio.gather(task1, task2)` ? >> Список возвращённых значений в порядке передачи задач
3. Какая задача завершится первой при конкурентном выполнении `taskA` (задержка 2 сек), `taskB` (задержка 1 сек) и `taskC` (задержка 3 сек)? >> B
4. Почему общее время работы параллельных асинхронных задач равно максимальному времени одной задачи, а не их сумме? >> Задачи запускаются одновременно и ожидают параллельно
5. В чём разница между передачей сырой корутины в `asyncio.gather()` и предварительным созданием `create_task()` ? >> `create_task()` немедленно планирует задачу в event loop; корутина без `create_task` начнёт выполняться только когда до неё дойдёт `gather`
6. В каком порядке стартуют асинхронные задачи при вызове `asyncio.gather(taskA, taskB, taskC)` ? >> A started → B started → C started
7. Сколько времени займёт последовательное выполнение 3 задач с задержками 2 сек, 1 сек и 3 сек? >> Около 6 секунд
8. Как `asyncio.gather()` обрабатывает исключения по умолчанию и как собрать все результаты при ошибках? >> При исключении в одной задаче `gather` немедленно выбрасывает его; остальные задачи не отменяются автоматически; `return_exceptions=True` позволяет собрать все результаты и исключения
9. Функция для конкурентного запуска нескольких корутин? >> `asyncio.gather()`
10. За счёт чего `asyncio` создаёт иллюзию одновременности? >> Быстрое переключение event loop между корутинами в точках `await`
11. Кому корутина возвращает управление при `await` ? >> Event loop
12. Что является сердцем `asyncio` ? >> Event loop
13. Сколько корутин выполняется в один момент? >> Только одна
14. Что происходит после вызова `async def` функции? >> Возвращает объект-корутину; тело функции не выполняется
15. Как объявляется корутина? >> `async def`
16. Что делает event loop когда корутина достигает `await` ? >> Переключается на следующую готовую корутину
17. Что произойдёт при `await` вне `async def` ? >> `SyntaxError`
18. Главное преимущество `asyncio.sleep` перед `time.sleep` ? >> Не блокирует поток; возвращает управление event loop на время ожидания
19. Как называется механизм переключения в `asyncio` ? >> Кооперативная многозадачность
20. Основная функция event loop? >> Запуск, отслеживание готовности и переключение между корутинами
21. Может ли корутина сама продолжить выполнение после `await` ? >> Нет; event loop должен снова передать ей управление
22. Что если убрать `await` перед `asyncio.sleep()` ? >> Вернёт объект корутины без паузы; задержка не произойдёт
23. Где допустимо использование `await` ? >> Только внутри `async def` функций
24. Если 3 задачи 2с, 1с, 3с через `gather` – итог? >> Примерно 3 секунды; задачи выполняются конкурентно
25. Что делает оператор `await` ? >> Приостанавливает текущую корутину до получения результата и возвращает управление event loop
26. Что делает `asyncio.run(main())` ? >> Создаёт event loop, запускает `main` и закрывает loop после завершения
27. Является ли `asyncio` многопоточной библиотекой? >> Нет; работает в одном потоке через кооперативную многозадачность
