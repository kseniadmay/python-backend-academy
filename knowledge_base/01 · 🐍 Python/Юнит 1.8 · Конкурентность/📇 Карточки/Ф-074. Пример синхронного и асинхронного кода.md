1. Что произойдёт с фоновой задачей, созданной через `asyncio.create_task()` , если не сохранить ссылку на неё? >> Может быть уничтожена сборщиком мусора до завершения; нужно хранить ссылку или использовать `asyncio.gather()`
2. Что такое `asyncio.TaskGroup` ? >> Современная альтернатива `gather()` появившаяся в Python 3.11; автоматически отменяет все задачи группы при исключении в любой из них
3. Тип возвращаемого значения `response.json()` ? >> `dict` или `list` в зависимости от структуры JSON
4. Как `asyncio.gather()` принимает задачи? >> Как позиционные аргументы через запятую или через распаковку списка `*tasks`
5. Какая функция создаёт задачу начинающую выполняться немедленно? >> `asyncio.create_task()` ; задача планируется в event loop немедленно без явного `await`
6. Что делает `async with session.get(url) as response` ? >> Выполняет GET-запрос и создаёт контекст с гарантированным закрытием соединения
7. Какая библиотека для конкурентных HTTP-запросов в Python? >> `aiohttp`
8. Является ли `aiohttp` встроенной библиотекой? >> Нет; устанавливается через `pip install aiohttp`
9. Зависит ли время `gather()` от количества I/O-bound задач? >> В основном зависит от самой длительной задачи; при достаточном количестве соединений добавление задач почти не увеличивает общее время
10. Что делает `await response.json()` ? >> Ожидает получения тела ответа и десериализует из JSON
11. Ключевое различие между `asyncio.run()` и `asyncio.gather()` ? >> `asyncio.run()` создаёт и запускает event loop; `asyncio.gather()` запускает группу корутин внутри уже работающего loop
12. Что значит «начнёт выполнение в фоне» для `create_task()` ? >> Задача добавляется в очередь event loop; начнёт выполняться как только текущая корутина дойдёт до `await`
