1. Что происходит, когда генераторная функция завершает выполнение и в ней больше нет выражений `yield`? >> Выбрасывается `StopIteration`
2. Что вернёт 4-й вызов `next(gen)` для генератора Фибоначчи с `yield a` (`0, 1, 1, 2, 3...`)? >> `2`
3. До какого момента выполняется код генератора при вызове `next(gen)`? >> До следующего `yield`
4. Что делает ключевое слово `yield` в теле функции? >> Возвращает значение вызывающему коду и приостанавливает выполнение
5. Что вернёт 2-й вызов `next(gen)` для генератора Фибоначчи с `yield a` (`0, 1, 1, 2...`)? >> `1`
6. Как передать значение внутрь работающего генератора из вызывающего кода? >> Через `gen.send(value)`; переданное значение становится результатом выражения `yield` внутри генератора
7. Какое число будет последним в списке `[next(gen) for _ in range(7)]` для генератора Фибоначчи (0, 1, 1, ...)? >> `8`
8. Какое значение возвращается первым при итерации генератора чисел Фибоначчи через yield? >> `0`
9. Где используется `yield`? >> Внутри функций; превращает функцию в генераторную
10. Начинается ли выполнение тела генератора при его вызове? >> Нет; только после первого `next()`
11. Заменяет ли `yield from` цикл `for` при возврате элементов? >> Да; `yield from iterable` лаконично заменяет `for x in iterable: yield x`
12. В какой момент выполняется код после `yield a` внутри генератора? >> Только при следующем возобновлении генератора вызовом `next()` или на следующем шаге цикла
13. Что означает `*iterables` в `def chain(*iterables)`? >> Функция принимает произвольное количество итерируемых аргументов
14. Что вернёт `list(itertools.chain([1, 2], [3, 4], [5, 6]))`? >> `[1, 2, 3, 4, 5, 6]`
15. Почему `yield` эффективнее возврата списка для больших данных? >> Вычисляет значения по одному; не хранит всю последовательность в памяти
16. Какие начальные значения задаются переменным `a` и `b` в генераторе Фибоначчи (`0, 1, 1, 2, 3...`), если первой отдаётся `a`, а шаг делает `a, b = b, a + b`? >> `a = 0` и `b = 1`
17. Откуда продолжается выполнение при повторном `next()`? >> С места, где выполнение было приостановлено
18. Что делает `yield from it`? >> Поочерёдно выдаёт все элементы из итерируемого объекта `it`
19. Что сохраняется при паузе генератора? >> Локальные переменные и текущая позиция в коде
20. Что означает `_` в `[next(gen) for _ in range(7)]`? >> Переменная цикла, значение которой не используется
21. Где в Python сохраняется состояние локальных переменных генератора при приостановке на yield? >> Внутри объекта-генератора
22. Что делает `yield from`, когда переданный итератор пуст? >> Немедленно завершает делегирование и передаёт управление дальше
23. Что возвращается при вызове генераторной функции? >> Объект-генератор; тело функции не выполняется
24. Для чего предназначен `yield from`? >> Для делегирования итерации другому генератору или итерируемому объекту
