1. Что происходит, когда генераторная функция завершает выполнение и в ней больше нет выражений `yield` ? >> Выбрасывается `StopIteration`
2. Что вернёт 4-й вызов `next(gen)` для генератора чисел Фибоначчи: `def fibonacci():; a, b = 0, 1; while True:; yield a; a, b = b, a + b; gen = fibonacci()` ? >> `2`
3. До какого момента выполняется код генератора при вызове `next(gen)` ? >> До следующего `yield`
4. Что делает ключевое слово `yield` в теле функции? >> Возвращает значение вызывающему коду и приостанавливает выполнение
5. Что вернёт второй вызов `next(gen)` для генератора Фибоначчи: `def fibonacci():; a, b = 0, 1; while True:; yield a; a, b = b, a + b; gen = fibonacci()` ? >> `1`
6. Что делает функция-генератор при достижении инструкции yield? >> Передаёт управление и значение вызывающему коду
7. Как передать значение внутрь работающего генератора из вызывающего кода? >> Да; через `gen.send(value)` ; значение становится результатом выражения `yield` внутри генератора
8. Какое число будет последним в списке `[next(gen) for _ in range(7)]` для генератора Фибоначчи (0, 1, 1, ...)? >> `8`
9. Какое значение возвращается первым при итерации генератора чисел Фибоначчи через yield? >> `0`
10. Где используется `yield` ? >> Внутри функций; превращает функцию в генераторную
11. Начинается ли выполнение тела генератора при его вызове? >> Нет; только после первого `next()`
12. Заменяет ли `yield from` цикл `for` при возврате элементов? >> Да; `yield from iterable` лаконично заменяет `for x in iterable: yield x`
13. В какой момент выполняется строка `a, b = b, a + b` в генераторе Фибоначчи: `def fibonacci():; a, b = 0, 1; while True:; yield a; a, b = b, a + b` ? >> После возобновления при следующем `next()`
14. Что означает `*iterables` в `def chain(*iterables)` ? >> Функция принимает произвольное количество итерируемых аргументов
15. Что вернёт `list(chain([1,2], [3,4], [5,6]))` ? >> `[1, 2, 3, 4, 5, 6]`
16. Почему `yield` эффективнее возврата списка для больших данных? >> Вычисляет значения по одному; не хранит всю последовательность в памяти
17. Какие начальные значения у `a` и `b` в `fibonacci()` ? >> `0` и `1`
18. Откуда продолжается выполнение при повторном `next()` ? >> С места где выполнение было приостановлено
19. Что делает `yield from it` ? >> Поочерёдно выдаёт все элементы из итерируемого объекта `it`
20. Что сохраняется при паузе генератора? >> Локальные переменные и текущая позиция в коде
21. Что означает `_` в `[next(gen) for _ in range(7)]` ? >> Переменная цикла значение которой не используется
22. Где сохраняется состояние генератора? >> Внутри объекта-генератора
23. Что делает `yield from` когда переданный итератор пуст? >> Немедленно завершает делегирование и передаёт управление дальше
24. Что возвращается при вызове генераторной функции? >> Объект-генератор; тело функции не выполняется
25. Для чего предназначен `yield from` ? >> Для делегирования итерации другому генератору или итерируемому объекту
