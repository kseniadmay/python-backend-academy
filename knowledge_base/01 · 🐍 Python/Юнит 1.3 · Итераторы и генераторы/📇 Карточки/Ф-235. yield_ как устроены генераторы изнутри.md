1. Что делает yield с выполнением функции? >> Приостанавливает функцию, сохраняя все локальные переменные, до следующего вызова next().
2. Чем генераторное выражение отличается от спискового включения по синтаксису? >> Круглые скобки () вместо квадратных [] — остальное совпадает.
3. Что делает yield from? >> Делегирует генератору всю выдачу значений из другого итерируемого объекта, эквивалент цикла for x in sub: yield x.
4. Что делает метод send() у генератора? >> Передаёт значение внутрь генератора, которое становится результатом выражения yield внутри функции.
5. Зачем нужен конвейер генераторов (generator pipeline)? >> Обрабатывает данные лениво, поэлементно, не материализуя промежуточные списки между этапами.
6. Что происходит с локальными переменными функции между вызовами next() генератора? >> Они сохраняются ("замораживаются") в приостановленном состоянии функции, не пересоздаются заново.
7. Что делает yield from при делегировании ДРУГОМУ генератору (не просто iterable)? >> Дополнительно прозрачно прокидывает send()/throw()/close() во вложенный генератор, не только значения.
8. Является ли генераторное выражение (x for x in range(10)) объектом списка? >> Нет, это генератор — ленивый, вычисляет значения по требованию.
9. Что произойдёт при первом next() у генератора, использующего send()? >> Первый next() обязателен для того, чтобы дойти до первого yield — send() значения на этом первом шаге не примет, нужно сначала "разбудить" генератор.
10. Строится ли список в памяти между этапами конвейера генераторов? >> Нет, данные передаются поэлементно от одного генератора к другому без промежуточной материализации.
11. Что делает generator.close()? >> Принудительно завершает генератор, бросая GeneratorExit внутри него в точке остановки.
12. Что произойдёт при вызове next() на уже закрытом (close()) генераторе? >> StopIteration.
13. Может ли yield находиться внутри цикла try/except? >> Да, и это частый паттерн — позволяет генератору реагировать на исключения, переданные через throw().
14. Что делает generator.throw(SomeError)? >> Бросает указанное исключение внутри генератора в точке, где он сейчас приостановлен.
15. Чем асинхронный генератор (async def с yield) отличается от обычного? >> Использует async for для перебора и await внутри — сочетает ленивую генерацию с асинхронным ожиданием I/O.
