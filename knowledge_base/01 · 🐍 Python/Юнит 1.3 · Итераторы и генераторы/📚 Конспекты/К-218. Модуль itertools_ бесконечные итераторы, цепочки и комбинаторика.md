## Модуль itertools и бесконечные итераторы

**`itertools`** — библиотека быстрых строительных блоков на C с **ленивыми вычислениями** и памятью $O(1)$ без промежуточных списков.

Бесконечные итераторы не имеют конца, поэтому при обходе их ограничивают через `islice`, `zip` или `break`.

### 1. `count(start=0, step=1)` — арифметический счётчик ID

Генерирует бесконечный поток чисел от `start` с шагом `step`:

```python
from itertools import count, islice

# count(start, step) — счётчик без аллокаций
ids = count(start=100, step=5)
print(list(islice(ids, 4)))
# >>> [100, 105, 110, 115]
```

### 2. `cycle(iterable)` — циклическое переключение (Round-Robin)

Бесконечно повторяет элементы коллекции по кругу для равномерного распределения задач:

```python
from itertools import cycle

workers = cycle([
    'worker-1', 'worker-2', 'worker-3'
])
tasks = ['t1', 't2', 't3', 't4']
print(list(zip(tasks, workers)))
# >>> [('t1', 'worker-1'), ('t2', 'worker-2'),
# >>> ('t3', 'worker-3'), ('t4', 'worker-1')]
```

### 3. `repeat(elem, times=None)` — фиксация константы за O(1) памяти

Многократно возвращает один и тот же объект без лишних аллокаций:

```python
from itertools import repeat

print(list(repeat('ping', 3)))
# >>> ['ping', 'ping', 'ping']
```

## Объединение и фильтрация потоков: chain, islice, takewhile, dropwhile

### 1. `chain(*iterables)` и `chain.from_iterable()` — конкатенация за O(1) памяти

Склеивают последовательности лениво без создания промежуточных копий (в отличие от `list1 + list2`):

```python
from itertools import chain

# chain.from_iterable — разворот без копий
matrix = [[1, 2], [3, 4], [5, 6]]
flat = list(chain.from_iterable(matrix))
print(flat)
# >>> [1, 2, 3, 4, 5, 6]
```

### 2. `islice(iterable, start, stop[, step])` — срез по генераторам

Обычный срез `gen[2:6]` на генераторе вызывает `TypeError`, а `islice` безопасно срезает поток:

```python
from itertools import islice

gen = (x * x for x in range(1000))

# Ленивый срез [2:6] без загрузки в память
res = list(islice(gen, 2, 6))
print(res)
# >>> [4, 9, 16, 25]
```

### 3. `takewhile` vs `dropwhile` — фильтрация по первому условию

Два противоположных фильтра по границе первого нарушения условия:

- `takewhile` отдаёт элементы, пока предикат истинен, и останавливается на первом `False`.
- `dropwhile` пропускает элементы, пока условие истинно, а начиная с первого `False` отдаёт весь остаток.

Сравним поведение обеих функций на одной последовательности:

```python
from itertools import takewhile, dropwhile

nums = [1, 3, 5, 2, 4, 7]

# Берёт элементы до первого нарушения
print(list(takewhile(lambda x: x < 5, nums)))
# >>> [1, 3]

# Пропускает начало, потом отдаёт всё
print(list(dropwhile(lambda x: x < 5, nums)))
# >>> [5, 2, 4, 7]
```

## Группировка и нарезка батчами: groupby и batched

**`groupby(iterable, key=None)`** объединяет **только соседние** элементы с одинаковым ключом (как `uniq` в Linux).

Поэтому перед вызовом `groupby` последовательность обязательно нужно отсортировать по тому же ключу `key`:

```python
from itertools import groupby

orders = [
    {'status': 'paid', 'id': 1},
    {'status': 'new', 'id': 2},
    {'status': 'paid', 'id': 3},
]

# groupby требует предварительной сортировки!
orders_sorted = sorted(
    orders,
    key=lambda x: x['status'],
)
by_status = groupby(
    orders_sorted,
    key=lambda x: x['status'],
)
grouped = {
    k: list(v) for k, v in by_status
}
for status, items in grouped.items():
    ids = [x['id'] for x in items]
    print(f'{status}: {ids}')
    # >>> new: [2]
    # >>> paid: [1, 3]
```

Учтите особенность: подытераторы групп делят один базовый итератор — если не сохранить группу в `list(v)` до следующего шага цикла, данные предыдущей группы потеряются.

С Python 3.12 в стандартной библиотеке появилась функция **`itertools.batched(iterable, n)`**, нарезающая поток чанками до `n` элементов (удобно для `bulk_insert` в БД; раньше это писали циклом с `islice`).

## Комбинаторика: product, permutations, combinations

Комбинаторные функции заменяют вложенные циклы и рекурсивный перебор вариантов.

### 1. `product(*iterables)` — декартово произведение (вложенные циклы)

Возвращает все пары элементов из переданных коллекций (как вложенные `for`):

```python
from itertools import product

# product(A, B) — декартово произведение
print(list(product([1, 2], ['a', 'b'])))
# >>> [(1, 'a'), (1, 'b'), (2, 'a'), (2, 'b')]
```

### 2. `permutations(iterable, r=None)` — перестановки (порядок важен)

Генерирует все упорядоченные перестановки длиной `r`:

```python
from itertools import permutations

# Пары (A, B) и (B, A) считаются РАЗНЫМИ
print(list(permutations('AB', 2)))
# >>> [('A', 'B'), ('B', 'A')]
```

### 3. `combinations(iterable, r)` — сочетания без повторений

Строит уникальные комбинации из `r` элементов, где порядок не имеет значения:

```python
from itertools import combinations

# Порядок элементов не важен
print(list(combinations('ABC', 2)))
# >>> [('A', 'B'), ('A', 'C'), ('B', 'C')]
```

### 4. `combinations_with_replacement(iterable, r)` — сочетания с повторением элементов

Допускает выбор одного и того же элемента несколько раз внутри комбинации:

```python
from itertools import (
    combinations_with_replacement as cwr
)

print(list(cwr('AB', 2)))
# >>> [('A', 'A'), ('A', 'B'), ('B', 'B')]
```

## Накопление и разветвление: accumulate и tee

### 1. `accumulate(iterable, func=operator.add)` — бегущий накопительный итог

Работает как выписка по счёту: на каждом шаге отдаёт накопленный итог (сумму по умолчанию либо любую функцию, например `max`):

```python
from itertools import accumulate

transactions = [1000, -200, -300, 500]
balance_history = list(
    accumulate(transactions)
)

# Накопительный баланс
print(balance_history)
# >>> [1000, 800, 500, 1000]

temps = [18, 22, 20, 25, 21]

# Бегущий максимум
print(list(accumulate(temps, max)))
# >>> [18, 22, 22, 25, 25]
```

### 2. `tee(iterable, n=2)` — раздвоение одного потока данных

Создаёт `n` независимых курсоров поверх одного итератора. Читайте ветки с близкой скоростью: если одна уйдёт далеко вперёд, Python буферизует непрочитанный хвост в RAM:

```python
from itertools import tee

gen = (x * 2 for x in range(1, 4))

# Дублируем поток итератора на 2 курсора
it1, it2 = tee(gen, 2)

print('Ветка 1:', list(it1))
# >>> Ветка 1: [2, 4, 6]

print('Ветка 2:', list(it2))
# >>> Ветка 2: [2, 4, 6]
```

## Маскирование и выравнивание: `compress` и `zip_longest`

Две утилиты `itertools`, регулярно встречающиеся на собеседованиях и при обработке табличных потоков:

- **`compress(data, selectors)`** — лениво фильтрует поток `data`, оставляя только те элементы, которым соответствует истинный флаг в булевой маске `selectors`.
- **`zip_longest(*iterables, fillvalue=None)`** — в отличие от встроенного `zip` (который обрезает результат по самой короткой коллекции), продолжает склейку до конца самой длинной, подставляя `fillvalue`:

```python
from itertools import compress, zip_longest

servers = ['srv-1', 'srv-2', 'srv-3']
healthy = [True, False, True]
print(list(compress(servers, healthy)))
# >>> ['srv-1', 'srv-3']

a = [1, 2, 3]
b = ['x']
padded = zip_longest(a, b, fillvalue='-')
print(list(padded))
# >>> [(1, 'x'), (2, '-'), (3, '-')]
```

> **Junior vs Senior**:
> - **Junior**: Склеивает крупные списки через `a + b + c` (копируя память), использует `groupby` без предварительной сортировки и теряет хвост данных при обычном `zip()` на списках разной длины.
> - **Senior**: Объединяет потоки за $O(1)$ памяти через `chain.from_iterable`, сортирует данные по тому же ключу перед `groupby`, режет пачки через `batched`/`islice` и использует `zip_longest` с явным `fillvalue`.
