## Зачем нужен itertools

Модуль **`itertools`** — это стандартная библиотека быстрых (реализованных на C) строительных блоков для работы с итераторами. Главное преимущество всех функций `itertools` — **ленивость** и память **$O(1)$**: они вычисляют элементы по одному на лету, не создавая гигантских промежуточных списков в оперативной памяти.

---

## Бесконечные итераторы: count, cycle, repeat

Бесконечные итераторы не имеют условия завершения. При переборе их ограничивают через `islice`, `zip` или условие `break`:

**1. `count(start=0, step=1)` — арифметический счётчик ID:**
```python
from itertools import count, islice

# Бесконечный инкремент без выделения списка в
# памяти
ids = count(start=100, step=5)
# [100, 105, 110, 115]
print(list(islice(ids, 4)))
```

**2. `cycle(iterable)` — циклическое переключение (Round-Robin):**
```python
from itertools import cycle

# Равномерное распределение задач по пулу
# воркеров
workers = cycle(['worker-1', 'worker-2', 'worker-3'])
tasks = ['t1', 't2', 't3', 't4']
print(list(zip(tasks, workers)))
# [('t1', 'worker-1'), ('t2', 'worker-2'),
# ('t3', 'worker-3'), ('t4', 'worker-1')]
```

**3. `repeat(elem, times=None)` — фиксация константы за $O(1)$ памяти:**
```python
from itertools import repeat

# Повторение объекта без дублирования ссылок в
# памяти
# ['ping', 'ping', 'ping']
print(list(repeat('ping', 3)))
```

## Объединение и фильтрация потоков: chain, islice, takewhile, dropwhile

**1. `chain(*iterables)` и `chain.from_iterable()` — конкатенация за $O(1)$ доп. памяти:**
Склеивают последовательности без создания промежуточных копий (в отличие от `list1 + list2`):
```python
from itertools import chain

# Выравнивание (flatten) вложенного списка без
# дублирования в памяти
matrix = [[1, 2], [3, 4], [5, 6]]
flat = list(chain.from_iterable(matrix))
# [1, 2, 3, 4, 5, 6]
print(flat)
```

**2. `islice(iterable, start, stop[, step])` — срез по генераторам:**
Стандартный срез `gen[2:6]` на генераторе вызывает ошибку `TypeError`. `islice` позволяет безопасно срезать ленивый поток:
```python
from itertools import islice

gen = (x * x for x in range(1000))
print(list(islice(gen, 2, 6)))  # [4, 9, 16, 25]
```

**3. `takewhile` vs `dropwhile` — фильтрация по первому условию:**
- `takewhile` берёт элементы, пока предикат истинен; при первом же `False` немедленно завершает поток.
- `dropwhile` отбрасывает элементы, пока условие истинно; при первом же `False` отдаёт всё оставшееся до конца.
```python
from itertools import takewhile, dropwhile

nums = [1, 3, 5, 2, 4, 7]
# [1, 3]
print(list(takewhile(lambda x: x < 5, nums)))
# [5, 2, 4, 7]
print(list(dropwhile(lambda x: x < 5, nums)))
```

## Группировка и нарезка батчами: groupby и batched

**`groupby(iterable, key=None)`** группирует элементы по значению ключа, но имеет **главную ловушку собеседований**: он объединяет **только соседние (подряд идущие)** элементы с одинаковым ключом — по аналогии с утилитой `uniq` в Linux. Поэтому перед вызовом `groupby` данные **обязательно нужно отсортировать** по тому же ключу `key`:

```python
from itertools import groupby

orders = [
    {'status': 'paid', 'id': 1},
    {'status': 'new', 'id': 2},
    {'status': 'paid', 'id': 3},
]

# 1. Сортируем по ключу: без этого 'paid'
# распадётся на две разные группы
orders_sorted = sorted(orders, key=lambda x: x['status'])

# 2. Группируем (вложенный итератор group
# материализуем сразу на шаге цикла)
grouped = {
    status: list(group)
    for status, group in groupby(orders_sorted, key=lambda x: x['status'])
}

# 3. Выводим результат группировки
for status, items in grouped.items():
    print(f"{status}: {[x['id'] for x in items]}")
# new: [2]
# paid: [1, 3]
```

Вторая тонкость `groupby`: возвращаемые подитераторы `group` разделяют общий базовый итератор. Если перейти к следующей итерации внешнего цикла, не сохранив предыдущий `group` в `list(group)`, данные прошлой группы будут потеряны.

Начиная с Python 3.12, в стандартной библиотеке появилась функция **`itertools.batched(iterable, n)`**, которая разбивает поток данных на кортежи длиной до `n` элементов — удобно для пакетной вставки (`bulk_insert`) в базу данных или отправки запросов чанками. В более ранних версиях Python батчинг реализуют через цикл с `islice(it, n)`.

## Комбинаторика: product, permutations, combinations

Комбинаторные функции заменяют многоуровневые вложенные циклы и рекурсивный перебор вариантов:

**1. `product(*iterables)` — декартово произведение (вложенные циклы):**
```python
from itertools import product

# Эквивалент циклов: for x in [1, 2]: for y in
# ['a', 'b']:
print(list(product([1, 2], ['a', 'b'])))
# [(1, 'a'), (1, 'b'), (2, 'a'), (2, 'b')]
```

**2. `permutations(iterable, r=None)` — перестановки (порядок важен):**
```python
from itertools import permutations

# Пары (A, B) и (B, A) считаются РАЗНЫМИ
print(list(permutations('AB', 2)))
# [('A', 'B'), ('B', 'A')]
```

**3. `combinations(iterable, r)` — сочетания без повторений:**
```python
from itertools import combinations

# Порядок НЕ важен: ('A', 'B') и ('B', 'A') —
# это один и тот же набор
print(list(combinations('ABC', 2)))
# [('A', 'B'), ('A', 'C'), ('B', 'C')]
```

**4. `combinations_with_replacement(iterable, r)` — сочетания с повторением элементов:**
```python
from itertools import combinations_with_replacement

print(list(combinations_with_replacement('AB', 2)))
# [('A', 'A'), ('A', 'B'), ('B', 'B')]
```

## Накопление и разветвление: accumulate и tee

**1. `accumulate(iterable, func=operator.add)` — бегущий накопительный итог:**
- *Аналогия для новичка*: это как история баланса в банковской выписке. Каждая строка показывает текущий суммарный итог после очередной операции.
- По умолчанию складывает числа, но можно передать любую операцию (например, бегущий максимум `max`):
```python
from itertools import accumulate

transactions = [1000, -200, -300, 500]
balance_history = list(accumulate(transactions))
# [1000, 800, 500, 1000]
print(balance_history)

# Бегущий максимум
temps = [18, 22, 19, 25, 21]
# [18, 22, 22, 25, 25]
print(list(accumulate(temps, max)))
```

**2. `tee(iterable, n=2)` — раздвоение одного потока данных:**
- *Аналогия для новичка*: как сантехнический тройник на трубе с водой. Из одной входящей трубы получаются два независимых крана с тем же самым потоком данных.
- *Важная ловушка памяти*: оба итератора нужно читать параллельно с одинаковой скоростью. Если один итератор уйдёт далеко вперёд, Python будет вынужден хранить все непрочитанные вторым краном данные в оперативной памяти RAM:
```python
from itertools import tee

gen = (x * 2 for x in range(1, 4))
it1, it2 = tee(gen, 2)

print('Ветка 1:', list(it1))  # [2, 4, 6]
print('Ветка 2:', list(it2))  # [2, 4, 6]
```
