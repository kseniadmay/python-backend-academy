1. Что такое магические (dunder) методы? >> Методы вида __method__, которые Python вызывает автоматически в ответ на встроенные операции (сложение, сравнение, вывод и т.д.).
2. Какой метод отвечает за вывод объекта в консоли разработчика? >> __repr__.
3. Какой метод отвечает за вывод через print()? >> __str__.
4. Какой метод перегружает оператор +? >> __add__.
5. Какой метод делает объект вызываемым как функцию: obj()? >> __call__.
6. Какие методы нужны для протокола итератора? >> __iter__ и __next__.
7. Что произойдёт с __hash__, если класс переопределяет __eq__ без явного __hash__? >> Объект станет нехэшируемым (__hash__ станет None).
8. Какие методы нужны для протокола контекстного менеджера (with)? >> __enter__ и __exit__.
9. Какой метод определяет поведение оператора [] для чтения: obj[key]? >> __getitem__.
10. Какой метод определяет поведение len(obj)? >> __len__.
11. Какой метод определяет поведение оператора in: x in obj? >> __contains__.
12. Что произойдёт, если у класса нет __contains__, но есть __iter__? >> Python автоматически будет использовать перебор через __iter__ для проверки in.
13. Какой метод вызывается при удалении атрибута через del obj.attr? >> __delattr__.
14. Какой метод определяет поведение with obj: ... при входе в блок? >> __enter__.
15. Чем __repr__ отличается по назначению от __str__? >> __repr__ — однозначное представление для разработчика/отладки (по возможности воспроизводимое), __str__ — читаемое представление для конечного пользователя.
16. Что Python использует, если у класса определён __repr__, но не определён __str__? >> __str__ по умолчанию делегирует к __repr__.
17. Какой метод определяет поведение унарного минуса: -obj? >> __neg__.
18. Какой метод вызывается при обращении к несуществующему атрибуту объекта? >> __getattr__ (вызывается только если обычный поиск атрибута не нашёл его).
19. Чем __getattr__ отличается от __getattribute__? >> __getattribute__ вызывается ПРИ ЛЮБОМ обращении к атрибуту, __getattr__ — только если обычный механизм поиска атрибута не нашёл его.
20. Какой метод определяет поведение оператора []= для записи: obj[key] = value? >> __setitem__.
21. Какой метод делает объект итерируемым в цикле for? >> __iter__.
22. Какой метод вызывается при exit из блока with при возникшем исключении? >> __exit__(self, exc_type, exc_value, traceback) — получает информацию об исключении и может его подавить, вернув True.
