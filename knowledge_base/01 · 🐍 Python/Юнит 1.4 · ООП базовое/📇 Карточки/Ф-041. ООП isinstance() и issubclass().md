1. Работает ли `isinstance()` с абстрактными базовыми классами (`abc.ABC`) и виртуальными подклассами? >> Да; если класс зарегистрирован через `register()` абстрактного класса или проходит его проверку `__subclasshook__()`, `isinstance()` вернёт `True` даже без явного наследования
2. Какую функцию использовать для проверки, является ли объект экземпляром класса или подкласса? >> `isinstance(obj, cls)`
3. Что общего у `isinstance` и `issubclass`? >> Обе возвращают `bool` и учитывают иерархию наследования
4. Что вернёт `issubclass(Dog, Animal)`, если `Dog` наследует `Animal`? >> `True`, так как класс `Dog` является прямым потомком `Animal`
5. Какая функция проверяет, является ли один класс производным от другого? >> `issubclass(cls1, cls2)`
6. Какая проверка вернёт `False` для объекта подкласса при сравнении с базовым классом? >> `type(obj) == BaseClass`
7. Какой результат вернёт проверка `isinstance(True, int)` в Python и почему? >> `True`; `bool` является подклассом `int`
8. Какая функция принимает объект первым аргументом? >> `isinstance`
9. Для чего используется кортеж во втором аргументе `isinstance`? >> Для проверки принадлежности объекта к любому из перечисленных классов
10. Что можно передать вторым аргументом `isinstance` для проверки на несколько классов? >> Кортеж классов: `isinstance(obj, (list, tuple))`
11. Какой результат вернёт проверка `isinstance([], (list, tuple))` при передаче кортежа допустимых типов? >> `True`, так как пустой список является экземпляром `list`, входящего в проверяемый кортеж типов
12. Является ли класс подклассом самого себя? >> Да; `issubclass(bool, bool)` → `True`; каждый класс считается подклассом себя самого
13. Какой результат вернёт проверка `issubclass(bool, int)` и какова иерархия наследования типа `bool` в Python? >> `True`, так как в Python тип `bool` исторически и архитектурно является прямым подклассом `int`
14. Какая функция принимает исключительно классы обоими аргументами? >> `issubclass`; передача экземпляра вместо класса выбросит `TypeError`
15. Какой результат вернёт проверка типа `isinstance([], list)` для литерала пустого списка в Python? >> `True`, так как литерал `[]` создаёт экземпляр встроенного класса `list`
16. В чём преимущество `isinstance` перед `type(obj) == cls`? >> Учитывает иерархию наследования; `type()` возвращает точный тип без учёта родителей
