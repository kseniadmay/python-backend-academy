## Базовое наследование и выбор против композиции

Наследование выражает отношение «является» (`is-a`): дочерний класс получает атрибуты и методы родителя и может их переопределять:

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return f'{self.name} издаёт звук'

class Dog(Animal):
    def speak(self):
        return f'{self.name} лает'

class Cat(Animal):
    pass

print(Dog('Рекс').speak())
# >>> Рекс лает

print(Cat('Мурка').speak())
# >>> Мурка издаёт звук
```

Применяйте наследование, только когда дочерний класс действительно является подтипом родителя (`is-a`). Если нужно просто переиспользовать чужие методы, выбирайте **композицию** («содержит в себе», `has-a`).

## isinstance() – проверка типа с учётом иерархии

**`isinstance(obj, Class)`** проверяет, является ли `obj` экземпляром `Class` или любого его подкласса (поддерживается также кортеж классов):

```python
class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    pass

class Cat(Animal):
    pass

d = Dog('Рекс')
print(isinstance(d, Dog))
# >>> True

# Dog — подкласс Animal
print(isinstance(d, Animal))
# >>> True

# Точный тип именно Dog, не Animal
print(type(d) == Animal)
# >>> False

print(isinstance(d, (Dog, Cat)))
# >>> True
```

Используйте `isinstance()` перед специализированной обработкой объекта, чтобы код корректно принимал подклассы.

## issubclass() – проверка отношения между классами

**`issubclass(ChildClass, ParentClass)`** проверяет наследование на уровне самих **классов** (полезно в фабриках и регистрации плагинов):

```python
class Animal:
    pass

class Dog(Animal):
    pass

print(issubclass(Dog, Animal))
# >>> True

# Родитель не является подклассом потомка
print(issubclass(Animal, Dog))
# >>> False

# Класс считается подклассом самого себя
print(issubclass(Dog, Dog))
# >>> True
```

## Преимущества isinstance() перед прямым сравнением type()

`isinstance()` уважает полиморфизм: код, ожидающий `Animal`, безопасно примет любой подкласс `Animal` с совместимым интерфейсом.

Прямое сравнение `type(obj) == Animal` ломается на наследниках и считается антипаттерном за пределами редких случаев, где нужна строго точная проверка типа.

## Виртуальные подклассы и явная регистрация через register()

Функция `isinstance()` поддерживает регистрацию виртуальных подклассов без физического наследования через ABC-метод `register()`:

```python
from abc import ABC, abstractmethod

class SoundEmitter(ABC):
    @abstractmethod
    def make_sound(self) -> str:
        pass

class Radio:
    def make_sound(self) -> str:
        return 'Играет музыка'

# Делаем Radio виртуальным подклассом
SoundEmitter.register(Radio)

r = Radio()
print(isinstance(r, SoundEmitter))
# >>> True

print(issubclass(Radio, SoundEmitter))
# >>> True
```

Виртуальный подкласс проходит проверки `isinstance()` и `issubclass()`, не добавляя родительский класс в цепочку MRO.

## Структурная типизация в рантайме: метод `__subclasshook__`

Модуль `abc` позволяет абстрактному классу определить метод `__subclasshook__(cls, C)`, проверяющий наличие нужных методов в классе `C`:

- Так устроена стандартная библиотека `collections.abc` (`Iterable`, `Sequence`, `Mapping`).
- Любой класс с методом `__iter__` автоматически признаётся экземпляром `collections.abc.Iterable` без явного вызова `register()` или наследования.
