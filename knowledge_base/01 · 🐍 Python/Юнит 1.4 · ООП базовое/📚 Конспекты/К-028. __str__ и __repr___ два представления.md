## Различие назначения методов `__str__` и `__repr__`

Один объект нужно показывать в двух разных контекстах: человеку (читаемо и кратко) и разработчику в отладчике (однозначно и полно).

Python разделяет эти две задачи между магическими методами `__str__` и `__repr__`.

---

## `__str__` – представление для человека

**`__str__`** вызывается через `print(obj)` или `str(obj)` и возвращает удобную для пользователя строку:

```python
from datetime import date

d = date(2024, 1, 15)
print(str(d))
# >>> 2024-01-15
```

Дата выводится в чистом формате ISO для отчётов и интерфейса без технических деталей класса.

---

## `__repr__` – представление для разработчика

**`__repr__`** вызывается в REPL, стек-трейсах, логах и функцией `repr(obj)` для однозначной диагностики типа и атрибутов:

```python
from datetime import date

d = date(2024, 1, 15)
print(repr(d))
# >>> datetime.date(2024, 1, 15)
```

Идеал для `__repr__` — строка, пригодная для воссоздания объекта (`eval(repr(obj)) == obj`), либо хотя бы точное имя класса и ключевые поля.

---

## Как реализовать оба метода в своём классе

Переопределим оба представления на примере простого класса двумерного вектора:

```python
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    # Для разработчиков и отладки (repr)
    def __repr__(self):
        return f'Vector({self.x}, {self.y})'

    # Для пользователя и print()
    def __str__(self):
        return f'({self.x}, {self.y})'

v = Vector(3, 5)
print(repr(v))
# >>> Vector(3, 5)

print(v)
# >>> (3, 5)
```

`__repr__` чётко показывает конструктор `Vector(3, 5)` для логов, а `__str__` отдаёт пользователю координаты `(3, 5)`.

---

## Асимметрия фолбэка и практические правила

Если в классе задан только `__repr__`, Python использует его и как фолбэк вместо `__str__`.

Обратное неверно: если определить только `__str__`, в REPL и логах останется адрес `<__main__.MyClass object at 0x...>`.

Определяйте `__repr__` для каждого класса как стандарт отладки, а `__str__` добавляйте только тогда, когда объект нужно красиво выводить пользователю.
