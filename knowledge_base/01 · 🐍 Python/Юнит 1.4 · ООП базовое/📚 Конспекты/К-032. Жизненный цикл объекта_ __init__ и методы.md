## Класс и экземпляр – в чём разница

**Класс** – это описание структуры: какие атрибуты будет иметь объект, какие методы он умеет вызывать. **Экземпляр** – это конкретный объект в памяти, созданный по этому описанию. Когда вы пишете `Car('BMW')`, Python выделяет память и создаёт живой объект с собственным состоянием.

---

## `__init__` – инициализация состояния

```python
class Car:
    def __init__(self, brand):
        self.brand = brand  # уникальная характеристика этого экземпляра
        self.speed = 0  # начальное состояние одинаково для всех

    def accelerate(self, value):
        self.speed += value

car = Car('BMW')
car.accelerate(50)
```

`__init__` вызывается автоматически один раз – в момент создания объекта. Его задача – записать начальное состояние: какие атрибуты есть у объекта и какие у них значения сразу после рождения.

Через `self.brand = brand` Python записывает переданное значение именно в этот конкретный экземпляр, а не во все объекты класса. `self.speed = 0` устанавливает значение по умолчанию, одинаковое для любого нового `Car`. Без явной инициализации в `__init__` атрибуты не существуют – обращение к ним вызовет `AttributeError`.

## Обычные методы – поведение объекта

Метод `accelerate` описывает, что объект **умеет делать**. В отличие от `__init__`, обычные методы вызываются явно и столько раз, сколько нужно. Они работают с уже существующим состоянием объекта через `self`, читая и изменяя его атрибуты.

Разделение на **состояние** (что объект есть) и **поведение** (что объект делает) – базовый принцип ООП. `__init__` отвечает за первое, методы – за второе. Смешивать их не стоит: логика ускорения не должна жить в конструкторе, а инициализация атрибутов – в методах движения.

---

## Ключевые различия

`__init__` вызывается автоматически при создании объекта и срабатывает ровно один раз. Обычные методы вызываются явно и могут вызываться сколько угодно раз на протяжении всей жизни объекта. `__init__` формирует начальное состояние, методы это состояние используют и изменяют.

Технически `__init__` – это обычный метод с особым соглашением об имени и автоматическом вызове. Никакой магии: Python просто вызывает его сразу после того, как `__new__` создал объект в памяти.

---

## Частая архитектурная ошибка

Перегружать `__init__` сложной логикой – плохая практика. Конструктор должен только устанавливать начальное состояние. Если инициализация требует сложных вычислений, сетевых запросов или обращения к базе данных, это сигнал вынести логику в отдельный метод или фабричную функцию. Тяжёлый конструктор усложняет тестирование: объект становится трудно создать в изоляции.
