## Класс и экземпляр – в чём разница

**Класс** — это описание структуры: какие атрибуты будут у объекта и какие методы он умеет вызывать.

**Экземпляр** — живой объект в памяти со своим состоянием, созданный по чертежу класса выражением вроде `Car('BMW')`.

---

## `__init__` – инициализация состояния

После того как `__new__` выделил память, Python автоматически вызывает метод `__init__`, чтобы задать начальные атрибуты экземпляра:

```python
class Car:
    def __init__(self, brand):
        # Уникальный атрибут экземпляра
        self.brand = brand

        # Общее начальное состояние
        self.speed = 0

    def accelerate(self, value):
        self.speed += value

car = Car('BMW')
car.accelerate(50)
print(car.brand, car.speed)
# >>> BMW 50
```

Через `self.brand = brand` значение записывается именно в конкретный объект. Без явной инициализации поля в `__init__` обращение к нему вызовет `AttributeError`.

---

## Обычные методы – поведение объекта

Метод `accelerate` задаёт **поведение**: в отличие от однократного `__init__`, обычные методы вызывают явно столько раз, сколько нужно, изменяя уже существующие поля `self`.

Разделение на **состояние** (в `__init__`) и **поведение** (в методах) — основа ООП: логика движения не должна жить в конструкторе, а создание обязательных полей — в произвольных методах.

---

## Частая архитектурная ошибка в `__init__`

Перегружать `__init__` тяжёлой логикой (сетевыми запросами, походами в БД, сложным расчётом) — плохая практика: конструктор должен лишь быстро задавать начальное состояние.

Если объекту нужна тяжёлая подготовка или I/O, выносите её в отдельный метод или фабричную функцию — иначе класс будет крайне сложно инициализировать в изолированных тестах.
