## Что такое магические методы и модель данных

**Магические методы** (dunder-методы вида `__method__`) формируют модель данных Python (*Python Data Model*): интерпретатор вызывает их автоматически при операциях `+`, `print()`, `len()`, `in`, `for` или `with`.

Реализуя нужные методы, пользовательский класс встраивается в синтаксис языка и ведёт себя как встроенный тип («поддержка протокола»).

---

## Категории методов и пример класса `Money`

Основные группы магических методов в модели данных Python:

| Категория | Ключевые методы | Что включают в классе |
| :--- | :--- | :--- |
| **Жизненный цикл и текст** | `__new__`, `__init__`, `__repr__`, `__str__` | Создание и вывод объекта |
| **Арифметика** | `__add__`, `__sub__`, `__mul__`, `__radd__` | Операторы `+`, `-`, `*` |
| **Сравнение и контейнеры** | `__eq__`, `__lt__`, `__len__`, `__getitem__`, `__iter__` | `==`, `<`, `len()`, `for` |
| **Контекст и вызовы** | `__enter__`/`__exit__`, `__call__`, `__get__` | `with`, `obj()`, дескрипторы |

Пример класса-значения `Money`, поддерживающего строковые представления:

```python
class Money:
    def __init__(self, amount, curr='USD'):
        self.amount = amount
        self.currency = curr

    # Однозначный формат для отладки
    def __repr__(self):
        amt, cur = self.amount, self.currency
        return f'Money({amt}, {cur!r})'

    # Читаемый вывод для пользователя
    def __str__(self):
        amt, cur = self.amount, self.currency
        return f'{amt} {cur}'

price = Money(100)
print(repr(price), '|', price)
# >>> Money(100, 'USD') | 100 USD
```

## Контракт `__eq__` и `__hash__`

При переопределении `__eq__` Python автоматически выставляет `__hash__ = None` и запрещает класть объект в `set` или ключом `dict`, чтобы не нарушить инвариант равенства хэшей.

Чтобы вернуть хэшируемость, определите `__hash__` согласованно с теми же полями, что участвуют в `__eq__`:

```python
class Money:
    def __init__(self, amount, curr='USD'):
        self.amount = amount
        self.currency = curr

    def __eq__(self, other):
        if not isinstance(other, Money):
            return NotImplemented
        a = (self.amount, self.currency)
        b = (other.amount, other.currency)
        return a == b

    def __hash__(self):
        key = (self.amount, self.currency)
        return hash(key)

wallet = {Money(50, 'EUR'), Money(50, 'EUR')}
print(len(wallet))
# >>> 1
```

## Когда использовать магические методы

Переопределяйте операторы, когда объект естественно ведёт себя как значение (`Money`, `Vector`, `DateRange`). Не добавляйте `__add__` к классам вроде `UserService`, где сложение не имеет смысла.

При этом `__repr__` стоит определять почти для каждого класса, чтобы в логах сразу видеть поля объекта вместо адреса памяти.
