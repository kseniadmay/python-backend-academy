1. Что выведет `square(5)` при `square = partial(power, exp=2)` для `power(base, exp): return base ** exp`? >> `25` (вызов `power(5, exp=2)`) >> `25`
2. В чём практическая разница между вызовами `square(5)` (через `partial(power, exp=2)` ) и прямым `power(5, 2)` ? >> Результат одинаков; в `square` аргумент `exp=2` зафиксирован заранее
3. Что выведет вызов `greet()` после декорирования: `def my_decorator(func):; def wrapper():; print('before'); func(); return wrapper; @my_decorator; def greet():; print('Hello'); greet()` ? >> `before` , затем `Hello`
4. Что выведет `cube(3)` при `cube = partial(power, exp=3)` для `power(base, exp): return base ** exp`? >> `27` (вызов `power(3, exp=3)`) >> `27`
5. Что произойдёт с `__name__` и `__doc__` декорируемой функции, если декоратор НЕ использует `@functools.wraps`? >> Они перезапишутся метаданными функции-обёртки: `'wrapper'` и docstring обёртки >> `'wrapper'` и `None`
6. Что выведет `print(greet.__name__)`, если декоратор использует `@functools.wraps(func)`? >> Имя исходной функции `'greet'` (метаданные корректно сохранены) >> `'greet'`
7. Что обязательно должна возвращать функция `wrapper` внутри декоратора? >> Результат вызова оригинальной функции `func(*args, **kwargs)`
8. Что вернёт `greet.__doc__`, если декоратор использует `@functools.wraps(func)`? >> Докстринг исходной функции `'Greets the user'` >> `'Greets the user'`
9. Что такое `partial` ? >> Функция из `functools` , создающая новую функцию с частично зафиксированными аргументами оригинальной
10. Какие атрибуты сохраняет `@wraps` ? >> `__name__` , `__doc__` , `__module__` , `__qualname__` , `__annotations__` , `__wrapped__`
11. Для каких функций декоратор `@functools.lru_cache` наиболее эффективен? >> Для рекурсивных и тяжёлых вычислений с повторяющимися аргументами
12. Почему `lru_cache` эффективен для `fibonacci` ? >> Исключает повторные вычисления: каждое `fibonacci(n)` вычисляется ровно один раз и берётся из кэша при повторном обращении
13. Как импортировать `partial` ? >> `from functools import partial`
14. Что означает LRU в `lru_cache` ? >> Least Recently Used – вытеснение наименее недавно использовавшихся записей при достижении лимита
15. Изменяет ли `partial` оригинальную функцию? >> Нет; создаёт новый объект типа `functools.partial`
16. Где располагается `@wraps(func)` внутри декоратора? >> Непосредственно перед определением внутренней функции `wrapper`
17. Какой декоратор сохраняет метаданные оригинальной функции внутри декоратора? >> `@wraps` из `functools`
18. Как создать `square` через `partial` на основе `power(base, exp)` ? >> `square = partial(power, exp=2)`
19. Как называется стандартный модуль Python с утилитами для работы с функциями? >> `functools`
20. Что произойдёт с `__name__` без `@wraps` ? >> Будет перезаписан именем обёртки: `'wrapper'`
21. Как импортировать `lru_cache` ? >> `from functools import lru_cache`
22. Какое ограничение накладывает `lru_cache` на аргументы функции? >> Аргументы должны быть хешируемыми ( `hashable` ); передача `list` или `dict` выбросит `TypeError`
23. Какой декоратор из `functools` кэширует результаты вызовов функций? >> `lru_cache`
24. Какой параметр ограничивает размер кэша в `lru_cache` ? >> `maxsize` ; по умолчанию `128` ; `None` – безлимитный кэш; `0` – кэш отключён
25. Что такое LRU-кэширование? >> Механизм хранения результатов вычислений; при достижении `maxsize` удаляются самые давно неиспользуемые записи
26. Какая современная альтернатива `lru_cache` появилась в Python 3.9? >> `@cache` из `functools` – эквивалент `lru_cache(maxsize=None)` без накладных расходов на управление размером
27. Что такое частичное применение функций? >> Фиксация части аргументов функции для создания новой функции с меньшим количеством параметров
