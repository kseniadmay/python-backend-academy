1. Какая переменная из внешней области видимости сохраняется в объекте замыкания внутренней функции `multiplier(x)` при вызове фабрики `make_multiplier(n)`? >> Аргумент `n` из внешней функции `make_multiplier`.
2. Какое значение вернёт вызов функции `f(10)` при фабрике `make_multiplier(2)`? >> `20` – внутренняя функция `multiplier` сохраняет `n = 2` в замыкании; при `f(10)` вычисляется `10 * 2`
3. Как исправить ловушку позднего связывания в цикле `[lambda: i for i in range(3)]`? >> Захватить текущее значение через аргумент по умолчанию: `lambda i=i: i` (или использовать `functools.partial`).
4. При объявлении `funcs = [lambda x=i: x for i in range(3)]` какой результат вернёт вызов `[f() for f in funcs]`? >> `[0, 1, 2]`.
5. Чему равно значение `i` при вызове лямбд из списка `[lambda: i for i in range(3)]`? >> `2` — последнее значение после завершения цикла.
6. Какое числовое значение вернёт вызов `times3(5)` для замыкания-умножителя на 3? >> `15` – внутренняя функция `multiplier` сохраняет `n = 3` в объекте замыкания; при `times3(5)` вычисляется `5 * 3`.
7. Почему конструкция `lambda i=i: i` решает проблему позднего связывания в цикле? >> Значение аргумента по умолчанию вычисляется и фиксируется в момент создания функции, а не в момент вызова.
8. Что возвращает фабричная функция `make_multiplier(n)`? >> Вложенную функцию `multiplier` с захваченным `n`.
9. Почему выражение `[f() for f in [lambda: i for i in range(3)]]` вернёт `[2, 2, 2]`, а не `[0, 1, 2]` (эффект позднего связывания)? >> Все лямбда-функции замыкаются на одну переменную `i`, а не на её текущее значение; к моменту вызова цикл уже завершён и `i == 2`.
10. Как `nonlocal` связан с замыканиями? >> `nonlocal` позволяет вложенной функции не только читать, но и изменять переменную из охватывающей области; без него присваивание создаст новую локальную переменную.
11. На каком механизме работают декораторы в Python? >> На замыканиях.
12. Как диагностировать захваченные переменные замыкания? >> Через атрибут `__closure__`: `f.__closure__` возвращает кортеж `cell`-объектов с захваченными значениями.
13. Что такое замыкание (`closure`) в Python? >> Функция, которая запоминает переменные из охватывающей области видимости и сохраняет доступ к ним после завершения внешней функции.
14. Что происходит с переменной внешней функции после её завершения, если на неё ссылается замыкание? >> Переменная сохраняется в памяти — сборщик мусора не удаляет её, пока существует замыкание.
15. Что такое фабричная функция? >> Функция, создающая и возвращающая другие функции, настраивая их поведение через замыкания.
16. Что именно хранит замыкание: значение переменной или ссылку? >> Ссылку на переменную; это и является причиной ловушки в циклах.
17. Какую область видимости запоминает замыкание? >> Охватывающую (`Enclosing`) — уровень E в LEGB.
18. Как называется удержание переменных внешней области видимости в памяти? >> Захват переменных (`capture`).
