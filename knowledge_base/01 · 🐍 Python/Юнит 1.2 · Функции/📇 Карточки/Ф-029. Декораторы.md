1. Сколько уровней вложенности функций необходимо для реализации параметризованного декоратора с аргументами в Python? >> Три: внешняя функция принимает аргументы декоратора, средняя — `func`, внутренняя — `wrapper`.
2. В каком порядке применяются (оборачиваются) и в каком порядке затем выполняются несколько последовательных декораторов `@A` и `@B`? >> Оборачиваются снизу вверх: `@A` над `@B` эквивалентно `f = A(B(f))`, а при вызове `f()` сначала выполняется внешний код обёртки `A`, затем `B`, затем сама `f`.
3. Сколько раз выполнится тело функции `greet()` при её однократном вызове, если она декорирована параметризованным декоратором `@repeat(3)`? >> 3 раза подряд.
4. Как устроен базовый шаблон декоратора для замера времени выполнения (`@timer`)? >> Сохранить `start = time.perf_counter()` перед вызовом `func()`, после вызова вычислить прошедшее время (`time.perf_counter() - start`) и вернуть результат.
5. Как функция `wrapper` в параметризованном декораторе `@repeat(n)` обращается к значению `n`? >> Через замыкание: `n` захватывается из области видимости внешней функции.
6. Как реализовать параметризованный декоратор, чтобы передавать ему аргументы вроде `@my_decorator(timeout=10)`? >> Обернуть декоратор во внешнюю функцию-фабрику: `def my_decorator(timeout): def decorator(func): def wrapper(*args, **kwargs): ...`.
7. Что произойдёт с атрибутом `__name__` декорированной функции, если забыть `@functools.wraps`? >> Примет значение `'wrapper'` вместо имени оригинальной функции.
8. Влияет ли применение декоратора на синтаксис вызова декорированной функции со стороны вызывающего кода? >> Нет; функция вызывается так же, как без декоратора.
9. Что принимает средняя (вторая по вложенности) функция в параметризованном декораторе? >> Оригинальную функцию `func`.
10. Что принимает внешняя функция в `repeat(n)`? >> Аргумент декоратора — количество повторений `n`.
11. Каковы типичные практические примеры применения декораторов функций в Python? >> Логирование, замер времени, кэширование, проверка прав доступа, retry-логика.
12. Зачем внутри `wrapper` вызывается оригинальная функция? >> Чтобы выполнить её логику и получить результат.
13. Что должен возвращать `wrapper`? >> Результат вызова оригинальной функции.
14. Какую задачу решает `@wraps(func)`? >> Сохраняет метаданные оригинальной функции: `__name__`, `__doc__` и другие атрибуты.
15. Что такое декоратор в Python? >> Функция, принимающая другую функцию, дополняющая её логикой и возвращающая новую функцию.
16. Что принимает `wrapper`, чтобы работать с любой функцией? >> `*args` и `**kwargs`.
17. Для чего используются декораторы функций в языке Python? >> Для добавления поведения функции без изменения её исходного кода.
18. Может ли декоратор изменить возвращаемое значение? >> Да; `wrapper` полностью контролирует, что возвращается вызывающему коду.
19. Когда нужны три уровня вложенности? >> Когда декоратор принимает собственные аргументы: `@repeat(3)`.
20. Какой символ указывает на применение декоратора? >> `@`.
21. Из какого модуля импортируется `@wraps`? >> `functools`.
22. Что произойдёт, если `wrapper` не возвращает `result`? >> Функция всегда будет возвращать `None`.
23. Является ли `@wraps` обязательным? >> Нет, но это стандартная практика; без него теряются метаданные функции.
24. Чему эквивалентен `@decorator` над `func`? >> `func = decorator(func)`.
