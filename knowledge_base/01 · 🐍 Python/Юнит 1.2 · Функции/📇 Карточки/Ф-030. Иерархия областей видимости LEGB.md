1. К какой области видимости относятся `len` , `print` , `range` ? >> Built-in (B)
2. Что определяет иерархия LEGB в Python? >> Порядок поиска имён переменных в различных областях видимости
3. Где Python ищет переменную в последнюю очередь? >> В области встроенных имён (Built-in)
4. Если переменная не найдена в Local и Enclosing, где Python продолжит поиск? >> В глобальной области модуля (Global)
5. Что охватывает уровень Global (G)? >> Уровень модуля: переменные и функции, объявленные вне всех функций
6. К какому уровню LEGB относится переменная, объявленная на уровне модуля? >> Global (G)
7. Если имя не найдено ни на одном уровне LEGB, что произойдёт? >> Python выбросит `NameError`
8. Для какой конструкции особенно важен уровень Enclosing (E)? >> Для замыканий (closures); именно через него внутренняя функция обращается к переменным внешней
9. Что охватывает уровень Local (L)? >> Локальную область текущей функции; переменные, объявленные внутри неё
10. Что содержится в области Built-in (B)? >> Встроенные имена Python: функции ( `len` , `print` , `range` ), исключения ( `TypeError` , `ValueError` ) и константы
11. Что охватывает уровень Enclosing (E)? >> Область охватывающих функций; используется в замыканиях (closures)
12. Что такое shadowing в контексте LEGB? >> Когда переменная на внутреннем уровне перекрывает имя с внешнего уровня; например, локальная переменная `len` скроет встроенную функцию `len` из Built-in
13. С какого уровня Python начинает поиск переменной внутри функции? >> С локального (Local)
14. Как расшифровывается LEGB и каков порядок поиска? >> Local -> Enclosing -> Global -> Built-in; Python проверяет уровни последовательно и останавливается на первом совпадении
