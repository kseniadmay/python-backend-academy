1. Из скольких выражений может состоять тело анонимной `lambda`-функции в Python? >> Ровно из одного — не набор инструкций, без if/else в виде оператора, без циклов.
2. Какой самый частый практический сценарий использования `lambda`-функций в Python? >> Аргумент key= для sorted(), max(), min(), или callback для filter()/map().
3. Почему PEP 8 не рекомендует `f = lambda: ...` с присваиванием переменной? >> У обычной функции `def` есть осмысленное имя в трейсбеке, у лямбды `__name__` всегда равно `'<lambda>'`, что затрудняет отладку логов.
4. В чём ловушка лямбды внутри цикла? >> Лямбда захватывает переменную, а не её значение на момент создания — та же проблема, что и с замыканиями.
5. Допустимо ли объявлять анонимную функцию `lambda` без параметров в синтаксисе Python? >> Да: `f = lambda: 42`.
6. Поддерживает ли синтаксис `lambda` в Python значения параметров по умолчанию (например, `lambda x=0: x + 1`)? >> Да: `lambda x, y=10: x + y` — синтаксис значений по умолчанию полностью поддерживается.
7. Возможна ли прямая рекурсия внутри анонимной `lambda`-функции без связывания её с именем переменной? >> Технически возможна через передачу функции самой себе аргументом — комбинатор неподвижной точки вида `(lambda f, n: f(f, n))(lambda self, n: ..., 5)`, но на практике для рекурсии используют `def`.
8. Какой результат вернёт немедленный вызов лямбда-функции `(lambda x: x**2)(5)` в Python? >> 25 — лямбду можно вызвать сразу же после определения.
9. Поддерживает ли синтаксис `lambda` приём переменного числа аргументов через `*args` и `**kwargs`? >> Да: `f = lambda *args, **kwargs: sum(args)`.
10. Какое строковое значение содержит атрибут `__name__` для любой лямбда-функции в Python? >> `'<lambda>'` — у всех лямбда-функций всегда одно и то же служебное имя, независимо от переменной, в которую они сохранены.
11. Допустимо ли передавать `lambda`-функцию в качестве значения аргумента по умолчанию в Python? >> Да: `def f(callback=lambda: None):` — распространённый паттерн опционального обратного вызова (no-op по умолчанию).
