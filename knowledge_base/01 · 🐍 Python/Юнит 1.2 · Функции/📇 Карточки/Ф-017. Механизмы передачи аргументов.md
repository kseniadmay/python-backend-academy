1. В чём ловушка с переприсваиванием изменяемого аргумента внутри функции (`lst = [1, 2, 3]`)? >> `def f(lst): lst = [1,2,3]` не изменит внешний список; переприсваивание разрывает связь с оригиналом; для изменения нужны методы мутации: `.append()`, `.extend()` и т.д.
2. Указывает ли параметр `lst` внутри функции `append_item(lst)` на тот же объект в памяти, что и переданный внешний список `my_list`? >> Да, на тот же объект списка в памяти, что и `my_list` снаружи.
3. Что выведет `print(my_list)` после вызова функции `append_item(my_list)`, если внутри неё выполняется `lst.append(99)` над исходным списком `[1, 2, 3]`? >> `[1, 2, 3, 99]`.
4. Почему значение переменной `a = 5` не меняется после вызова функции `def change(x): x = 100` в Python? >> `int` неизменяем; оператор `=` лишь перепривязывает локальное имя `x` к новому объекту `100`, не затрагивая исходный объект `a`.
5. Что происходит при переприсваивании аргумента внутри функции (`x = 100`)? >> Локальная переменная начинает указывать на новый объект; оригинал не затрагивается.
6. Может ли функция изменить значение переданного неизменяемого объекта (`int`, `str`, `tuple`) во внешнем коде? >> Нет; любое «изменение» создаёт новый объект и новую локальную ссылку.
7. Какая операция изменяет оригинал без разрыва ссылки? >> Методы мутации: `.append()`, `.extend()`, `.update()` и др.
8. Создаётся ли новая переменная при вызове `.append()` на `mutable`-объекте? >> Нет; метод работает напрямую с исходным объектом по существующей ссылке.
9. Что именно копируется при передаче аргумента в функцию? >> Копируется ссылка на объект, но не сам объект; функция получает доступ к тому же адресу в памяти.
10. От чего зависит, изменит ли функция оригинальный объект? >> От изменяемости (`mutability`) объекта: `mutable` — изменится, `immutable` — нет.
11. Как изменения `mutable`-объекта внутри функции отражаются снаружи? >> Изменения видны снаружи, так как функция работает с тем же объектом в памяти.
12. Почему Python не является ни `pass by value`, ни `pass by reference`? >> Передаётся копия ссылки на объект; поведение зависит от изменяемости объекта, а не от механизма передачи.
13. Как называется механизм передачи аргументов в Python? >> Передача по присваиванию (`pass by assignment`); также называется передачей ссылки на объект.
14. В какой момент переменная внутри функции ссылается на тот же объект, что и снаружи? >> В момент вызова, до любого переприсваивания внутри функции.
