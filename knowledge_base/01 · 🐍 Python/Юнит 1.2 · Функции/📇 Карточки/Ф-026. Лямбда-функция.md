1. Сколько аргументов может принимать `lambda`-функция в Python и какие есть ограничения на её использование? >> Любое количество, включая ноль (`lambda: 42`); ограничение — тело должно состоять строго из одного выражения (нельзя использовать циклы, `return`, `try`, составные блоки).
2. Какое ключевое синтаксическое ограничение накладывается на тело `lambda`-функции в Python? >> Только одно выражение (`expression`); составные инструкции (`if/else` как блок кода, циклы `for`, оператор `return`, аннотации типов) недопустимы. Условие возможно только через тернарное выражение: `значение_if if условие else значение_else`.
3. Какой результат вернёт вызов анонимной лямбда-функции `(lambda x: x ** 2)(5)` в Python? >> `25`.
4. Может ли тело `lambda`-функции содержать несколько инструкций, и как перенести длинную лямбду на несколько строк? >> Нет: тело `lambda` строго ограничено одним выражением; при необходимости длинное выражение переносят на несколько строк внутри круглых скобок `(...)` — например: `(lambda x: x * 2 if x > 0 else 0)`.
5. Что является приоритетом при выборе между `lambda` и `def`? >> Читаемость кода.
6. Какую роль играет `u` в `lambda u: u['age']` при сортировке или фильтрации коллекции? >> Входной аргумент функции, представляющий очередной элемент коллекции (например, словарь с ключом `'age'`).
7. Как называются функции, создаваемые через `lambda`? >> Анонимные функции.
8. Для чего используется лямбда-функция в вызове `sorted(users, key=lambda u: u['age'])`? >> Определяет правило сортировки: извлекает значение `'age'` из каждого словаря для сравнения.
9. В каких сценариях в Python предпочтительно использовать анонимную лямбда-функцию (lambda)? >> Для коротких вспомогательных функций на месте: в `sorted()`, `map()`, `filter()`.
10. Где располагается лямбда в вызове `sorted()`? >> Передаётся как значение именованного параметра `key`.
11. Чем количество аргументов лямбды отличается от количества выражений в теле? >> Аргументов может быть любое количество; тело — строго одно выражение.
12. Нужно ли писать `return` в лямбда-функции? >> Нет; результат выражения возвращается неявно; явный `return` выбросит `SyntaxError`.
13. Что такое лямбда-функция в Python? >> Анонимная функция, объявляемая в одну строку через ключевое слово `lambda`; содержит только одно выражение, результат которого возвращается неявно.
14. Какое ключевое слово создаёт анонимную функцию? >> `lambda`.
15. Почему лямбда не подходит для сложной логики? >> Ограничение на одно выражение и отсутствие имени снижают читаемость; PEP 8 рекомендует использовать `def`.
