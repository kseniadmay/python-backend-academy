2. От чего зависит значение `__name__` ? >> От того, запущен файл напрямую или импортирован
3. Что такое `__main__.py` ? >> Специальный файл внутри пакета; позволяет запускать пакет как программу: `python -m my_package`
4. Основная цель `if __name__ == '__main__':` ? >> Разделение кода для прямого запуска и для использования как модуля
5. Чему равно `__name__` при импорте модуля? >> Имени модуля (строка с именем файла без `.py` )
6. Для чего в библиотеках используют `if __name__ == '__main__':` при тестировании? >> Для быстрых проверок функций прямо внутри файла без сторонних инструментов
7. Чему равно `__name__` при прямом запуске? >> `'__main__'`
8. Какая переменная есть в каждом Python-файле для определения способа запуска? >> `__name__`

10. Как называется конструкция для отделения исполняемого кода от кода для импорта? >> `if __name__ == '__main__':`

12. Почему демонстрацию модуля удобно помещать в `if __name__ == '__main__':` ? >> Видна при прямом запуске; не мешает при импорте
13. Что произойдёт с кодом в `if __name__ == '__main__':` при импорте? >> Не будет выполнен
