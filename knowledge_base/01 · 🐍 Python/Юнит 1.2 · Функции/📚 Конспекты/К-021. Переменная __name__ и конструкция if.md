## Что такое `__name__`

В каждом Python-модуле интерпретатор автоматически задаёт переменную **`__name__`**, по которой файл понимает, запустили его напрямую или импортировали:

| Способ запуска файла | Значение `__name__` | Роль модуля |
| :--- | :--- | :--- |
| `python my_module.py` | `'__main__'` | Точка входа, запущен как скрипт |
| `import my_module` | `'my_module'` | Импортирован другим модулем |

---

## Назначение проверки `if __name__ == '__main__'`

При импорте Python исполняет весь код верхнего уровня, поэтому незащищённые вызовы сработают даже при `import`:

```python
def calculate(x):
    return x * 2

# Выполнится даже при обычном import!
print(calculate(5))
# >>> 10
```

Конструкция `if __name__ == '__main__'` фильтрует код, запускаемый только при прямом старте файла:

```python
def calculate(x):
    return x * 2

if __name__ == '__main__':
    print(f'__name__ = {__name__}')
    # >>> __name__ = __main__

    # Выполнится только при прямом запуске
    print(calculate(5))
    # >>> 10
```

## Где применяется и главное правило

Блок `if __name__ == '__main__'` применяют в трёх типовых сценариях:

- **Точка входа:** запуск основной логики скрипта (`main.py` или `__main__.py` для запуска через `python -m my_package`).
- **Быстрая отладка:** локальные тестовые вызовы функций, которые не сработают при импорте из тестов или других модулей.
- **CLI-утилиты:** файл совмещает в себе переиспользуемую библиотеку и самостоятельную консольную команду.

Главное правило: объявления (`def`, `class`, константы) размещайте на верхнем уровне, а любой запуск логики, I/O и вывод — строго внутри `if __name__ == '__main__'`.
