## Суть ловушки

Значение по умолчанию вычисляется один раз в момент `def`, поэтому изменяемый объект (`list`, `dict`, `set`) будет разделяться между всеми вызовами:

```python
def add_item(item, cart=[]):
    cart.append(item)
    return cart

cart1 = add_item('apple')
print(cart1)
# >>> ['apple']

cart2 = add_item('banana')

# Дефолтный список стал общим!
print(cart2)
# >>> ['apple', 'banana']

# Оба вызова вернули один и тот же список
print(cart1 is cart2)
# >>> True
```

---

## Правильный способ

Передавайте в качестве значения по умолчанию `None` и создавайте новый объект прямо внутри тела функции:

```python
def add_item(item, cart=None):
    if cart is None:
        # Новый список при каждом вызове
        cart = []
    cart.append(item)
    return cart

cart1 = add_item('apple')
cart2 = add_item('banana')
print(cart1)
# >>> ['apple']

print(cart2)
# >>> ['banana']
```

`None` — неизменяемый синглтон, поэтому при каждом вызове без аргумента `cart` гарантированно получает собственный свежий список.

## Где физически хранятся аргументы по умолчанию

Функция в Python — полноценный объект, а её дефолтные аргументы при создании складываются в кортеж `__defaults__`:

```python
def add_item(item, cart=[]):
    cart.append(item)
    return cart

print('До:', add_item.__defaults__)
# >>> До: ([],)

add_item('log')
print('После:', add_item.__defaults__)
# >>> После: (['log'],)
```

Мутация меняет содержимое этого единственного объекта в `__defaults__` — точно так же ловушка срабатывает для `dict`, `set` и экземпляров пользовательских классов.

---

## Когда использовать

Правило без исключений: если аргумент по умолчанию изменяемый — ставьте `None` (а в `@dataclass` используйте `field(default_factory=list)`).

Неизменяемые значения по умолчанию (`0`, `''`, `None`, `tuple()`) полностью безопасны, так как их невозможно мутировать на месте.
