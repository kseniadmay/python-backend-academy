## map() – применить функцию к каждому элементу

**`map(func, iterable)`** применяет `func` к каждому элементу последовательности и возвращает **ленивый итератор** (без немедленного выделения памяти под список):

```python
numbers = [1, 2, 3, 4, 5]

squared = map(lambda x: x ** 2, numbers)

# Ленивый итератор типа map
print(type(squared).__name__)
# >>> map

# Явная материализация в список
print(list(squared))
# >>> [1, 4, 9, 16, 25]

a = [1, 2, 3]
b = [10, 20, 30]
sums = list(map(lambda x, y: x + y, a, b))
print(sums)
# >>> [11, 22, 33]
```

## filter() – оставить только подходящие элементы

**`filter(func, iterable)`** возвращает ленивый итератор только из тех элементов, для которых `func` вернула истинное значение (а при `None` отсеивает falsy-элементы):

```python
numbers = [1, 2, 3, 4, 5, 6, 7, 8]

evens = filter(lambda x: x % 2 == 0, numbers)
print(list(evens))
# >>> [2, 4, 6, 8]

vals = [0, 1, '', 'text', None, [], [1, 2]]
truthy = filter(None, vals)

# Фильтрация falsy-значений
print(list(truthy))
# >>> [1, 'text', [1, 2]]
```

## map/filter vs list comprehension

Выбор между функциональным стилем и списковыми включениями зависит от наличия готовой именованной функции:

```python
numbers = [1, 2, 3, 4, 5]

# Функциональный стиль: map + filter
evens = filter(lambda x: x % 2 == 0, numbers)
res_func = list(map(lambda x: x ** 2, evens))

# Идиоматичный Python: list comprehension
res_comp = [
    x ** 2 for x in numbers if x % 2 == 0
]
print(res_func)
# >>> [4, 16]

print(res_comp)
# >>> [4, 16]
```

При сложной фильтрации с `lambda` списковые включения и генераторные выражения читаются проще. Но если функция уже существует отдельно (`map(int, strs)` или `map(str.strip, lines)`), `map` выглядит лаконичнее.

## Ленивость – общее с генераторами

`map` и `filter` не вычисляют результат заранее: очередной элемент рассчитывается только по запросу (`next()`, цикл `for`, вызов `list()`).

Поэтому их можно применять к бесконечным потокам без затрат памяти на промежуточный список:

```python
import itertools

# Бесконечный ленивый счётчик с 1
infinite = itertools.count(1)
squares = map(lambda x: x ** 2, infinite)

# Берём первые 5 квадратов через islice
res = list(itertools.islice(squares, 5))
print(res)
# >>> [1, 4, 9, 16, 25]
```
