## Что такое lambda

**`lambda`** — способ создать анонимную функцию в одном выражении без ключевого слова `def`. Результатом будет обычный объект функции, который можно вызвать или передать аргументом:

```python
# Анонимная функция в одну строку
square = lambda x: x ** 2
print(square(5))
# >>> 25

# Несколько аргументов через запятую
add = lambda a, b: a + b
print(add(2, 3))
# >>> 5
```

---

## Синтаксис и ограничения

Синтаксический шаблон анонимной функции:

```python
lambda аргументы: выражение
```

Тело лямбды ограничено **ровно одним выражением**, а не блоком инструкций:

- нельзя использовать инструкции (`for`, `while`, `return`, обычное присваивание `=`, аннотации типов);
- ветвления записываются только через тернарный оператор `значение_if if условие else значение_else`.

Пример тернарного условия внутри анонимной функции:

```python
classify = (
    # Тернарное условие внутри lambda
    lambda n: 'even' if n % 2 == 0 else 'odd'
)
print(classify(7))
# >>> odd
```

Если логика не помещается в одно выражение — переходите на обычную функцию `def`.

## Главный сценарий – функция-ключ

Лямбды применяют прежде всего как короткий одноразовый callback в функциях высшего порядка (`sorted()`, `max()`, `min()`, `filter()`):

```python
users = [
    {'name': 'Alice', 'age': 30},
    {'name': 'Bob', 'age': 25},
]

# Сортировка по ключу словаря 'age'
users_sorted = sorted(
    users,
    key=lambda u: u['age'],
)
print(users_sorted)
# >>> [{'name': 'Bob', 'age': 25},
# >>> {'name': 'Alice', 'age': 30}]

# Фильтрация чётных чисел
evens = list(
    filter(lambda x: x % 2 == 0, range(10))
)
print(evens)
# >>> [0, 2, 4, 6, 8]
```

Передача `key=lambda ...` избавляет от объявления лишней именованной функции ради одной строки логики.

## Стандарт PEP 8 и правила использования

PEP 8 не рекомендует присваивать лямбду переменной — для именованных функций всегда используйте `def`:

```python
# Плохо: имя в трейсбеке останется '<lambda>'
f = lambda x: x * 2

# Хорошо: осмысленное имя в отладке
def double(x):
    return x * 2
```

Обычная функция хранит понятное имя в `__name__` и стектрейсе при ошибке, тогда как у лямбды там всегда `'<lambda>'`. Используйте `lambda` строго для коротких однострочников внутри `key=` или колбэков.

## Ловушка: лямбда и замыкание в цикле

Лямбда захватывает ссылку на переменную цикла, а не её снимок на итерации — зафиксировать значение можно аргументом по умолчанию `lambda i=i: i`:

```python
# Позднее связывание: все возвращают 2
bad = [lambda: i for i in range(3)]
print([f() for f in bad])
# >>> [2, 2, 2]

# Фиксация через аргумент по умолчанию
good = [lambda i=i: i for i in range(3)]
print([f() for f in good])
# >>> [0, 1, 2]
```

> **Junior vs Senior**:
> - **Junior**: пишет громоздкие выражения в `lambda`, присваивает их переменной (`f = lambda x: ...`) вопреки PEP 8 и попадает в ловушку позднего связывания в цикле.
> - **Senior**: оставляет `lambda` для коротких inline-ключей (`sorted(..., key=...)`, `min`/`max`), для переиспользуемых функций пишет `def` с аннотациями типов и фиксирует переменную цикла через `i=i`.
