## `@lru_cache` – кеширование результатов функции

Рекурсивные функции без мемоизации (как `fibonacci(100)`) пересчитывают одни и те же подзадачи экспоненциальное число раз.

Декоратор **`@lru_cache`** сохраняет результат по набору аргументов и мгновенно возвращает его из памяти при повторном вызове:

```python
from functools import lru_cache

# Кеширует результаты для аргументов n
@lru_cache(maxsize=128)
def fibonacci(n):
    if n < 2:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

print(fibonacci(10))
# >>> 55

# Статистика попаданий (hits/misses)
print(fibonacci.cache_info())
# >>> CacheInfo(hits=8, misses=11, maxsize=128, currsize=11)
```

Алгоритм **LRU** (*Least Recently Used*) при заполнении кеша до `maxsize` (по умолчанию `128`) вытесняет самые давние записи, а при `maxsize=None` (либо декораторе `@cache` в Python 3.9+) кеш растёт без ограничений.

Ограничение: `@lru_cache` подходит только для **чистых функций** с хэшируемыми аргументами (список `list` вызовет `TypeError`).

## `partial` – фиксация аргументов функции

Когда универсальную функцию часто вызывают с одними и теми же параметрами, `functools.partial` позволяет предзаполнить их и получить новую функцию:

```python
from functools import partial

def power(base, exp):
    return base ** exp

# Фиксируем аргумент exp=2 заранее
square = partial(power, exp=2)

# Фиксируем exp=3 в новой функции
cube = partial(power, exp=3)

print(square(5))
# >>> 25

print(cube(3))
# >>> 27
```

`partial` удобен при конфигурировании колбэков, сортировок и обработчиков событий с заранее заданными настройками.

## `@wraps` – сохранение метаданных при написании декораторов

Когда декоратор подменяет функцию внутренней обёрткой `wrapper`, атрибуты `__name__` и `__doc__` оригинала теряются.

Декоратор **`@wraps(func)`** копирует исходные метаданные на `wrapper`:

```python
from functools import wraps

def my_decorator(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

@my_decorator
def greet():
    """Greets the user"""
    return 'Hello!'

# @wraps сохранил оригинальное имя!
print(greet.__name__)
# >>> greet
```

Без `@wraps(func)` свойство `greet.__name__` вернуло бы `'wrapper'`, ломая интроспекцию и трейсбеки; добавлять его в каждый декоратор — обязательный стандарт на код-ревью.

## Когда что применять

Сводка ключевых инструментов модуля `functools`:

| Инструмент | Что делает | Когда применять |
| :--- | :--- | :--- |
| **`@lru_cache` / `@cache`** | Мемоизирует возврат по аргументам | Дорогие чистые функции, рекурсия, конфиги |
| **`partial`** | Предзаполняет часть аргументов | Колбэки и шаблонные вызовы функций |
| **`@wraps`** | Копирует `__name__` и `__doc__` | Обязателен внутри любого декоратора |
