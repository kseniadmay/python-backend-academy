1. Что произойдёт при попытке присвоить экземпляру со `__slots__` новый атрибут, не указанный в слотах? >> Выбросится исключение `AttributeError`, так как динамическое добавление полей заблокировано.
2. Что произойдёт при прямом обращении к `obj.__dict__` у экземпляра класса с чистым `__slots__`? >> Выбросится исключение `AttributeError`, поскольку словарь `__dict__` у таких экземпляров не создаётся.
3. Что произойдёт с памятью экземпляра, если класс со `__slots__` унаследует от родителя без `__slots__`? >> Новые поля дочернего класса попадут в слоты, но унаследованный от родителя словарь `__dict__` всё равно будет создаваться и нивелирует экономию памяти.
4. Зачем в дочернем классе, наследующем от класса со `__slots__` и не добавляющем новых полей, объявляют `__slots__ = ()`? >> Без явного объявления `__slots__` Python создаст для дочернего класса собственный `__dict__`; пустой кортеж `__slots__ = ()` сохраняет отсутствие словаря.
5. Что произойдёт при попытке множественного наследования от двух классов с непустыми `__slots__`? >> При создании класса сразу выбросится `TypeError: multiple bases have instance lay-out conflict` из-за несовместимости смещений в памяти.
6. Какое специальное имя нужно добавить в `__slots__`, чтобы объекты класса поддерживали слабые ссылки (`weakref.ref`)? >> `'__weakref__'`; без него создание слабой ссылки на слотовый объект вызывает `TypeError`.
7. Как разрешить классу со `__slots__` дополнительно принимать произвольные динамические атрибуты? >> Добавить строку `'__dict__'` в кортеж `__slots__`; слотовые поля останутся компактными, а динамические попадут в созданный словарь.
