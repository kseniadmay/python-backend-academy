1. Как атрибут `__slots__` ведёт себя при наследовании классов? >> Если родитель без `__slots__` , дочерний класс всё равно получает `__dict__` ; для полной экономии памяти `__slots__` нужно определять во всех классах цепочки
2. Можно ли одновременно использовать `__slots__` и динамический словарь `__dict__` в классе? >> Да; если добавить `'__dict__'` в `__slots__` , объект получит и фиксированные слоты, и динамический словарь; теряется часть экономии памяти
3. В чем главный недостаток и ограничения использования __slots__ в Python? >> Невозможность динамически добавлять новые атрибуты; жёсткая фиксация структуры
4. При каком количестве экземпляров заметна польза от `__slots__` ? >> При сотнях тысяч и более
5. Что произойдёт при присвоении атрибута не указанного в `__slots__` ? >> `AttributeError` ; добавить новый атрибут динамически нельзя
6. Два основных преимущества `__slots__` ? >> Экономия памяти (нет `__dict__` ) и ускорение доступа к атрибутам
7. Что вернёт `p.__dict__` при использовании `__slots__` ? >> `AttributeError` ; `__dict__` отсутствует
8. Что заменяет `__slots__` ? >> Стандартный словарь `__dict__` ; вместо него создаётся фиксированная структура с заданными полями
9. В чём хранят атрибуты экземпляры классов по умолчанию? >> В словаре `__dict__` ; каждый экземпляр имеет свой `__dict__`
