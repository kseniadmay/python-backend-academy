1. Чем миксин отличается от обычного класса в иерархии наследования? >> Миксин никогда не создаётся отдельно, служит только для подмешивания одного конкретного поведения к другому классу.
2. Как разрешается diamond problem (ромбовидное наследование) в Python? >> Через MRO (C3-линеаризация) — фиксированный порядок обхода классов, видимый через __mro__.
3. Что даёт кооперативный super() в цепочке миксинов? >> Каждый класс вызывает super(), не зная явно следующего в цепочке — порядок целиком определяет MRO.
4. Когда автоматически вызывается __init_subclass__? >> При объявлении любого подкласса — ещё до создания экземпляров, часто используется для авторегистрации подклассов.
5. Когда предпочесть композицию вместо миксина? >> Когда поведений много и они меняются независимо — тогда объект-помощник как атрибут лучше, чем наследование от него.
6. Создаётся ли миксин как самостоятельный объект в реальном коде? >> Нет, по соглашению миксин не инстанцируется отдельно — используется только через подмешивание к другому классу.
7. Что покажет D.__mro__ для class D(B, C), где оба наследуют A? >> Порядок [D, B, C, A, object] — слева направо, как объявлено в списке наследования.
8. Что случится, если один из миксинов в кооперативной цепочке ЗАБУДЕТ вызвать super().__init__()? >> Цепочка инициализации оборвётся — классы после него в MRO не получат вызов __init__.
9. Как принято называть классы-миксины по соглашению? >> С суффиксом Mixin в имени: LoggingMixin, SerializableMixin.
10. Пример реального использования миксинов в популярном фреймворке? >> Django REST Framework строит ViewSet из миксинов: ListModelMixin, CreateModelMixin и т.д.
11. Что произойдёт, если два миксина в списке наследования определяют одинаковый метод без вызова super()? >> Победит тот, что левее в списке наследования (по MRO) — второй метод будет полностью перекрыт, а не объединён.
12. Может ли миксин иметь собственное состояние (атрибуты), а не только методы? >> Технически может, но это считается плохой практикой — миксин должен быть максимально "тонким", без своего состояния.
13. Как проверить, что класс использует конкретный миксин? >> Через isinstance(obj, LoggingMixin) или issubclass(MyClass, LoggingMixin).
14. Что произойдёт при вызове метода миксина у класса, который его не наследует? >> AttributeError — метод физически недоступен без наследования от миксина.
