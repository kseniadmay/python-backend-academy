## `@classmethod` – метод, привязанный к классу

Обычный метод получает `self` – ссылку на экземпляр. **`@classmethod`** получает вместо него **`cls`** – ссылку на сам класс. Метод вызывается на уровне класса и применяется для создания **альтернативных конструкторов** (фабричных методов):

```python
class MyDateTime:
    def __init__(self, year, month, day):
        self.year = year
        self.month = month
        self.day = day

    # Получает класс cls первым аргументом
    @classmethod
    def from_isoformat(cls, date_string):
        parts = date_string.split('-')
        year, month, day = (
            int(parts[0]),
            int(parts[1]),
            int(parts[2]),
        )
        # Альтернативный конструктор из строки
        return cls(year, month, day)

dt = MyDateTime.from_isoformat('2025-05-26')
print(dt.year, dt.month, dt.day)
# >>> 2025 5 26
```

Альтернативный конструктор подготавливает сырые входные данные и возвращает новый экземпляр через `cls(...)`.

## Полиморфизм фабричных методов при наследовании

Главное преимущество `cls(...)` вместо жестко прописанного имени класса — корректная поддержка наследования:

```python
class MyDateTime:
    def __init__(self, year, month, day):
        self.year, self.month, self.day = (
            year,
            month,
            day,
        )

    @classmethod
    def from_isoformat(cls, date_str):
        y, m, d = map(
            int,
            date_str.split('-'),
        )
        return cls(y, m, d)

# Наследует фабричный метод класса
class AdminDateTime(MyDateTime):
    pass

# cls подставится как AdminDateTime
dt = AdminDateTime.from_isoformat(
    '2025-05-26'
)
print(type(dt).__name__)
# >>> AdminDateTime
```

Метод написан один раз в базовом классе, но при вызове через подкласс `cls` автоматически ссылается на `AdminDateTime`, сохраняя полиморфизм.

## `@staticmethod` – независимая утилита внутри класса

**`@staticmethod`** не получает ни `self`, ни `cls`. Это обычная чистая функция, помещенная в пространство имен класса для логической группировки:

```python
class MathUtils:
    # Утилита: не видит ни self, ни cls
    @staticmethod
    def add(a, b):
        return a + b

result = MathUtils.add(10, 5)
print(result)
# >>> 15
```

Статический метод не имеет доступа к состоянию объекта или класса и легко тестируется в полной изоляции.

## `@property` – вычисляемый атрибут без скобок

Декоратор **`@property`** превращает метод в виртуальный атрибут. Обращение к нему выглядит как чтение обычного поля, но под капотом выполняется вычисление:

```python
import math

class Circle:
    def __init__(self, radius):
        self._radius = radius

    # Вычисляемое поле без круглых скобок
    @property
    def area(self):
        return math.pi * (self._radius ** 2)

c = Circle(5)
print(round(c.area, 2))
# >>> 78.54
```

Если у свойства объявлен только геттер, оно становится свойством только для чтения (`read-only`). Попытка прямой записи `c.area = 50` вызовет `AttributeError`.

## Управление записью через @setter

Чтобы разрешить модификацию вычисляемого свойства, объявляется парный декоратор `@<name>.setter`:

```python
class Temperature:
    def __init__(self, celsius):
        self._celsius = celsius

    @property
    def celsius(self):
        return self._celsius

    # Валидация при записи t.celsius = ...
    @celsius.setter
    def celsius(self, value):
        # Защита от невалидной температуры
        if value < -273.15:
            raise ValueError(
                'Температура ниже '
                'абсолютного нуля'
            )
        self._celsius = value

t = Temperature(25)
t.celsius = 30
print(t.celsius)
# >>> 30
```

Сеттер позволяет инкапсулировать валидацию и пересчет зависимых полей за естественным синтаксисом присваивания.

---

## Когда что использовать

`@classmethod` нужен, когда метод должен создавать объекты или работать с атрибутами класса, особенно с учётом наследования. `@staticmethod` – когда функция логически принадлежит классу, но не использует ни `self`, ни `cls`. `@property` – когда нужно скрыть вычисление за простым доступом к атрибуту или защитить данные от прямой записи.
