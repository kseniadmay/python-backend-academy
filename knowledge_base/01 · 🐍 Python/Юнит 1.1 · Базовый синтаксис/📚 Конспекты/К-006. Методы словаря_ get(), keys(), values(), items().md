## Обращение по ключу vs get()

```python
user = {'name': 'Alex', 'age': 30}

print(user['name'])
# >>> Alex

# Прямой доступ по несуществующему ключу:
try:
    print(user['email'])
except KeyError as err:
    print(type(err).__name__)
# >>> KeyError

# Безопасное чтение через get()
print(user.get('email'))
# >>> None
# дефолт при отсутствии ключа
print(user.get('email', 'нет'))
# >>> нет
```

`dict[key]` бросает `KeyError`, если ключа нет – подходит, когда отсутствие ключа действительно исключительная ситуация. `dict.get(key, default)` возвращает `default` (по умолчанию `None`) вместо ошибки – подходит, когда отсутствие ключа – штатный, ожидаемый случай.

## keys(), values(), items() – три представления словаря

```python
user = {
    'name': 'Alex',
    'age': 30,
    'city': 'Moscow'
}
# Представление всех ключей
print(user.keys())
# >>> dict_keys(['name', 'age', 'city'])

# Представление всех значений
print(user.values())
# >>> dict_values(['Alex', 30, 'Moscow'])

# Пары (ключ, значение)
print(user.items())
# >>> dict_items([('name', 'Alex'), ('age', 30), ('city', 'Moscow')])
```

Все три метода возвращают не списки, а специальные **view-объекты** (`dict_keys`, `dict_values`, `dict_items`) – они "живые": если словарь изменится после вызова `.keys()`, представление отразит изменения без повторного вызова. Для получения обычного списка – обернуть в `list()`.

## setdefault() и update()

```python
counts = {}
for word in ['apple', 'banana', 'apple']:
    # Безопасный счётчик через .get()
    counts[word] = counts.get(word, 0) + 1
print(counts)
# >>> {'apple': 2, 'banana': 1}

groups = {}
# Создаём список, если ключа ещё нет
groups.setdefault('admins', []).append('Alex')
groups.setdefault('admins', []).append('Nina')
print(groups)
# >>> {'admins': ['Alex', 'Nina']}

config = {'host': 'localhost', 'timeout': 30}
# Массовое обновление ключей dict
config.update({'retries': 3, 'timeout': 60})
print(config)
# >>> {'host': 'localhost', 'timeout': 60, 'retries': 3}
```

## pop() и popitem()

```python
d = {'a': 1, 'b': 2}
# удаляет ключ и возвращает значение
value = d.pop('a')
print(value, d)
# >>> 1 {'b': 2}
# с default – не падает, если ключа нет
value2 = d.pop('z', 'нет ключа')

# popitem() удаляет последнюю пару (LIFO)
d2 = {'x': 10, 'y': 20}
print(d2.popitem(), d2)
# >>> ('y', 20) {'x': 10}
```

## Когда использовать

`get()` – везде, где отсутствие ключа не должно ломать программу. `items()` – стандартный способ перебрать пары ключ-значение. `setdefault()` – компактная замена `if key not in dict: dict[key] = default` (хотя для группировки часто удобнее `collections.defaultdict`).

`dict[key]` без `get` – когда отсутствие ключа – это баг, который должен быть виден сразу через исключение, а не молча превратиться в `None`.

## Эффективная работа со словарями

> **Junior vs Senior**:
> - **Junior**: Пишет ручную проверку `if k in d: ... else: ...`, выполняя два последовательных поиска по хэш-таблице вместо одного.
> - **Senior**: Применяет `d.get(k, default)` для безопасного чтения или `d.setdefault(k, [])` / `defaultdict` при группировке коллекций.
