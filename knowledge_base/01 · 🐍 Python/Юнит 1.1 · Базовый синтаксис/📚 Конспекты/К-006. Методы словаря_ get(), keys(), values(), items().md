## Обращение по ключу vs get()

```python
user = {'name': 'Alex', 'age': 30}

print(user['name'])  # 'Alex'
# KeyError: 'email' – ключа нет, программа падает
print(user['email'])

# None – без ошибки
print(user.get('email'))
# 'нет' – значение по умолчанию вторым аргументом
print(user.get('email', 'нет'))
```

`dict[key]` бросает `KeyError`, если ключа нет – подходит, когда отсутствие ключа действительно исключительная ситуация. `dict.get(key, default)` возвращает `default` (по умолчанию `None`) вместо ошибки – подходит, когда отсутствие ключа – штатный, ожидаемый случай.

## keys(), values(), items() – три представления словаря

```python
user = {'name': 'Alex', 'age': 30, 'city': 'Moscow'}

# dict_keys(['name', 'age', 'city'])
print(user.keys())
# dict_values(['Alex', 30, 'Moscow'])
print(user.values())
# dict_items([('name', 'Alex'), ('age', 30), ('city', 'Moscow')])
print(user.items())

# можно и просто 'for key in user' – эквивалентно
for key in user.keys():
    # по очереди: 'name', 'age', 'city'
    print(key)

for value in user.values():
    # по очереди: 'Alex', 30, 'Moscow'
    print(value)

# самый частый способ перебрать пары
for key, value in user.items():
    # 'name: Alex', 'age: 30', 'city: Moscow'
    print(f'{key}: {value}')
```

Все три метода возвращают не списки, а специальные **view-объекты** (`dict_keys`, `dict_values`, `dict_items`) – они "живые": если словарь изменится после вызова `.keys()`, представление отразит изменения без повторного вызова. Для получения обычного списка – обернуть в `list()`.

## setdefault() и update()

```python
counts = {}
for word in ['a', 'b', 'a', 'c', 'b', 'a']:
    # классическая идиома подсчёта через get()
    counts[word] = counts.get(word, 0) + 1
# {'a': 3, 'b': 2, 'c': 1}
print(counts)

groups = {}
groups.setdefault('admins', []).append('Alex')
groups.setdefault('admins', []).append('Nina')
# {'admins': ['Alex', 'Nina']}
print(groups)

config = {'timeout': 30}
config.update({'retries': 3, 'timeout': 60})
# {'timeout': 60, 'retries': 3}
print(config)
```

## pop() и popitem()

```python
d = {'a': 1, 'b': 2}
# удаляет ключ и возвращает значение
value = d.pop('a')
print(value, d)  # 1 {'b': 2}
# с default – не падает, если ключа нет
value2 = d.pop('z', 'нет ключа')
```

## Когда использовать

`get()` – везде, где отсутствие ключа не должно ломать программу. `items()` – стандартный способ перебрать пары ключ-значение. `setdefault()` – компактная замена `if key not in dict: dict[key] = default` (хотя для группировки часто удобнее `collections.defaultdict`). `dict[key]` без `get` – когда отсутствие ключа – это баг, который должен быть виден сразу через исключение, а не молча превратиться в `None`.
