## Обращение по ключу vs get()

Сравним поведение прямого обращения `dict[key]` и безопасного метода `dict.get(key, default)` при отсутствии ключа:

```python
user = {'name': 'Alex', 'age': 30}

print(user['name'])
# >>> Alex

# Прямой доступ при отсутствии ключа:
try:
    print(user['email'])
except KeyError as err:
    print(type(err).__name__)
# >>> KeyError

# Безопасное чтение через get()
print(user.get('email'))
# >>> None

# Значение по умолчанию вместо None
print(user.get('email', 'нет'))
# >>> нет
```

Используйте `dict[key]`, когда отсутствие ключа — баг, который должен сразу упасть с `KeyError`. Метод `get()` возвращает `default` и подходит, когда ключ может штатно отсутствовать.

## keys(), values(), items() – три представления словаря

Методы `keys()`, `values()` и `items()` возвращают динамические представления содержимого словаря:

```python
user = {
    'name': 'Alex',
    'age': 30,
    'city': 'Moscow'
}

# Представление всех ключей
print(user.keys())
# >>> dict_keys(['name', 'age', 'city'])

# Представление всех значений
print(user.values())
# >>> dict_values(['Alex', 30, 'Moscow'])

# Пары (ключ, значение)
print(user.items())
# >>> dict_items([('name', 'Alex'),
# >>> ('age', 30), ('city', 'Moscow')])
```

Эти методы возвращают «живые» **view-объекты** (`dict_keys`, `dict_values`, `dict_items`): при изменении словаря они обновляются без копирования. Для обычного списка оберните их в `list()`.

## setdefault() и update()

Методы `setdefault()` и `update()` помогают инициализировать отсутствующие ключи и пакетно обновлять словарь на месте:

```python
counts = {}
for word in ['apple', 'banana', 'apple']:
    counts[word] = counts.get(word, 0) + 1
print(counts)
# >>> {'apple': 2, 'banana': 1}

groups = {}

# Создаёт [], только если ключа ещё нет
groups.setdefault('admins', []).append('Alex')
groups.setdefault('admins', []).append('Nina')
print(groups)
# >>> {'admins': ['Alex', 'Nina']}

config = {'host': 'localhost', 'timeout': 30}

# Массовое обновление ключей словаря
config.update({'retries': 3, 'timeout': 60})
print(config)
# >>> {'host': 'localhost',
# >>> 'timeout': 60, 'retries': 3}
```

В отличие от `get()`, метод `setdefault(k, default)` не только возвращает значение, но и записывает `default` в словарь при отсутствии ключа. Метод `update()` перезаписывает совпадающие ключи и добавляет новые.

## pop() и popitem()

Чтобы одновременно удалить элемент из словаря и забрать его значение, применяют `pop()` и `popitem()`:

```python
d = {'a': 1, 'b': 2}

# Удаляет ключ и возвращает значение
value = d.pop('a')
print(value, d)
# >>> 1 {'b': 2}

# С default не падает, если ключа нет
value2 = d.pop('z', 'нет ключа')
print(value2)
# >>> нет ключа

# popitem() удаляет последнюю пару (LIFO)
d2 = {'x': 10, 'y': 20}
print(d2.popitem(), d2)
# >>> ('y', 20) {'x': 10}
```

Метод `pop(key, default)` без второго аргумента бросает `KeyError` при отсутствии ключа, а `popitem()` начиная с Python 3.7 гарантированно извлекает последнюю добавленную пару в порядке LIFO.

## Когда что использовать и эффективная работа со словарями

Выбирайте `get()` для безопасного чтения с дефолтом, `items()` для итерации по парам и `setdefault()` (или `collections.defaultdict`) для группировки без лишних проверок.

Прямой доступ `dict[key]` оставляйте для обязательных контрактов, где отсутствие ключа должно немедленно сигнализировать об ошибке.

> **Junior vs Senior**:
> - **Junior**: Пишет ручную проверку `if k in d: ... else: ...`, выполняя два последовательных поиска по хэш-таблице вместо одного.
> - **Senior**: Применяет `d.get(k, default)` для безопасного чтения или `d.setdefault(k, [])` / `defaultdict` при группировке коллекций.
