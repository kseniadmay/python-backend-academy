## Что такое моржовый оператор

**`:=`** (walrus operator, «моржовый оператор» – название из-за визуального сходства с мордой моржа) появился в Python 3.8 (PEP 572). Он позволяет **присвоить значение переменной прямо внутри выражения**, а не отдельной строкой перед ним – там, где раньше приходилось либо вычислять значение дважды, либо заводить промежуточную переменную отдельной строкой.

---

## Проблема, которую он решает

```python
data = [1, 2, 3, 4, 5]
if len(data) > 3:
    print(f'Слишком много элементов: {len(data)}')  # 'Слишком много элементов: 5'

if (n := len(data)) > 3:
    print(f'Слишком много элементов: {n}')  # 'Слишком много элементов: 5'
```

Выражение `(n := len(data))` одновременно **вычисляет** `len(data)`, **присваивает** результат переменной `n` и **возвращает** это значение, чтобы условие `if` могло его сравнить – всё за один проход, без повторного вызова функции и без отдельной строки присваивания до `if`.

---

## Частый сценарий – цикл while с проверкой и использованием

```python
line = file.readline()
while line:
    process(line)
    line = file.readline()

while (line := file.readline()):
    process(line)
```

Классическая ловушка "инициализировать переменную перед циклом, потом обновлять её же в конце тела цикла" – частый источник забытых обновлений и лишнего дублирования кода. Walrus убирает необходимость писать вызов дважды.

## Внутри списковых включений

```python
import re

results = [re.match(pattern, line).group() for line in lines if re.match(pattern, line)]

results = [m.group() for line in lines if (m := re.match(pattern, line))]
```

Это устраняет не только повторный вызов (что может быть дорого – как в примере с regex), но и реальный риск рассинхронизации, если условие и вычисляемое выражение случайно перестанут совпадать при правках кода.

---

## Синтаксические ограничения

Моржовый оператор **нельзя** использовать как обычное присваивание на верхнем уровне строки – `x := 5` отдельной строкой вызовет `SyntaxError`, для этого по-прежнему используется `x = 5`. `:=` предназначен именно для присваивания **внутри** более крупного выражения – условия, включения, аргумента вызова. Присваивание через `:=` также обычно оборачивают в скобки для ясности приоритета операций, хотя синтаксически это не всегда обязательно.

---

## Когда использовать

Уместен там, где значение нужно и для проверки условия, и для дальнейшего использования сразу следом – избегает повторного вычисления и промежуточной переменной, объявленной отдельной строкой. Злоупотребление моржовым оператором (несколько `:=` в одном сложном выражении ради компактности) ухудшает читаемость – как и везде в Python, краткость должна помогать понимать код, а не соревноваться в минимализме строк.
