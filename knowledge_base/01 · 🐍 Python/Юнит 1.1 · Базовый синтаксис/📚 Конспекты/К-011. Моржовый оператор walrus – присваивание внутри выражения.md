## Что такое моржовый оператор и какую проблему он решает

**`:=`** (walrus operator, «моржовый оператор» из PEP 572, Python 3.8) позволяет присвоить значение переменной прямо внутри выражения.

Это избавляет от двойного вызова функции или лишней временной переменной перед условием:

```python
data = [1, 2, 3, 4, 5]

# Без моржа len() вызывается дважды
if len(data) > 3:
    print(f'Много элементов: {len(data)}')
    # >>> Много элементов: 5

# Моржовый оператор: присвоили в n
if (n := len(data)) > 3:
    print(f'Слишком много элементов: {n}')
    # >>> Слишком много элементов: 5
```

Выражение `(n := len(data))` одновременно вычисляет длину, сохраняет её в `n` и возвращает результат для проверки `> 3`.

## Частый сценарий – цикл while с проверкой и чтением

В циклах `while` оператор `:=` убирает дублирование чтения до цикла и в конце каждой его итерации:

```python
line = file.readline()

# Классический цикл с дублированием
while line:
    process(line)
    line = file.readline()

# Чтение и проверка в одной строке
while (line := file.readline()):
    process(line)
```

Такая запись устраняет риск забыть повторное обновление переменной в конце тела цикла.

## Внутри списковых включений

При фильтрации в list comprehension оператор `:=` сохраняет результат дорогостоящего вызова (например, `re.match`), чтобы не вычислять его дважды:

```python
import re

lines = ['item: 42', 'skip', 'item: 100']
pattern = r'item: \d+'

# Медленно: re.match срабатывает дважды
results = [
    re.match(pattern, line).group()
    for line in lines
    if re.match(pattern, line)
]

# Быстро: сохраняем Match в m один раз
results_walrus = [
    m.group() for line in lines
    if (m := re.match(pattern, line))
]
print(results_walrus)
# >>> ['item: 42', 'item: 100']
```

Помимо ускорения, это гарантирует синхронность условия `if` и вычисляемого результата.

## Синтаксические ограничения и правила использования

Моржовый оператор разрешён только внутри более крупного выражения (условия, включения, аргумента) — отдельная строка `x := 5` вызовет `SyntaxError`. Для ясности приоритета `:=` принято брать в скобки.

Используйте `:=` там, где значение сразу нужно и для проверки, и для использования в теле. Несколько `:=` в одном выражении резко ухудшают читаемость.
