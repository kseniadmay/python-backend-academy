## append() – добавляет один элемент целиком

Чтобы добавить ровно один объект в конец списка за амортизированное $O(1)$, используют метод `append()`:

```python
lst = [1, 2, 3]
lst.append([4, 5])

# Вложенный список добавлен целиком
print(lst)
# >>> [1, 2, 3, [4, 5]]
```

`append()` всегда увеличивает длину списка ровно на `1` — даже переданный список становится одним вложенным элементом, а не разворачивается.

## extend() – добавляет элементы из итерируемого объекта по отдельности

Чтобы влить элементы другой коллекции в конец списка поштучно, применяют метод `extend()`:

```python
lst = [1, 2, 3]
lst.extend([4, 5])

# Элементы добавлены поштучно
print(lst)
# >>> [1, 2, 3, 4, 5]

lst2 = [1, 2, 3]
lst2.append(4)
lst2.append(5)

# Два отдельных вызова вместо extend
print(lst2)
# >>> [1, 2, 3, 4, 5]
```

`extend()` принимает любой итерируемый объект (`list`, `tuple`, `set`, генератор или `str` — строку разберёт по символам) и работает для списков как `lst += other`.

## insert() – вставка по конкретному индексу

Для вставки элемента в произвольную позицию списка по индексу существует метод `insert(index, value)`:

```python
lst = [1, 2, 4]

# Вставить значение 3 на позицию с индексом 2
lst.insert(2, 3)
print(lst)
# >>> [1, 2, 3, 4]
```

Операция выполняется за $O(n)$: чтобы освободить слот по индексу `i`, Python физически сдвигает все элементы правее вправо.

## remove(), pop(), del, clear() – удаление

Удалять элементы из списка можно по значению, по индексу или очищая коллекцию целиком:

```python
lst = [1, 2, 3, 2]

# Удаляет первое вхождение значения 2
lst.remove(2)
print(lst)
# >>> [1, 3, 2]

# Удаляет с конца за O(1) и возвращает
popped = lst.pop()
print(popped, lst)
# >>> 2 [1, 3]

# Сдвиг оставшихся элементов влево: O(n)
popped2 = lst.pop(0)
print(popped2, lst)
# >>> 1 [3]

# Удаление по индексу/срезу без возврата
del lst[0]

# Полная очистка списка на месте
lst.clear()
```

`remove()` ищет первое совпадение по **значению** ($O(n)$, кидает `ValueError`, если элемента нет), а `pop()` удаляет по **индексу** и возвращает удалённое.

`del` удаляет элемент или срез без возврата значения, а `clear()` полностью очищает список на месте.

---

## Когда использовать методы изменения списка

Используйте `append()` для одиночного элемента, `extend()` для пакетного слияния коллекций и `pop()` без аргументов для работы со стеком за $O(1)$.

Частых `insert(0, x)` и `pop(0)` избегайте из-за сдвига массива за $O(n)$ — для очереди FIFO берите `collections.deque`.

> **Junior vs Senior**:
> - **Junior**: Добавляет элементы пакета в цикле через `for x in batch: lst.append(x)`, многократно вызывая реаллокацию динамического массива.
> - **Senior**: Применяет единичный `lst.extend(batch)` — CPython заранее выделяет необходимый объём памяти за одну реаллокацию буфера.
