## append() – добавляет один элемент целиком

```python
lst = [1, 2, 3]
lst.append([4, 5])
# [1, 2, 3, [4, 5]] – список [4, 5] добавлен
# КАК ОДИН элемент
print(lst)
```

`append()` всегда увеличивает длину списка ровно на 1 – даже если добавляемый объект сам является списком, он становится одним вложенным элементом, а не разворачивается.

---

## extend() – добавляет элементы из итерируемого объекта по отдельности

```python
lst = [1, 2, 3]
lst.extend([4, 5])
# [1, 2, 3, 4, 5] – каждый элемент [4, 5]
# добавлен отдельно
print(lst)

lst2 = [1, 2, 3]
lst2.append(4)
lst2.append(5)
# [1, 2, 3, 4, 5] – то же самое, но два вызова
# вместо одного
# extend([4, 5])
print(lst2)
```

`extend()` принимает любой итерируемый объект (список, кортеж, множество, генератор, даже строку – тогда добавятся отдельные символы) и добавляет каждый его элемент по отдельности, эквивалентно `lst += other` для списков.

---

## insert() – вставка по конкретному индексу

```python
lst = [1, 2, 4]
# вставить значение 3 на позицию с индексом 2
lst.insert(2, 3)
print(lst)  # [1, 2, 3, 4]
```

---

## remove(), pop(), del, clear() – удаление

```python
lst = [1, 2, 3, 2]

# удаляет ПЕРВОЕ вхождение значения 2 (не по
# индексу)
lst.remove(2)
print(lst)  # [1, 3, 2]

# без аргумента – удаляет и возвращает
# ПОСЛЕДНИЙ элемент
popped = lst.pop()
print(popped, lst)  # 2 [1, 3]

# с индексом – удаляет и возвращает элемент по
# этому индексу
popped2 = lst.pop(0)
print(popped2, lst)  # 1 [3]

# удаление по индексу без возврата значения
del lst[0]
# удалить всё содержимое, список остаётся, но
# пустой
lst.clear()
```

`remove()` ищет по **значению** и удаляет первое совпадение – бросает `ValueError`, если значения нет. `pop()` работает по **индексу** (или без аргумента – с конца) и возвращает удалённый элемент, что удобно, когда значение нужно использовать дальше.

---

## Когда использовать

`append()` – добавить один элемент (в том числе список как единое целое). `extend()` – влить содержимое одной коллекции в другую поэлементно. `insert()` – редко нужен на практике (вставка в середину списка – $O(n)$, дорогая операция для больших списков). `remove()` – когда известно значение, но не индекс. `pop()` – когда нужно и удалить, и получить удалённое значение, особенно для реализации стека (`pop()` с конца) или очереди (`pop(0)`, хотя для очереди эффективнее `collections.deque`).
