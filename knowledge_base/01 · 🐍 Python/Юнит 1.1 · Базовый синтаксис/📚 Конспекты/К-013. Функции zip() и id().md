## zip() – параллельный перебор нескольких последовательностей

**`zip()`** объединяет несколько итерируемых объектов поэлементно и возвращает ленивый итератор кортежей:

```python
names = ['Alice', 'Bob', 'Charlie']
scores = [90, 85, 70]

# Соединяем элементы кортежами попарно
pairs = list(zip(names, scores))
print(pairs)
# >>> [('Alice', 90), ('Bob', 85), ('Charlie', 70)]
```

---

## zip() останавливается на самой короткой последовательности

Если длины коллекций не совпадают, `zip()` тихо останавливается на самой короткой без исключений и заполнителей:

```python
# 2 элемента
names = ['Alice', 'Bob']

# 3 элемента
scores = [90, 85, 70]

result = list(zip(names, scores))

# Срез по длине короткого списка
print(result)
# >>> [('Alice', 90), ('Bob', 85)]
```

Чтобы избежать скрытой потери хвоста данных при разных длинах, применяйте один из двух вариантов:

- **`zip(..., strict=True)`** (Python 3.10+): выбросит `ValueError`, если длины последовательностей не совпали.
- **`itertools.zip_longest(..., fillvalue=...)`**: дойдёт до конца самой длинной коллекции, подставляя заполнитель.

## Разворачивание zip через ту же функцию

Передача распакованного списка пар в `zip(*pairs)` обращает операцию и «транспонирует» строки в столбцы:

```python
pairs = [
    ('Alice', 90),
    ('Bob', 85),
    ('Charlie', 70),
]

# Распаковка кортежей обратно через zip(*...)
names, scores = zip(*pairs)

print(names)
# >>> ('Alice', 'Bob', 'Charlie')

print(scores)
# >>> (90, 85, 70)
```

Идиома `zip(*pairs)` использует стандартную распаковку аргументов `*` и преобразует список пар в два кортежа.

## id() – идентификатор объекта в памяти

**`id(obj)`** возвращает уникальное целое число, идентифицирующее объект на всё время его жизни (в CPython это адрес объекта в памяти):

```python
a = [1, 2, 3]
b = a
c = [1, 2, 3]

# b ссылается на тот же объект в памяти
print(id(a) == id(b))
# >>> True

# c — отдельный объект в куче
print(id(a) == id(c))
# >>> False
```

Именно на равенстве идентификаторов работает оператор `is`: проверка `a is b` в Python эквивалентна `id(a) == id(b)`.

## Практическое применение id() и правила выбора

При обходе графов или нехэшируемых объектов `id()` позволяет отслеживать уже посещённые экземпляры по физической ссылке:

```python
def process(items, seen_ids=None):
    if seen_ids is None:
        seen_ids = set()
    for item in items:
        if id(item) in seen_ids:
            # Пропускаем посещённый объект
            continue
        seen_ids.add(id(item))
```

Используйте `zip()` для параллельного перебора связанных коллекций (контролируя `strict=True`), а `id()` оставляйте для отладки и проверки физической идентичности — в бизнес-логике предпочтительнее `==` или `is`.
