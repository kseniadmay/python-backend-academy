## `Counter` – подсчёт частоты элементов

Встроенные `list` и `dict` покрывают базовые сценарии, но модуль `collections` избавляет от ручных проверок ключей и медленных сдвигов памяти.

**`Counter`** — это подкласс `dict`, который подсчитывает частоту элементов любой последовательности за один проход $O(n)$:

```python
from collections import Counter

# Подсчёт частот символов за O(n)
print(Counter('abracadabra'))
# >>> Counter({'a': 5, 'b': 2, 'r': 2,
# >>> 'c': 1, 'd': 1})

counts = Counter([1, 1, 2, 3])

# Топ-2 самых частых элемента
print(counts.most_common(2))
# >>> [(1, 2), (2, 1)]
```

Метод **`most_common(n)`** сразу возвращает `n` самых частых элементов в виде пар `(элемент, количество)` без ручной сортировки словаря.

## `defaultdict` – словарь без `KeyError`

В обычном `dict` обращение к отсутствующему ключу вызывает `KeyError`, вынуждая писать `if key not in d:` перед добавлением.

**`defaultdict`** автоматически создаёт значение по умолчанию, вызывая переданную фабричную функцию при первом обращении к ключу:

```python
from collections import defaultdict

d = defaultdict(list)

# Ключа нет — автосоздаётся []
d['key'].append(1)
print(d['key'])
# >>> [1]
```

Передавайте именно имя фабрики без скобок (`list`, `int`, `set` или callable), а не `list()` — Python вызовет её сам при отсутствии ключа.

## `deque` – двусторонняя очередь с O(1) на обоих концах

Операции `list.insert(0, x)` и `list.pop(0)` работают за $O(n)$, так как сдвигают весь непрерывный массив элементов в памяти.

**`deque`** хранит данные в двусвязном списке блоков, поэтому добавление и удаление с обоих концов (`append`, `appendleft`, `pop`, `popleft`) выполняются за $O(1)$:

```python
from collections import deque

dq = deque([1, 2, 3])

# Мгновенная вставка в начало (O(1))
dq.appendleft(0)

# Мгновенное извлечение слева (O(1))
val = dq.popleft()
print(val)
# >>> 0

print(list(dq))
# >>> [1, 2, 3]
```

С параметром `maxlen=N` двусторонняя очередь автоматически работает как кольцевой буфер истории последних `N` событий.

## Сравнение структур collections и выбор в продакшене

Сводка специализированных коллекций и сценариев их применения:

| Структура | Ключевое преимущество | Типичная задача |
| :--- | :--- | :--- |
| **`Counter`** | Подсчёт частот и `most_common(n)` | Аналитика, топ запросов, дубликаты |
| **`defaultdict`** | Автоинициализация ключа без `if` | Группировка записей по ключу |
| **`deque`** | Константный $O(1)$ с обоих краёв | Очереди FIFO, обход BFS, `maxlen` |

> **Junior vs Senior**:
> - **Junior**: Вручную подсчитывает частоты элементов через цикл со словарём или реализует очередь через `list.pop(0)`.
> - **Senior**: Использует `collections.Counter` для подсчёта за $O(n)$ и `collections.deque` для двусторонних очередей с константным $O(1)$.
