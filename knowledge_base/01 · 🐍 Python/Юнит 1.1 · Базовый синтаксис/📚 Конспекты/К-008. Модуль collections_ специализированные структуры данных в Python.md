## Зачем это нужно

`list` и `dict` покрывают большинство задач, но в ряде сценариев заставляют писать лишний код: проверки на существование ключа, ручная сортировка по значениям, медленные операции с началом списка. Модуль `collections` предоставляет структуры, которые решают эти задачи встроенными механизмами – без лишних строк и без потери производительности.

---

## `Counter` – подсчёт элементов

**`Counter`**** **- это подкласс словаря, заточенный под подсчёт частоты элементов в любом итерируемом объекте: строке, списке, кортеже.

```python
from collections import Counter

print(Counter('abracadabra'))

counts = Counter([1, 1, 2, 3])
print(counts.most_common(2))
```

Метод **`most_common(n)`** возвращает `n` самых частых элементов в виде списка кортежей формата `(элемент, количество)`. Без `Counter` то же самое потребовало бы цикла, словаря с ручным накоплением и сортировки с лямбдой.

`Counter` часто используют для анализа текста, подсчёта запросов, поиска дубликатов.

## `defaultdict` – словарь без `KeyError`

При обращении к несуществующему ключу обычный `dict` бросает `KeyError`. Это заставляет писать проверки вроде `if key not in d: d[key] = []` перед каждой операцией. **`defaultdict`**** **устраняет проблему: при обращении к отсутствующему ключу он автоматически создаёт значение, вызывая переданную фабричную функцию.

```python
from collections import defaultdict

d = defaultdict(list)

d['key'].append(1)  # ключа 'key' нет – создаётся автоматически с []
print(d['key'])  # [1]
```

Обратите внимание: в `defaultdict` передаётся **имя функции без скобок** – `list`, а не `list()`. Python сам вызовет её при необходимости. Можно передавать `int` (начальное значение `0`), `set`, `str` или любой другой callable.

Типичный сценарий – группировка данных по ключу, например сортировка записей по категории или агрегация в одну строку вместо трёх.

## `deque` – двусторонняя очередь с $O(1)$ на обоих концах

Обычный `list` плохо справляется с операциями на левом конце. `list.insert(0, x)` и `list.pop(0)` имеют сложность $O(n)$: при каждой такой операции Python вынужден сдвигать все существующие элементы в памяти. На больших списках это ощутимо.

**`deque`**** **(double-ended queue) устроен иначе: он не хранит элементы в одном непрерывном блоке памяти, поэтому добавление и удаление с обоих концов выполняется за $O(1)$ – за постоянное время, не зависящее от размера коллекции.

```python
from collections import deque

dq = deque([1, 2, 3])

dq.appendleft(0)  # [0, 1, 2, 3] – O(1)
val = dq.popleft()  # возвращает 0, очередь снова [1, 2, 3] – O(1)
```

Основные методы: `append(x)` и `appendleft(x)` добавляют элемент справа и слева соответственно, `popleft()` удаляет и возвращает элемент слева. Все операции – $O(1)$.

`deque` применяют для реализации очередей (FIFO), истории последних N действий (с параметром `maxlen`), обхода графов в ширину (BFS).

## Когда что использовать

**`Counter`** – когда нужно посчитать частоту элементов или найти самые распространённые значения.

**`defaultdict`** – когда нужно группировать данные по ключам и хочется избавиться от проверок на существование ключа.

**`deque`** – когда нужна очередь с частыми операциями на левом конце, и производительность имеет значение.
