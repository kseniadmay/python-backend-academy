## frozenset – неизменяемая версия set

**`frozenset`** — это множество (уникальные элементы, поиск через хэш-таблицу за $O(1)$), которое нельзя менять после создания: у него нет `add()`, `remove()`, `update()`:

```python
s = {1, 2, 3}

# OK — обычный set изменяемый
s.add(4)
print(s)
# >>> {1, 2, 3, 4}

fs = frozenset([1, 2, 3])

# У frozenset нет add: AttributeError
try:
    fs.add(4)
except AttributeError as err:
    print(type(err).__name__)
# >>> AttributeError
```

---

## Главная практическая причина существования – хэшируемость

Как и `tuple` против `list`, `frozenset` неизменяем и поэтому **хэшируем** (обычный `set` положить в другой `set` или ключом `dict` нельзя).

Это позволяет использовать `frozenset` в роли ключа словаря кэша или элемента множества:

```python
frozen = frozenset([1, 2, 3])

# OK — frozenset хэшируем
set_of_sets = {frozen, frozenset([4, 5])}
print(len(set_of_sets))
# >>> 2

cache = {}

# frozenset как ключ словаря кэша
key = frozenset(['read', 'write'])
cache[key] = 'права администратора'
```

## Операции – те же, что у set, кроме мутирующих

Теоретико-множественные операции (`|`, `&`, `-`, `^`, `issubset`, `issuperset`) работают одинаково для `set` и `frozenset`:

```python
a = frozenset([1, 2, 3])
b = frozenset([2, 3, 4])

# O(len(a) + len(b)) — объединение
print(a | b)
# >>> frozenset({1, 2, 3, 4})

# O(min(len(a), len(b))) — пересечение
print(a & b)
# >>> frozenset({2, 3})

# O(len(a)) — разность множеств
print(a - b)
# >>> frozenset({1})
```

## Когда выбирать frozenset vs set в архитектуре сервисов

Выбор между изменяемым и неизменяемым множеством зависит от контракта данных:

- **Выбирайте `frozenset`**: когда набор уникальных признаков служит ключом словаря / элементом `set`, либо нужен строгий read-only контракт без риска случайной мутации.
- **Выбирайте `set`**: когда коллекция динамически пополняется (`.add()`, `.discard()`) или нужна простая инициализация через литерал `{1, 2, 3}`.

> **Junior vs Senior**:
> - **Junior**: Пытается добавить обычный `set` в качестве элемента другого множества или ключа словаря, получая `TypeError: unhashable type: 'set'`.
> - **Senior**: Использует `frozenset` для неизменяемых множеств прав доступа (RBAC) или составных ключей кэша, обеспечивая корректное хэширование.
