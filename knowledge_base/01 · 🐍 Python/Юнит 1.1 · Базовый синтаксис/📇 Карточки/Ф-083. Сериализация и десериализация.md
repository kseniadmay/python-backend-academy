1. Что такое сериализация данных и какие целевые форматы наиболее популярны в backend-разработке на Python? >> Файл, база данных, сеть
2. Как кастомизировать процесс сериализации и десериализации объекта через модуль `pickle` ? >> Определить `__reduce__()` или `__getstate__` / `__setstate__` в классе
3. Функция `pickle` для чтения из файла? >> `pickle.load(file)`
4. Что `pickle` может сериализовать в отличие от `json` ? >> Классы, функции, замыкания и сложные вложенные структуры Python
5. Можно ли сериализовать функцию через `json` ? >> Нет; только базовые типы: `str` , `int` , `float` , `bool` , `None` , `list` , `dict`
6. Поддерживает ли `json` тип `set` по умолчанию? >> Нет; выбросит `TypeError` ; нужен кастомный encoder
7. Разница между `json.dump()` / `json.load()` и `json.dumps()` / `json.loads()` ? >> `dump` / `load` работают с файловым объектом; `dumps` / `loads` – со строкой
8. Главный недостаток `pickle` с точки зрения переносимости? >> Непортируемый; работает только в Python
9. Какой формат лучше для открытых API? >> `json`
10. Что нужно для сериализации нестандартного объекта в `json` ? >> Кастомный encoder: подкласс `json.JSONEncoder` с переопределённым `default()`
11. Режим открытия файла для `pickle.load()` ? >> `'rb'` (read binary)
12. Для сохранения состояния Python-скрипта с функциями? >> `pickle`
13. Почему десериализация `pickle` небезопасна? >> Позволяет выполнить произвольный код при загрузке; никогда не десериализовать из ненадёжных источников
14. Для долгосрочного хранения при возможной смене языка? >> `json`
15. Ключевые характеристики `json` ? >> Текстовый, портируемый, человекочитаемый, безопасный
16. Что такое протоколы в `pickle` ? >> Версии формата сериализации (0–5); более новые протоколы эффективнее; указываются через `protocol=` : `pickle.dump(obj, f, protocol=5)`
17. Почему `json` называют портируемым? >> Поддерживается практически всеми языками программирования
18. Для обмена между Python и JavaScript – какой модуль? >> `json`
19. Функция `pickle` для записи в файл? >> `pickle.dump(obj, file)`
20. Режим открытия файла для `pickle.dump()` ? >> `'wb'` (write binary)
21. Входят ли `pickle` и `json` в стандартную библиотеку? >> Да
22. Что такое сериализация? >> Преобразование объекта из памяти в формат для хранения или передачи
23. Что такое десериализация? >> Восстановление объекта из сохранённого формата обратно в память
24. Безопасен ли `json` для десериализации из интернета? >> Да; не исполняет код
25. Два встроенных инструмента сериализации в Python? >> `pickle` и `json`
26. К какому типу форматов относится `pickle` ? >> Python-специфичный бинарный формат
