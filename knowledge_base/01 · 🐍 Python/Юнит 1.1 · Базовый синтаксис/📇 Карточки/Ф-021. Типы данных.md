1. Какие типы можно использовать в качестве ключей словаря? >> Только хешируемые ( `hashable` ) объекты; как правило это неизменяемые типы: `str` , `int` , `tuple` , `frozenset`
2. К какому классу относится `tuple` ? >> Неизменяемый ( `immutable` )
3. Что происходит с оригинальным объектом, если изменяемый аргумент модифицируется внутри функции? >> Оригинальный объект изменится; Python передаёт не копию, а ссылку на тот же объект в памяти
4. К какому классу относится `set` ? >> Изменяемый ( `mutable` )
5. Какой тип является неизменяемым аналогом `list` ? >> `tuple`
6. Является ли `tuple` допустимым ключом словаря? >> Да, если все его элементы тоже хешируемы; `tuple` содержащий `list` ключом быть не может
7. К какому классу относится `float` ? >> Неизменяемый ( `immutable` )
8. К какому классу относится `frozenset` ? >> Неизменяемый ( `immutable` )
9. Что характеризует изменяемые ( `mutable` ) объекты? >> Их содержимое можно изменять после создания без смены идентичности объекта ( `id` остаётся прежним)
10. В чём практическое отличие передачи `list` и `int` в функцию? >> Изменение `list` внутри функции затронет оригинал; `int` изменить на месте нельзя – любая операция создаёт новый объект
11. Какой тип является изменяемым аналогом `tuple` ? >> `list`
12. К какому классу относится `str` ? >> Неизменяемый ( `immutable` )
13. Какой тип является неизменяемым аналогом `set` ? >> `frozenset`
14. Почему важно понимать разницу между `mutable` и `immutable` при работе с функциями? >> Чтобы избежать нежелательных побочных эффектов: изменяемые аргументы могут быть случайно модифицированы внутри функции, что изменит оригинальные данные
15. Является ли `list` допустимым ключом словаря? >> Нет; `list` – изменяемый и нехешируемый тип; попытка использовать его как ключ выбросит `TypeError`
16. К какому классу относится `int` ? >> Неизменяемый ( `immutable` )
17. К какому классу относится `list` ? >> Изменяемый ( `mutable` )
18. К какому классу относится `bytearray` ? >> Изменяемый ( `mutable` )
19. К какому классу относится `bool` ? >> Неизменяемый ( `immutable` ); `bool` является подклассом `int` : `True == 1` , `False == 0`
20. Какой тип является изменяемым аналогом `bytes` ? >> `bytearray`
21. Что характеризует неизменяемые ( `immutable` ) объекты? >> Их содержимое нельзя изменить после создания; любая «модификация» создаёт новый объект
22. К какому классу относится `bytes` ? >> Неизменяемый ( `immutable` )
23. К какому классу относится `dict` ? >> Изменяемый ( `mutable` )
24. На какие два класса делятся типы данных в Python по критерию изменяемости? >> Изменяемые ( `mutable` ) и неизменяемые ( `immutable` )
25. Можно ли изменить отдельный символ строки `str` после её создания? >> Нет; `str` – неизменяемый тип; попытка присвоения `s[0] = 'x'` выбросит `TypeError`
