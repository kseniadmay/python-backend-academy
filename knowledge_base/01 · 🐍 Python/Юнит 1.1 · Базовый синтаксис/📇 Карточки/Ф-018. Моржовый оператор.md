1. if (n := len(items)) > 10: - Что будет содержать переменная `n` и будет ли она доступна после блока `if`: `items = [1, 2, 3, 4, 5]; if (n := len(items)) > 3:; print(f'Items count: {n}')` ? >> Длину списка `items` ; при этом `n` остаётся доступной и после блока `if`
2. data = get_data() if data: process(data) - Как переписать следующий код с помощью моржового оператора `:=` , исключив дублирование вызова: `data = get_data(); if data:; process(data)` ? >> - if (data := get_data()): process(data)
3. С чем связано название моржовый оператор? >> С визуальным сходством символов `:=` с глазами и клыками моржа
4. Как неофициально называют оператор `:=` ? >> Моржовый оператор (walrus operator)
5. Верно ли, что `:=` позволяет сразу использовать присвоенное значение в том же выражении? >> Да, это его основное назначение: присвоить и использовать за один шаг
6. Какую основную возможность предоставляет оператор `:=` ? >> Присваивание значения переменной непосредственно внутри выражения с возможностью сразу использовать это значение
7. В каких конструкциях чаще всего применяется оператор `:=` ? >> В условиях и циклах: `if` , `while`
8. В какой версии Python появился оператор присваивания внутри выражения `:=` ? >> Python 3.8
