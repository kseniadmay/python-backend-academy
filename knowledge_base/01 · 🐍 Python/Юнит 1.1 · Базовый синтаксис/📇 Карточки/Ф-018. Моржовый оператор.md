1. Что будет содержать переменная `n` и доступна ли она после блока `if (n := len(items)) > 3`? >> Длину списка `items`; при этом `n` остаётся доступной и после блока `if`.
2. Как объединить вызов функции и проверку истинности результата `data = get_data()` в одно выражение с помощью моржового оператора `:=`? >> `if (data := get_data()): process(data)`.
3. С чем связано название моржовый оператор? >> С визуальным сходством символов `:=` с глазами и клыками моржа.
4. Как неофициально называют оператор `:=`? >> Моржовый оператор (walrus operator).
5. Почему выражение присваивания через моржовый оператор `:=` внутри сравнения почти всегда нужно брать в скобки, например `(x := len(items)) > 3`? >> Оператор `:=` имеет более низкий приоритет, чем операторы сравнения (`>`, `==`): без скобок `x := len(items) > 3` присвоит `x` булево значение `True`/`False`, а не длину.
6. Какую основную возможность предоставляет оператор `:=`? >> Присваивание значения переменной непосредственно внутри выражения с возможностью сразу использовать это значение.
7. В каких конструкциях чаще всего применяется оператор `:=`? >> В условиях и циклах: `if`, `while`.
8. В какой версии Python появился оператор присваивания внутри выражения `:=`? >> Python 3.8.
