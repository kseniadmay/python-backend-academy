1. Назовите 5 стандартных уровней логирования в модуле logging в порядке возрастания важности. >> `DEBUG` → `INFO` → `WARNING` → `ERROR` → `CRITICAL`
2. Для чего `timeit` ? >> Точное измерение времени выполнения небольшого участка кода
3. Как читать `traceback` ? >> Снизу вверх; последняя строка – непосредственное место ошибки
4. Что значит воспроизвести баг минимальным примером? >> Создать самый короткий код гарантированно вызывающий ту же ошибку
5. Команда `n` в `pdb` ? >> Следующая строка (без захода в функцию)
6. Команда `q` в `pdb` ? >> Выйти из дебаггера
7. Команда `l` в `pdb` ? >> Показать фрагмент кода вокруг текущей позиции
8. Что дают IDE-дебаггеры по сравнению с `pdb` ? >> Установка точек останова кликом, удобный просмотр переменных, стека и выражений без команд
9. Функция для ручной установки точки останова? >> `pdb.set_trace()`
10. Команда `s` в `pdb` ? >> Зайти внутрь вызываемой функции
11. Что использовать для проверки предположений перед дебаггером? >> `assert` или `print`
12. Первый шаг алгоритма отладки? >> Воспроизведение бага на минимальном примере
13. Уровень для максимально подробной информации? >> `logging.DEBUG`
14. Что следует за воспроизведением бага? >> Изоляция проблемного участка
15. С какой версии Python появился `breakpoint()` ? >> Python 3.7
16. Самый быстрый способ отладки для простых случаев? >> `print()` и `logging`
17. Что такое `ipdb` ? >> Улучшенная версия `pdb` с подсветкой синтаксиса и автодополнением
18. Почему `print` неприемлем в production-коде? >> Нет контроля уровня важности, нет фильтрации, нет записи в файл; засоряет вывод
19. Команда `p x` в `pdb` ? >> Напечатать значение переменной `x`
20. Когда нужно профилирование? >> Когда код работает корректно, но слишком медленно
21. Что такое `pdb` ? >> Встроенный интерактивный дебаггер для пошагового исследования состояния программы
22. Модуль для полного профилирования? >> `cProfile` ; показывает время выполнения каждой функции
23. Преимущество `breakpoint()` перед `pdb.set_trace()` ? >> Короче и не требует явного импорта `pdb`
24. Почему `logging` предпочтительнее `print` ? >> Настраиваемые уровни важности, фильтрация, запись в файл; не нужно удалять код после отладки
25. Что нужно импортировать для логирования? >> `import logging`
26. Команда `c` в `pdb` ? >> Продолжить выполнение до следующей точки останова
27. В чём ограничение `cProfile` ? >> Показывает статистику по функциям, но не по строкам; для построчного профилирования нужен `line_profiler`
28. Как настроить базовый уровень вывода логов? >> `logging.basicConfig(level=logging.DEBUG)`
