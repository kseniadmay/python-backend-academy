1. При `a = [1, 2, 3, 4, 5]`: Что вернёт `a[-2]` ? >> `4`
2. При `a = [1, 2, 3, 4, 5]`: Что вернёт `a[-3:]` ? >> `[3, 4, 5]`
3. При `a = [1, 2, 3, 4, 5]`: Что вернёт `a[-1]` ? >> `5`
4. В чём практическое преимущество отрицательных индексов перед `len()` ? >> Сокращают код и не требуют явного вычисления длины последовательности
5. Какой отрицательный индекс соответствует предпоследнему элементу? >> `-2`
6. Для чего предназначены отрицательные индексы в Python? >> Для обращения к элементам последовательности с конца
7. Что произойдёт при обращении `a[-1]` , если список `a` пустой? >> Python выбросит `IndexError: list index out of range`
8. Какая конструкция через `len()` эквивалентна `a[-1]` ? >> `a[len(a) - 1]`
9. Какой отрицательный индекс соответствует последнему элементу? >> `-1`
