1. При `" ".join(['Python', 'is', 'cool'])`: Что является разделителем? >> Пробел `" "`
2. При `'hello world'.split()`: Результат выполнения кода? >> `['hello', 'world']`
3. При `"a,b,c".split(',')`: Результат выполнения кода? >> `['a', 'b', 'c']`
4. При `"".join(['h', 'i'])`: Результат выполнения кода? >> `'hi'`
5. В чём разница между методами `str.split()` (без аргументов) и `str.split(' ')` ? >> `split()` без аргумента разбивает по любым пробельным символам и игнорирует повторы; `split(' ')` разбивает строго по одному пробелу и может вернуть пустые строки
6. При `", ".join(['a', 'b', 'c'])`: Результат выполнения кода? >> `'a, b, c'`
7. Какой символ используется как разделитель в `split()` по умолчанию? >> Любой пробельный символ (пробел, `\t` , `\n` ); при этом последовательные пробелы считаются одним разделителем, пустые строки в результат не попадают
8. Что делает метод `split()` ? >> Разбивает строку по разделителю и возвращает список подстрок
9. На каком объекте вызывается `join()` ? >> На строке-разделителе: `'разделитель'.join(iterable)`
10. Если в `split(arg)` указан аргумент, что он определяет? >> Конкретный символ или подстроку, по которой разбивается строка
11. Какой метод преобразует список строк в одну строку? >> `join()`
12. Какой разделитель использовать, чтобы склеить `['h', 'i']` в `'hi'` ? >> Пустую строку `""` (вызов `"".join(['h', 'i'])`)
13. Какой метод получает список слов из предложения? >> `split()`
14. Какова функция `join()` ? >> Соединяет элементы итерируемого объекта в одну строку через строку-разделитель
15. Как называется метод, обратный `split()` ? >> `join()`
16. Что принимает `join()` в качестве аргумента? >> Любой итерируемый объект, содержащий **только строки** ; если элементы не `str` – выбросит `TypeError`
