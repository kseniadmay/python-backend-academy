1. Что выведет следующий код с оператором распаковки `*`: `nums = [1, 2, 3]; print(*nums)` ? >> `1 2 3`
2. Каков строгий порядок объявления параметров в сигнатуре функции в Python? >> Позиционные → `*args` → keyword-only → `**kwargs` ; нарушение порядка выбросит `SyntaxError`
3. Что будет содержать словарь `kwargs` при вызове `func(1, 2, 3, name='Alice', age=30)`: `def func(*args, **kwargs):; print(kwargs)` ? >> `{'name': 'Alice', 'age': 30}`
4. Что будет содержать кортеж `args` при вызове `func(1, 2, 3, name='Alice', age=30)`: `def func(*args, **kwargs):; print(args)` ? >> `(1, 2, 3)`
5. Что такое keyword-only (именованные) аргументы в Python и как их объявить? >> Параметры, объявленные после `*args` ; их можно передать только по имени: `def f(*args, key):` – `key` обязательно именованный
6. Чему эквивалентен вызов `func(**data)` для `data = {'a': 1, 'b': 2}` ? >> `func(a=1, b=2)`
7. В какую структуру собираются аргументы через `*args` ? >> `tuple`
8. Что даёт `*args` в определении функции? >> Возможность передавать произвольное количество позиционных аргументов; внутри функции доступны как `tuple`
9. Что попадёт в `**kwargs` при вызове `func(1, 2, name='Alice')` ? >> Словарь `{'name': 'Alice'}`
10. Что попадёт в `*args` при вызове `func(1, 2, name='Alice')` ? >> Кортеж `(1, 2)`
11. В какую структуру собираются аргументы через `**kwargs` ? >> `dict`
12. Что даёт `**kwargs` в определении функции? >> Возможность передавать произвольное количество именованных аргументов; внутри функции доступны как `dict`
13. Как расшифровывается `kwargs` ? >> Keyword arguments – именованные аргументы
14. Что выведет `print([1, 2])` без оператора `*` ? >> `[1, 2]` – весь список как один объект
15. Для чего используются операторы `*` и `**` при вызове функций в Python? >> Для распаковки коллекций в аргументы: `*` распаковывает `list` / `tuple` в позиционные, `**` распаковывает `dict` в именованные
16. Являются ли имена `args` и `kwargs` обязательными? >> Нет, это общепринятые соглашения; технически имя может быть любым валидным идентификатором
