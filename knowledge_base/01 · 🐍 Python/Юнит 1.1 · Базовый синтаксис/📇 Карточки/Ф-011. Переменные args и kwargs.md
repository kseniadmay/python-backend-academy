1. Какой вывод в консоль произведёт распаковка элементов списка в вызове `print(*[1, 2, 3])` в Python? >> `1 2 3`.
2. Каков строгий порядок объявления параметров в сигнатуре функции в Python? >> Позиционные → `*args` → keyword-only → `**kwargs`; нарушение порядка выбросит `SyntaxError`.
3. Какие пары «ключ-значение» войдут в словарь `kwargs` при вызове функции `func(1, 2, 3, name='Alice', age=30)`? >> `{'name': 'Alice', 'age': 30}`.
4. Какие значения войдут в кортеж позиционных аргументов `args` при вызове функции `func(1, 2, 3, name='Alice', age=30)`? >> `(1, 2, 3)`.
5. Что такое keyword-only (именованные) аргументы в Python и как их объявить? >> Параметры, объявленные после `*` или `*args`; их можно передать только по имени: `def f(*, key):` или `def f(*args, key):` — `key` обязательно именованный.
6. Чему эквивалентен вызов `func(**data)` для `data = {'a': 1, 'b': 2}`? >> `func(a=1, b=2)`.
7. В какую структуру собираются аргументы через `*args`? >> `tuple`.
8. Что даёт `*args` в определении функции? >> Возможность передавать произвольное количество позиционных аргументов; внутри функции доступны как `tuple`.
9. В какую структуру собираются аргументы через `**kwargs`? >> `dict`.
10. Что даёт `**kwargs` в определении функции? >> Возможность передавать произвольное количество именованных аргументов; внутри функции доступны как `dict`.
11. Как расшифровывается `kwargs`? >> Keyword arguments — именованные аргументы.
12. Что выведет `print([1, 2])` без оператора `*`? >> `[1, 2]` — весь список как один объект.
13. Для чего используются операторы `*` и `**` при вызове функций в Python? >> Для распаковки коллекций в аргументы: `*` распаковывает `list` / `tuple` в позиционные, `**` распаковывает `dict` в именованные.
14. Являются ли имена `args` и `kwargs` обязательными? >> Нет, это общепринятые соглашения; технически имя может быть любым валидным идентификатором.
