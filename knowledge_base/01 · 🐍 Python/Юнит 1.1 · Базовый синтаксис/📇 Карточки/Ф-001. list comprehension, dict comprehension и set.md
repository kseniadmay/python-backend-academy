1. Каковы главные преимущества list comprehension перед классическим циклом `for` с `list.append()`? >> Компактность, декларативная читаемость и более высокая скорость выполнения в CPython
2. Где пишется конструкция `if ... else` (выбор значения) внутри list comprehension, а где одиночный `if` (фильтр)? >> `[x if x > 0 else 0 for x in lst]` — тернарный выбор `A if условие else B` пишется **ПЕРЕД** `for` (меняет сам элемент), а фильтрующий `if условие` без `else` пишется **ПОСЛЕ** `for` (отсеивает элементы)
3. Как создать матрицу (таблицу умножения) размером 3×3 с помощью вложенного list comprehension? >> `[[row * col for col in range(3)] for row in range(3)]` — внешний цикл `for row in range(3)` перебирает строки матрицы, а внутренний `for col in range(3)` генерирует список элементов (столбцы) внутри каждой строки.
4. Что вернёт `[x for x in range(20) if x % 2 == 0]`? >> Список чётных чисел от `0` до `18` включительно: `[0, 2, 4, ..., 18]`
5. Список квадратов чисел 0–9 через list comprehension? >> `[x**2 for x in range(10)]`
6. Когда предпочтительнее генераторное выражение `(...)` вместо списка `[...]`? >> Когда последовательность обходится только один раз или объём данных слишком велик для хранения целиком в оперативной памяти (RAM)
7. В чём фундаментальное различие между списковым включением `[x**2 for x in seq]` и генераторным выражением `(x**2 for x in seq)`? >> Квадратные скобки `[...]` создают `list` — он сразу вычисляет и сохраняет все элементы в памяти ($O(n)$ RAM). Круглые скобки `(...)` создают `generator` — он вычисляет элементы лениво по одному по мере запроса через `next()` ($O(1)$ RAM)
8. Какими скобками создаётся set comprehension (генератор множества)? >> Фигурными `{x for x in seq}` (в отличие от словаря `dict`, внутри нет двоеточия `ключ: значение`)
9. Как называется comprehension, записанный внутри другого comprehension? >> Вложенный (nested) comprehension
10. Как называются выражения в круглых скобках `(expr for x in iterable)`, похожие на list comprehension? >> Генераторные выражения (generator expressions)
11. Почему list comprehension `[f(x) for x in seq]` в CPython быстрее цикла `for` с `res.append()`? >> В comprehension используется специализированная инструкция байткода `LIST_APPEND`, исключающая поиск атрибута и вызов метода на каждой итерации
12. Какова главная особенность результата set comprehension `{...}`? >> Множество автоматически удаляет все дубликаты (хранит только уникальные хешируемые элементы), при этом порядок элементов не гарантируется
13. Какой тип данных создаёт выражение `{x: x**2 for x in range(5)}`? >> Словарь (`dict`), так как используется синтаксис пар `ключ: значение` внутри фигурных скобок
14. Какими скобками создаётся list comprehension? >> Квадратными скобками `[...]`
15. Что вернёт выражение `{x: x**2 for x in range(5)}`? >> Словарь квадратов чисел: `{0: 0, 1: 1, 2: 4, 3: 9, 4: 16}`
16. В каких случаях comprehension ухудшает читаемость кода? >> При сложной логике с несколькими условиями или при вложенности глубже двух уровней — в таких случаях чище и понятнее написать обычный цикл `for`
17. Как в list comprehension работает фильтрация элементов `[x for x in seq if cond]`, и почему там нельзя `else`? >> Фильтрующий `if` без `else` ставится после `for` и отсеивает элементы. Тернарный выбор с `else` (`x if cond else y`) ставится перед `for`
18. Что вернёт set comprehension `{len(word) for word in ['apple', 'pie', 'cat']}`? >> Множество уникальных длин слов: `{3, 5}` (слова `'pie'` и `'cat'` оба имеют длину `3`, дубликат схлопывается)
19. Как поменять местами ключи и значения (инвертировать словарь) через dict comprehension? >> `{v: k for k, v in original.items()}`
