1. Чему эквивалентен метод `Path.unlink()` из библиотеки `pathlib` в модуле `os` ? >> `os.remove()`
2. Как безопасно удалить файл с помощью `pathlib` , не вызывая исключения, если файл отсутствует? >> `path.unlink(missing_ok=True)`
3. Что произойдёт если вызвать `unlink()` на директории? >> `IsADirectoryError` ; метод предназначен только для файлов
4. Какой модуль считается более современным? >> `pathlib` ; появился в Python 3.4
5. Два основных модуля для работы с файловой системой? >> `os` и `pathlib`
6. Как импортировать `Path` ? >> `from pathlib import Path`
7. Стандартное поведение `unlink()` при отсутствии файла? >> Выбрасывает `FileNotFoundError`
8. Как удалить директорию со всем содержимым? >> `shutil.rmtree()`
9. Метод `Path` для удаления пустой директории? >> `.rmdir()` ; аналог `os.rmdir()`
10. Какая библиотека для удаления больших структур каталогов? >> `shutil` ; `shutil.rmtree(path)` рекурсивно удаляет директорию со всем содержимым
11. Функция `os` для удаления пустой директории? >> `os.rmdir()`
12. Как скопировать файл через `shutil` ? >> `shutil.copy(src, dst)` – копирует файл; `shutil.copy2()` – копирует с метаданными
13. В чём разница между `os.remove()` и `os.rmdir()` ? >> `os.remove()` удаляет файл; `os.rmdir()` – только пустую директорию
14. Удалит ли `os.rmdir()` папку со скрытыми файлами? >> Нет; папка должна быть абсолютно пустой
15. Как рекурсивно обойти все файлы в директории? >> `os.walk(path)` – возвращает генератор кортежей `(dirpath, dirnames, filenames)` для каждой поддиректории
16. Преимущество `pathlib` перед `os` ? >> Объектно-ориентированный API; более читаемый и удобный синтаксис через оператор `/` для путей
17. Функция `os` для удаления файла? >> `os.remove()`
18. Ограничение `os.rmdir()` ? >> Директория должна быть абсолютно пустой
19. Метод `Path` для удаления файла? >> `.unlink()`
20. Что рекомендуется перед удалением файла? >> Проверять существование через `path.exists()` или использовать `try/except FileNotFoundError`
21. Метод для проверки существования пути? >> `path.exists()`
