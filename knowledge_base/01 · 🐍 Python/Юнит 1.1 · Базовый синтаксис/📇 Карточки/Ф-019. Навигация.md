1. Как получить текущую директорию через `os`? >> `os.getcwd()`
2. Как получить текущую директорию через `pathlib`? >> `Path.cwd()`
3. Что возвращает `os.getcwd()` и в чём отличие от `pathlib.Path.cwd()`? >> Строку (`str`)
4. Что возвращает `Path.cwd()`? >> Объект `Path`
5. Как сменить директорию через `os`? >> `os.chdir('/путь')`
6. Какой способ работы с путями предпочтителен в современном Python? >> `pathlib`
7. Начиная с какой версии Python `pathlib` стандартен? >> Python 3.4
8. Вместо какого модуля используют `pathlib` в новом коде? >> `os.path`
9. Какой оператор объединяет пути в `pathlib`? >> `/`
10. Аналог оператора `/` из `pathlib` в `os`? >> `os.path.join()`
11. Как проверить существование пути через `Path`? >> `path.exists()`
12. Что возвращает атрибут `.parent`? >> Объект `Path` родительской директории
13. В чём разница между атрибутами `.name`, `.stem` и `.suffix` объекта `pathlib.Path` на примере `p = Path('/home/user/document.tar.gz')`? >> `p.name` → `'document.tar.gz'` (полное имя файла с расширением); `p.stem` → `'document.tar'` (имя без ПОСЛЕДНЕГО расширения — у файла с двумя расширениями отрезается только одно); `p.suffix` → `'.gz'` (только последнее расширение)
14. Что возвращает атрибут `.stem`? >> Имя файла без расширения
15. Что возвращает атрибут `.suffix`? >> Расширение файла включая точку
16. Что возвращает атрибут `.parts` объекта `pathlib.Path`? >> Кортеж всех компонентов пути: `Path('/home/user/file.txt').parts` ↔ `('/', 'home', 'user', 'file.txt')`
17. Какая часть `/home/user/readme.txt` является `stem`? >> `readme`
18. Какая часть `/home/user/readme.txt` является `suffix`? >> `.txt`
19. Что вернёт `Path('/usr/bin/python').suffix`? >> Пустую строку `''`
20. Что вернёт `Path('/home/user/script.py').parent`? >> Объект `Path` указывающий на `/home/user`
21. Как построить путь к файлу `config/settings.json` с помощью библиотеки `pathlib`? >> `Path.cwd() / 'config' / 'settings.json'`
22. Как создать директорию через `pathlib`? >> `path.mkdir()`; `path.mkdir(parents=True, exist_ok=True)` создаёт вложенные директории без ошибки если уже существуют
23. В каком модуле `getcwd`? >> `os`
24. В каком модуле класс `Path`? >> `pathlib`
25. Заменяет ли `pathlib` `os.chdir()`? >> Нет; для смены рабочей директории используют `os.chdir()`
