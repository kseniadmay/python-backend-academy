1. Что такое метод с точки зрения структуры класса? >> Обычная функция внутри класса, описывающая поведение объекта
2. В какой момент вызывается `__init__` ? >> Автоматически при создании экземпляра класса
3. Когда вызывается конструктор, а когда метод? >> Конструктор – при создании экземпляра; метод – явно в процессе работы с объектом
4. Как в Python называется специальный метод, выполняющий роль конструктора? >> `__init__`
5. Верно ли что конструктор технически является методом? >> Да, но с особым назначением
6. Как вызывается обычный метод в отличие от конструктора? >> Метод вызывается явно
7. Ограничено ли количество вызовов обычного метода? >> Нет, вызывается столько раз сколько нужно
8. Какова основная задача конструктора? >> Инициализировать атрибуты объекта
9. Сколько раз вызывается конструктор для одного объекта? >> Один раз при создании
