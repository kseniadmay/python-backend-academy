1. Что такое метод с точки зрения структуры класса? >> Обычная функция внутри класса, описывающая поведение объекта
2. В какой момент вызывается `__init__`? >> Автоматически при создании экземпляра класса
3. Когда вызывается инициализатор `__init__` (условно называемый конструктором), а когда обычный метод? >> `__init__` — автоматически при создании экземпляра; обычный метод — явно при работе с объектом
4. Как в Python называются специальные методы, отвечающие за создание и инициализацию объекта (роль конструктора)? >> Непосредственно объект создаёт конструктор `__new__`, а атрибуты заполняет инициализатор `__init__` (именно его в обиходе часто называют конструктором)
5. Верно ли, что `__init__` технически является обычным методом экземпляра (а не `classmethod`)? >> Да, он принимает первым аргументом экземпляр `self`, но носит специальное имя и вызывается автоматически после создания объекта
6. Как вызывается обычный метод в отличие от конструктора? >> Метод вызывается явно
7. Ограничено ли количество вызовов обычного метода? >> Нет, вызывается столько раз, сколько нужно
8. Какова основная задача инициализатора `__init__` в ООП на Python? >> Инициализировать атрибуты объекта
9. Сколько раз автоматически вызывается `__init__` для одного объекта? >> Один раз при его создании (если не вызывать `obj.__init__()` вручную)
