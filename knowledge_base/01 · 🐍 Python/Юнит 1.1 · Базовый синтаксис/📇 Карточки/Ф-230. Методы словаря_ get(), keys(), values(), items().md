1. Чем dict.get(key) отличается от dict[key]? >> dict[key] бросает KeyError при отсутствии ключа, get() возвращает None (или заданное значение по умолчанию) без ошибки.
2. Что возвращает метод items()? >> View-объект пар (ключ, значение) — dict_items.
3. Являются ли keys()/values()/items() "живыми" представлениями? >> Да, они отражают изменения словаря без повторного вызова метода.
4. Что делает setdefault(key, default)? >> Возвращает значение по ключу, а если ключа нет — создаёт его со значением default.
5. Чем pop(key) у словаря отличается от pop(key, default)? >> Первый бросит KeyError при отсутствии ключа, второй вернёт default без ошибки.
6. Как быстрее всего посчитать частоту слов через get()? >> counts[word] = counts.get(word, 0) + 1.
7. Что вернёт list(d.keys()), если d — пустой словарь? >> Пустой список [].
8. Можно ли изменять словарь прямо во время итерации по нему в цикле for? >> Нет, это бросит RuntimeError: dictionary changed size during iteration — нужно итерировать по копии.
9. Что делает dict.fromkeys(['a','b'], 0)? >> Создаёт новый словарь с указанными ключами и одинаковым значением по умолчанию: {'a':0, 'b':0}.
10. Чем dict.update(other) отличается от {**d, **other}? >> update() мутирует словарь d на месте, а {**d, **other} создаёт новый словарь, не трогая исходный.
11. Сохраняют ли современные словари Python порядок вставки ключей? >> Да, начиная с Python 3.7 порядок вставки гарантирован спецификацией языка.
12. Что произойдёт при popitem() у словаря? >> Удалит и вернёт последнюю добавленную пару (ключ, значение) — в порядке LIFO.
13. Что произойдёт при переборе for k in d.keys(), а затем изменении словаря d внутри цикла (не добавление/удаление ключей, а изменение значения)? >> Сработает без ошибки — RuntimeError возникает только при изменении набора КЛЮЧЕЙ (добавление/удаление), не значений.
14. Можно ли использовать list в качестве значения при dict.fromkeys(['a','b'], [])? >> Технически да, но все ключи будут ссылаться на ОДИН И ТОТ ЖЕ список — классическая ловушка изменяемого значения по умолчанию.
15. Что вернёт {}.get('x')? >> None — метод get безопасен даже для пустого словаря.
16. Есть ли гарантия порядка при переборе словаря через for k, v in d.items()? >> Да, с Python 3.7 порядок вставки ключей гарантирован спецификацией.
17. Что делает d1 | d2 (Python 3.9+) применительно к словарям? >> Оператор слияния словарей — эквивалент {**d1, **d2}, создаёт новый словарь.
