1. Сколько раз вызывается функция `iter()` перед началом цикла `for x in my_list` ? >> Один раз
2. Что делает `iter(obj)` ? >> Вызывает `__iter__()` и возвращает итератор объекта
3. Какая функция получает итератор из итерируемого объекта? >> `iter()`
4. Как часто вызывается `next()` при переборе коллекции в `for` ? >> По одному разу для каждого элемента
5. Как изменяется состояние итератора при каждом `next()` ? >> Продвигается вперёд на один шаг; вернуться назад нельзя
6. Какой магический метод вызывается при `iter(obj)` ? >> `__iter__()`
7. Какое исключение возникает при вызове `next()` на исчерпанном итераторе? >> `StopIteration`
8. Какой магический метод вызывается при `next(iterator)` ? >> `__next__()`
9. Какая конструкция автоматически выполняет `iter()` и `next()` ? >> Цикл `for` ; он также автоматически перехватывает `StopIteration` и завершает итерацию
10. Как избежать `StopIteration` при пустом итераторе? >> Передать второй аргумент-умолчание: `next(it, 'end')`
11. Что вернёт `next(it, 'end')` если итератор исчерпан? >> `'end'`
12. Что произойдёт при третьем `next(it)` для `iter([10, 20])` ? >> `StopIteration`
13. Какая функция получает следующий элемент из итератора? >> `next()`
