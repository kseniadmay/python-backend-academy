1. При `from collections import namedtuple; Point = namedtuple('Point', ['x', 'y']); p = Point(3, 5)`: Как получить значение `3` по имени поля? >> `p.x`
2. При `from collections import namedtuple; Point = namedtuple('Point', ['x', 'y']); p = Point(3, 5)`: Как получить значение `5` по индексу? >> `p[1]`
3. Как создать изменённую копию объекта `namedtuple` , не нарушая его неизменяемость? >> `p._replace(x=10)` – возвращает новый объект с изменёнными полями
4. Как преобразовать экземпляр `namedtuple` в обычный словарь `dict` ? >> `p._asdict()` – возвращает `dict` с именами полей как ключами
5. Как объявить именованный кортеж `namedtuple` Point с полями `x` и `y` ? >> from collections import namedtuple Point = namedtuple('Point', ['x', 'y'])
6. При `from collections import namedtuple; Point = namedtuple('Point', ['x', 'y'])`: Чем является первый аргумент в `namedtuple` ? >> Именем создаваемого типа данных
7. При `from collections import namedtuple; Point = namedtuple('Point', ['x', 'y']); p = Point(3, 5)`: Что вернёт `p[0]` ? >> `3`
8. Что означает утверждение, что `collections.namedtuple` – это фабрика классов? >> `namedtuple()` – это функция, которая динамически генерирует и возвращает новый класс; каждый вызов создаёт отдельный тип
9. Каковы преимущества `namedtuple` по сравнению с написанием обычного пользовательского класса? >> Не требует написания `__init__` , `__repr__` и других методов – они генерируются автоматически
10. При `from collections import namedtuple; Point = namedtuple('Point', ['x', 'y'])`: Чем является второй аргумент в `namedtuple` ? >> Списком имён полей кортежа
11. В каких случаях `namedtuple` предпочтительнее полноценного класса? >> Для простых структур данных без бизнес-логики и методов
12. Какой тип данных лежит в основе `namedtuple` ? >> Обычный `tuple`
13. Из какого модуля импортируется `namedtuple` ? >> Из модуля `collections`
14. Что такое `namedtuple` ? >> Подкласс `tuple` , позволяющий обращаться к элементам по именам полей, а не только по индексам; остаётся неизменяемым как обычный кортеж
15. Какими двумя способами можно получить доступ к элементу `namedtuple` ? >> По имени поля ( `p.x` ) и по числовому индексу ( `p[0]` )
16. Строка импорта `namedtuple` >> `from collections import namedtuple`
17. Что произойдёт при попытке изменить поле `namedtuple` ? >> Выбросит `AttributeError` : объект не поддерживает присваивание атрибутов
18. Как изменяемость `namedtuple` соотносится с обычным `tuple` ? >> Одинакова: `namedtuple` неизменяем ( `immutable` )
