1. В чём главное отличие list от tuple? >> list изменяем (mutable), tuple неизменяем (immutable) после создания.
2. Почему tuple можно использовать как ключ словаря, а list нельзя? >> Tuple хэшируем благодаря неизменяемости, list — нет, потому что его содержимое может измениться после добавления в словарь.
3. Что произойдёт при `tup[0] = 100`, если tup — кортеж? >> `TypeError`: 'tuple' object does not support item assignment.
4. Что быстрее создаётся — list или tuple с тем же содержимым? >> tuple, за счёт того что не нужно резервировать место под потенциальный рост.
5. Когда семантически уместнее использовать tuple вместо list? >> Для фиксированной по смыслу записи (координаты, RGB, возврат нескольких значений из функции) — не для коллекции, которая может расти.
6. Поддерживает ли `tuple` срезы и индексацию? >> Да, `tuple` поддерживает все операции чтения (`tup[0]`, `tup[1:3]`); срез кортежа возвращает новый `tuple`
7. Что произойдёт при попытке добавить tuple в set? >> Сработает, tuple хэшируем (если все его элементы тоже хэшируемы).
8. Может ли tuple содержать изменяемые объекты внутри, например список? >> Да: (1, [2, 3]) — сам tuple неизменяем по структуре (нельзя переприсвоить элемент), но вложенный список внутри можно мутировать.
9. Останется ли кортеж `tuple` хэшируемым, если внутри него есть вложенный список (`(1, [2, 3])`)? >> Нет — наличие изменяемого (mutable) списка `list` внутри делает весь `tuple` нехэшируемым (`TypeError: unhashable type: 'list'`).
10. Что экономичнее по памяти — `tuple` или `list` с одинаковым содержимым? >> `tuple` занимает немного меньше памяти, так как не резервирует буфер под динамическое расширение
11. Объект какого типа фактически возвращает инструкция `return x, y` из функции в Python? >> На самом деле tuple (x, y), просто без явных скобок.
12. Что произойдёт при tuple(list_obj)? >> Создаст новый tuple с теми же элементами — поверхностное преобразование типа, не глубокая копия вложенных объектов.
13. Что произойдёт при изменении элемента вложенного изменяемого списка `t[1][0] = 99` внутри кортежа `t = (1, [2, 3])`? >> Сработает без ошибки — сам tuple не меняется (его элементы те же объекты), но вложенный список мутируется.
14. Какая функция создаёт tuple из генератора? >> tuple(generator) — материализует все значения в неизменяемую последовательность.
15. Что быстрее — обход for по list или по tuple одинаковой длины? >> Практически одинаково, разница в скорости итерации незначительна, tuple выигрывает в основном на создании/памяти.
16. Как одной строкой создать tuple из одного элемента? >> (x,) — обязательна запятая, иначе (x) — это просто x в скобках, не tuple.
17. Что вернёт `type((1, 2, 3))`? >> `<class 'tuple'>`
