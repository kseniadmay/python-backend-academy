1. При `import re; re.findall(r'\d+', "abc 123 def 456")`: Какой результат вернёт этот вызов? >> `['123', '456']`
2. В каком формате `re.findall()` возвращает результаты поиска? >> В виде `list` строк; если в шаблоне есть группы – список кортежей
3. Какая функция `re` ищет совпадение только в начале строки? >> `re.match()`
4. Какая функция модуля `re` используется для замены подстрок по регулярному выражению? - `re.sub()` ; пример: - import re text = 'Цена: 123 руб.' result = re.sub(r'\d+', 'XXX', text) print(result) >> > Цена: XXX руб.
5. Какая функция `re` выполняет поиск совпадения по всей строке? >> `re.search()`
6. Когда и почему рекомендуется использовать `re.compile()` ? >> Когда одно и то же регулярное выражение используется многократно
7. Какую команду необходимо написать для доступа к инструментам регулярных выражений? >> `import re`
8. Какой стандартный модуль Python используется для работы с регулярными выражениями? >> `re`
9. В чём ключевое отличие `re.match()` от `re.search()` ? >> `re.match()` проверяет совпадение только в начале строки; `re.search()` ищет первое совпадение в любом месте строки
