1. Какую роль играют абстрактные базовые классы ( `abc.ABC` ) в архитектуре Python-приложений? >> Определяют обязательный интерфейс для подклассов; класс с `@abstractmethod` нельзя инстанцировать напрямую
2. Приватность в Python – технический запрет или соглашение? >> Соглашение; технического запрета нет
3. Что такое name mangling в Python? >> Механизм, при котором `__attr` преобразуется в `_ClassName__attr` ; затрудняет случайный доступ, но не запрещает его полностью
4. Какой механизм позволяет создавать абстрактные классы? >> `ABC` (Abstract Base Classes) из модуля `abc` ; методы помечаются декоратором `@abstractmethod`
5. Какая концепция типизации добавляет гибкости объектной модели Python? >> Утиная типизация ( `duck typing` )
6. Верно ли, что Python не поддерживает абстракцию? >> Нет; Python поддерживает абстракцию через `ABC` и `@abstractmethod` из модуля `abc`
7. Какое из четырёх принципов ООП реализуется через `ABC` ? >> Абстракция
8. Насколько строгой является инкапсуляция в Python? >> Не строгая; доступ к атрибутам ограничивается соглашением, а не на уровне языка
9. Какое ключевое слово для ограничения доступа отсутствует в Python? >> `private`
10. Что такое утиная типизация? >> Подход, при котором важен не тип объекта, а наличие нужных методов; если объект ведёт себя нужным образом – его можно использовать независимо от класса
11. Что такое MRO в контексте множественного наследования? >> Method Resolution Order – порядок поиска методов при множественном наследовании; определяется алгоритмом C3-линеаризации; просмотреть можно через `ClassName.__mro__`
12. Какие четыре принципа ООП поддерживает Python? >> Инкапсуляция, наследование, полиморфизм, абстракция
13. Что используется вместо интерфейсов в Python? >> Абстрактные классы ( `ABC` ) и утиная типизация
14. Как реализуется приватность в Python без специальных ключевых слов? >> Соглашением об именовании: `_name` – защищённый (условно), `__name` – псевдоприватный через name mangling
15. Какую форму наследования поддерживает Python? >> Множественное наследование: класс может наследоваться от нескольких родительских классов
16. Существуют ли в Python интерфейсы в явном виде? >> Нет
