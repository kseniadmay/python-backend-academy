1. Даны последовательности `main_seq = (1, 2, 3, 4, 5)` и `subset = (2, 3)`. Как проверить, что все элементы `subset` входят в `main_seq`, через `all()`? >> `all(x in main_seq for x in subset)` — генераторное выражение лениво обходит `subset`: при первом же элементе, отсутствующем в `main_seq`, функция `all()` мгновенно останавливает вычисление (short-circuit) и возвращает `False`. Если все элементы найдены — возвращает `True`.
2. В чём разница между методом `set.issubset()` и оператором `<=`? >> Для объектов `set` они функционально идентичны; разница в том, что `.issubset()` принимает любой итерируемый объект, а `<=` требует `set` с обеих сторон
3. Что вернёт `set(b).issubset(set(a))` для `a = (1, 2, 3, 4, 5)` и `b = (2, 3)`? >> `True`, так как все элементы множества {2, 3} входят в {1, 2, 3, 4, 5}
4. Почему для проверки вхождения мультимножества (с учётом дубликатов) ни `set(b).issubset(set(a))`, ни `all(x in a for x in b)` не подходят и нужен `collections.Counter`? >> `set()` удаляет дубликаты, а `all(x in a for x in b)` проверяет лишь факт наличия элемента без учёта кратности (оба вернут `True` для `a=[1, 2, 3]`, `b=[2, 2]`); кратность учитывает `Counter(b) <= Counter(a)`

6. Какую операцию нужно выполнить с кортежем перед `.issubset()`? >> Преобразовать в `set` через `set()`
7. Как проверить, является ли один кортеж подмножеством другого через методы множеств? >> `set(b).issubset(set(a))` – преобразовать оба в `set` и использовать `.issubset()`
8. Какой тип данных возвращает выражение `all(x in a for x in b)` в Python? >> `bool`
9. Что делает выражение `x in a for x in b` внутри `all()`? >> Создаёт генератор, проверяющий наличие каждого элемента `x` из `b` в `a`; `all()` вернёт `True` только если все проверки истинны
10. Почему `set()` может быть менее точным при работе с дублями? >> `set()` удаляет все повторяющиеся элементы, теряя информацию о количестве вхождений
11. Какой оператор эквивалентен `.issubset()`? >> `<=`; `set(b) <= set(a)`
12. Какой логический результат вернёт операция проверки нестрогого подмножества `set([1, 2]) <= set([1, 2, 3])` в Python? >> `True`, так как множество {1, 2} является строгим (и нестрогим) подмножеством {1, 2, 3}
