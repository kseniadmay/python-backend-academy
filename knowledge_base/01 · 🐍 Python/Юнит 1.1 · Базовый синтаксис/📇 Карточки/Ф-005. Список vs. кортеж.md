1. В чём принципиальное различие между `list` и `tuple` с точки зрения мутабельности? >> `list` — изменяемый (`mutable`) тип, его элементы можно добавлять, удалять и перезаписывать in-place. `tuple` — неизменяемый (`immutable`) тип: после создания его структура и ссылки на элементы зафиксированы.
2. Что произойдёт при попытке перезаписать элемент кортежа: `t = (1, 2); t[0] = 100`? >> Возникнет исключение `TypeError: 'tuple' object does not support item assignment`.
3. Почему `tuple` можно использовать в качестве ключа словаря `dict`, а `list` нельзя? >> Ключи словаря обязаны быть хэшируемыми (`hashable`). Неизменяемый `tuple` вычисляет стабильный хэш от своих элементов, тогда как мутабельный `list` не имеет стабильного хэша и выбрасывает `TypeError: unhashable type: 'list'`.
4. Останется ли кортеж хэшируемым, если он содержит вложенный список, например `t = (1, [2, 3])`? >> Нет. Наличие изменяемого элемента внутри кортежа делает весь кортеж нехэшируемым — вызов `hash(t)` выбросит `TypeError: unhashable type: 'list'`.
5. Что произойдёт при изменении вложенного списка внутри кортежа: `t = (1, [2, 3]); t[1].append(4)`? >> Операция успешно выполнится. Сам кортеж неизменяем (он хранит неизменную ссылку на объект списка), но сам внутренний объект списка мутирует in-place.
6. Какая структура эффективнее по памяти и почему: `list` или `tuple` с одинаковым набором элементов? >> `tuple`. Список `list` динамически резервирует дополнительный буфер памяти (over-allocation) под будущий вызов `append()`, а кортеж создаётся фиксированного размера ровно под переданные элементы без оверхеда.
7. Что быстрее создаётся в CPython — `list` или `tuple` с одинаковым содержимым? >> `tuple` создаётся заметно быстрее благодаря оптимизации CPython (аллокация памяти фиксированного размера и внутреннее кэширование пустых и малых кортежей free list).
8. Есть ли разница в скорости последовательной итерации (цикл `for`) по `list` и `tuple` одинаковой длины? >> Практически нет. Скорость итерации идентична, так как обе структуры представляют собой непрерывный массив указателей на объекты в памяти.
9. Какова общепринятая архитектурная семантика использования `list` против `tuple`? >> `list` используется для однородных коллекций переменной длины (список заказов, сообщений). `tuple` — для гетерогенных записей фиксированной структуры (координаты `(x, y)`, RGB-цвет, запись БД с полями разных типов).
10. Объект какого типа фактически возвращает инструкция `return x, y` из функции в Python? >> Кортеж `tuple`. В Python запятая образует кортеж, поэтому запись `return x, y` полностью эквивалентна `return (x, y)`.
11. Как синтаксически правильно создать кортеж из одного элемента? >> Обязательно с завершающей запятой: `(x,)` или `x,`. Выражение `(x)` без запятой — это просто математические скобки вокруг значения `x`.
12. Что возвращает операция `tuple(list_obj)` — глубокую копию или поверхностную структуру? >> Поверхностное создание (shallow): создаётся новый кортеж, но он содержит те же самые ссылки на исходные элементы, глубокое копирование не происходит.
13. Можно ли применить к кортежу `tuple` срезы и операцию проверки вхождения `in`? >> Да. Кортеж является полноценной последовательностью (`Sequence`), поддерживает индексацию, срезы (возвращающие новый кортеж), `len()` и оператор `in`.
14. Какая функция преобразует генератор или итератор в неизменяемую последовательность элементов в памяти? >> `tuple(generator)` — моментально исчерпывает генератор и материализует все его значения в компактный кортеж.
15. Можно ли удалить отдельный элемент из кортежа через `del t[0]`? >> Нет, попытка выбросит `TypeError: 'tuple' object doesn't support item deletion` из-за неизменяемости кортежа.
16. Какое поведение демонстрирует оператор `+=` для кортежей: `t = (1, 2); t += (3,)`? >> В отличие от списков, где `+=` мутирует массив in-place, для кортежа `+=` создаёт совершенно новый объект кортежа и перезаписывает переменную `t` новой ссылкой.
17. Что произойдёт при попытке добавить `tuple` в множество `set.add(t)`? >> Сработает успешно при условии, что все элементы внутри кортежа также являются хэшируемыми. Если внутри есть `list`, возникнет `TypeError`.
18. Что вернёт вызов `type((1, 2, 3))`? >> `<class 'tuple'>`.
