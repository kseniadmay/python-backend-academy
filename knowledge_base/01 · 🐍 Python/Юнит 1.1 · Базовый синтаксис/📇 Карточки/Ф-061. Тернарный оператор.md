2. При `status = 'adult' if age >= 18 else 'minor'`: Какое значение получит `status` , если `age = 20` ? >> `'adult'`
3. При `status = 'adult' if age >= 18 else 'minor'`: Какое условие проверяется? >> `age >= 18`
4. При `status = 'adult' if age >= 18 else 'minor'`: Какое значение получит `status` , если `age = 15` ? >> `'minor'`
5. Где находится логическое условие в тернарном операторе? >> Между `if` и `else`
6. Какова общая синтаксическая структура тернарного оператора в Python? >> значение_если_истина if условие else значение_если_ложь
7. Какая часть тернарного оператора располагается в начале выражения? >> Значение, которое возвращается при истинном условии
8. В выражении `A if B else C` какое значение будет выбрано, если `B` равно `False` ? >> `C`
9. Какое основное правило использования тернарного оператора? >> Уместен для простых однозначных условий; при сложной логике снижает читаемость – лучше использовать полный `if-else`
10. Что следует сразу за ключевым словом `else` в тернарном выражении? >> Значение, которое возвращается при ложности условия
