2. Какое значение получит `status` при `age = 20` в тернарном выражении `status = 'adult' if age >= 18 else 'minor'`? >> `'adult'`
3. Какое условие проверяется в тернарном выражении `status = 'adult' if age >= 18 else 'minor'`? >> `age >= 18`
4. Какое значение получит `status` при `age = 15` в тернарном выражении `status = 'adult' if age >= 18 else 'minor'`? >> `'minor'`
5. Где находится логическое условие в тернарном операторе? >> Между `if` и `else`

8. В выражении `A if B else C` какое значение будет выбрано, если `B` равно `False`? >> `C`
