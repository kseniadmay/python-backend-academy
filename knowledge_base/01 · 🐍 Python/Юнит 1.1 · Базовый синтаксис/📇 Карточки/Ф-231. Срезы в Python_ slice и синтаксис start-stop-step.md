1. Что означают три части среза [start:stop:step]? >> start — начало (включительно), stop — конец (не включительно), step — шаг.
2. Что делает срез с отрицательным step, например `[: : -1]`? >> Разворачивает последовательность — идёт с конца к началу.
3. Возвращает ли срез копию или представление исходного объекта? >> Копию (поверхностную) — изменение среза не затрагивает оригинал.
4. Что такое объект slice? >> Встроенный тип, на который является синтаксическим сахаром запись a:b:c — можно создать явно через slice(start, stop, step).
5. Что делает lst[1:3] = [20, 30, 40]? >> Slice assignment — заменяет 2 элемента на 3, список автоматически меняет размер.
6. Что вернёт "Python"[1:4]? >> "yth" — символы с индекса 1 по 3 включительно (4 не включён).
7. Что вернёт `lst[: : 3]`? >> Каждый третий элемент, начиная с первого.
8. Что произойдёт при срезе за границами длины списка, например lst[2:100] для списка из 5 элементов? >> Ошибки не будет — срез просто вернёт элементы до конца списка, Python не бросает IndexError для срезов.
9. Чем отличается доступ lst[-1] от среза lst[-1:]? >> lst[-1] — сам последний элемент; lst[-1:] — список из одного элемента, содержащего последний.
10. Как получить объект slice явно, не через синтаксис двоеточий? >> slice(start, stop, step).
11. Что вернёт list(range(10))[2:2]? >> Пустой список [] — start и stop совпадают, диапазон пуст.
12. Как получить среднюю треть списка (без вычисления точных индексов вручную)? >> lst[len(lst)//3 : 2*len(lst)//3] — через вычисление границ по длине.
13. Работают ли срезы для строк так же, как для списков? >> Да, идентичный синтаксис и семантика — строка тоже возвращает копию (новую строку), а не изменяет исходную (строки неизменяемы в принципе).
14. Что произойдёт при срезе с шагом 0: `lst[: : 0]`? >> ValueError: slice step cannot be zero.
