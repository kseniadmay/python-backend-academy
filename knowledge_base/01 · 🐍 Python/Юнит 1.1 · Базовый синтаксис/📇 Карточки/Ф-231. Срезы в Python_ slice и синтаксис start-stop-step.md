1. Каков общий синтаксис среза последовательности и что означает каждый из параметров? >> `sequence[start:stop:step]`: `start` — начальный индекс (включительно), `stop` — конечный индекс (не включительно), `step` — шаг выборки.
2. Какой синтаксис среза выполняет разворот последовательности в обратном порядке? >> `a[: : -1]` — отрицательный шаг `-1` без указания границ обходит последовательность от конца к началу.
3. Какой тип копии создаёт взятие среза списка `sub = a[1:4]`? >> Поверхностную копию (`shallow copy`). Создаётся новый список, но его элементы ссылаются на те же самые объекты, что и оригинал.
4. Что произойдёт при обращении по срезу за границы длины списка, например `[1, 2, 3][1:100]`? >> Ошибки не будет. Срезы в Python не выбрасывают `IndexError` при выходе за границы, а автоматически усекаются до фактической длины (вернёт `[2, 3]`).
5. Что произойдёт при попытке указать нулевой шаг в срезе: `lst[: : 0]`? >> Возникнет исключение `ValueError: slice step cannot be zero`.
6. Что такое присваивание срезу (slice assignment), например `lst[1:3] = [20, 30, 40]`? >> Замена диапазона элементов на месте (in-place). Список автоматически меняет длину, если количество вставляемых элементов не совпадает с длиной среза.
7. Что произойдёт при присваивании срезу пустого списка: `lst[1:4] = []` или `del lst[1:4]`? >> Удаление элементов диапазона на месте (in-place) со сдвигом последующих элементов влево за время $O(n)$.
8. Какой встроенный тип создаёт явный объект среза и как его применить к объекту `a`? >> Тип `slice(start, stop, step)`. Применяется стандартно: `a[s]`, где `s = slice(1, 4)`. Это синтаксический аналог `a[1:4]`.
9. Какой результат вернёт взятие среза с шагом два `a[: : 2]` для списка `a = [0, 1, 2, 3, 4, 5]`? >> `[0, 2, 4]` — выборка каждого второго элемента начиная с нулевого индекса.
10. В чём принципиальное отличие доступа по единичному отрицательному индексу `lst[-1]` от среза `lst[-1:]`? >> `lst[-1]` возвращает сам последний элемент (скалярное значение), а `lst[-1:]` возвращает список из одного последнего элемента.
11. Что вернёт срез, если параметры `start` и `stop` совпадают, например `lst[2:2]`? >> Пустой список `[]`, так как интервал `[start, stop)` не содержит ни одного элемента.
12. Что означает `None` на месте аргументов в `slice(None, stop)` или `a[:stop]`? >> `None` указывает брать значение по умолчанию: с начала последовательности для `start` или до конца для `stop`.
13. Работают ли срезы со строками `str` и создают ли они новый объект? >> Да. Срезы поддерживаются всеми последовательностями. Поскольку строки неизменяемы, срез строки всегда возвращает новую строку.
14. Какой вызов функции `slice()` полностью эквивалентен синтаксису `[: : 2]`? >> `slice(None, None, 2)`.
15. Какова временная и пространственная сложность операции взятия среза `a[start:stop]` длины k? >> $O(k)$ по времени и по памяти, так как создаётся новый список и копируются k указателей на элементы.
16. Что вернёт выражение `"Python"[1:4]`? >> `"yth"` — символы с индексов 1, 2, 3 (индекс 4 не входит).
