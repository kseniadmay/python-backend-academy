1. Каково назначение функции `zip()`? >> Объединяет несколько итерируемых объектов в итератор кортежей, сопоставляя элементы по индексу
2. Что возвращает `zip()`? >> Итератор; для получения списка нужно явно вызвать `list(zip(...))`
3. К какому типу функций относится `zip()`? >> Встроенная функция (`built-in`)
4. Что можно передать в `zip()` в качестве аргументов? >> Любые итерируемые объекты (`list`, `tuple`, `str`, `range` и др.)
5. Сколько итерируемых объектов можно передать в `zip()`? >> Два и более; при одном аргументе вернёт итератор одноэлементных кортежей
6. В какой тип данных `zip()` упаковывает каждую группу элементов? >> В `tuple`
7. По какому принципу `zip()` формирует кортежи? >> Берёт элементы с одинаковым индексом из каждого переданного объекта
8. По какому объекту `zip()` определяет момент остановки при разной длине? >> По самому короткому; остаток более длинных объектов игнорируется
9. Как объединить итерируемые объекты разной длины с помощью `zip` без потери элементов? >> Использовать `zip_longest()` из модуля `itertools`; недостающие значения заполняются `None` или указанным `fillvalue`
10. `[10, 5]` и `[90, 85, 100]` — сколько кортежей вернёт `zip()`? >> `2`; элемент `100` будет проигнорирован
11. Как получить список кортежей из `zip()`? >> `list(zip(...))`
12. Что вернёт выражение `list(zip([1, 2, 3], ['a', 'b']))`? >> `[(1, 'a'), (2, 'b')]`
13. Почему в результате `zip([1, 2, 3], ['a', 'b'])` нет пары для `3`? >> Итерация останавливается по самому короткому объекту — `['a', 'b']`
14. `zip([1, 2, 3], ['a', 'b'])` — с каким элементом будет спарено число `2`? >> `'b'`
15. `list(zip([], [1, 2, 3]))` — результат? >> `[]` — пустой список, так как первый объект пуст
16. Что сопоставлено `'Charlie'` при `zip(names, scores)` для `names = ['Alice', 'Bob', 'Charlie']` и `scores = [90, 85, 92]`? >> `92`
17. Какой кортеж будет первым результатом работы `zip(names, scores)` для `names = ['Alice', 'Bob']` и `scores = [90, 85]`? >> `('Alice', 90)`
18. Что выведет код `names = ['Alice', 'Bob']; scores = [90, 85, 70]; [print(name, score) for name, score in zip(names, scores)]`? >> Выведет две строки: `Alice 90` и `Bob 85` (элемент `70` игнорируется)
19. Что содержит переменная `score` на второй итерации цикла `for name, score in zip(['Alice', 'Bob', 'Charlie'], [90, 85, 70]):`? >> `85`
20. Как работает выражение `zip(*matrix)` для `matrix = [[1, 2, 3], [4, 5, 6]]` и для чего оно используется? >> Для транспонирования матрицы: строки превращаются в столбцы и наоборот (`[(1, 4), (2, 5), (3, 6)]`)
