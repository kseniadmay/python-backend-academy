1. Как программно проверить текущее значение изменяемого аргумента по умолчанию у функции? >> Через атрибут `__defaults__`: `add_item.__defaults__` покажет текущее состояние объекта по умолчанию
2. В какой момент создаются и вычисляются значения аргументов функции по умолчанию? >> Один раз при определении функции; не при каждом вызове
3. Какой список вернёт второй вызов `add_item(1)` для функции с изменяемым дефолтным аргументом `def add_item(val, lst=[])`? >> `[1, 1]` — дефолтный список создаётся один раз при определении функции `def` и разделяется между вызовами (`[1]`, затем `[1, 1]`)
4. Почему использование изменяемого словаря `d={}` в аргументах по умолчанию опасно и как правильно инициализировать его через `d=None`? >> Словарь `d={}` создаётся один раз при определении функции и разделяется между вызовами; рекомендуется `def f(d=None):` с проверкой `if d is None: d = {}`
5. Почему использование `lst=None` в качестве дефолтного аргумента решает проблему изменяемых параметров? >> `None` – неизменяемый объект; при каждом вызове создаётся новый локальный список
6. Создаёт ли Python новый список при каждом вызове функции `add_item(1)` с дефолтным аргументом `lst=[]`? >> Нет; используется один и тот же объект, созданный один раз при выполнении инструкции определения функции `def`
7. Что такое ловушка изменяемого дефолтного аргумента? >> Дефолтный `list` или `dict` сохраняет состояние между вызовами функции, накапливая данные
8. К какому неожиданному поведению приведёт повторный вызов функции с изменяемым аргументом по умолчанию `def add_item(item, lst=[])`? >> Дефолтный список `[]` создаётся один раз при определении функции, поэтому каждый новый вызов без передачи `lst` будет накапливать элементы в одном и том же списке
9. Как правильно инициализировать список внутри функции при `lst=None`? >> `if lst is None: lst = []`; при каждом вызове создаётся новый объект
10. Какое значение рекомендуется использовать вместо изменяемого дефолтного аргумента? >> None: в сигнатуре функции мутабельный аргумент объявляется со значением по умолчанию None (например, arg=None), а инициализация нового списка или словаря выполняется внутри тела функции (if arg is None: arg = []).
11. Почему изменяемые объекты как дефолтные аргументы считаются ловушкой? >> Все вызовы без явной передачи аргумента делят один и тот же объект в памяти
