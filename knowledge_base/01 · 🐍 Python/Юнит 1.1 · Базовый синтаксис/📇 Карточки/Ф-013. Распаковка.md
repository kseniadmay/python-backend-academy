1. Какое содержимое попадёт в переменную `middle` при распаковке `first, *middle, last = [1, 2, 3, 4, 5]`? >> `[2, 3, 4]`.
2. Чему будет равно значение переменной `y` после кортежной распаковки `x, y = (10, 20)`? >> `20`.
3. Какое значение получит переменная `b` при позиционной распаковке `a, b, c = [1, 2, 3]`? >> `2`.
4. Какое значение получит переменная `a` при позиционной распаковке `a, b, c = [1, 2, 3]`? >> `1`.
5. Какое значение примет переменная `first` при звёздочной распаковке `first, *middle, last = [1, 2, 3, 4, 5]`? >> `1`.
6. Какое значение примет переменная `last` при звёздочной распаковке `first, *middle, last = [1, 2, 3, 4, 5]`? >> `5`.
7. Какое значение получит переменная `c` при позиционной распаковке `a, b, c = [1, 2, 3]`? >> `3`.
8. Чему равна переменная `first` при распаковке со звёздочкой `first, *rest = [1, 2, 3, 4, 5]`? >> `1`.
9. Чему будет равен список `rest` при распаковке со звёздочкой `first, *rest = [1, 2, 3, 4, 5]`? >> `[2, 3, 4, 5]`.
10. Какую функцию выполняет оператор `*` в контексте расширенной распаковки? >> Собирает остаток элементов итерируемого объекта в список.
11. Как называется механизм распаковки, использующий символ `*` для сбора части элементов? >> Extended unpacking (расширенная распаковка).
12. В какой тип данных собираются элементы при использовании конструкции `*rest`? >> Всегда в `list`, даже если исходный объект был кортежем или строкой.
13. Что произойдёт, если количество переменных при распаковке не совпадает с количеством элементов? >> Python выбросит `ValueError: too many values to unpack` или `not enough values to unpack`.
14. Что в Python означает термин распаковка (unpacking)? >> Присвоение элементов итерируемого объекта нескольким переменным сразу.
