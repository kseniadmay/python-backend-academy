3. При `a, b, c = [1, 2, 3]`: Какое значение получит `b` ? >> `2`
4. При `a, b, c = [1, 2, 3]`: Какое значение получит `a` ? >> `1`
5. При `first, *middle, last = [1, 2, 3, 4, 5]`: Какое значение примет `first` ? >> `1`
6. При `first, *middle, last = [1, 2, 3, 4, 5]`: Какое значение примет `last` ? >> `5`
7. При `a, b, c = [1, 2, 3]`: Какое значение получит `c` ? >> `3`
8. При `first, *rest = [1, 2, 3, 4, 5]`: Чему равна `first` ? >> `1`
9. При `first, *rest = [1, 2, 3, 4, 5]`: Чему равен `rest` ? >> `[2, 3, 4, 5]`

11. Как называется механизм распаковки, использующий символ `*` для сбора части элементов? >> Extended unpacking (расширенная распаковка)
12. В какой тип данных собираются элементы при использовании конструкции `*rest` ? >> Всегда в `list` , даже если исходный объект был кортежем или строкой
13. Что произойдёт, если количество переменных при распаковке не совпадает с количеством элементов? >> Python выбросит `ValueError: too many values to unpack` или `not enough values to unpack`
14. Что в Python означает термин распаковка (unpacking)? >> Присвоение элементов итерируемого объекта нескольким переменным сразу
