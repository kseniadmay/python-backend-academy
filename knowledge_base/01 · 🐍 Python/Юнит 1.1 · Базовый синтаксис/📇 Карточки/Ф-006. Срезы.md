1. При `a = [0, 1, 2, 3, 4, 5]; b = a[1:4]`: Какие индексы попадут в `b` ? >> `1` , `2` , `3`
2. При `a = [0, 1, 2, 3, 4, 5]; b = a[:3]`: Что вернёт `b` ? >> `[0, 1, 2]`
3. При `a = [0, 1, 2, 3, 4, 5]; b = a[1:4]`: Что вернёт `b` ? >> `[1, 2, 3]`
4. При `a = [0, 1, 2, 3, 4, 5]; b = a[: : 2]`: Что вернёт `b` ? >> `[0, 2, 4]`
5. При `first_three = slice(None, 3)`: Как применить объект к списку `a` ? >> `a[first_three]`
6. При `a = [0, 1, 2, 3, 4, 5]; b = a[1:3]`: Что произойдёт с оригинальным списком `a` ? >> Останется без изменений
7. При `a = [0, 1, 2, 3, 4, 5]; b = a[: : -1]`: Что вернёт `b` ? >> `[5, 4, 3, 2, 1, 0]`
8. Что означает `None` на месте `stop` в `slice()` ? >> Срез будет идти до конца последовательности
9. Включается ли элемент с индексом `stop` в результат? >> Нет, не включительно
10. Каков общий синтаксис среза в Python? >> `[start:stop:step]`
11. Создаёт ли срез новый объект или изменяет оригинал? >> Создаёт новый объект; оригинал не изменяется
12. Включается ли элемент с индексом `start` в результат? >> Да, включительно
13. Какой синтаксис разворачивает последовательность `a` ? >> `a[: : -1]`
14. Какая функция позволяет создавать именованные объекты срезов? >> `slice()`
15. Какой тип копии создаёт срез списка? >> Поверхностную ( `shallow copy` ); вложенные объекты не копируются, а копируются только ссылки на них
16. Что определяет параметр `start` ? >> Начальный индекс среза (включительно)
17. Какой вызов `slice()` эквивалентен `[: : 2]` ? >> `slice(None, None, 2)`
18. Что означает `None` на месте `start` в `slice()` ? >> Срез начнётся с начала последовательности
19. В чём польза `slice()` по сравнению с обычным синтаксисом? >> Позволяет переиспользовать срез и избегать магических чисел в коде
20. К каким типам данных применимы срезы? >> К строкам, спискам, кортежам, `range` , `bytes` , `bytearray` и другим последовательностям
21. Что определяет параметр `step` ? >> Шаг выборки элементов из последовательности
22. Какой аргумент `slice(start, stop, step)` соответствует шагу? >> Третий аргумент – `step`
23. Какой вызов `slice()` эквивалентен `[:3]` ? >> `slice(None, 3)`
24. Что определяет параметр `stop` ? >> Конечный индекс среза (не включительно)
