1. Чем append() отличается от extend()? >> append() добавляет один элемент целиком (даже если это список), extend() добавляет элементы итерируемого объекта по отдельности.
2. Что выведет `[1,2].append([3,4])`? >> [1, 2, [3, 4]] — вложенный список как один элемент.
3. Что выведет `[1,2].extend([3,4])`? >> [1, 2, 3, 4] — элементы добавлены по отдельности.
4. Чем remove() отличается от pop()? >> remove() удаляет первое вхождение по значению, pop() удаляет и возвращает элемент по индексу (или последний по умолчанию).
5. Что бросит remove(), если значения нет в списке? >> ValueError.
6. Какова сложность insert() в середину большого списка? >> O(n) — требует сдвига всех последующих элементов.
7. Что делает lst.insert(0, x)? >> Вставляет x в начало списка, сдвигая остальные элементы — O(n) операция.
8. Что произойдёт при lst.remove(x), если x встречается несколько раз? >> Удалится только первое (самое левое) вхождение.
9. Что делает lst.clear()? >> Удаляет всё содержимое списка на месте, сам объект списка остаётся, но становится пустым.
10. Чем pop() без аргумента отличается от pop(0)? >> pop() удаляет и возвращает последний элемент (O(1)), pop(0) — первый элемент со сдвигом остальных (O(n)).
11. Что вернёт lst.count(x)? >> Количество вхождений x в список.
12. Что делает lst.reverse()? >> Разворачивает список на месте (in-place), в отличие от `lst[: : -1]`, который создаёт новый список.
13. Можно ли объединить два списка через +? >> Да, list1 + list2 создаёт новый список — в отличие от extend(), который мутирует существующий на месте.
14. Возвращает ли append() новый список? >> Нет, возвращает None — изменяет список на месте (in-place), как и extend(), sort(), reverse().
15. Что произойдёт при lst += "abc", если lst — список? >> Эквивалентно extend("abc") — добавит по одному символу: ['a','b','c'] в конец списка (строка — итерируемый объект).
16. Чем sort() отличается от sorted() применительно к спискам? >> sort() сортирует на месте и возвращает None; sorted() возвращает новый отсортированный список, не трогая оригинал.
17. Как удалить все элементы списка, равные конкретному значению, а не только первое вхождение? >> lst[:] = [x for x in lst if x != value] или через filter — remove() удаляет только первое.
