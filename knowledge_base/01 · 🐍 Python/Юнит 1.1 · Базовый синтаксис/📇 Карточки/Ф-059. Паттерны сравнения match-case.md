1. Какую цепочку использовали для имитации сопоставления до Python 3.10? >> Цепочку `if-elif-else`
2. Какое ключевое слово используется для определения шаблона внутри блока сопоставления? >> `case`
3. Что означает выражение `match command:` ? >> Указывает объект `command` как субъект сопоставления – его значение будет последовательно проверяться против каждого `case`
4. Чем является `'quit'` в выражении `case 'quit':` ? >> Образцом (паттерном) для сравнения с выражением из `match`
5. В какой части конструкции `match-case` прописывается логика при совпадении? >> В теле соответствующего блока `case`
6. Какой символ используется для случая по умолчанию в `match-case` ? >> `_` – wildcard-паттерн, совпадает с любым значением
7. Какое ключевое слово начинает блок структурного сопоставления? >> `match`
8. Является ли блок `case _` обязательным? >> Нет, используется только для обработки неописанных случаев; если отсутствует и ни один `case` не совпал – выполнение продолжается без ошибки
9. Как записывается паттерн для проверки строкового значения `'hello'` ? >> `case 'hello':`
10. Какова роль блока `case _` в `match-case` ? >> Обработка всех неподошедших вариантов – аналог `default` в `switch`
11. С каким оператором других языков часто сравнивают `match-case` ? >> С оператором `switch` в языках C, Java, JavaScript
12. Как записывается начало блока сопоставления для переменной `x` ? >> `match x:`
13. В какой версии Python впервые появилось структурное сопоставление с образцом? >> Python 3.10
14. Что происходит, если нет совпадений и отсутствует `case _` ? >> Ни один `case` не выполняется, выполнение продолжается дальше без ошибки
15. Какой объект использовали для имитации выбора вариантов до Python 3.10? >> Словарь ( `dict` ) с функциями в качестве значений
