1. В чём разница между операциями `a.extend(b)` , `a += b` и `a = a + b` для списков? >> `a += b` ; оба изменяют список `a` на месте; в отличие от `a = a + b` , который создаёт новый объект
2. Что произойдёт, если передать строку в метод extend() списка? >> Каждый символ строки добавится как отдельный элемент; `a.extend('abc')` → `['a', 'b', 'c']`
3. a = [1, 2, 3] a.extend([4, 5]) - Что произойдёт со списком `a` после выполнения метода `.extend()`: `a = [1, 2, 3]; a.extend([4, 5])` ? >> `[1, 2, 3, 4, 5]`
4. При `a = [1, 2, 3]; a.append([4, 5])`: Каков результат? >> `[1, 2, 3, [4, 5]]`
5. Что принимает `extend()` в качестве аргумента? >> Любой итерируемый объект ( `list` , `tuple` , `str` , `generator` и др.)
6. Каким образом `extend()` добавляет элементы? >> Каждый элемент итерируемого объекта добавляется в список по отдельности
7. Если в `a.append()` передать список, сколько новых элементов верхнего уровня появится? >> Один – весь список добавится как единый вложенный объект
8. Какой метод объединяет два списка в один плоский без вложений? >> `extend()`
9. В чём ключевое различие между `append([x, y])` и `extend([x, y])` ? >> `append()` добавляет список целиком как один элемент; `extend()` добавляет `x` и `y` по отдельности
