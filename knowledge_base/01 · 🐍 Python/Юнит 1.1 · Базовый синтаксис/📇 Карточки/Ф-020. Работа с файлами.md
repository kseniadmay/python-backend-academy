1. Как переместить указатель в файле и узнать его текущую позицию? >> `f.seek(pos)` – перемещает указатель на байт `pos` ; `f.tell()` – возвращает текущую позицию
2. Какой способ чтения большого текстового файла (на несколько гигабайт) является наиболее эффективным по памяти? >> Построчный перебор `for line in f:` ; файл не загружается целиком в память
3. Что вернёт метод `read()` при открытии файла в бинарном режиме `'rb'`: `with open('image.png', 'rb') as f:; data = f.read()` ? >> `bytes`
4. В чём разница между файловыми режимами `'r+'` и `'w'` ? >> `'r+'` читает существующий файл без очистки; `'w'` сразу очищает
5. Какие режимы встроенной функции `open()` создают новый файл на диске, если он не существовал? >> `'w'` , `'a'` , `'x'`
6. Что вернёт второй вызов `read()` для открытого файла? >> Пустую строку; указатель уже в конце файла
7. Какой строковый режим открытия файла в функции `open()` используется для добавления данных в конец файла в Python? >> `'a'`
8. Что вернёт `read()` в текстовом режиме? >> `str`
9. Какой метод файлового объекта в Python используется для записи одной строки в открытый файл? >> `write()`
10. Какой метод файлового объекта в Python считывает всё содержимое файла целиком в одну строку? >> `read()`
11. Для каких файлов нужен бинарный режим `'b'` ? >> Изображения, PDF и другие нетекстовые данные
12. Какой режим открытия файла в функции `open()` предотвратит перезапись существующего файла (вызовет `FileExistsError`)? >> `'x'` ; выбросит `FileExistsError` если файл уже существует
13. Какой режим открытия файла в функции `open()` используется для полной очистки и перезаписи файла в Python? >> `'w'` ; если файл существует – очищает его
14. Зачем `'rb'` вместо `'r'` для JPG? >> `'r'` попытается декодировать байты как текст что вызовет `UnicodeDecodeError`
15. Какая функция используется для открытия файлов? >> `open()`
16. Что вернёт `readlines()` если файл пуст? >> Пустой список `[]`
17. Что произойдёт при открытии несуществующего файла в режиме `'r'` ? >> `FileNotFoundError`
18. Какой режим открытия файла в функции `open()` используется для записи нетекстовых бинарных данных в Python? >> `'wb'`
19. Какой метод файлового объекта в Python используется для последовательной записи списка строк в файл? >> `writelines()` ; символы `\n` должны быть в элементах списка
20. Может ли `writelines()` автоматически добавлять `\n` ? >> Нет, метод `writelines()` записывает строки точно как есть, без автоматического добавления символов перевода строки `\n`
21. Какой метод файлового объекта в Python считывает строки файла в список элементов? >> `readlines()`
22. Режим по умолчанию в `open()` ? >> `'r'` (чтение текста)
23. Какой модификатор режима открытия файла в Python позволяет одновременно читать и записывать данные? >> `'r+'`
24. Сохраняются ли данные при режиме `'a'` ? >> Да; новые данные добавляются в конец
25. К чему приведёт режим `'w'` для существующего файла? >> Файл будет полностью очищен
26. Что делает `strip()` при обработке строки из файла? >> Удаляет пробельные символы и `\n` с обоих концов строки
27. Сколько минимум аргументов нужно в `open()` ? >> Один – путь к файлу
28. Какой параметр всегда указывать для корректной работы с Unicode? >> `encoding='utf-8'`
29. Как передать кодировку в бинарном режиме? >> Никак; в бинарном режиме кодировка не указывается
30. Какую конструкцию использовать для гарантии закрытия файла? >> Контекстный менеджер `with`
31. Нужно ли вызывать `close()` при использовании `with` ? >> Нет; закрытие происходит автоматически при выходе из блока
