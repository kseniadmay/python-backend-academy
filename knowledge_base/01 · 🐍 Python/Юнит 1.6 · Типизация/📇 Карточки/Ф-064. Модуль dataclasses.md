1. Что выведет `print(u)` для объекта `@dataclass` User('Alice', 30): `from dataclasses import dataclass; @dataclass; class User:; name: str; age: int; active: bool = True; u = User('Alice', 30); print(u)` ? >> `User(name='Alice', age=30, active=True)`
2. Какую ошибку вызывает использование изменяемого значения по умолчанию ( `items: list = []` ) в `@dataclass` и как её исправить? >> `list` , `dict` , `set` нельзя указывать напрямую как дефолтное значение – выбросит `ValueError` ; нужно использовать `field(default_factory=list)`
3. Как создать объект датакласса `User` , если поле `active` имеет значение по умолчанию `True`: `from dataclasses import dataclass; @dataclass; class User:; name: str; age: int; active: bool = True` ? >> `u = User('Alice', 30)` ; `active` автоматически примет значение `True`
4. Какую задачу выполняет декоратор `@dataclass` ? >> Автоматически генерирует специальные методы ( `__init__` , `__repr__` , `__eq__` ) на основе аннотированных полей класса
5. В чём преимущество `@dataclass` перед `namedtuple` ? >> `@dataclass` – полноценный класс; можно добавлять методы, наследоваться, использовать `frozen=True` для неизменяемости
6. Какой метод позволяет сравнивать два объекта `@dataclass` по значениям полей? >> `__eq__`
7. Как импортировать декоратор `dataclass` ? >> `from dataclasses import dataclass`
8. На основе чего `@dataclass` понимает, какие поля обрабатывать? >> На основе аннотированных полей класса; поля без аннотации типа игнорируются
9. Какие три метода `@dataclass` генерирует по умолчанию? >> `__init__` , `__repr__` , `__eq__`
10. Может ли класс с `@dataclass` содержать обычные методы? >> Да, это полноценный класс
11. Как объявить поле `age` целочисленного типа в `@dataclass` ? >> `age: int`
12. Начиная с какой версии Python доступен модуль `dataclasses` ? >> Python 3.7
13. Как сделать экземпляр `@dataclass` неизменяемым? >> `@dataclass(frozen=True)`
14. Что даёт параметр `frozen=True` помимо запрета изменений? >> Делает объект хешируемым ( `hashable` ): можно использовать как ключ словаря или элемент `set` ; попытка изменить атрибут выбросит `FrozenInstanceError`
15. От какого типа кода избавляет `@dataclass` ? >> От шаблонного ( `boilerplate` ) кода: ручного написания `__init__` , `__repr__` и `__eq__`
16. Что такое `boilerplate` -код? >> Повторяющийся шаблонный код, необходимый для базовой работы класса; `@dataclass` генерирует его автоматически
17. Какой метод генерируется для текстового представления объекта при отладке? >> `__repr__`
18. Обязательно ли указывать тип поля, чтобы `@dataclass` его обработал? >> Да, только аннотированные поля учитываются декоратором
19. Как задать значение по умолчанию для поля в `@dataclass` ? >> Обычным присваиванием после аннотации: `active: bool = True`
20. Из какого модуля импортируется декоратор `dataclass` ? >> Из модуля `dataclasses`
