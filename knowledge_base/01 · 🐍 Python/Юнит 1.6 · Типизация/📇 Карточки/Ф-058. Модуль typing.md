1. Что означает аннотация типов `Callable[[int, int], int]` из модуля `typing` ? >> Типы входных аргументов; последний `int` – тип возвращаемого значения
2. Как выглядит стандартная аннотация типов для словаря `dict` со строковыми ключами и числовыми значениями в Python 3.9+? >> `dict[str, int]`
3. Как аннотировать список целых чисел в Python 3.9+? >> `list[int]`
4. Для чего используется `typing.Literal` в аннотациях типов? >> Ограничивает значение конкретными литералами: `def f(mode: Literal['r', 'w', 'a']) -> None:`
5. Для чего используется `typing.TypeVar` в аннотациях типов Python? >> Создание обобщённых (generic) функций и классов; позволяет связать типы аргументов и возвращаемого значения: `T = TypeVar('T')`
6. Что означает `Optional` в аннотации? >> Значение может быть указанного типа или `None`
7. Для чего `Iterable` ? >> Аннотация объектов поддерживающих итерацию через `__iter__`
8. С какой версии можно использовать встроенные `list` , `dict` без импорта из `typing` ? >> Python 3.9+
9. Почему `typing` актуален в Python 3.9+? >> Для обратной совместимости с кодом под Python 3.8 и ниже
10. Как аннотировать `str` или `None` в Python 3.10+? >> `str | None`
11. Назначение `Union` ? >> Значение может принадлежать одному из нескольких типов
12. Четыре основных типа из `typing` для коллекций? >> `List` , `Dict` , `Tuple` , `Set`
13. Для чего `Sequence` ? >> Аннотация последовательностей поддерживающих индексацию и `len()`
14. Как записать `Union[int, str]` в Python 3.10+? >> `int | str`
15. Чем заменить `Union` в Python 3.10+? >> Оператором `|`
16. Назначение модуля `typing` ? >> Специальные типы для точных аннотаций; необходим для совместимости со старыми версиями Python
17. Для чего `Callable` ? >> Аннотация вызываемых объектов с указанием типов аргументов и возвращаемого значения
18. Как аннотировать кортеж с ровно двумя `int` ? >> `Tuple[int, int]` ; `Tuple[int, ...]` означает кортеж произвольной длины из `int`
19. Для чего `Final` ? >> Указывает что переменная не должна переопределяться; `MAX: Final = 100`
20. Чему эквивалентен `Optional[X]` ? >> `Union[X, None]`
21. Роль типа `Any` ? >> Отключает проверку типов для значения; совместим с любым типом
