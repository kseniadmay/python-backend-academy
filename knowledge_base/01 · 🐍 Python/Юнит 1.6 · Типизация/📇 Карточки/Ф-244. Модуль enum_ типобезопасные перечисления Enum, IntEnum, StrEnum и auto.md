1. Чему равно выражение Color.RED == 'red', если Color наследуется от базового класса Enum (где RED = 'red')? >> False — члены базового Enum не равны своим сырым значениям (строкам или числам), они сравниваются только с самими собой.
2. Чем отличается обращение к Enum через круглые скобки Status('paid') от квадратных скобок Status['PAID']? >> Круглые скобки Status('paid') ищут член перечисления по его ЗНАЧЕНИЮ (.value), а квадратные Status['PAID'] — по его ИМЕНИ (.name).
3. Какие два атрибута есть у каждого элемента перечисления Enum для получения его имени и значения? >> .name (строковое имя константы, например 'PAID') и .value (само значение, например 'paid' или 1).
4. Чем StrEnum (Python 3.11+) отличается от обычного Enum со строковыми значениями? >> StrEnum одновременно наследуется от str и Enum: его члены равны соответствующим строкам (Role.ADMIN == 'admin' -> True) и напрямую сериализуются в JSON.
5. Какие значения генерирует функция auto() в обычном Enum и какие — в StrEnum? >> В обычном Enum и IntEnum — целые числа начиная с 1 (1, 2, 3...), а в StrEnum — имя атрибута в нижнем регистре (например, ADMIN = auto() даст 'admin').
6. Что произойдёт в обычном Enum без декораторов, если двум разным именам присвоить одинаковое значение? >> Второе имя станет алиасом (псевдонимом) первого, будет ссылаться на тот же самый объект и пропустится при обычной итерации по классу Enum.
7. Зачем нужен декоратор @unique из модуля enum? >> Он запрещает алиасы (дублирующиеся значения) в перечислении и выбрасывает ValueError при объявлении класса, если два поля имеют одинаковый .value.
8. Для каких задач в модуле enum используется класс Flag (и IntFlag)? >> Для битовых флагов и масок прав доступа, которые можно комбинировать побитовыми операторами | (ИЛИ), & (И) и проверять через оператор in.
9. Какие числовые значения присваивает auto() внутри класса, унаследованного от Flag? >> Степени двойки: 1, 2, 4, 8, 16..., чтобы каждый флаг занимал отдельный бит и не пересекался с другими при побитовом сложении.
10. Можно ли сравнивать члены одного Enum через оператор идентичности is (например, status is OrderStatus.PAID)? >> Да, каждый член Enum гарантированно является синглтоном, поэтому проверка через is быстра, надёжна и рекомендуется PEP 8 наряду с ==.
11. Что произойдёт при попытке изменить значение члена перечисления в рантайме (например, OrderStatus.PAID.value = 'done')? >> Возникнет AttributeError — члены Enum неизменяемы после создания класса.
12. Как до Python 3.11 создавали строковые перечисления, совместимые с JSON и сравнением со строками? >> Через множественное наследование class MyEnum(str, Enum):, причём тип str обязательно должен стоять перед Enum в списке базовых классов.
13. Можно ли унаследовать новый класс от существующего Enum, в котором уже объявлены члены перечисления? >> Нет, Python выбросит TypeError — расширять Enum с уже определёнными элементами через наследование запрещено (наследовать можно только от пустого базового Enum с методами).
14. Как получить словарь или список всех членов Enum, включая алиасы (псевдонимы с дублирующимися значениями)? >> Через специальный атрибут класса MyEnum.__members__, который хранит отображение всех имён (включая алиасы) на объекты членов.
15. Можно ли добавлять в класс Enum собственные методы и вычисляемые свойства (@property)? >> Да, Enum — это полноценный класс Python, в котором можно объявлять методы для инкапсуляции логики, связанной с конкретным статусом или типом.
16. Какое исключение выбросит вызов OrderStatus('unknown_value'), если такого значения нет в перечислении? >> ValueError: 'unknown_value' is not a valid OrderStatus.
