## Что такое сериализация: сохранение состояния между процессами

**Сериализация** переводит структуры Python в строку или поток байтов для записи на диск, кэширования в Redis и отправки по сети. **Десериализация** восстанавливает объект обратно в RAM.

В FastAPI/Django и очередях Celery сериализация нужна на каждом межпроцессном границе, поскольку объекты памяти процесса исчезают при его остановке:

```python
import json

user = {'name': 'Alex', 'role': 'admin'}

# Сериализация dict в JSON-строку
serialized = json.dumps(user)
print('Тип:', type(serialized).__name__)
# >>> Тип: str

print('Строка:', serialized)
# >>> Строка: {"name": "Alex", "role": "admin"}
```

## json.dumps() и json.loads(): строковая сериализация для API

Модуль **`json`** реализует текстовый кросс-языковой формат JSON.

Соответствие типов при преобразовании между Python и JSON:

| Тип Python | Представление в JSON | Пример |
| :--- | :--- | :--- |
| `dict` | JSON Object | `{"a": 1}` |
| `list`, `tuple` | JSON Array | `[1, 2]` |
| `str` | String | `"text"` |
| `int`, `float` | Number | `42`, `3.14` |
| `True` / `False` / `None` | `true` / `false` / `null` | `false`, `null` |

Функции с суффиксом `s` (`dumps`, `loads`) работают напрямую со строками в памяти:

```python
import json

data = {
    'name': 'Alex',
    'age': 30,
    'is_admin': False,
    'tags': ['python', 'api'],
}

json_str = json.dumps(data)
print('JSON:', json_str)
# >>> JSON: {"name": "Alex", "age": 30, "is_admin": false, "tags": ["python", "api"]}

restored = json.loads(json_str)
print('Имя:', restored['name'])
# >>> Имя: Alex
```

## json.dump() vs json.load(): потоковая работа с файлами

Функции без суффикса `s` пишут и читают напрямую через файловый поток, экономя память на промежуточной строке:

- **`json.dump(obj, fp)`** — сериализует объект и записывает прямо в поток `fp`.
- **`json.load(fp)`** — читает и парсит JSON непосредственно из открытого потока `fp`.

Продемонстрируем потоковую запись и чтение через `io.StringIO`:

```python
import io
import json

payload = {'status': 'ok', 'code': 200}
stream = io.StringIO()

# dump пишет напрямую в файловый поток
json.dump(payload, stream)

# Перемотка и чтение из потока
stream.seek(0)
loaded = json.load(stream)
print('Из потока:', loaded['code'])
# >>> Из потока: 200
```

## Модуль pickle: бинарная сериализация объектов Python

**`pickle`** — встроенный бинарный протокол сериализации для Python, упаковывающий почти любой объект (классы, `set`, функции, циклические ссылки) в байтовую строку `bytes`.

Сравним упаковку и восстановление пользовательского класса `User` в байтах:

```python
import pickle

class User:
    def __init__(self, name: str, age: int):
        self.name = name
        self.age = age

user = User('Alex', 30)

binary = pickle.dumps(user)
print('Тип:', type(binary).__name__)
# >>> Тип: bytes

restored = pickle.loads(binary)
print('Имя:', restored.name)
# >>> Имя: Alex
```

## Сравнение json vs pickle и критическая опасность `__reduce__`

Ключевые отличия двух форматов сериализации:

| Критерий | `json` | `pickle` |
| :--- | :--- | :--- |
| Переносимость | Все языки (JS, Go, Rust) | Только Python (зависит от версии) |
| Типы данных | Примитивы, списки, словари | Почти любые классы и `set` |
| Читаемость | Прозрачный текст | Бинарный поток `bytes` |
| Безопасность | Безопасен для внешнего ввода | **Опасен (RCE)** на чужих данных |

Никогда не передавайте внешние или пользовательские байты в `pickle.loads()`.

Через метод **`__reduce__()`** атакующий может встроить вызов `os.system` или `subprocess` (RCE):

```python
import pickle

class Exploit:
    def __reduce__(self):
        # Инструкция, выполняемая при loads()
        return (print, ('⚠️ Взлом!',))

payload = pickle.dumps(Exploit())

# ОПАСНО: pickle.loads() выполнит код!
restored = pickle.loads(payload)
# >>> ⚠️ Взлом!
```

## Кастомный энкодер json: сериализация datetime и UUID

Стандартный `json.dumps()` падает с `TypeError` на объектах `datetime` или `UUID`.

Чтобы задать правило сериализации нестандартных типов, передают функцию-конвертер в параметр `default` (в FastAPI/Pydantic v2 это делает метод `model.model_dump_json()`):

```python
from datetime import datetime
import json

def custom_encoder(obj):
    if isinstance(obj, datetime):
        return obj.isoformat()
    msg = f'{type(obj)} не сериализуем'
    raise TypeError(msg)

now = datetime(2026, 10, 20, 12, 0)
data = {'event': 'login', 'date': now}

encoded = json.dumps(
    data, default=custom_encoder
)
print(encoded)
# >>> {"event": "login", "date": "2026-10-20T12:00:00"}
```
