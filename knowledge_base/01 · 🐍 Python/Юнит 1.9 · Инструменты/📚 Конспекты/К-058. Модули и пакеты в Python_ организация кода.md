## Модуль – базовая единица

**Модуль** – это любой файл с расширением `.py`. Он позволяет логически сгруппировать связанный код: функции, классы, константы. Главное преимущество – повторное использование: написал один раз, импортируй где угодно.

```python

def add(a, b):
    return a + b

def multiply(a, b):
    return a * b
```

```python
import math_utils
from math_utils import add
```

`import math_utils` даёт доступ ко всему модулю через точечную нотацию: `math_utils.add(2, 3)`. `from math_utils import add` импортирует конкретное имя напрямую в текущее пространство имён.

## Пакет – директория с модулями

Когда модулей становится много, их организуют в **пакеты**. Пакет – это директория, содержащая несколько модулей. Структура типичного пакета:

```text
my_package/
    __init__.py
    utils.py
    models.py
    helpers/
        __init__.py
        string_helper.py
```

Доступ к вложенным элементам через точечную нотацию работает так же, как `/` в файловых путях:

```python
from my_package import utils
from my_package.helpers import string_helper
```

## `__init__.py` – что делает папку пакетом

Наличие файла **`__init__.py`** сигнализирует Python, что директорию нужно рассматривать как пакет, доступный для импорта. Файл может быть пустым – само его присутствие уже имеет значение.

Код внутри `__init__.py` выполняется при первом импорте пакета. Это удобно для предварительной настройки или экспорта публичного API пакета:

```python
from .utils import add  # теперь можно писать from my_package import add
```

Начиная с Python 3.3 появились namespace packages – пакеты без `__init__.py`. Но использование файла остаётся стандартом: это делает архитектуру явной и предсказуемой для других разработчиков.

## Как Python ищет модули при импорте

При `import something` Python ищет модуль в следующем порядке: сначала в `sys.modules` (кеш уже импортированных модулей), затем в директории текущего файла, затем по путям из `sys.path` – список директорий, который включает стандартную библиотеку и установленные пакеты.

Это важно понимать при отладке `ImportError`: модуль может не находиться потому, что его директория не входит в `sys.path`.

## Относительные vs абсолютные импорты

Внутри пакета можно использовать два вида импортов. **Абсолютный** – полный путь от корня проекта: `from my_package.utils import add`. **Относительный** – путь относительно текущего модуля: `from .utils import add` (одна точка – текущий пакет, две точки – родительский).

Относительные импорты работают только внутри пакетов. Смешивать их без необходимости не стоит: абсолютные импорты читаются проще и реже вызывают путаницу.

---

## Разница между модулем и пакетом

Модуль – это файл `.py` с кодом: минимальная единица организации. Пакет – это директория с файлом `__init__.py`, содержащая модули и подпакеты: организационная структура для масштабирования. Пакет сам по себе тоже является объектом в Python – его можно импортировать, он имеет атрибуты и пространство имён.

Практический совет: не проектируйте сложную структуру пакетов заранее. Начинайте с модулей, и переходите к пакетам тогда, когда количество файлов начинает затруднять навигацию по проекту.
