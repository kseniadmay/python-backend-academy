1. Что такое реэкспорт имён в `__init__.py` пакета и зачем он нужен? >> Инициализационный код, реэкспорт имён из подмодулей, определение `__all__`
2. Для чего используется переменная `__all__` в модулях Python? >> Определяет список имён, экспортируемых при `from module import *` ; ограничивает публичный интерфейс модуля
3. Как Python кэширует импортированные модули? >> В `sys.modules` ; повторный `import` не перезагружает модуль – берётся из кэша
4. Как правильно импортировать функцию `add` из модуля `math_utils.py` ? >> `from math_utils import add`
5. Что такое модуль в Python? >> Любой файл с расширением `.py`
6. Как импортировать `string_helper` из `my_package/helpers` ? >> `from my_package.helpers import string_helper`
7. Как называются пакеты без `__init__.py` ? >> Namespace packages
8. Функция `__init__.py` ? >> Сигнализирует Python что директория является пакетом; выполняется при первом импорте пакета
9. Является ли `math_utils.py` с одной функцией модулем? >> Да; любой `.py` файл является модулем
10. С какой версии Python появились namespace packages? >> Python 3.3
11. Что может содержать модуль? >> Функции, классы, переменные и исполняемый код
12. Что такое пакет в Python? >> Директория с модулями и файлом `__init__.py`
13. Ключевое структурное различие между модулем и пакетом? >> Модуль – файл `.py` ; пакет – директория с `__init__.py`
14. Что такое относительный импорт? >> Импорт относительно текущего пакета: `from . import utils` – из текущего пакета; `from .. import config` – из родительского
15. Как импортировать модуль `utils` из `my_package` ? >> `from my_package import utils`
16. Почему рекомендуют использовать `__init__.py` даже там где не обязательно? >> Для явного обозначения пакета, совместимости и возможности инициализации
17. Должен ли `__init__.py` содержать код? >> Нет; может быть пустым
18. Как импортировать несколько функций из одного модуля? >> `from модуль import функция1, функция2`
19. Как импортировать весь модуль `math_utils` ? >> `import math_utils`
20. Какой файл обязателен для классического пакета? >> `__init__.py`
21. Что выполняется первым при импорте пакета? >> `__init__.py`
