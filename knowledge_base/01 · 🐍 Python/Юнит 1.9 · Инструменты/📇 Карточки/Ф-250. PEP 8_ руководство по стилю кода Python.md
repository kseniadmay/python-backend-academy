1. Что такое PEP 8? >> Официальное руководство по стилю кода Python, соглашение сообщества, не требование интерпретатора.
2. Сколько пробелов рекомендует PEP 8 на уровень отступа? >> 4 пробела, без табуляции.
3. Какой регистр рекомендован для имён функций и переменных? >> snake_case.
4. Какой регистр рекомендован для имён классов? >> PascalCase (CapWords).
5. Какой регистр рекомендован для констант? >> UPPER_SNAKE_CASE.
6. Сколько пустых строк рекомендуется перед определением класса/функции верхнего уровня? >> Две.
7. Какие инструменты автоматически проверяют соответствие PEP 8? >> flake8, pylint (линтеры) и black, autopep8 (форматтеры).
8. Кто является одним из авторов PEP 8? >> Гвидо ван Россум, создатель Python, с соавторами.
9. Какой символ рекомендуется для "приватных" атрибутов по соглашению? >> Одно подчёркивание в начале имени: _internal_value.
10. Что означает двойное подчёркивание в начале имени атрибута (__value)? >> Запускает name mangling — атрибут переименовывается на уровне класса для затруднения случайного доступа извне.
11. Сколько пустых строк рекомендуется между методами внутри класса? >> Одна.
12. Как PEP 8 рекомендует группировать импорты? >> Сначала стандартная библиотека, затем сторонние пакеты, затем локальные модули — с пустой строкой между группами.
13. Обязателен ли PEP 8 к исполнению интерпретатором? >> Нет, это соглашение сообщества, а не синтаксическое требование — код без PEP 8 всё равно выполнится.
14. Какой инструмент автоматически переформатирует код под единый стиль, а не просто указывает на нарушения? >> black (форматтер), в отличие от flake8/pylint (линтеры, только сообщают).
15. Как PEP 8 рекомендует называть модуль (файл .py)? >> Коротким именем в нижнем регистре, snake_case при необходимости: my_module.py.
16. Что PEP 8 говорит про сравнение с булевыми значениями напрямую (if x == True)? >> Не рекомендуется — использовать if x: напрямую, это избыточное сравнение.
17. Рекомендует ли PEP 8 использовать однобуквенные имена переменных 'l', 'O', 'I'? >> Нет, они слишком похожи на цифры 1, 0 в некоторых шрифтах — рекомендуется избегать.
18. Что PEP 8 говорит о пробелах вокруг оператора =  в присваивании по умолчанию в сигнатуре функции? >> Без пробелов: def f(x=5), но с пробелами при наличии аннотации типа: def f(x: int = 5).
