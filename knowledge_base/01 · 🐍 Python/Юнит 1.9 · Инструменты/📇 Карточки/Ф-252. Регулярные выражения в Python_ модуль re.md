1. Чем метод `re.search()` отличается от `re.match()` в Python? >> search() ищет совпадение где угодно в строке, match() — только с начала строки.
2. Что возвращает вызов функции `re.findall()`? >> Список всех непересекающихся совпадений.
3. Какую операцию выполняет функция `re.sub(pattern, repl, string)` из модуля `re` в Python? >> Заменяет совпадения по шаблону на указанную строку.
4. Что означает \d, \w, \s в регулярных выражениях? >> \d — цифра, \w — буква/цифра/подчёркивание, \s — пробельный символ.
5. Чем жадный квантификатор в регулярных выражениях отличается от ленивого? >> Жадный квантификатор (`*`, `+`) захватывает максимально длинную строку, а ленивый (`*?`, `+?`) — минимально возможную.
6. Как извлечь значение совпавшей именованной группы `(?P<name>...)` из объекта `re.Match` в Python? >> match.group('name') или `match.groupdict()`.
7. Зачем использовать `re.compile()` при многократном применении одного регулярного выражения? >> Компилирует шаблон один раз — быстрее при повторном использовании в цикле.
8. Что делает символ ^ в регулярном выражении вне символьного класса? >> Обозначает начало строки.
9. Что делает символ $ в регулярном выражении? >> Обозначает конец строки.
10. Чем [abc] отличается от (abc) в регулярке? >> [abc] — один из символов a, b или c; (abc) — группа, требующая точной последовательности "abc".
11. Что делает флаг re.IGNORECASE (re.I)? >> Делает совпадение нечувствительным к регистру.
12. Что делает {2,4} после символа/группы в регулярке? >> От 2 до 4 повторений.
13. Чем finditer() отличается от findall()? >> finditer() возвращает итератор объектов Match (с доступом к позиции, группам), findall() — просто список строк совпадений.
14. Как экранировать спецсимвол регулярки, чтобы искать его буквально? >> Обратным слэшем (\.) или через `re.escape()` для целой строки.
15. Какую роль выполняет незахватывающая группа `(?:...)` в синтаксисе регулярных выражений Python? >> Группа без захвата — группирует для приоритета операций, но не попадает в результат group()/groups().
16. Что делает флаг re.MULTILINE (re.M)? >> ^ и $ начинают соответствовать началу/концу КАЖДОЙ строки текста, а не только всей строки целиком.
17. Что делает флаг `re.DOTALL` (`re.S`)? >> Метасимвол `.` начинает соответствовать и символу перевода строки тоже (по умолчанию `.` не матчит `\n`).
18. Чем re.sub(pattern, repl, string, count=1) отличается от обычного re.sub? >> Заменит только первое совпадение, а не все — count ограничивает число замен.
19. Можно ли использовать функцию в качестве параметра `repl` в вызове `re.sub()`? >> Да: `re.sub(pattern, lambda m: m.group().upper(), text)` — функция получает объект `Match` и возвращает строку замены.
20. Что означает `\b` в регулярном выражении? >> Граница слова — срабатывает на переходе между «словным» (`\w`) и «несловным» (`\W`) символом без потребления самого символа
