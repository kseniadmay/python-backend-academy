1. Какой оператор перегружен у объектов pathlib.Path для удобного и кроссплатформенного соединения путей? >> Оператор деления / (например, Path('app') / 'configs' / 'settings.json').
2. В чём разница между свойствами .name, .stem и .suffix у объекта Path('/dir/archive.tar.gz')? >> .name вернёт 'archive.tar.gz' (имя целиком), .stem вернёт 'archive.tar' (имя без последнего расширения), а .suffix — '.gz' (последнее расширение с точкой).
3. Как получить список всех расширений составного файла вроде 'archive.tar.gz' через pathlib? >> Через свойство .suffixes, которое вернёт список ['.tar', '.gz'].
4. Какие два параметра нужно передать в path.mkdir(parents=True, exist_ok=True) и за что они отвечают? >> parents=True создаёт все недостающие родительские директории по цепочке (как mkdir -p), а exist_ok=True предотвращает ошибку FileExistsError, если папка уже существует.
5. Чем метод path.rglob('*.py') отличается от path.glob('*.py')? >> glob('*.py') ищет совпадения только непосредственно в указанной директории, а rglob('*.py') ищет рекурсивно во всех вложенных поддиректориях (эквивалент glob('**/*.py')).
6. Как прочитать или записать небольшой текстовый файл через объект Path в одну строку без явного блока with open()? >> Использовать методы path.read_text(encoding='utf-8') и path.write_text(data, encoding='utf-8'), которые сами открывают и гарантированно закрывают файл.
7. Как в современном Python надёжно получить путь к папке, в которой лежит текущий исполняемый .py-файл? >> Через выражение Path(__file__).resolve().parent.
8. Что делает метод path.resolve()? >> Превращает относительный путь в канонический абсолютный путь, устраняя переходы '..' и раскрывая все символические ссылки (symlinks).
9. Изменяет ли метод path.with_suffix('.bak') исходный объект Path? >> Нет, объекты Path неизменяемы (immutable); методы with_suffix() и with_name() всегда возвращают новый объект Path.
10. Чем отличаются классы PurePath и Path в модуле pathlib? >> PurePath выполняет только строковые операции над путями в памяти без обращения к ОС (позволяет работать с Windows-путями на Linux), а Path добавляет реальные системные вызовы к файловой системе (exists, open, mkdir).
11. Что возвращает метод path.iterdir()? >> Итератор (генератор) объектов Path для всех файлов и подпапок, находящихся непосредственно внутри данной директории (без спецзаписей '.' и '..').
12. Какими методами объекта Path удаляются файл и пустая директория? >> Файл (или симлинк) удаляется методом path.unlink(missing_ok=True), а пустая директория — методом path.rmdir().
13. Как через объект Path узнать размер файла в байтах и время его последнего изменения? >> Вызвать path.stat().st_size для размера в байтах и path.stat().st_mtime для времени модификации.
14. Как получить путь к домашней директории пользователя и текущей рабочей директории через pathlib? >> Через классовые методы Path.home() и Path.cwd().
15. Можно ли передавать объект pathlib.Path напрямую во встроенную функцию open() или функции модулей os и shutil? >> Да, поскольку Path реализует протокол os.PathLike (метод __fspath__), все стандартные функции Python принимают его наравне со строками.
16. Как с помощью pathlib вычислить относительный путь одного объекта Path относительно другого базового каталога? >> Использовать метод path.relative_to(base_dir) (если путь не лежит внутри base_dir, будет выброшен ValueError).
