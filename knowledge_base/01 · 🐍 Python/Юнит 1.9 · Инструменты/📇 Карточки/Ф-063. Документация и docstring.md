1. Где располагается `docstring` в коде? >> Сразу после заголовка функции, класса или модуля – до тела
2. Что такое `docstring` в Python? >> Строковый литерал в тройных кавычках, расположенный сразу после заголовка функции, класса или модуля; становится атрибутом `__doc__` и используется инструментами документирования
3. Может ли `docstring` быть написан в одинарных кавычках? >> Технически да – любой строковый литерал становится `__doc__` ; но PEP 257 требует тройные кавычки; одинарные работают, но не соответствуют стандарту
4. Что должен описывать качественный `docstring` функции? >> Назначение функции, аргументы (типы и смысл), возвращаемое значение и исключения, которые функция может выбросить
5. Какие кавычки используются для оформления `docstring` ? >> PEP 257 рекомендует тройные двойные кавычки `"""` . Тройные одинарные `'''` технически допустимы, но не приняты в стандарте
6. Что возвращает `dir()` для объекта? >> Отсортированный список строк с именами атрибутов и методов объекта, включая унаследованные; может быть переопределён через `__dir__`
7. Какой атрибут хранит строку документации объекта? >> `__doc__` ; если `docstring` отсутствует – возвращает `None` , не пустую строку
8. Влияет ли `docstring` на логику выполнения программы? >> Нет; это строковый литерал, который Python присваивает атрибуту `__doc__` ; на поведение программы не влияет
9. Как получить `docstring` функции `sum` напрямую? >> `sum.__doc__`
10. В чём разница между `help(f)` и `f.__doc__` ? >> `help()` форматирует справку и выводит в stdout, возвращает `None` ; `__doc__` возвращает строку напрямую – удобно для программной обработки
11. Как вызвать справку для функции `print` ? >> `help(print)`
12. С помощью какой функции можно получить отформатированную справку об объекте? >> `help()` ; форматирует и выводит сигнатуру + `docstring` в stdout, возвращает `None`
13. Должен ли `docstring` описывать аргументы функции? >> Да; формат описания зависит от принятого стиля: Google Style, NumPy Style или reStructuredText (Sphinx)
14. Должен ли `docstring` описывать возвращаемое значение? >> Да; однострочный `docstring` может опустить это, если возврат очевиден; многострочный – обязан описывать
