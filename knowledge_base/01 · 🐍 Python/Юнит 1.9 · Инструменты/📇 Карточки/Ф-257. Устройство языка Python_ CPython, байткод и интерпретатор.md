1. Python — это язык или реализация? >> Python — спецификация языка; CPython — самая распространённая эталонная реализация на C.
2. Во что компилируется исходный код Python перед выполнением? >> В байткод — набор инструкций для виртуальной машины Python (PVM).
3. Что хранится в папке __pycache__? >> Закэшированный байткод (.pyc файлы), чтобы не перекомпилировать модуль заново при каждом запуске.
4. Какой модуль стандартной библиотеки показывает байткод функции? >> dis (dis.dis(func)).
5. Назовите альтернативные реализации Python помимо CPython. >> PyPy (с JIT-компиляцией), Jython (на JVM), IronPython (на .NET).
6. Почему GIL — не требование языка Python, а деталь CPython? >> Другие реализации (например, PyPy) экспериментируют с моделями без GIL; GIL — особенность конкретно CPython.
7. Как называется виртуальная машина, исполняющая байткод Python? >> PVM (Python Virtual Machine).
8. Компилируется ли Python в машинный код напрямую, как C? >> Нет, он компилируется в промежуточный байткод, который затем интерпретируется PVM.
9. Что произойдёт, если исходный .py файл не менялся с последней компиляции? >> Python использует закэшированный байткод из __pycache__, не перекомпилируя заново.
10. Какая экспериментальная возможность Python 3.13 убирает GIL? >> Free-threaded сборка (PEP 703), не включена по умолчанию.
11. Пример реализации Python, использующей JIT-компиляцию для ускорения? >> PyPy.
12. На каком языке написан сам CPython? >> На C.
13. Что происходит с байткодом при изменении версии Python (например, 3.11 -> 3.12)? >> Формат байткода может измениться — файлы .pyc одной версии несовместимы с интерпретатором другой версии.
14. Хранит ли .pyc файл исходный код в читаемом виде? >> Нет, только скомпилированный байткод — исходный .py всё равно нужен для отладки с полными сообщениями об ошибках в некоторых случаях.
15. Что делает функция compile() во встроенных функциях Python? >> Компилирует строку с исходным кодом в объект кода (байткод), который затем можно выполнить через exec()/eval().
16. Чем eval() отличается от exec()? >> eval() вычисляет и возвращает значение ОДНОГО выражения, exec() выполняет произвольный блок инструкций без возврата значения.
