1. Что вернёт метод `.most_common(2)` объекта `Counter`: `from collections import Counter; counts = Counter([1, 1, 2, 3]); print(counts.most_common(2))` ? >> `[(1, 2), (2, 1)]`
2. Что вернёт и как изменит `deque` метод `.appendleft()`: `from collections import deque; dq = deque([1, 2, 3]); dq.appendleft(0); print(dq)` ? >> `deque([0, 1, 2, 3])`
3. Поддерживает ли `collections.Counter` арифметические операции над частотами? >> Да; `Counter` можно складывать, вычитать и пересекать: `Counter('ab') + Counter('bc')` → `Counter({'b': 2, 'a': 1, 'c': 1})`
4. `Counter('abracadabra')` – результат? >> `Counter({'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1})`
5. Что такое параметр `maxlen` у `deque` ? >> Ограничивает максимальный размер очереди; при добавлении нового элемента старый с противоположного конца автоматически удаляется
6. Метод удаления и возврата элемента из начала `deque` ? >> `popleft()`
7. Что делает `defaultdict(int)` при обращении к новому ключу? >> Создаёт ключ со значением `0` – результат вызова `int()`
8. Метод добавления элемента в начало `deque` ? >> `appendleft()`
9. Какой метод возвращает наиболее частые элементы? >> `most_common(n)` ; возвращает список из `n` кортежей `(элемент, количество)` в порядке убывания
10. Что означает `deque` ? >> Double-ended queue – двусторонняя очередь
11. Что такое `defaultdict` ? >> Подкласс `dict` , автоматически создающий значение по умолчанию через `default_factory` при обращении к несуществующему ключу
12. Почему `list.pop(0)` и `list.insert(0, x)` неэффективны? >> Сложность `O(n)` – требуют сдвига всех элементов; `deque.popleft()` и `deque.appendleft()` работают за `O(1)`
13. Чем `defaultdict` отличается от `dict.get(key, default)` ? >> `dict.get()` возвращает дефолт без создания ключа; `defaultdict` создаёт ключ с дефолтным значением в словаре
14. Что представляет первое и второе число в кортеже из `most_common()` ? >> Первое – сам элемент, второе – количество его вхождений
15. Что возвращает `Counter` при обращении к отсутствующему ключу? >> `0` ; в отличие от обычного `dict` , не выбрасывает `KeyError`
16. Что принимает `Counter` на вход? >> Любой итерируемый объект: строку, список, кортеж и др.
17. Для каких операций оптимизирован `deque` ? >> Добавление и удаление элементов с обоих концов за `O(1)`
18. Какую проблему решает `defaultdict` ? >> Устраняет необходимость проверки существования ключа и ручной инициализации значения; вместо `KeyError` создаёт дефолтное значение
19. Как импортировать `deque` ? >> `from collections import deque`
20. Как создать `defaultdict` со списками как дефолтными значениями? >> `defaultdict(list)`
21. Что произойдёт при `popleft()` на пустом `deque` ? >> Выбросит `IndexError`
22. Как создать `deque` из списка `[1, 2, 3]` ? >> `dq = deque([1, 2, 3])`
23. Из какого модуля импортируется `Counter` ? >> `from collections import Counter`
24. Для чего предназначен `Counter` ? >> Подсчёт количества вхождений элементов в итерируемом объекте; возвращает словарь вида `{элемент: количество}`
25. Нужно ли проверять существование ключа перед `d['key'].append(1)` в `defaultdict(list)` ? >> Нет; список будет создан автоматически
26. `Counter("abc")['z']` – результат? >> `0`
27. Является ли `Counter` подклассом `dict` ? >> Да; поддерживает все операции словаря плюс дополнительные методы подсчёта
