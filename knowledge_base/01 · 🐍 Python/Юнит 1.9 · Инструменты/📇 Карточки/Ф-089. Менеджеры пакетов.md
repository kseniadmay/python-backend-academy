1. Каковы преимущества менеджера зависимостей Poetry по сравнению с традиционным `pip + venv + requirements.txt` ? >> Виртуальное окружение: `poetry` создаёт и привязывает изолированное окружение к конкретному проекту
2. В чём преимущество `poetry.lock` ? >> Фиксирует точные версии всех зависимостей (включая транзитивные), гарантируя идентичность окружения при каждом развёртывании
3. Для чего используется термин воспроизводимая сборка? >> Для гарантии того, что при каждом развёртывании устанавливаются одни и те же версии зависимостей
4. Какой современный инструмент объединяет управление зависимостями, окружением и сборкой? >> `poetry`
5. Из какого репозитория `pip` по умолчанию устанавливает пакеты? >> PyPI (Python Package Index)
6. В каком файле фиксируются зависимости проекта при использовании `pip` ? >> `requirements.txt`
7. Какой файл генерирует `poetry` для обеспечения воспроизводимости сборок? >> `poetry.lock`
8. Какой инструмент является стандартным менеджером пакетов в Python? >> `pip`
9. Каково основное назначение менеджера пакетов в Python? >> Установка, обновление и удаление сторонних библиотек
10. Чем `pyproject.toml` отличается от `requirements.txt` ? >> `requirements.txt` содержит плоский список пакетов для `pip` ; `pyproject.toml` – стандарт PEP 518, хранит метаданные проекта, зависимости и настройки инструментов в структурированном формате
11. К какому типу библиотек относятся пакеты, которыми управляет `pip` ? >> Сторонние библиотеки из репозитория PyPI
12. Какая функция `poetry` относится к подготовке пакета к распространению? >> Сборка пакета ( `poetry build` ) – создаёт дистрибутив для публикации на PyPI
13. В каком файле `poetry` хранит информацию о зависимостях проекта? >> `pyproject.toml`
14. Какое ключевое отличие `poetry` от `pip` ? >> `pip` отвечает только за установку пакетов; `poetry` объединяет управление зависимостями, виртуальным окружением и сборкой пакета в одном инструменте
15. Для каких трёх задач `poetry` предоставляет единый интерфейс? >> Управление зависимостями, виртуальным окружением и сборкой пакета
