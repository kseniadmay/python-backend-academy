1. На какой версии языка Python, согласно современным стандартам, пишется весь новый код? >> На Python 3.
2. В каком году официально прекратилась поддержка языка Python 2? >> В 2020 году.
3. В чём ключевое отличие обычного модуля от пакета в файловой системе Python? >> Модуль — это одиночный файл `.py`, а пакет — директория с модулями и иерархическим пространством имён через точку (`pkg.submod`).
4. Что такое namespace-пакет (неявный пакет пространства имён по PEP 420), появившийся в Python 3.3? >> Пакет без файла `__init__.py`, части которого могут располагаться в разных директориях `sys.path` и объединяться под общим именем.
5. Зачем в классическом пакете Python создаётся файл `__init__.py` даже в современном Python 3? >> Он явно обозначает границы пакета, выполняется при первом импорте и позволяет сформировать удобный публичный интерфейс (фасад) пакета.
6. Какое изменение в работе функций вроде `range()`, `map()`, `filter()` и `dict.keys()` произошло при переходе от Python 2 к Python 3? >> Вместо создания полных списков в памяти они стали возвращать ленивые итераторы и объекты-представления (`dict_keys`), экономя память.
7. Как изменилось представление строк и работа оператора деления `/` в Python 3 по сравнению с Python 2? >> Тип `str` стал по умолчанию строкой Unicode (вместо байтов), а оператор `/` всегда выполняет истинное деление с плавающей точкой (`float`).
8. В каком порядке интерпретатор Python ищет модуль или пакет при выполнении инструкции `import`? >> Сначала в кэше `sys.modules`, затем среди встроенных модулей (`built-in`) и далее по списку директорий в `sys.path`.
