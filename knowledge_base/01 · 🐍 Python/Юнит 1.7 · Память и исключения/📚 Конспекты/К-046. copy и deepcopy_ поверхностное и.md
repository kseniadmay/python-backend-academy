## Присваивание – это не копирование

`b = a` не создаёт новый объект – обе переменные ссылаются на один и тот же объект в памяти. Чтобы получить независимую копию, нужно явное копирование – и здесь есть два уровня.

---

## Поверхностная копия (shallow copy)

**Поверхностная копия** создаёт новый внешний объект, но **не копирует** вложенные объекты внутри – они остаются общими (теми же ссылками) для оригинала и копии.

```python
import copy

original = [[1, 2], [3, 4]]
shallow = copy.copy(original)  # или original[:], или list(original)

shallow.append([5, 6])  # новый элемент верхнего уровня – не влияет на original
print(original)  # [[1, 2], [3, 4]] – не изменился

shallow[0].append(99)  # а вот изменение ВЛОЖЕННОГО списка...
print(original)  # [[1, 2, 99], [3, 4]] – изменился!
```

`shallow` и `original` – разные списки верхнего уровня, но `shallow[0]` и `original[0]` – это **один и тот же** вложенный список. Именно поэтому изменение вложенного элемента через копию отражается на оригинале – они всё ещё делят общие внутренние объекты.

---

## Глубокая копия (deep copy)

**Глубокая копия** рекурсивно копирует вообще всё – и внешний объект, и каждый вложенный объект на любом уровне вложенности. Результат полностью независим от оригинала.

```python
original = [[1, 2], [3, 4]]
deep = copy.deepcopy(original)

deep[0].append(99)
print(original)  # [[1, 2], [3, 4]] – не изменился, копия полностью независима
print(deep)  # [[1, 2, 99], [3, 4]]
```

## Срез и list() – тоже поверхностная копия

```python
original = [[1, 2], [3, 4]]
copy1 = original[:]  # поверхностная копия
copy2 = list(original)  # тоже поверхностная копия
copy3 = original.copy()  # тоже поверхностная копия
```

Частая ошибка новичков – считать, что `lst[:]` или `list(lst)` дают полностью независимую копию. Это верно только для плоских структур (списка чисел или строк); как только внутри есть вложенные изменяемые объекты – нужен именно `deepcopy`.

---

## Когда это действительно важно

```python
class Team:
    def __init__(self, members=None):
        self.members = members if members is not None else []

template = {'role': 'guest', 'permissions': []}

user_config = copy.deepcopy(template)  # без deepcopy user_config['permissions']
user_config['permissions'].append('read')  # был бы ТЕМ ЖЕ списком, что и в template
print(template['permissions'])  # [] – добавление права одному пользователю
```

Это особенно значимо для неизменяемых на вид структур конфигурации, шаблонов объектов, значений по умолчанию – там, где один "шаблон" копируется много раз и каждая копия должна жить своей жизнью.

---

## Когда использовать

Поверхностной копии достаточно для плоских структур (список чисел, список строк) или когда вложенные объекты действительно должны оставаться общими намеренно. Глубокая копия нужна, как только структура вложенная (список списков, словарь с вложенными объектами) и копия должна быть полностью независима от оригинала – иначе получите трудноуловимый баг, когда изменение "копии" неожиданно проявляется в оригинале.
