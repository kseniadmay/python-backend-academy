1. В чём разница между `sys.getrefcount()` и модулем `gc` при управлении памятью в CPython? >> `sys.getrefcount()` мониторит количество ссылок; `gc` обнаруживает и очищает циклические ссылки
2. Какую проблему создавал метод `__del__` при циклических ссылках в старых версиях Python и как она была решена? >> Объекты с `__del__` и циклическими ссылками не могут быть безопасно удалены `gc` в старых версиях Python; в Python 3.4+ это исправлено через `PEP 442`
3. Какая функция показывает количество ссылок на объект? >> `sys.getrefcount(obj)`
4. Какой механизм является основным для управления памятью в Python? >> Reference counting (подсчёт ссылок)
5. К чему приводят циклические ссылки? >> К утечке памяти
6. Что такое циклическая ссылка? >> Ситуация когда два или более объектов ссылаются друг на друга; счётчики не падают до нуля
7. Как быстро освобождается память при reference counting? >> Немедленно; детерминированно в отличие от GC
8. Когда счётчик ссылок увеличивается? >> При появлении новой ссылки на объект
9. Сколько поколений в `gc` ? >> Три: `0` , `1` , `2`
10. Какая команда явно удаляет ссылку? >> `del`
11. Как называется компонент для борьбы с циклическими ссылками? >> Garbage collector ( `gc` )
12. Что делает модуль `gc` ? >> Периодически ищет объекты с циклическими ссылками и удаляет их
13. Что происходит когда счётчик достигает `0` ? >> Объект немедленно удаляется, память освобождается
14. На каком принципе организована работа `gc` ? >> По поколениям
15. В чём главная проблема reference counting? >> Не может обнаружить и очистить циклические ссылки
16. Какое поколение соответствует новым объектам? >> `0`
17. Почему `del a, b` не освобождает память при циклических ссылках? >> Счётчики объектов остаются ненулевыми из-за взаимных ссылок
18. Какое поколение соответствует долгоживущим объектам? >> `2`
19. Как принудительно запустить сборку мусора? >> `gc.collect()` ; возвращает количество найденных и удалённых недостижимых объектов
20. Что хранит каждый объект для отслеживания востребованности? >> Счётчик ссылок
21. Когда счётчик ссылок уменьшается? >> При удалении ссылки: `del` , выходе из области видимости, переприсваивании
22. Является ли `gc` основным механизмом удаления объектов? >> Нет; основной – reference counting; `gc` – вспомогательный для циклических ссылок
23. Какое влияние на счётчик оказывает `del a` ? >> Уменьшает на `1` ; если счётчик падает до `0` – объект удаляется
24. Почему `getrefcount()` возвращает на одну ссылку больше? >> Аргумент функции создаёт временную ссылку при передаче
25. Как изменится счётчик после `b = a` ? >> Увеличится на `1`
26. Что произойдёт если полностью отключить `gc` ? >> Циклические ссылки будут накапливаться и вызывать постоянные утечки памяти
27. В каком модуле реализован garbage collector? >> `gc`
28. Какое поколение проверяется наиболее часто? >> `0`
