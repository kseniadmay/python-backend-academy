1. В чём опасность перехвата `except BaseException:` вместо `except Exception:` ? >> Невозможность завершить программу через `Ctrl+C` или `sys.exit()`

4. Цепочка наследования для `RecursionError` ? >> `BaseException → Exception → RuntimeError → RecursionError`
5. Является ли `RecursionError` ошибкой времени выполнения? >> Да; подкласс `RuntimeError`
6. Что произойдёт при изменении словаря во время итерации? >> `RuntimeError: dictionary changed size during iteration`
7. Является ли `ValueError` подклассом `RuntimeError` ? >> Нет; самостоятельный подкласс `Exception`
8. Какое исключение вызывается при превышении лимита рекурсии? >> `RecursionError`
9. Ловит ли `except Exception` исключение `KeyboardInterrupt` ? >> Нет; `KeyboardInterrupt` наследуется напрямую от `BaseException`
10. Чем опасен голый `except:` без указания класса? >> Эквивалентен `except BaseException:` : перехватит все исключения включая системные; никогда не использовать в production
11. Что указывать в `except` чтобы поймать почти всё не затрагивая системные? >> `Exception`
12. К какой ветке относится `RuntimeError` ? >> `BaseException → Exception → RuntimeError`
13. Почему нежелательно ловить `BaseException` ? >> Перехватит `SystemExit` и `KeyboardInterrupt` , мешая штатному завершению программы
14. Что произойдёт при изменении размера коллекции во время цикла? >> `RuntimeError`
15. В чём отличие `BaseException` от `Exception` при перехвате? >> `BaseException` ловит всё включая `SystemExit` и `KeyboardInterrupt` ; `Exception` – только прикладные ошибки
16. Какое сообщение сопровождает `RecursionError` ? >> `maximum recursion depth exceeded`
17. Является ли `Exception` подклассом `BaseException` ? >> Да
18. Какая ошибка при обращении к завершённому генератору? >> `RuntimeError`
19. Для каких ошибок предназначен `RuntimeError` ? >> Для ошибок времени выполнения не подпадающих под более конкретные категории
20. Три основных потомка `BaseException` ? >> `SystemExit` , `KeyboardInterrupt` , `Exception`
21. Какое исключение ловить чтобы не прерывать работу при ошибках логики? >> `Exception`
22. Является ли `KeyError` частью `RuntimeError` ? >> Нет; `KeyError → LookupError → Exception`
23. Что вызовет бесконечно рекурсивная функция? >> `RecursionError`
24. Какой класс на вершине иерархии исключений? >> `BaseException`
25. Подклассом чего является `RecursionError` ? >> `RuntimeError`
