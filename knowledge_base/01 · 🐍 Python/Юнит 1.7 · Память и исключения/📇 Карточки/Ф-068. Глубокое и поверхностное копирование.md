1. Что вернёт проверка `shallow is original` после создания поверхностной копии `shallow = original.copy()` ? >> `False` ; разные объекты-контейнеры
2. Что произойдет с оригинальным списком original после deepcopy и изменения вложенного элемента? >> Оригинал не изменится: `[[1, 2], [3, 4]]`
3. Что произойдёт с исходным списком `original = [[1, 2], [3, 4]]` , если изменить элемент поверхностной копии `shallow[0].append(99)` ? >> `original` изменится: `[[1, 2, 99], [3, 4]]`
4. Что вернёт проверка `shallow[0] is original[0]` после поверхностного копирования `shallow = original.copy()` для `original = [[1, 2], [3, 4]]` ? >> `True` ; вложенные объекты идентичны
5. Назовите три способа создания поверхностной копии (shallow copy) списка без использования модуля `copy` . >> `list.copy()` , срез `lst[:]` , конструктор `list(original)`
6. Что вернёт проверка `deep[0] is original[0]` после глубокого копирования через `copy.deepcopy()` ? >> `False` ; вложенные объекты тоже скопированы
7. Как `deepcopy` обрабатывает циклические ссылки? >> Корректно; ведёт внутренний словарь уже скопированных объектов ( `memo` ) чтобы не зациклиться
8. Когда достаточно shallow copy? >> Если структура плоская или вложенные объекты неизменяемые
9. Почему `b = a` не считается копированием? >> Не создаёт новый объект; лишь связывает два имени с одним участком памяти
10. Как `deepcopy` соотносится с `copy` по скорости? >> Медленнее; рекурсивно обходит всю структуру
11. Как изменение вложенного объекта через shallow copy влияет на оригинал? >> Изменение видно в оригинале; оба объекта ссылаются на одни и те же вложенные элементы
12. Какой модуль используется для глубокого копирования? >> `copy`
13. Создаёт ли `b = a` копию объекта? >> Нет; обе переменные указывают на один объект в памяти
14. Когда необходимо deep copy? >> При наличии вложенных изменяемых объектов требующих полной независимости от оригинала
15. Что такое глубокое копирование? >> Рекурсивное копирование объекта и всех вложенных элементов; создаёт полностью независимую структуру
16. Как `deepcopy` влияет на память? >> Потребляет больше; создаёт дубликаты всех вложенных объектов
17. Влияет ли изменение вложенного объекта `deep copy` на оригинал? >> Нет; полная независимость
18. Какая функция создаёт полную независимую копию? >> `copy.deepcopy()`
19. Как создать shallow copy через модуль `copy` ? >> `copy.copy(obj)` ; работает для любых объектов, не только списков
20. В чём особенность поверхностного копирования? >> Создаётся новый объект-контейнер, но вложенные объекты не копируются – копируются только ссылки на них
