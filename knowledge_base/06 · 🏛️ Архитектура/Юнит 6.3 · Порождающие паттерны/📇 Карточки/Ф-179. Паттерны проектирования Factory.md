1. Почему клиент не должен знать конкретный класс в Factory? >> Снижение связанности (coupling); клиент зависит от абстракции, а не реализации; легче тестировать через мок-объекты
2. Как реализовать Factory Method через словарь в Python? >> Словарь хранит строки → классы; `creators = {'email': EmailNotifier}` ; `return creators[channel]()` – создаёт экземпляр
3. В чём идея Factory Method (фабричный метод)? >> Базовый класс определяет интерфейс метода создания объекта ( `create()` ), а подклассы переопределяют его; создание делегируется наследникам
4. Что такое абстрактный класс в контексте Factory в Python? >> Класс с `ABC` и `@abstractmethod` ; нельзя создать напрямую; подклассы обязаны реализовать помеченные методы
5. Какова основная цель паттерна Factory? >> Вынести логику создания объектов в отдельное место; клиентский код работает с объектами через общий интерфейс, не зная конкретных классов
6. Как добавить новый канал `WhatsApp` в существующую Factory? >> Создать класс `WhatsAppNotifier` и добавить `'whatsapp': WhatsAppNotifier` в словарь фабрики; клиентский код не меняется
7. В чём идея Simple Factory (простая фабрика)? >> Статический метод или класс, принимающий параметр и возвращающий нужный объект; не является классическим GoF-паттерном, но широко используется
8. Как Factory связан с принципом dependency inversion (DIP)? >> Клиент зависит от абстрактного интерфейса ( `Notifier` ), а не от конкретных реализаций; конкретные классы создаются только в фабрике
9. В чём идея Abstract Factory (абстрактная фабрика)? >> «Фабрика фабрик»; создаёт семейства взаимосвязанных объектов; конкретная фабрика выбирается один раз, затем клиент работает только с абстрактным интерфейсом
10. К какой категории паттернов относится Factory? >> Порождающие (Creational); управляют созданием объектов
11. Как Factory помогает в тестировании? >> Можно подменить фабрику на тестовую, возвращающую моки; клиентский код не нужно менять
12. Чем Abstract Factory отличается от Factory Method? >> Factory Method – один метод создания одного типа объектов; Abstract Factory – несколько методов для создания целого семейства связанных объектов
13. Какому принципу SOLID следует паттерн Factory? >> OCP (Open/Closed Principle): добавление нового типа не требует изменения существующего кода фабрики и клиента
14. Что произойдёт, если в фабрику передать неизвестный тип? >> Следует бросать `ValueError` ; без этого словарь бросит `KeyError` – менее информативно
15. Чем словарь лучше `if/elif` в фабрике? >> Добавление нового типа требует одной строки в словаре; не нужно изменять логику ветвлений; соответствует OCP
