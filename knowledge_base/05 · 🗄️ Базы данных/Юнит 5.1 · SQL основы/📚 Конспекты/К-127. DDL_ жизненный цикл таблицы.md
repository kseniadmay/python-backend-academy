## Четыре подмножества SQL: DDL, DML, DCL и TCL

> **Каркас против содержимого**: команды **DDL** (`CREATE`, `ALTER`, `DROP`) возводят и меняют стены таблиц, а команды **DML** (`SELECT`, `INSERT`, `UPDATE`, `DELETE`) работают со строками внутри этих стен.

```text
Классификация операторов языка SQL:
┌────────────────────────────────────────────┐
│ • DDL (Data Definition Language):          │
│   CREATE, ALTER, DROP, TRUNCATE            │
│   (Структура таблиц, типов и индексов)     │
├────────────────────────────────────────────┤
│ • DML (Data Manipulation Language):        │
│   SELECT, INSERT, UPDATE, DELETE           │
│   (Чтение и модификация строк данных)      │
├────────────────────────────────────────────┤
│ • TCL (Transaction Control Language):      │
│   BEGIN, COMMIT, ROLLBACK, SAVEPOINT       │
├────────────────────────────────────────────┤
│ • DCL (Data Control Language):             │
│   GRANT, REVOKE (Права доступа и роли)     │
└────────────────────────────────────────────┘
```

## Выбор типов данных при проектировании схемы

Правильный выбор типов столбцов в PostgreSQL защищает от потери точности и переполнения:

| Сущность | ❌ Антипаттерн | ✅ Стандарт в PostgreSQL | Инженерное обоснование |
| :--- | :--- | :--- | :--- |
| **Деньги и баланс** | `REAL` / `FLOAT` | `NUMERIC(12, 2)` или `BIGINT` (копейки) | В двоичном `float` `0.1 + 0.2 != 0.3` — на счетах появятся погрешности |
| **Автоинкремент ID** | `SERIAL` (32 бита) | `BIGINT GENERATED ALWAYS AS IDENTITY` | 32-битный `INTEGER` переполняется на $2.14 \times 10^9$ строках |
| **Дата и время** | `TIMESTAMP` / `TEXT` | `TIMESTAMPTZ` (с часовым поясом) | Хранит момент в UTC и приводит к зоне клиента |
| **Строки текста** | `CHAR(100)` | `TEXT` или `VARCHAR(n)` | `CHAR(n)` добивает хвост строки пустыми пробелами |

## Создание таблицы с ограничениями (`CREATE TABLE`)

Команда `CREATE TABLE IF NOT EXISTS` задаёт имена колонок, типы и инварианты целостности (`PRIMARY KEY`, `NOT NULL`, `UNIQUE`, `DEFAULT`, `CHECK`):

```python
import sqlite3

with sqlite3.connect(':memory:') as conn:
    conn.execute('''
        CREATE TABLE IF NOT EXISTS accounts (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            owner TEXT NOT NULL UNIQUE,
            cents INT NOT NULL DEFAULT 0
                CHECK (cents >= 0)
        )
    ''')
    conn.execute("INSERT INTO accounts (owner) VALUES ('Ann')")
    print(conn.execute('SELECT * FROM accounts').fetchall())
```

## Расширение живой таблицы через `ALTER TABLE ADD COLUMN`

Команда `ALTER TABLE ... ADD COLUMN` позволяет добавить новое поле в работающую таблицу без потери накопленных записей.

Начиная с PostgreSQL 11 добавление колонки с константным `DEFAULT` выполняется мгновенно за $O(1)$ в метаданных каталога без физической перезаписи диска:

```python
import sqlite3

with sqlite3.connect(':memory:') as conn:
    conn.execute('CREATE TABLE users (id INT, name TEXT)')
    conn.execute("INSERT INTO users VALUES (1, 'Alice')")
    conn.execute(
        "ALTER TABLE users ADD COLUMN role TEXT DEFAULT 'dev'"
    )
    print(conn.execute('SELECT * FROM users').fetchall())
```

## Переименование столбцов и риск блокировок при смене типа

Переименование колонки (`RENAME COLUMN old TO new`) меняет только системный каталог и работает мгновенно.

Напротив, смена типа колонки (`ALTER COLUMN price TYPE NUMERIC`) на большой таблице в продакшене опасна: она берёт эксклюзивную блокировку `ACCESS EXCLUSIVE LOCK` и полностью перезаписывает файл таблицы:

```python
import sqlite3

with sqlite3.connect(':memory:') as conn:
    conn.execute('CREATE TABLE items (id INT, title TEXT)')
    conn.execute("INSERT INTO items VALUES (1, 'Book')")
    conn.execute(
        'ALTER TABLE items RENAME COLUMN title TO name'
    )
    cols = [r[1] for r in conn.execute('PRAGMA table_info(items)')]
    print('Колонки:', cols)
```

## Полное удаление таблицы (`DROP TABLE IF EXISTS`)

Команда `DROP TABLE` безвозвратно уничтожает и саму структуру таблицы, и все её строки, и привязанные к ней индексы:

```python
import sqlite3

with sqlite3.connect(':memory:') as conn:
    conn.execute('CREATE TABLE temp_cache (k TEXT)')
    conn.execute('DROP TABLE IF EXISTS temp_cache')
    left = conn.execute(
        "SELECT name FROM sqlite_master WHERE type='table'"
    ).fetchall()
    print('Оставшиеся таблицы:', left)
```
