1. Какой этап является завершающим? >> `LIMIT` (или `TOP` / `FETCH FIRST` )
2. Какая команда SQL используется для выборки данных из таблицы? >> `SELECT`
3. Фрагмент `WHERE` для поиска имён, начинающихся на «A»? >> `WHERE name LIKE 'A%'`
4. Какой оператор используется для поиска по текстовому шаблону? >> `LIKE`
5. Какая конструкция используется для фильтрации групп данных? >> `HAVING` – аналог `WHERE` , но применяется после `GROUP BY` к агрегированным результатам
6. Как в SQL записывается оператор «не равно»? >> `<>` – ANSI-стандарт; `!=` – диалектный синоним, поддерживается в PostgreSQL, MySQL, но не во всех СУБД
7. Какой этап является первым в логическом порядке выполнения? >> `FROM` – сначала определяется источник данных
8. Какая команда сортирует результат? >> `ORDER BY`
9. В какой СУБД для ограничения строк используется `ROWNUM` ? >> Oracle (до 12c)
10. Какая команда ограничивает количество возвращаемых строк в PostgreSQL и MySQL? >> `LIMIT`
11. Какой этап следует непосредственно перед `SELECT` ? >> `HAVING`
12. К какому понятию относится знание о том, что `FROM` выполняется раньше `WHERE` ? >> Logical Query Processing (логический порядок выполнения SQL-запроса)
13. Какой этап следует сразу за `WHERE` ? >> `GROUP BY`
14. Что означает `ASC` в `ORDER BY` ? >> Сортировка по возрастанию
15. Какой логический оператор инвертирует условие? >> `NOT`
16. Как выглядит SQL-оператор «больше или равно»? >> `>=`
17. Как в `SELECT` выбрать только определённые столбцы? >> Перечислить их имена через запятую: `SELECT name, salary FROM employees`
18. Какое ключевое слово ищет имена с буквой «a» на любой позиции? >> `LIKE '%a%'`
19. Какой логический оператор используется, если достаточно одного из условий? >> `OR`
20. Как выглядит SQL-оператор «меньше или равно»? >> `<=`
21. Что означает `_` в операторе `LIKE` ? >> Ровно один любой символ
22. В какой СУБД для ограничения строк используется `TOP` ? >> MS SQL Server
23. Какую конструкцию использовать для поиска строк с отсутствующими данными? >> `IS NULL` ; нельзя использовать `= NULL` – NULL не равно ничему, включая само себя
24. Если в `LIMIT` указано 10, сколько строк максимум вернёт запрос? >> `10` (или меньше, если в выборке всего меньше 10 строк)
25. Упорядочите этапы: `SELECT` , `FROM` , `WHERE` >> `FROM` → `WHERE` → `SELECT`
26. Выполняется ли `WHERE` до или после `FROM` ? >> После `FROM` – сначала определяется таблица, затем фильтруются строки
27. Каков логический порядок выполнения SQL-запроса? >> `FROM` → `WHERE` → `GROUP BY` → `HAVING` → `SELECT` → `ORDER BY` → `LIMIT`
28. Упорядочите этапы: `LIMIT` , `ORDER BY` , `SELECT` >> `SELECT` → `ORDER BY` → `LIMIT`
29. Аналог `LIMIT` в MS SQL? >> `TOP n` : `SELECT TOP 10 * FROM employees`
30. Какой этап следует сразу за `GROUP BY` ? >> `HAVING`
31. На каком этапе происходит фильтрация строк? >> `WHERE` – выполняется до `SELECT` , поэтому нельзя использовать алиасы из `SELECT` в `WHERE`
32. Как найти строки, где `manager_id` не указан? >> `WHERE manager_id IS NULL`
33. Что выполняется раньше в логическом порядке: `SELECT` или `ORDER BY` ? >> `SELECT` – он на 5-м месте, `ORDER BY` на 6-м
34. Какой логический оператор объединяет условия, когда должны выполняться оба? >> `AND`
35. Какое ключевое слово используется для фильтрации строк по условию? >> `WHERE`
36. Аналог `LIMIT` в Oracle? >> `ROWNUM` в старых версиях; в Oracle 12c+ – `FETCH FIRST n ROWS ONLY`
37. Можно ли в `ORDER BY` сортировать по нескольким столбцам? >> Да: `ORDER BY salary DESC, name ASC` – второй столбец используется при равенстве значений первого
38. Какой оператор проверяет вхождение значения в диапазон? >> `BETWEEN` : `WHERE salary BETWEEN 50000 AND 100000` (включает границы)
39. Какая сортировка применяется по умолчанию, если не указать `ASC` или `DESC` ? >> По возрастанию ( `ASC` )
40. Какой оператор проверяет вхождение значения в список? >> `IN` : `WHERE department IN ('Design', 'Marketing')`
41. Для чего используется `ORDER BY ... LIMIT 10` ? >> Для получения первых 10 строк в заданном порядке; без `ORDER BY` результат недетерминирован
42. Что означает `DESC` в `ORDER BY` ? >> Сортировка по убыванию
43. Что означает `*` в `SELECT *` ? >> Выбор всех столбцов таблицы; в production избегают – лучше перечислять нужные столбцы явно
44. В каком порядке пишутся основные блоки SQL-запроса? >> `SELECT ... FROM ... WHERE ... ORDER BY ... LIMIT`
45. Верно ли, что `ORDER BY` выполняется после `SELECT` ? >> Да; поэтому в `ORDER BY` можно использовать алиасы, заданные в `SELECT`
46. Какая команда пишется в начале запроса, но выполняется почти в конце? >> `SELECT` – синтаксически первая, логически пятая
47. Что означает `%` в операторе `LIKE` ? >> Любое количество символов, включая ноль
