## Главное отличие оконных функций `OVER()` от `GROUP BY`

> **Аналитика без потери строк**: обычный `GROUP BY` схлопывает строки группы в одну итоговую запись, а оконная функция `OVER (...)` вычисляет ранг или агрегат в скользящем окне, **сохраняя каждую исходную строку таблицы**.

```text
Анатомия вызова оконной функции:
┌─────────────────────────────────────────┐
│ DENSE_RANK()                            │
│   │  (Какую метрику считаем)            │
│ OVER (                                  │
│   PARTITION BY dept                     │
│     │  (На какие независимые окна делим)│
│   ORDER BY salary DESC                  │
│     │  (В каком порядке ранжируем окно) │
│ )                                       │
└─────────────────────────────────────────┘
```

## Сравнение `ROW_NUMBER`, `RANK` и `DENSE_RANK` при ничьих

Как три функции ранжирования распределяют места на значениях `100, 100, 80, 50`:

| Зарплата (`DESC`) | `ROW_NUMBER()` (Счётчик строк) | `RANK()` (С пропуском после ничьей) | `DENSE_RANK()` (Плотный без дыр) |
| :--- | :--- | :--- | :--- |
| **`100`** | **`1`** | **`1`** | **`1`** |
| **`100`** (ничья) | **`2`** | **`1`** | **`1`** |
| **`80`** | **`3`** | **`3`** (2-е место пропущено!) | **`2`** (без пропуска!) |
| **`50`** | **`4`** | **`4`** | **`3`** |

```python
import sqlite3

with sqlite3.connect(':memory:') as conn:
    conn.execute('CREATE TABLE s (v INT)')
    conn.executemany('INSERT INTO s VALUES (?)', [(100,), (100,), (80,)])
    sql = '''
    SELECT v, ROW_NUMBER() OVER (ORDER BY v DESC),
    RANK() OVER (ORDER BY v DESC),
    DENSE_RANK() OVER (ORDER BY v DESC) FROM s
    '''
    print(conn.execute(sql).fetchall())
```

## Разбиение на независимые окна через `PARTITION BY`

Клауза `PARTITION BY dept` внутри `OVER (...)` сбрасывает счётчик ранга или суммы отдельно для каждого отдела:

```python
import sqlite3

with sqlite3.connect(':memory:') as conn:
    conn.execute('CREATE TABLE e (d TEXT, s INT)')
    conn.executemany(
        'INSERT INTO e VALUES (?, ?)',
        [('IT', 300), ('IT', 200), ('HR', 250)],
    )
    sql = (
        'SELECT d, s, ROW_NUMBER() OVER '
        '(PARTITION BY d ORDER BY s DESC) FROM e'
    )
    print(conn.execute(sql).fetchall())
```

## Обращение к соседним строкам без `JOIN`: `LAG` и `LEAD`

Функция **`LAG(col, offset, default)`** берёт значение из предыдущей строки окна, а **`LEAD`** — из следующей, позволяя считать прирост метрик за один проход без `SELF JOIN`:

```python
import sqlite3

with sqlite3.connect(':memory:') as conn:
    conn.execute('CREATE TABLE rev (day INT, val INT)')
    conn.executemany(
        'INSERT INTO rev VALUES (?, ?)',
        [(1, 100), (2, 140), (3, 130)],
    )
    sql = '''
    SELECT day, val - LAG(val, 1, val) OVER (ORDER BY day)
    FROM rev
    '''
    print('Прирост по дням:', conn.execute(sql).fetchall())
```

## Нарастающий итог (`Running Total`) через `SUM() OVER`

Когда внутрь `SUM(val) OVER (ORDER BY day)` добавляется сортировка `ORDER BY`, обычная сумма превращается в накопительный итог от начала окна до текущей строки:

```python
import sqlite3

with sqlite3.connect(':memory:') as conn:
    conn.execute('CREATE TABLE tx (id INT, amt INT)')
    conn.executemany(
        'INSERT INTO tx VALUES (?, ?)',
        [(1, 100), (2, 50), (3, 200)],
    )
    sql = '''
    SELECT id, amt, SUM(amt) OVER (ORDER BY id)
    FROM tx
    '''
    print('Баланс:', conn.execute(sql).fetchall())
```

## Фильтрация оконных функций через внешний `CTE`

Поскольку оконные функции вычисляются только на фазе `SELECT`, вызвать их внутри `WHERE` напрямую нельзя — расчёт оборачивают в `WITH ranked AS (...)` и фильтруют `WHERE rnk = 1` снаружи:

```python
import sqlite3

with sqlite3.connect(':memory:') as conn:
    conn.execute('CREATE TABLE e (d TEXT, n TEXT, s INT)')
    conn.executemany(
        'INSERT INTO e VALUES (?, ?, ?)',
        [('IT', 'Ann', 300), ('IT', 'Bob', 200), ('HR', 'Cid', 250)],
    )
    sql = (
        'WITH r AS (SELECT d, n, RANK() OVER (PARTITION BY d '
        'ORDER BY s DESC) AS rk FROM e) SELECT d, n FROM r WHERE rk=1'
    )
    print('Лидеры:', conn.execute(sql).fetchall())
```
