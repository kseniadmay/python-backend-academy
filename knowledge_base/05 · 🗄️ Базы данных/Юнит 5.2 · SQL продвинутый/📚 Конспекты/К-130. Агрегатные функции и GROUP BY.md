## Механика схлопывания строк в `GROUP BY`

> **Железное правило группировки**: при использовании `GROUP BY` в секции `SELECT` могут находиться **только** столбцы из `GROUP BY` (ключ группы) и агрегатные функции (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`).

```text
Таблица sales до группировки:
┌──────┬────────┬────────┐
│ dept │ seller │ amount │
├──────┼────────┼────────┤
│ IT   │ Alice  │  1000  │
│ IT   │ Bob    │  1500  │
│ HR   │ Clara  │   800  │
└──────┴────────┴────────┘
            │
            ▼ GROUP BY dept (схлопывание по отделу)
┌──────┬──────────┬─────────────┐
│ dept │ COUNT(*) │ SUM(amount) │
├──────┼──────────┼─────────────┤
│ IT   │    2     │    2500     │
│ HR   │    1     │     800     │
└──────┴──────────┴─────────────┘
```

## Пять агрегатных функций и их поведение с `NULL`

Все агрегатные функции в SQL, **кроме `COUNT(*)`**, полностью игнорируют значения `NULL`:

| Функция | Что вычисляет | Реакция на `NULL` | Результат на `(100, 200, NULL)` |
| :--- | :--- | :--- | :--- |
| **`COUNT(*)`** | Общее число строк в группе | ✅ Считает строки с `NULL` | **`3`** |
| **`COUNT(col)`** | Число строк, где `col IS NOT NULL` | Игнорирует `NULL` | **`2`** |
| **`COUNT(DISTINCT col)`** | Число уникальных не-`NULL` значений | Игнорирует `NULL` и дубли | **`2`** |
| **`SUM(col)`** | Сумма значений столбца | Игнорирует `NULL` (на пустом наборе даёт `NULL`) | **`300`** |
| **`AVG(col)`** | Среднее **только по не-`NULL` строкам** | Делит `SUM(col)` на `COUNT(col)`! | **`150.0`** ($300 / 2$) |
| **`MIN(col)` / `MAX(col)`** | Минимум и максимум | Игнорирует `NULL` | **`100`** / **`200`** |

## Разница между `COUNT(*)`, `COUNT(col)` и `COUNT(DISTINCT col)`

Наглядно сравним все три варианта подсчёта на таблице с дубликатами и `NULL`:

```python
import sqlite3

with sqlite3.connect(':memory:') as conn:
    conn.execute('CREATE TABLE log (city TEXT)')
    conn.executemany(
        'INSERT INTO log VALUES (?)',
        [('Moscow',), ('Moscow',), (None,)],
    )
    sql = '''
    SELECT COUNT(*), COUNT(city), COUNT(DISTINCT city)
    FROM log
    '''
    print('Подсчёт:', conn.execute(sql).fetchone())
```

## Коварная ловушка `AVG(col)` на строках с `NULL`

Поскольку `AVG(bonus)` игнорирует строки с `NULL`, он делит сумму только на число премированных сотрудников (`COUNT(bonus)`), завышая средний показатель по отделу:

```python
import sqlite3

with sqlite3.connect(':memory:') as conn:
    conn.execute('CREATE TABLE b (emp TEXT, val INT)')
    conn.executemany(
        'INSERT INTO b VALUES (?, ?)',
        [('A', 100), ('B', 200), ('C', None)],
    )
    raw_avg = conn.execute('SELECT AVG(val) FROM b').fetchone()[0]
    print('AVG без учёта NULL:', raw_avg)
```

## Защита агрегаций от `NULL` через `COALESCE`

Функция **`COALESCE(val, 0)`** возвращает первый не-`NULL` аргумент. Оборачивание поля в `AVG(COALESCE(val, 0))` и `COALESCE(SUM(val), 0)` гарантирует математически честный расчёт:

```python
import sqlite3

with sqlite3.connect(':memory:') as conn:
    conn.execute('CREATE TABLE b (emp TEXT, val INT)')
    conn.executemany(
        'INSERT INTO b VALUES (?, ?)',
        [('A', 100), ('B', 200), ('C', None)],
    )
    sql = 'SELECT AVG(COALESCE(val, 0)) FROM b'
    print('Честный AVG:', conn.execute(sql).fetchone()[0])
```

## Многомерная группировка по нескольким столбцам

В `GROUP BY dept, grade` уникальная корзина создаётся для каждой комбинации «Отдел + Грейд»:

```python
import sqlite3

with sqlite3.connect(':memory:') as conn:
    conn.execute('CREATE TABLE st (d TEXT, l TEXT, s INT)')
    conn.executemany(
        'INSERT INTO st VALUES (?, ?, ?)',
        [('IT', 'Sr', 300), ('IT', 'Jr', 100), ('IT', 'Sr', 320)],
    )
    sql = 'SELECT d, l, COUNT(*), AVG(s) FROM st GROUP BY d, l'
    print(conn.execute(sql).fetchall())
```
