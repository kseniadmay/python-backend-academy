1. Начиная с какой версии MongoDB поддерживает многодокументные транзакции? >> MongoDB 4.0; до этого транзакции поддерживались только на уровне одного документа
2. Как соотносятся понятия MongoDB и реляционных БД? >> Документ ≈ строка; коллекция ≈ таблица; поле ≈ столбец; но схема не фиксирована – разные документы коллекции могут иметь разную структуру
3. Что произойдёт при `update_one` без `$set` ? >> Документ будет полностью заменён переданным объектом; это распространённая ловушка
4. Как подключиться к MongoDB через pymongo? >> `client = MongoClient("mongodb://localhost:27017")` ; затем `db = client["mydb"]` ; `collection = db["users"]`
5. Когда MongoDB хуже PostgreSQL? >> Сильно связанные данные с частыми JOIN; финансовые системы с требованием строгой транзакционности и целостности; когда схема стабильна
6. Что возвращает `find()` до преобразования в список? >> Курсор ( `Cursor` ) – объект для ленивой итерации по результатам; `list(collection.find(...))` – полный список
7. Как обновить поле документа? >> `collection.update_one({"name": "Alice"}, {"$set": {"age": 31}})` ; без `$set` документ будет заменён целиком
8. Как удалить один документ? >> `collection.delete_one({"name": "Alice"})`
9. В чём риск отсутствия фиксированной схемы? >> Данные могут иметь непредсказуемую структуру; сложнее гарантировать целостность; нужна валидация на уровне приложения или через `$jsonSchema`
10. Нужна ли миграция схемы при добавлении нового поля в документ? >> Нет; MongoDB примет документ с новыми полями без изменений конфигурации; это преимущество и риск одновременно
11. Когда MongoDB лучше PostgreSQL? >> Гибкая или часто меняющаяся схема; документо-ориентированные данные (каталоги товаров с разными атрибутами); быстрое прототипирование; горизонтальное масштабирование
12. Как вставить один документ в коллекцию? >> `collection.insert_one({"name": "Alice", "age": 30})`
13. Поддерживает ли MongoDB `JOIN` нативно? >> Нет; для связи коллекций используется `$lookup` в агрегационном pipeline; это не полный аналог SQL `JOIN`
14. Как найти документы с возрастом больше 25? >> `collection.find({"age": {"$gt": 25}})`
15. Как MongoDB хранит вложенные данные? >> Как вложенные объекты и массивы внутри документа; не требует отдельных таблиц для связей
16. Что такое MongoDB? >> Документоориентированная NoSQL база данных; данные хранятся в виде документов в формате BSON (Binary JSON)
17. Что такое шардирование в MongoDB? >> Горизонтальное масштабирование: разбиение данных между несколькими серверами; MongoDB изначально спроектирована для этого
18. Что такое `_id` в MongoDB? >> Обязательный уникальный идентификатор документа; по умолчанию тип `ObjectId` ; аналог первичного ключа
19. Что такое BSON? >> Binary JSON – бинарный формат хранения данных в MongoDB; поддерживает дополнительные типы (ObjectId, Date, binary) по сравнению с JSON
20. Как найти один документ по фильтру? >> `collection.find_one({"name": "Alice"})`
