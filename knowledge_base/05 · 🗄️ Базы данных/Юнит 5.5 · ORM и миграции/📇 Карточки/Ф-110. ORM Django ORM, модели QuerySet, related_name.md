1. Что такое `F` -выражение? >> Ссылка на значение поля в БД без загрузки в Python; позволяет делать атомарные обновления и сравнения между полями
2. Что возвращает `values()` ? >> QuerySet словарей вместо объектов модели; полезно для сериализации и оптимизации памяти
3. Поддерживает ли QuerySet цепочку методов? >> Да; `Employee.objects.filter(is_active=True).order_by('-salary').values('name', 'salary')`
4. Выполняется ли запрос при `qs = Employee.objects.filter(is_active=True)` ? >> Нет; это только описание запроса; SQL уходит в БД при первом обращении к данным
5. Что такое `on_delete=models.CASCADE` ? >> При удалении родительского объекта автоматически удаляются все связанные дочерние объекты
6. Что такое ленивость (lazy) QuerySet? >> SQL-запрос не выполняется при определении QuerySet; выполнение происходит только при итерации, `list()` , `len()` , `bool()` или срезе
7. Какие lookups для строкового поиска? >> `__contains` (LIKE, чувствителен к регистру); `__icontains` (ILIKE, без учёта регистра)
8. Что делает `values_list('name', flat=True)` ? >> Возвращает плоский список значений одного поля: `['Alice', 'Bob', ...]`
9. Основные агрегатные функции Django ORM? >> `Count` , `Sum` , `Avg` , `Min` , `Max` ; импортируются из `django.db.models`
10. Что возвращает `annotate()` ? >> QuerySet с дополнительным вычисляемым полем у каждого объекта; например, количество заказов у каждого пользователя
11. Как отсортировать по убыванию? >> `order_by('-salary')` ; минус перед именем поля – убывающий порядок
12. Какой метод эффективно проверяет наличие записей без загрузки данных? >> `exists()` ; выполняет `SELECT 1` – быстрее `count()` и `bool(qs)`
13. Почему `PROTECT` полезен? >> Предотвращает случайное удаление родителя при наличии дочерних объектов; БД выбросит ошибку
14. Что вернёт `get()` , если записей найдено 0 или 2+? >> `DoesNotExist` при отсутствии; `MultipleObjectsReturned` при нескольких совпадениях
15. Что возвращает `aggregate()` ? >> Словарь с итоговым значением для всего QuerySet; например, `{'salary__avg': 75000.0}`
16. Чем `filter()` отличается от `get()` ? >> `filter()` возвращает QuerySet (может быть пустым); `get()` возвращает один объект или бросает исключение ( `DoesNotExist` или `MultipleObjectsReturned` )
17. Что такое lookup в Django ORM? >> Суффикс после `__` в фильтрах: `__gt` , `__lt` , `__icontains` , `__year` , `__in` , `__range` и др.
18. Для чего используется `related_name` ? >> Задаёт имя обратной связи; `dept.employees.all()` вместо дефолтного `dept.employee_set.all()`
19. Что делает `auto_now_add=True` в `DateTimeField` ? >> Автоматически устанавливает текущее время при создании объекта; не изменяется при обновлении
20. От какого класса наследуются все модели Django? >> `django.db.models.Model`
21. Как атомарно увеличить зарплату всех сотрудников на 10%? >> `Employee.objects.update(salary=F('salary') * 1.1)` ; вычисление происходит на стороне БД
22. Как отфильтровать по полю связанной модели? >> Через `__` : `Employee.objects.filter(department__name="IT")` – Django автоматически делает JOIN
23. Какие ещё варианты `on_delete` существуют кроме `CASCADE` ? >> `SET_NULL` (устанавливает `NULL` ), `SET_DEFAULT` , `PROTECT` (запрещает удаление при наличии связей), `DO_NOTHING`
