1. Зачем в `to_tsvector()` указывается язык? >> Выбирает словарь и правила нормализации (стемминг, стоп-слова) для конкретного языка
2. Что делает оператор `@>` для массивов? >> Проверяет, содержит ли левый массив все элементы правого
3. Что делает оператор `->` в JSONB? >> Извлекает поле как JSON-объект/значение; `attributes -> 'specs'`
4. Что такое `EXCLUDED` в блоке `ON CONFLICT DO UPDATE` ? >> Виртуальная таблица с несохранёнными значениями из `INSERT` ; используется для получения новых значений при обновлении
5. Чем `JSONB` отличается от `JSON` в PostgreSQL? >> `JSON` хранит текст как есть (с дублями и пробелами); `JSONB` – бинарный формат: удаляет дубли ключей, быстрее при чтении, поддерживает индексы
6. Какое расширение используется для временных рядов? >> `TimescaleDB`
7. Что делает оператор `->>` в JSONB? >> Извлекает значение поля как текст ( `TEXT` ); нужен для сравнений и сортировки
8. В чём преимущество UUID перед автоинкрементом в распределённых системах? >> Не требует централизованной генерации; можно создавать ID на стороне клиента или в нескольких сервисах без коллизий
9. Что делает оператор `ANY` при работе с массивами? >> Проверяет, равен ли элемент хотя бы одному значению массива: `'python' = ANY(tags)`
10. Что такое CTE (Common Table Expressions)? >> Обобщённые табличные выражения с `WITH` ; позволяют именовать подзапросы и использовать их в основном запросе
11. Для чего используется `pg_trgm` ? >> Триграммный поиск и поиск по сходству строк (fuzzy search); используется для `LIKE '%...'` с индексом
12. Как вставить массив значений в SQL? >> `ARRAY['python', 'sql']` или `CAST('{python,sql}' AS TEXT[])`
13. Какой индекс используется для ускорения поиска в JSONB? >> `GIN` (Generalized Inverted Index)
14. Что делает `RETURNING` в `INSERT` / `UPDATE` / `DELETE` ? >> Возвращает данные изменённых строк без дополнительного `SELECT` ; например, `INSERT ... RETURNING id`
15. Какой синтаксис предпочтительнее `SERIAL` в PostgreSQL 10+? >> `GENERATED ALWAYS AS IDENTITY` ; явнее семантика, нет проблем с ручным `setval`
16. Что делает оператор `@>` в JSONB? >> Проверяет, содержит ли левый JSONB-объект правый целиком (containment)
17. Какой индекс оптимизирует поиск по массивам? >> `GIN`
18. Как объявить столбец для хранения массива строк? >> `tags TEXT[]`
19. Как генерировать UUID в PostgreSQL 13+? >> Встроенная функция `gen_random_uuid()` ; расширение не требуется
20. Что такое `tsvector` ? >> Нормализованный текст, подготовленный для полнотекстового поиска; лексемы без стоп-слов
21. Что создаётся «под капотом» при использовании `SERIAL` ? >> `SEQUENCE` ; `SERIAL` – синтаксический сахар над `INTEGER DEFAULT nextval(sequence)`
22. Какой оператор выполняет полнотекстовый поиск? >> `@@` ; сопоставляет `tsvector` и `tsquery`
23. Какое расширение добавляет поддержку геоданных? >> `PostGIS`
24. Что делает оператор `?` в JSONB? >> Проверяет наличие ключа в JSON-объекте
25. Могут ли CTE изменять данные? >> Да; PostgreSQL поддерживает модифицирующие CTE с `INSERT` / `UPDATE` / `DELETE` + `RETURNING`
26. Что такое `ON CONFLICT` ? >> Реализует UPSERT: при конфликте уникальности выполняет `DO UPDATE` или `DO NOTHING`
27. Что такое `tsquery` ? >> Поисковый запрос с лексемами и логическими операторами ( `&` , `|` , `!` )
28. Какое расширение PostgreSQL нужно для генерации UUID до версии 13? >> `uuid-ossp` ; функция `uuid_generate_v4()`
29. Что делает оператор `&&` для массивов? >> Проверяет наличие пересекающихся элементов между двумя массивами
30. Какой тип предпочтительнее: `JSON` или `JSONB` ? >> `JSONB` почти всегда; единственное преимущество `JSON` – точное сохранение оригинального текста (порядок ключей, дубли)
