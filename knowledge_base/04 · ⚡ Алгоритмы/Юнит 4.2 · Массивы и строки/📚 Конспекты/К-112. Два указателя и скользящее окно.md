# 🎯 Паттерны массивов: Два указателя, Скользящее окно и Префиксные суммы

> **Ментальная модель — «Гусеница на ветке и кассовый счётчик»**:
> - **Два указателя (Two Pointers)** — два человека идут по списку навстречу друг другу с разных концов (или один бежит впереди другого), находя пару за один проход $O(n)$ без вложенного цикла $O(n^2)$.
> - **Скользящее окно (Sliding Window)** — рамка (или гусеница), ползущая по массиву: при сдвиге вправо на 1 шаг не нужно заново суммировать всё окно — достаточно **прибавить один новый правый элемент и вычесть один ушедший левый** за $O(1)$!
> - **Префиксные суммы (Prefix Sums)** — показания электросчётчика: чтобы узнать расход за неделю, не нужно суммировать 7 дней — достаточно вычесть показания понедельника из показаний воскресенья за $O(1)$!

## Паттерн «Два указателя»: Встречные указатели (Opposite Pointers)

Применяется для **палиндромов**, разворота массива `in-place` и поиска пары с заданной суммой в **отсортированном** массиве (`Two Sum II`).

```text
Два указателя (target = 10):

Массив: [ 1,  3,  4,  7,  8 ]
Указ.:    L               R   1+8=9 < 10 (L+=1)
             L            R   3+8=11 > 10 (R-=1)
             L        R       3+7=10 (НАЙДЕНО!)
```

        cur_sum = nums[left] + nums[right]

            return left, right

## Паттерн «Два указателя»: Попутные указатели (Read & Write)

Оба указателя стартуют с начала (`0`): `fast` («чтец») сканирует каждый элемент, а `slow` («писатель») перезаписывает только нужные элементы на месте (`in-place` за $O(1)$ памяти) — например, удаление дубликатов из отсортированного массива.

```python
def deduplicate_sorted(
    nums: list[int]
) -> list[int]:
    """In-place дедупликация: O(n)/O(1)."""
    if not nums:
        return []
    write = 1
    for read in range(1, len(nums)):
        if nums[read] != nums[write - 1]:
            nums[write] = nums[read]
            write += 1
    return nums[:write]
```

## Скользящее окно фиксированного размера (Fixed Window)

Используется для поиска оптимального непрерывного подмассива фиксированной длины $k$ за $O(n)$ вместо $O(n \cdot k)$.

```text
Окно k = 3:

Шаг 1: [ 2,  1,  5 ], 1,  3,  2
       sum = 8

Шаг 2:   2, [ 1,  5,  1 ], 3,  2
       sum = 8 - 2 + 1 = 7

Шаг 3:   2,  1, [ 5,  1,  3 ], 2
       sum = 7 - 1 + 3 = 9 (MAX!)
```

```python
def max_subarray_sum_k(
    nums: list[int], k: int
) -> int:
    """Макс. сумма окна длины k: O(n)."""
    window_sum = sum(nums[:k])
    best_sum = window_sum
    for right in range(k, len(nums)):
        diff = nums[right] - nums[right - k]
        window_sum += diff
        if window_sum > best_sum:
            best_sum = window_sum
    return best_sum
```

## Динамическое скользящее окно: амортизированное $O(n)$

В задачах вроде *«Самая длинная подстрока без повторяющихся символов»* окно динамически расширяется и сжимается:
1. `right` расширяет окно вправо на каждом шаге.
2. Внутренний `while` сжимает окно слева (`left += 1`), пока инвариант нарушен.
3. Сложность остаётся **$O(n)$**, так как `left` и `right` двигаются только вперёд ($n + n = 2n = O(n)$ — амортизированный анализ).

```python
def longest_unique_substring(s: str) -> int:
    """Самая длинная подстрока: O(n)."""
    seen_chars: set[str] = set()
    left = 0
    max_len = 0
    for right, ch in enumerate(s):
        while ch in seen_chars:
            seen_chars.remove(s[left])
            left += 1
        seen_chars.add(ch)
        cur_w = right - left + 1
        max_len = max(max_len, cur_w)
```

## Паттерн «Префиксные суммы» (Prefix Sums): срез за $O(1)$

Если нужно многократно отвечать на запрос **«Сумма на отрезке $[L, R]$»**, наивный `sum(nums[L:R+1])` тратит $O(n)$ на каждый запрос.
Массив `prefix` длины $n + 1$ позволяет находить сумму любого диапазона за **$O(1)$**:

$$\text{sum}(L, R) = \text{prefix}[R + 1] - \text{prefix}[L]$$

## Сравнение 3 паттернов массивов и ловушка отрицательных чисел

| Паттерн | Типичное условие | Время | Память |
| :--- | :--- | :--- | :--- |
| **Два указателя** | Сортировка, палиндром, in-place фильтр | **$O(n)$** | **$O(1)$** |
| **Скользящее окно** | Подмассив/подстрока (макс/мин сумма или длина) | **$O(n)$** | **$O(1)$** или **$O(k)$** |
| **Префиксные суммы** | Запросы суммы на отрезке $[L, R]$ | **$O(1)$** за запрос | **$O(n)$** |
