## Два указателя, скользящее окно и префиксные суммы

> Два указателя движутся по массиву навстречу друг другу, скользящее окно ползёт как гусеница по ветке, а префиксные суммы работают как счётчик электроэнергии.

Эти три техники превращают вложенные переборы $O(n^2)$ в быстрые линейные проходы:

- **Два указателя (Two Pointers)** — два индекса сканируют массив за один проход $O(n)$ без лишней памяти.
- **Скользящее окно (Sliding Window)** — при сдвиге рамки на шаг прибавляют один правый элемент и вычитают ушедший левый за $O(1)$.
- **Префиксные суммы (Prefix Sums)** — разность накопленных итогов `prefix[R+1] - prefix[L]` даёт сумму любого отрезка за $O(1)$.

## Два указателя: встречный проход

Паттерн применяют для палиндромов, разворота массива `in-place` и поиска пары с нужной суммой в **отсортированном** массиве (`Two Sum II`):

```text
Два указателя (target = 10):

Массив: [ 1,  3,  4,  7,  8 ]
Указ.:    L               R   1+8=9 < 10
             L            R   3+8=11 > 10
             L        R       3+7=10 (OK!)
```

Если текущая сумма меньше цели — двигаем левый указатель вправо, если больше — правый влево:

```python
def two_sum_sorted(
    nums: list[int], target: int
) -> tuple[int, int] | None:
    left, right = 0, len(nums) - 1
    while left < right:
        cur_sum = nums[left] + nums[right]
        if cur_sum == target:
            return left, right
        if cur_sum < target:
            left += 1
        else:
            right -= 1
    return None

ans = two_sum_sorted([1, 3, 4, 7, 8], 10)
print('Индексы target=10:', ans)
# >>> Индексы target=10: (1, 3)
```

## Два указателя: чтец и писатель (`Read & Write`)

Попутные указатели стартуют с начала массива и решают задачи модификации на месте (`in-place` за $O(1)$ памяти).

Указатель `read` сканирует элементы подряд, а `write` перезаписывает только уникальные значения отсортированного списка:

```python
def deduplicate_sorted(
    nums: list[int]
) -> list[int]:
    if not nums:
        return []

    # write хранит границу уникальных
    write = 1
    for read in range(1, len(nums)):
        if nums[read] != nums[write - 1]:
            nums[write] = nums[read]
            write += 1
    return nums[:write]

print(deduplicate_sorted([1, 1, 2, 2, 3]))
# >>> [1, 2, 3]
```

## Скользящее окно фиксированного размера

Чтобы найти оптимальный подмассив заданной длины $k$, окно сдвигают на один шаг вправо за $O(n)$ вместо пересчёта суммы за $O(n \cdot k)$:

```text
Окно k = 3:

Шаг 1: [ 2,  1,  5 ], 1,  3,  2  -> 8
Шаг 2:   2, [ 1,  5,  1 ], 3,  2 -> 7
Шаг 3:   2,  1, [ 5,  1,  3 ], 2 -> 9 (MAX!)
```

При сдвиге достаточно добавить новый элемент справа и вычесть ушедший элемент слева:

```python
def max_subarray_sum_k(
    nums: list[int], k: int
) -> int:
    window_sum = sum(nums[:k])
    best_sum = window_sum
    for right in range(k, len(nums)):
        diff = nums[right] - nums[right - k]
        window_sum += diff
        if window_sum > best_sum:
            best_sum = window_sum
    return best_sum

arr = [2, 1, 5, 1, 3, 2]
res = max_subarray_sum_k(arr, 3)
print('Макс. сумма окна:', res)
# >>> Макс. сумма окна: 9
```

## Динамическое скользящее окно: амортизированное O(n)

В задачах вроде *«Самая длинная подстрока без повторов»* ширина окна меняется динамически:

1. `right` расширяет окно вправо на каждом шаге цикла.
2. Внутренний `while` сжимает окно слева (`left += 1`), пока условие уникальности нарушено.
3. Оба указателя двигаются только вперёд ($n + n = 2n$), сохраняя линейную сложность $O(n)$:

```python
def longest_unique_substring(s: str) -> int:
    seen_chars: set[str] = set()
    left = 0
    best = 0
    for right, ch in enumerate(s):
        while ch in seen_chars:
            seen_chars.remove(s[left])
            left += 1
        seen_chars.add(ch)
        best = max(best, right - left + 1)
    return best

print(longest_unique_substring('abcabcbb'))
# >>> 3
```

## Префиксные суммы: запрос отрезка за O(1)

Чтобы многократно отвечать на вопрос «сумма на отрезке $[L, R]$», заранее строят массив накопленных сумм `prefix` длины $n + 1$.

После однократной подготовки $O(n)$ сумма любого диапазона вычисляется за $O(1)$ формулой `prefix[R + 1] - prefix[L]`:

```python
class RangeSumQuery:
    def __init__(
        self, nums: list[int]
    ) -> None:
        self.prefix = [0] * (len(nums) + 1)
        for i, x in enumerate(nums):
            prev = self.prefix[i]
            self.prefix[i + 1] = prev + x

    def sum_range(
        self, left: int, right: int
    ) -> int:
        p = self.prefix
        return p[right + 1] - p[left]

rsq = RangeSumQuery([10, 20, 30, 40, 50])
print('Сумма [1..3]:', rsq.sum_range(1, 3))
# >>> Сумма [1..3]: 90
```

## Сравнение паттернов и ловушка отрицательных чисел

Выбор между окном и префиксными суммами зависит от ограничений на элементы массива:

| Паттерн | Типичное условие | Время | Память |
| :--- | :--- | :--- | :--- |
| **Два указателя** | Отсортированный массив, палиндром, `in-place` | **$O(n)$** | **$O(1)$** |
| **Скользящее окно** | Подмассив/подстрока (макс/мин длина или сумма) | **$O(n)$** | **$O(1)$** / **$O(k)$** |
| **Префиксные суммы** | Многократные запросы суммы на отрезке $[L, R]$ | **$O(1)$** на запрос | **$O(n)$** |

**Ловушка отрицательных чисел:** динамическое окно работает только при монотонности; если в массиве есть отрицательные числа, вместо окна используют префиксные суммы с хэш-таблицей.
