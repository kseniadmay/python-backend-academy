1. Когда движется левая граница в `min_subarray_len`? >> Когда условие выполнено (`window_sum >= target`) – сжимаем окно, пытаясь найти меньшую длину
2. Когда движется правая граница в `min_subarray_len`? >> Всегда – правая граница расширяет окно; когда сумма ≥ target, обновляем ответ и сжимаем слева
3. Какое ключевое ограничение накладывает метод скользящего окна (sliding window) на элементы массива? >> Только непрерывные подпоследовательности
4. Принцип `reverse_array` через два указателя? >> Указатели с обоих концов меняют элементы местами и движутся к центру
5. Как обновляется сумма окна при сдвиге? >> `window_sum = window_sum - arr[i - k] + arr[i]` – убрать ушедший, добавить новый
6. Какой тип скользящего окна (фиксированный или динамический) используется в алгоритме поиска longest unique substring? >> Переменного размера
7. Три применения двух указателей? >> Поиск пар в отсортированных массивах, проверка палиндрома, слияние двух массивов
8. Принцип `is_palindrome` через два указателя? >> Указатели с обоих концов движутся навстречу; сравнивают символы до пересечения
9. Память базовых реализаций двух указателей? >> $O(1)$
10. Что хранит `char_index` в `longest_unique_substring`? >> Последний встреченный индекс каждого символа
11. Для каких массивов применяется метод двух указателей? >> Отсортированных или при поиске пар с заданным условием
12. Что если массив не отсортирован? >> Сначала отсортировать $O(n log n)$; итоговая сложность $O(n log n)$
13. Что делает быстрый указатель в `remove_duplicates`? >> Сканирует массив в поисках уникальных элементов
14. Какова алгоритмическая сложность поиска подмассива с максимальной суммой методом скользящего окна (sliding window)? >> $O(n)$
15. Что такое скользящее окно (Sliding Window)? >> Подмассив фиксированного или переменного размера, перемещающийся по данным за один проход
16. Для чего sliding window в потоковых данных? >> Поддержание актуальных метрик по последним $N$ событиям без пересчёта с нуля
17. Что такое техника двух указателей? >> Два индекса перемещаются по массиву в определённом направлении для решения задачи за один проход
18. Как обновлять левую границу `left` в алгоритме `longest_unique_substring`, если символ `s[right]` уже встречался в `char_index`? >> `left = max(left, char_index[s[right]] + 1)` – `max` защищает от сдвига `left` назад, если предыдущее вхождение символа было до начала текущего окна
19. Задачи для окна переменного размера? >> Длиннейшая/кратчайшая подпоследовательность с условием (уникальные символы, сумма ≥ target)
20. Что решают техники Two Pointers и Sliding Window по сложности? >> Снижают $O(n²)$ до $O(n)$ за счёт избегания вложенных циклов
21. Задачи для окна фиксированного размера? >> Максимальная/минимальная сумма, среднее внутри окна заданной длины
22. Какова временная сложность поиска пары элементов с заданной суммой в отсортированном массиве методом двух указателей? >> $O(n)$ при уже отсортированном массиве
23. Что делает медленный указатель в `remove_duplicates`? >> Указывает позицию для записи следующего уникального элемента
24. Что такое массив префиксных сумм и за какую сложность он вычисляет сумму на отрезке [L, R]? >> За $O(1)$ после предрасчёта за $O(n)$: `prefix[i] = prefix[i-1] + arr[i-1]`, а сумма вычисляется по формуле `prefix[R + 1] - prefix[L]`.
25. Почему скользящее окно нельзя применять для поиска подмассива с заданной суммой, если в массиве есть отрицательные числа? >> Ломается монотонность окна: при сдвиге правой или левой границы сумма может непредсказуемо как расти, так и убывать.
26. Какую комбинацию техник используют для поиска подмассива с суммой K при наличии отрицательных чисел? >> Префиксные суммы в сочетании с хэш-таблицей (prefix sums + hashmap): проверяем `current_prefix - k in seen_prefixes` за $O(n)$ времени и памяти.
