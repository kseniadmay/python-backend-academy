1. Может ли алгоритм иметь $O(n)$ по времени и $O(1)$ по памяти одновременно? >> Да; например, поиск максимума в массиве: один проход, одна фиксированная переменная
2. Что такое Timsort? >> Адаптивный стабильный гибридный алгоритм сортировки (Merge Sort + Insertion Sort) со сложностью $O(n \log n)$ по времени и $O(n)$ по памяти
3. Сложность вложенного двойного цикла по $n$ элементам? >> $O(n^2)$
4. Сложность проверки чётности `n % 2 == 0`? >> $O(1)$
5. Три сценария анализа сложности алгоритма? >> Худший (Worst-Case), средний (Average-Case) и лучший (Best-Case). Big O фиксирует верхнюю границу худшего сценария
6. Как проверить наличие дубликатов за $O(n)$? >> `len(arr) != len(set(arr))`; создание `set` занимает $O(n)$, а сравнение длин — $O(1)$
7. Сложность функций `sort()` и `sorted()` в Python? >> $O(n \log n)$ по времени (алгоритм Timsort); `arr.sort()` работает in-place за $O(1)$ доп. памяти, `sorted()` выделяет $O(n)$ памяти под новый список
8. Пример алгоритма со сложностью $O(n^2)$? >> Сортировка пузырьком (Bubble Sort), наивная проверка дубликатов двойным вложенным циклом
9. Что такое временная сложность? >> Оценка скорости роста числа элементарных шагов процессора относительно размера входных данных
10. Почему `s[::-1]` требует $O(n)$ по памяти? >> Строки в Python неизменяемы (immutable), поэтому срез создаёт новый строковый объект длины $n$
11. Пространственная сложность `[x * 2 for x in arr]`? >> $O(n)$; генератор списка аллоцирует новый список длины $n$
12. Когда линейный поиск работает за $O(1)$? >> В лучшем сценарии (Best-Case), если искомый элемент находится на первой позиции
13. Сложность линейного поиска в худшем случае? >> $O(n)$, если элемент находится в самом конце списка или отсутствует
14. Пространственная сложность нескольких фиксированных переменных? >> $O(1)$; расход памяти постоянен и не зависит от размера входных данных
15. Пространственная сложность нового массива размером $n$? >> $O(n)$
16. Пространственная сложность рекурсивного факториала? >> $O(n)$; глубина стека вызовов (Call Stack) вырастает до $n$ фреймов
17. Пример операции со сложностью $O(1)$? >> Получение элемента по индексу `arr[0]`, вычисление `len(arr)`, доступ к значению по ключу в словаре `d[key]`
18. Сложность `arr[i]` в списке Python? >> $O(1)$; прямой доступ по вычисленному адресу смещения в непрерывном массиве указателей
19. Сложность `sum(arr)`? >> $O(n)$; выполняет последовательное сложение каждого элемента массива
20. Что такое пространственная сложность? >> Оценка объёма дополнительной оперативной памяти (Auxiliary Space), выделяемой алгоритмом при росте $n$
21. Что такое скрытая квадратичность? >> Вызов функции со сложностью $O(n)$ внутри цикла на $n$ итераций (например, `arr.count(x)` или `x in list` внутри `for`); даёт итоговую сложность $O(n^2)$
22. Сколько шагов делает бинарный поиск при $n = 1\,000\,000$? >> Не более 20 шагов ($\log_2 10^6 \approx 19.93$)
23. Сколько шагов делает бинарный поиск при $n = 1\,000$? >> Не более 10 шагов ($\log_2 10^3 \approx 9.96$)
24. Почему `arr.count(x)` внутри цикла даёт $O(n^2)$? >> Метод `count(x)` выполняет полный проход по массиву ($O(n)$) на каждой из $n$ итераций внешнего цикла
25. Типичный алгоритм со сложностью $O(\log n)$? >> Бинарный поиск: на каждом шаге область поиска делится пополам
26. Как рекурсия влияет на пространственную сложность? >> Каждый рекурсивный вызов сохраняет фрейм в стеке вызовов (Call Stack), требуя памяти пропорционально максимальной глубине рекурсии
27. Пространственная сложность итеративного вычисления факториала? >> $O(1)$; используется одна переменная-аккумулятор без роста стека
