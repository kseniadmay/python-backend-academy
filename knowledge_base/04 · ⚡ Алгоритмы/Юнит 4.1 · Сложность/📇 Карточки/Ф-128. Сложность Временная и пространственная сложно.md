1. Может ли алгоритм иметь $O(n)$ по времени и $O(1)$ по памяти одновременно? >> Да; например, поиск максимума в массиве: один проход, одна переменная
2. Что такое Timsort? >> Гибридный алгоритм (merge sort + insertion sort); применяется в Python и Java; стабильный; $O(n \log n)$ в среднем и худшем случае
3. Сложность вложенного двойного цикла по $n$ элементам? >> $O(n²)$
4. Сложность `n % 2 == 0` ? >> $O(1)$
5. Три случая при анализе сложности алгоритма? >> Лучший (best case), средний (average case), худший (worst case); Big O обычно описывает худший
6. Как проверить дубликаты за $O(n)$ ? >> `len(arr) != len(set(arr))` ; создание `set` – $O(n)$ , сравнение длин – $O(1)$
7. Сложность `sort()` и `sorted()` в Python? >> $O(n \log n)$ ; используется алгоритм Timsort
8. Пример алгоритма $O(n²)$ ? >> Сортировка пузырьком, сортировка вставками; вложенные циклы по одному массиву
9. Что такое временная сложность? >> Как растёт количество операций с ростом входных данных
10. Почему `s[: : -1]` имеет $O(n)$ по памяти? >> Создаётся новая строка той же длины; оригинал не изменяется
11. Пространственная сложность `[x * 2 for x in arr]` ? >> $O(n)$ ; создаётся новый список той же длины
12. Когда линейный поиск $O(1)$ ? >> Лучший случай: элемент первым в списке
13. Сложность линейного поиска в худшем случае? >> $O(n)$ ; элемент в конце или отсутствует
14. Пространственная сложность нескольких фиксированных переменных? >> $O(1)$ ; память не растёт с размером входных данных
15. Пространственная сложность нового массива размером $n$ ? >> $O(n)$
16. Пространственная сложность рекурсивного факториала? >> $O(n)$ ; стек вырастает до $n$ фреймов
17. Пример операции $O(1)$ ? >> Получение элемента по индексу `arr[0]` ; проверка `n % 2 == 0` ; словарный поиск по ключу
18. Сложность `arr[i]` (обращение по индексу в списке Python)? >> $O(1)$
19. Сложность `sum(arr)` ? >> $O(n)$ ; проходит по каждому элементу
20. Что такое пространственная сложность? >> Как растёт потребление памяти с ростом входных данных
21. Что такое скрытая квадратичность? >> $O(n)$ -функция внутри цикла $O(n)$ даёт итоговую $O(n²)$ ; пример: `arr.count(x)` внутри цикла
22. Шагов бинарного поиска при $n = 1,000,000$ ? >> ~20
23. Шагов бинарного поиска при $n = 1000$ ? >> ~10
24. Почему `arr.count(x)` внутри цикла – $O(n²)$ ? >> `count()` сам $O(n)$ и вызывается $n$ раз; итого $O(n²)$
25. Алгоритм с $O(\log n)$ ? >> Бинарный поиск: на каждом шаге пространство поиска делится пополам
26. Как рекурсия влияет на пространственную сложность? >> Каждый вызов добавляет фрейм в стек вызовов; для $n$ уровней – $O(n)$ памяти
27. Пространственная сложность итеративного факториала? >> $O(1)$ ; только одна переменная для результата
