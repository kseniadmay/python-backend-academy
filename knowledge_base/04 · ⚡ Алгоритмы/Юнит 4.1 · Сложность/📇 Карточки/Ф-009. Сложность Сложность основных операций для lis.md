1. Какова амортизированная временная сложность удаления последнего элемента `arr.pop()` из конца списка в Python? >> $O(1)$
2. Какова алгоритмическая временная сложность встроенной функции сортировки `sorted()` в языке Python? >> $O(n \log n)$ по времени (алгоритм Timsort — адаптивный гибрид Merge Sort и Insertion Sort); $O(n)$ памяти. `sorted([3, 1, 2])` создаёт и возвращает **новый** отсортированный список `[1, 2, 3]`, не меняя исходный (в отличие от `arr.sort()`, который сортирует список на месте за $O(1)$ по доп. памяти).
3. Какова временная сложность операции вычисления разности двух множеств `s1 - s2` в Python? >> $O(\text{len}(s1))$ по длине первого множества. Для разности алгоритм обходит все элементы `s1` и за $O(1)$ проверяет отсутствие в `s2`. $O(\min(n, m))$ применяется для пересечения `s1 & s2`.
4. Каким типом структуры является `dict` в Python? >> Хэш-таблица; ключи хэшируются для определения индекса в памяти
5. Какова временная сложность создания поверхностной копии списка методом `arr.copy()` в Python? >> $O(n)$; поверхностная копия, копирует ссылки на все $n$ элементов
6. Какова временная сложность получения длины списка `len(arr)` в языке Python? >> $O(1)$; длина хранится как атрибут `ob_size` объекта
7. К какому типу относится `list` в Python? >> Динамический массив указателей (`PyObject*`) с геометрическим овер-аллокатором памяти
8. В чём разница во временной сложности операции проверки вхождения `x in list` и `x in set` в Python? >> `list` — $O(n)$ линейный перебор; `set` — $O(1)$ хэш-поиск в среднем
9. Какова временная сложность создания нового списка всех ключей словаря `list(d.keys())` в Python? >> $O(n)$; создание нового списка со ссылками на все ключи
10. Какова амортизированная временная сложность добавления элемента в конец списка методом `arr.append()` в Python? >> $O(1)$ амортизированная; геометрическое перевыделение буфера компенсирует редкие расширения
11. Какова временная сложность удаления элемента по его значению методом `arr.remove(x)` из списка в Python? >> $O(n)$; линейный поиск элемента плюс сдвиг последующих элементов влево
12. В чём разница в поведении методов множества `s.remove(x)` и `s.discard(x)` при отсутствии удаляемого элемента? >> `remove` выбрасывает `KeyError`, если элемента нет; `discard` молча игнорирует отсутствие
13. Какова временная сложность операции вычисления пересечения двух множеств `s1 & s2` в Python? >> $O(\min(n, m))$ — алгоритм итерируется по меньшему из двух множеств с проверкой наличия во втором за $O(1)$
14. Какова временная сложность операции объединения двух множеств `s1 | s2` в Python? >> $O(n + m)$ — копирует все уникальные элементы обоих множеств в новую хэш-таблицу
15. Для чего лучше использовать `set`, а не `list`? >> Хранение уникальных элементов, быстрый поиск (`x in s` за $O(1)$), операции над множествами
16. Почему `arr.insert(0, x)` — $O(n)$? >> Требует физического сдвига всех последующих элементов массива вправо на одну позицию
17. Какова средняя временная сложность проверки наличия элемента `x in s` во множестве `set` в Python? >> $O(1)$ в среднем; хэш-поиск
18. Какова средняя временная сложность удаления элемента по ключу `del d['key']` из словаря в Python? >> $O(1)$ в среднем; удаление записи из хэш-таблицы
19. Является ли `dict` в Python 3.7+ упорядоченным? >> Да; гарантирует порядок вставки (Insertion Order), но индексация по целочисленному смещению не поддерживается
20. Что делает хэш-функция? >> Вычисляет целочисленный хэш-код ключа для определения индекса ячейки (bucket) в памяти
21. Что такое `set` в Python? >> Хэш-таблица без значений (только уникальные ключи); реализация аналогична `dict`
22. Какова средняя амортизированная сложность добавления или обновления ключа в словаре `dict` в Python? >> $O(1)$ амортизированная
23. Какова временная сложность прямого доступа к элементу списка по индексу `arr[i]` в Python? >> $O(1)$; непрерывный массив ссылок позволяет мгновенно вычислить адрес по формуле `base + i * 8`
24. Почему `key in dict` быстрее `key in list`? >> `dict` использует хэш-функцию ($O(1)$ в среднем), а `list` — последовательный перебор ($O(n)$)
25. Какие базовые коллекции Python не поддерживают доступ по индексу? >> `dict` и `set`; они не поддерживают адресацию по индексу
26. Какова временная сложность проверки наличия элемента `x in arr` в стандартном списке `list` в Python? >> $O(n)$; последовательный перебор элементов
27. Какова временная сложность операции удаления первого элемента `arr.pop(0)` из списка в Python? >> $O(n)$; удаление первого элемента требует сдвига всех оставшихся элементов влево
28. Какова временная сложность получения количества элементов в словаре `len(d)` в Python? >> $O(1)$; длина хранится в заголовке словаря
29. Какова временная сложность методов поиска индекса `arr.index(x)` и подсчёта `arr.count(x)` в списке Python? >> $O(n)$; линейный проход по массиву
30. Какова средняя сложность поиска и получения значения по ключу `d['key']` и `d.get('key')` в словаре Python? >> $O(1)$ амортизированная
31. Какова временная сложность разворота списка на месте с помощью метода `arr.reverse()` в Python? >> $O(n)$ по времени, $O(1)$ по памяти (in-place разворот)
32. Какова амортизированная временная сложность добавления нового элемента `s.add(x)` во множество `set` в Python? >> $O(1)$ амортизированная
33. Когда операции со словарём деградируют до $O(n)$? >> При большом количестве коллизий хэшей
34. В чём алгоритмическое преимущество поиска дубликатов через множество `set` по сравнению с вложенными циклами в Python? >> `set`: $O(n)$ время, $O(n)$ память; вложенные циклы: $O(n^2)$ время, $O(1)$ память
