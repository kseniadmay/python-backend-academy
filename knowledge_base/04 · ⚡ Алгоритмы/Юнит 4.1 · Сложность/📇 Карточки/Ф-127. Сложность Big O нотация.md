1. Упростите $O(500)$? >> $O(1)$
2. Упростите $O(n + \log n)$? >> $O(n)$; младшее слагаемое $\log n$ отбрасывается
3. Как упрощается $O(n^2 + n)$? >> $O(n^2)$; выбирается доминирующее слагаемое с наивысшей скоростью роста
4. Полный порядок возрастания сложностей? >> $O(1) < O(\log n) < O(n) < O(n \log n) < O(n^2) < O(2^n) < O(n!)$
5. Упростите $O(3n^2)$? >> $O(n^2)$; константный множитель отбрасывается
6. Что описывает нотация Big O? >> Верхнюю границу асимптотического роста числа операций или памяти при стремлении размера данных к бесконечности
7. Сколько операций для $O(n)$ при $n = 1\,000$? >> $1\,000$
8. Почему Big O не измеряет время в секундах? >> Физическое время зависит от оборудования и нагрузки; Big O оценивает масштабируемость алгоритма независимо от платформы
9. Как называется $O(n^2)$? >> Квадратичная сложность (Quadratic Time); типична для двойных вложенных циклов
10. Как называется $O(2^n)$? >> Экспоненциальная сложность (Exponential Time); характерна для перебора всех подмножеств
11. Сколько операций для $O(n^2)$ при $n = 1\,000$? >> $1\,000\,000$
12. Упростите $O(2n)$? >> $O(n)$
13. Какой сценарий обычно описывает Big O? >> Худший случай (Worst-Case Scenario)
14. Почему константы в Big O отбрасываются? >> При $n \to \infty$ динамику роста определяет только доминирующий порядок, а не фиксированный коэффициент
15. Как называется $O(n)$? >> Линейная сложность (Linear Time); растёт пропорционально объёму данных
16. Как называется $O(\log n)$? >> Логарифмическая сложность (Logarithmic Time); типична для бинарного поиска
17. Что произойдёт с временем алгоритма $O(n^2)$, если объём данных вырастет в 10 раз? >> Время выполнения вырастет в 100 раз ($10^2$)
18. $O(n)$ или $O(n \log n)$ — что медленнее? >> $O(n \log n)$
19. Сложность алгоритма с вложенным циклом (например, пузырьковая сортировка)? >> $O(n^2)$
20. Как называется $O(1)$? >> Константная сложность (Constant Time); время выполнения не зависит от размера данных
21. $O(2^n)$ или $O(n!)$ — что растёт быстрее? >> $O(n!)$
22. Сколько операций для $O(\log_2 n)$ при $n = 1\,000$? >> $\approx 10$
23. Сложность алгоритма, проходящего по массиву один раз? >> $O(n)$
24. Как называется $O(n \log n)$? >> Линейно-логарифмическая сложность; типична для алгоритмов сортировки (Merge Sort, Timsort)
25. Сложность бинарного поиска? >> $O(\log n)$; на каждом шаге область поиска делится пополам
26. $O(2^n)$ или $O(n^2)$ — что быстрее? >> $O(n^2)$ быстрее экспоненциальной сложности
27. Как называется $O(n!)$? >> Факториальная сложность (Factorial Time); характерна для перебора всех перестановок
