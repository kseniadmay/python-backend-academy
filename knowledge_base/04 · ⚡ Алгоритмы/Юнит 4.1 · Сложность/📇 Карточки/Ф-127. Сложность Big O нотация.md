1. К какому базовому классу асимптотической сложности по правилу Big-O сводится константное время $O(500)$? >> $O(1)$
2. Упростите $O(n + log n)$? >> $O(n)$; младшее слагаемое $log n$ отбрасывается
3. Как упрощается $O(n² + n)$? >> $O(n²)$; выбирается доминирующее слагаемое с наивысшей скоростью роста
4. Полный порядок возрастания сложностей? >> $O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2^n) < O(n!)$
5. К какому классу асимптотической сложности сводится выражение $O(3n²)$ после отбрасывания константного множителя? >> $O(n²)$; константный множитель отбрасывается
6. Что описывает нотация Big O? >> Верхнюю границу асимптотического роста числа операций или памяти при стремлении размера данных к бесконечности
7. Сколько операций для $O(n)$ при $n = 1 000$? >> $1 000$
8. Почему Big O не измеряет время в секундах? >> Физическое время зависит от оборудования и нагрузки; Big O оценивает масштабируемость алгоритма независимо от платформы
9. Как называется класс асимптотической сложности $O(n²)$ в теории алгоритмов? >> Квадратичная сложность (Quadratic Time); типична для двойных вложенных циклов
10. Как называется $O(2^n)$? >> Экспоненциальная сложность (Exponential Time); характерна для перебора всех подмножеств
11. Сколько операций для $O(n²)$ при $n = 1 000$? >> $1 000 000$
12. К какому классу асимптотической сложности сводится выражение $O(2n)$ после отбрасывания константы? >> $O(n)$
13. Какой сценарий обычно описывает Big O? >> Худший случай (Worst-Case Scenario)
14. Почему константы в Big O отбрасываются? >> При $n → ∞$ динамику роста определяет только доминирующий порядок, а не фиксированный коэффициент
15. Как называется класс асимптотической сложности $O(n)$ в анализе алгоритмов? >> Линейная сложность (Linear Time); растёт пропорционально объёму данных
16. Как называется $O(log n)$? >> Логарифмическая сложность (Logarithmic Time); типична для бинарного поиска
17. Что произойдёт с временем алгоритма $O(n²)$, если объём данных вырастет в 10 раз? >> Время выполнения вырастет в 100 раз ($10²$)
18. $O(n)$ или $O(n log n)$ — что медленнее? >> $O(n log n)$
19. Какова теоретическая временная сложность алгоритма, использующего два вложенных цикла по массиву размера n? >> $O(n²)$
20. Как называется класс асимптотической сложности $O(1)$ в теории алгоритмов? >> Константная сложность (Constant Time); время выполнения не зависит от размера данных
21. $O(2^n)$ или $O(n!)$ — что растёт быстрее? >> $O(n!)$
22. Сколько операций для $O(log₂ n)$ при $n = 1 000$? >> $≈ 10$
23. Какова временная сложность алгоритма, выполняющего ровно один последовательный проход по массиву длины n? >> $O(n)$
24. Как называется $O(n log n)$? >> Линейно-логарифмическая сложность; типична для алгоритмов сортировки (Merge Sort, Timsort)
25. К какому классу Big O относится бинарный поиск в отсортированном массиве и почему область поиска уменьшается вдвое? >> $O(log n)$; на каждом шаге область поиска делится пополам
26. $O(2^n)$ или $O(n²)$ — что быстрее? >> $O(n²)$ быстрее экспоненциальной сложности
27. Как называется класс асимптотической сложности $O(n!)$ в теории алгоритмов? >> Факториальная сложность (Factorial Time); характерна для перебора всех перестановок
