1. Алгоритм, использующий стек? >> DFS (обход в глубину)
2. Что представляет собой абстрактная структура данных Дек (deque, Double-Ended Queue)? >> Двусторонняя очередь, поддерживающая добавление и удаление элементов с обоих концов за константное время $O(1)$ (реализована в Python как collections.deque на базе двусвязного списка блоков).
3. Принцип организации стека? >> LIFO – Last In, First Out
4. Алгоритм, использующий очередь? >> BFS (обход в ширину)
5. Потокобезопасная реализация очереди в Python? >> `queue.Queue`
6. В каких типовых алгоритмах и структурах данных наиболее эффективно применяется двусторонняя очередь (дек)? >> Проверка палиндрома, LRU-кэш, скользящее окно
7. Как импортировать `deque` ? >> `from collections import deque`
8. Почему стек и очередь называют абстрактными типами данных? >> Это не структуры в памяти, а наборы операций (интерфейсы); конкретная реализация может быть любой
9. `is_valid_brackets('()[]{}')` ? >> `True`, так как все скобки открываются и закрываются в корректном парном порядке
10. Операция добавления в конец очереди? >> `enqueue`
11. Как ограничить размер `deque` ? >> Параметром `maxlen` ; при переполнении элементы с противоположного конца автоматически удаляются
12. Как реализовать `peek` в Python? >> `stack[-1]` ; вызовет `IndexError` если стек пуст – нужна проверка
13. Сложность `push` и `pop` ? >> $O(1)$
14. Принцип организации очереди? >> FIFO – First In, First Out
15. Операция удаления из начала очереди? >> `dequeue`
16. С чем сравнивают стек? >> Стопка тарелок
17. Какой метод используется для добавления элемента в самое начало двусторонней очереди `collections.deque` в Python? >> `appendleft()`
18. Операция просмотра верхнего элемента без удаления? >> `peek`
19. Какова временная сложность операций добавления и удаления элементов с обоих концов двусторонней очереди (дека)? >> $O(1)$
20. Что означает LIFO? >> Последний добавленный извлекается первым
21. Что вернёт `[1, 2, 3].pop()` ? >> `3`
22. Какое состояние стека гарантирует корректность скобочного выражения? >> Пустой стек после обработки всей строки
23. Что делает `rotate(1)` у `deque` ? >> Циклический сдвиг вправо: последний элемент становится первым
24. Сложность `deque.popleft()` ? >> $O(1)$
25. С чем сравнивается закрывающая скобка? >> С верхним элементом стека ( `peek` )
26. Почему `deque` лучше `list` для очереди? >> `popleft()` работает за $O(1)$ против $O(n)$ у `list.pop(0)`
27. В чём главный алгоритмический недостаток использования метода `list.pop(0)` для реализации очереди в Python? >> $O(n)$ – все элементы сдвигаются
28. `is_valid_brackets('([)]')` ? >> `False`, так как нарушена парная вложенность: круглая скобка пытается закрыться после квадратной `([)]`
29. Что делает `queue.Queue.get()` при пустой очереди? >> Блокирует поток до появления элемента
30. Что делает алгоритм проверки скобок при открывающем символе? >> `push` в стек
31. Что происходит при `append` в `deque(maxlen=3)` , уже заполненный? >> Самый старый элемент с противоположного конца удаляется автоматически
32. Операция добавления на вершину стека? >> `push`
33. Операция извлечения верхнего элемента? >> `pop`
34. Какой стандартный метод списка в Python используется для операции `push` (помещения элемента на вершину стека)? >> `append()`
35. Какая популярная функция текстовых и графических редакторов реализуется с помощью структуры данных «стек»? >> Undo ( `Ctrl+Z` )
36. Что вернёт `deque([1, 2, 3]).popleft()` ? >> `1` (первый элемент удаляется из начала двусторонней очереди deque за O(1))
37. Где Python использует стек для вывода ошибок? >> Traceback – стек вызовов функций
