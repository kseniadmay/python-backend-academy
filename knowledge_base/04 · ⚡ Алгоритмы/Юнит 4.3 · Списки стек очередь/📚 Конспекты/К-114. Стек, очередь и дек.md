## Стек (LIFO), Очередь (FIFO) и Дек

> **Стопка тарелок против очереди у кассы**: в стеке последнюю положенную тарелку снимают первой, в очереди первым обслуживают того, кто пришёл раньше, а дек открыт с обоих концов.

Три базовые линейные абстракции различаются порядком доступа к элементам:

- **Стек (Stack — LIFO)**: Last In, First Out — добавление (`push`) и снятие (`pop`) идут с одной вершины.
- **Очередь (Queue — FIFO)**: First In, First Out — элементы входят в хвост и выходят из головы.
- **Дек (Deque — `collections.deque`)**: двусторонняя очередь с операциями за $O(1)$ на обоих концах.

## Стек на базе `list` и валидация скобок

В Python для стека идеально подходит обычный `list` с операциями в правом конце: `append(x)`, `pop()` и просмотр вершины `stack[-1]` работают за $O(1)$.

Помимо системного стека вызовов и вычисления выражений (RPN), стек используют для проверки корректности вложенных скобок:

```python
def is_valid_brackets(s: str) -> bool:
    pairs = {')': '(', ']': '[', '}': '{'}
    stack: list[str] = []
    for ch in s:
        if ch in pairs:
            if not stack:
                return False
            if stack.pop() != pairs[ch]:
                return False
        else:
            stack.append(ch)
    return len(stack) == 0

print('{[()]}:', is_valid_brackets('{[()]}'))
# >>> {[()]}: True

print('([)]:', is_valid_brackets('([)]'))
# >>> ([)]: False
```

## Монотонный стек: ближайший больший элемент

Если для каждого дня нужно узнать, через сколько дней станет теплее, наивный вложенный перебор работает за $O(n^2)$.

**Монотонный стек** хранит индексы дней с убывающей температурой: как только приходит более тёплый день, все предыдущие холодные дни извлекаются за один проход $O(n)$:

```python
def days_until_warmer(
    temps: list[int],
) -> list[int]:
    result = [0] * len(temps)
    stack: list[int] = []
    for day, t in enumerate(temps):
        while stack and temps[stack[-1]] < t:
            prev = stack.pop()
            result[prev] = day - prev
        stack.append(day)
    return result

temps = [73, 74, 75, 71, 69, 76]
ans = days_until_warmer(temps)
print('Дней до тепла:', ans)
# >>> Дней до тепла: [1, 1, 3, 2, 1, 0]
```

## Очередь FIFO и устройство `collections.deque`

Для очереди нельзя применять `list.pop(0)`: удаление слева физически сдвигает весь массив за $O(n)$.

В CPython **`collections.deque`** реализован как двусвязный список блоков памяти, поэтому чтение и запись с обоих краёв стоят строго $O(1)$:

```text
Устройство collections.deque:
None <- [..x] <=> [xxxx] <=> [x..] -> None
         ▲                    ▲
  popleft O(1)             pop O(1)
```

Сравнение `list` и `collections.deque` по операциям:

| Операция | `list` | `collections.deque` | Назначение |
| :--- | :--- | :--- | :--- |
| `append()` / `pop()` | $O(1)$ | $O(1)$ | Стек (LIFO) |
| `appendleft()` / `popleft()` | $O(n)$ | $O(1)$ | Очередь (FIFO) |
| Доступ по индексу `d[i]` | $O(1)$ | $O(n)$ | Чтение середины |
| Буфер `deque(maxlen=K)` | — | $O(1)$ | Кольцевой буфер |

## Очередь задач и кольцевой буфер `deque`

Параметр `maxlen` превращает `deque` в кольцевой буфер с автоматическим вытеснением самых старых записей при добавлении новых:

```python
from collections import deque

tasks: deque[str] = deque(['t1', 't2'])
tasks.append('t3')
done = tasks.popleft()

recent: deque[str] = deque(maxlen=3)
for i in range(1, 6):
    recent.append(f'ev_{i}')

print('Выполнена:', done)
# >>> Выполнена: t1

print('Остались:', list(tasks))
# >>> Остались: ['t2', 't3']

print('Последние 3:', list(recent))
# >>> Последние 3: ['ev_3', 'ev_4', 'ev_5']
```

> **Junior vs Senior**:
> - **Junior**: Использует `queue.pop(0)` на обычном списке в BFS или ограничителе частоты запросов, получая $O(V^2)$ вместо линейного времени.
> - **Senior**: Берёт `collections.deque` с `append()` / `popleft()` за $O(1)$ и применяет `deque(maxlen=N)` для истории последних событий.
