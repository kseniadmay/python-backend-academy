## Связный список в памяти против массива

> **Цепочка записок-подсказок**: в массиве `list` ячейки стоят подряд и доступны по индексу $O(1)$. В связном списке узлы разбросаны по памяти: у нас есть только ссылка `head`, а каждый узел хранит `next`.

- Чтобы дойти до 50-го узла, нужно пройти 49 предыдущих за $O(n)$.
- Зато вставить или удалить узел между двумя известными можно за $O(1)$ — достаточно переписать одну ссылку `next`.

## Односвязный и двусвязный списки

В зависимости от числа ссылок в узле выделяют два вида связных списков:

- **Односвязный список**: узел `ListNode` хранит значение `val` и ссылку `next` на следующий элемент (хвост указывает на `None`).
- **Двусвязный список**: хранит ещё и обратную ссылку `prev`, что позволяет удалять известный узел за $O(1)$ без поиска предыдущего (используется в `collections.deque` и **LRU Cache**).

```text
Односвязный список:
head -> [10 | *] -> [20 | *] -> [30 | None]

Двусвязный список:
None <- [10] <=> [20] <=> [30] -> None
```

Сравним стоимость операций с массивом `list`:

| Операция | `list` (массив) | Односвязный (`head`) | Двусвязный (`head+tail`) |
| :--- | :--- | :--- | :--- |
| Доступ по индексу `i` | **$O(1)$** | $O(n)$ | $O(n)$ |
| Вставка/удаление в `head` | $O(n)$ | **$O(1)$** | **$O(1)$** |
| Удаление с конца `tail` | **$O(1)$** | $O(n)$ | **$O(1)$** |
| Удаление узла `node` | $O(n)$ | $O(n)$ | **$O(1)$** |
| Локальность кэша CPU | **Высокая** | **Низкая** | **Низкая** |

## Паттерн `Dummy Node` (узел-страж)

При удалении узлов из списка сама голова `head` может оказаться удалённой.

Чтобы не писать отдельные ветки для `head is None` и первого элемента, перед головой ставят фиктивный узел `dummy = ListNode(0, head)`, а возвращают `dummy.next`:

```python
class ListNode:
    def __init__(self, val: int, nxt=None):
        self.val = val
        self.next = nxt

def remove_val(head, target: int):
    # Узел-страж упрощает удаление head
    dummy = ListNode(0, head)
    curr = dummy
    while curr.next is not None:
        if curr.next.val == target:
            curr.next = curr.next.next
        else:
            curr = curr.next
    return dummy.next

node = ListNode(1, ListNode(2, ListNode(3)))
res = remove_val(node, 1)
print('Новая голова:', res.val)
# >>> Новая голова: 2
```

## Разворот списка на месте (`In-place Reversal`)

Разворот за $O(n)$ времени и $O(1)$ памяти использует три ссылки (`prev`, `curr`, `nxt`), перенаправляя указатель `curr.next` назад на каждом шаге:

```text
До:    prev      curr ---> nxt ---> ...
После: prev <--- curr      nxt ---> ...
```

Критично сохранять `nxt = curr.next` первой строкой цикла до перезаписи `curr.next`:

```python
class ListNode:
    def __init__(self, val: int, nxt=None):
        self.val = val
        self.next = nxt

def reverse_list(head):
    prev, curr = None, head
    while curr is not None:
        nxt = curr.next
        curr.next = prev
        prev = curr
        curr = nxt
    return prev

n = ListNode(1, ListNode(2, ListNode(3)))
rev = reverse_list(n)
vals = []
while rev is not None:
    vals.append(rev.val)
    rev = rev.next

print('После разворота:', vals)
# >>> После разворота: [3, 2, 1]
```

## Черепаха и Заяц: поиск середины списка

Указатель `slow` делает 1 шаг за итерацию, а `fast` — 2 шага.

Когда `fast` доходит до конца списка (`None`), медленный указатель `slow` оказывается ровно на середине за один проход:

```python
class ListNode:
    def __init__(self, val: int, nxt=None):
        self.val = val
        self.next = nxt

def find_middle(head: ListNode) -> int:
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow.val

chain = ListNode(
    10,
    ListNode(20, ListNode(30, ListNode(40))),
)
print('Середина списка:', find_middle(chain))
# >>> Середина списка: 30
```

## Алгоритм Флойда: поиск цикла за O(1) памяти

Если в связном списке есть петля, быстрый указатель `fast` (2 шага) гарантированно догонит медленный `slow` (1 шаг) внутри цикла (`slow is fast`).

Это позволяет доказать наличие цикла за $O(n)$ времени и $O(1)$ памяти без выделения множества `visited`:

```python
class ListNode:
    def __init__(self, val: int, nxt=None):
        self.val = val
        self.next = nxt

def has_cycle(head) -> bool:
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False

c1 = ListNode(1)
c2 = ListNode(2)
c3 = ListNode(3)
c1.next, c2.next, c3.next = c2, c3, c2
print('Цикл обнаружен:', has_cycle(c1))
# >>> Цикл обнаружен: True
```

> **Junior vs Senior**:
> - **Junior**: Пишет `curr.next = prev` *до* сохранения `nxt = curr.next` (теряя хвост списка) или ищет цикл через `visited = set()` с тратой $O(n)$ памяти.
> - **Senior**: Сначала сохраняет `nxt`, использует `dummy`-узел для edge cases на `head` и проверяет циклы указателями Флойда за $O(1)$ памяти.
