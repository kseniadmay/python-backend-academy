1. Для каких структур рекурсия наиболее естественна? >> Деревья и графы – их определение само по себе рекурсивно
2. Что такое хвостовая рекурсия? >> Рекурсивный вызов – последнее действие функции; результат вызова сразу возвращается без дополнительных вычислений
3. Что вернёт `factorial(3)` ? >> `6`
4. С помощью какой функции стандартного модуля `sys` в Python можно изменить лимит глубины рекурсии? >> `sys.setrecursionlimit(n)`
5. Что такое рекурсия? >> Функция, которая вызывает саму себя для решения меньшей версии той же задачи
6. Ошибка при превышении лимита рекурсии? >> `RecursionError: maximum recursion depth exceeded`
7. Формула факториала через рекурсию? >> $n! = n \cdot (n-1)!$
8. В каких стратегиях рекурсия является ключевым инструментом? >> Divide and conquer (разделяй и властвуй) и backtracking (перебор с возвратом)
9. Оптимизирует ли Python хвостовую рекурсию (TCO)? >> Нет; CPython не выполняет tail call optimization – каждый вызов всё равно создаёт фрейм
10. Какова временная сложность вычисления чисел Фибоначчи при использовании рекурсии с мемоизацией (кэшированием)? >> $O(n)$ по времени и $O(n)$ по памяти
11. Как устранить повторные вычисления в рекурсии? >> Мемоизация: кэшировать результат каждого вызова в `dict` или через `@functools.lru_cache`
12. Где хранятся данные каждого рекурсивного вызова? >> В стеке вызовов (call stack): локальные переменные, аргументы, адрес возврата
13. Проблема рекурсивного Фибоначчи? >> Многократное повторное вычисление одних и тех же значений
14. Почему глубокая рекурсия вызывает stack overflow? >> Каждый вызов занимает фрейм в стеке; при превышении лимита стек переполняется
15. Базовый случай `factorial(n)` ? >> `n <= 1` → `return 1`
16. Что вернёт `factorial(0)` ? >> `1` (по математическому определению факториал нуля равен 1: 0! = 1)
17. Формула Фибоначчи? >> `fib(n) = fib(n-1) + fib(n-2)`
18. Какова временная сложность наивного рекурсивного алгоритма поиска n-го числа Фибоначчи? >> $O(2^n)$ – экспоненциальный рост из-за повторных вычислений
19. Почему рекурсивный случай должен стремиться к базовому? >> Иначе – бесконечная рекурсия и `RecursionError`
20. Базовый случай `fib(n)` ? >> `n <= 1` → `return n`
21. Какую фундаментальную роль выполняет базовый случай (base case) в рекурсивных алгоритмах? >> Условие при котором функция останавливается и возвращает результат без рекурсии
22. Лимит рекурсии в Python по умолчанию? >> 1000
23. Альтернатива рекурсии при большой глубине? >> Итеративный подход с явным стеком или циклы
24. С помощью какой функции модуля `sys` в Python можно узнать текущий лимит глубины рекурсии? >> `sys.getrecursionlimit()`
25. Суть рекурсивного случая? >> Сведение задачи к меньшей версии той же задачи, приближаясь к базовому случаю
26. Две обязательные части рекурсии? >> Базовый случай (условие остановки) и рекурсивный случай (сведение к меньшей задаче)
27. Примеры сортировок на основе divide and conquer? >> Merge Sort и Quick Sort
