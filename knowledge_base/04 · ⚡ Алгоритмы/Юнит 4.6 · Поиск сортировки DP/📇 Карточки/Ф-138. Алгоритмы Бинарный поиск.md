1. Действие если `arr[mid] > target` ? >> `right = mid - 1`
2. Стандартная библиотека Python для бинарного поиска? >> `bisect`
3. Пространственная сложность рекурсивного бинарного поиска? >> $O(\log n)$ – глубина стека вызовов
4. Почему в `find_first` после совпадения `right = mid - 1` ? >> Проверить, нет ли такого же элемента раньше (левее)
5. Что возвращается при нахождении элемента? >> Индекс ( `mid` )
6. Базовый случай рекурсии – элемент не найден? >> `left > right`
7. Что такое паттерн «бинарный поиск по пространству ответов»? >> Бинарный поиск применяется не по массиву, а по диапазону возможных ответов; используется когда функция монотонна: например, найти минимальную скорость, при которой задача решается за T часов
8. Основная идея бинарного поиска? >> На каждом шаге область поиска делится пополам за счёт сравнения с `mid`
9. Действие если `arr[mid] < target` ? >> `left = mid + 1`
10. Что вернёт бинарный поиск при нескольких одинаковых элементах? >> Индекс любого из них – не гарантированно первого или последнего
11. Пространственная сложность итеративного бинарного поиска? >> $O(1)$
12. В `find_first` что происходит при `arr[mid] == target` ? >> Сохраняется в `result` и поиск продолжается левее: `right = mid - 1`
13. Почему `(left + right) // 2` опасно в Java/C++? >> `left + right` может превысить `Integer.MAX_VALUE` и дать отрицательный результат; в Python это не проблема из-за произвольной точности целых
14. Почему бинарный поиск эффективнее линейного? >> Отбрасывает половину оставшихся вариантов на каждой итерации
15. Применим ли бинарный поиск к связным спискам? >> Нет – нет $O(1)$ доступа к `mid` ; перебор до середины $O(n)$ сводит на нет преимущество
16. Условие цикла `while` в бинарном поиске? >> `left <= right`
17. Что делает `bisect_left` ? >> Возвращает индекс первой позиции для вставки элемента (левее равных); если элемент есть – индекс его первого вхождения
18. Что возвращается если элемент не найден? >> `-1`
19. Сложность бинарного поиска? >> $O(\log n)$
20. Позиция `bisect_left` для `5` в `[1, 3, 5, 5, 7]` ? >> 2
21. Что делает `bisect.insort` ? >> Вставляет элемент в отсортированный список сохраняя порядок; $O(n)$ из-за сдвига элементов
22. Позиция `bisect_right` для `5` в `[1, 3, 5, 5, 7]` ? >> 4
23. Что делает `bisect_right` ? >> Возвращает позицию правее всех равных элементов; если элемент есть – индекс после последнего вхождения
24. Обязательное условие для бинарного поиска? >> Массив отсортирован
25. Как вычисляется `mid` ? >> `left + (right - left) // 2` – безопасный вариант; `(left + right) // 2` корректен в Python, но вызывает переполнение в Java/C++ при больших индексах
