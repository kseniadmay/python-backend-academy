1. `dp[1]` в табуляции Фибоначчи? >> `1`
2. Что такое оптимальная подструктура? >> Оптимальное решение задачи строится из оптимальных решений её подзадач
3. Почему мемоизация – top-down? >> Начинаем с исходной большой задачи и рекурсивно спускаемся к базовым случаям
4. Требует ли ДП всегда рекурсии? >> Нет – табуляция итеративна
5. Почему табуляция – bottom-up? >> Начинаем с базовых случаев и итеративно строим решения всё более крупных подзадач
6. `dp[0]` в табуляции Фибоначчи? >> `0`
7. Декоратор Python для мемоизации? >> `@lru_cache(maxsize=None)` из `functools` ; с Python 3.9+ можно `@cache` – более лаконичный синоним
8. Механизм мемоизации? >> Рекурсия + кэширование результатов в словаре или через декоратор
9. К чему сводится задача о лестнице? >> К числам Фибоначчи: `ways(n) = ways(n-1) + ways(n-2)`
10. Сложность наивного рекурсивного Фибоначчи? >> $O(2^n)$ – экспоненциальный рост из-за повторных вычислений
11. Цель задачи о монетах (Coin Change)? >> Набрать заданную сумму минимальным количеством монет
12. Что проверяется в начале функции с мемоизацией? >> Наличие значения в кэше; если есть – вернуть без рекурсии
13. Задача «Подъём по лестнице»? >> Количество способов подняться на $n$ ступеней, делая шаг на 1 или 2
14. Что означает `maxsize=None` в `lru_cache` ? >> Кэш растёт неограниченно – все результаты сохраняются
15. `dp[0]` в задаче о монетах? >> `0` – сумму 0 можно набрать нулём монет
16. Память оптимизированного итеративного Фибоначчи? >> $O(1)$
17. Сложность Фибоначчи с мемоизацией? >> $O(n)$ по времени и $O(n)$ по памяти (кэш + стек)
18. Типичные формулировки задач для ДП? >> Минимальное количество, максимальная сумма, количество способов
19. Как оптимизировать память в итеративном Фибоначчи? >> Хранить только два последних значения вместо всей таблицы
20. Чем инициализируются `dp[]` в задаче о монетах? >> `float('inf')` – бесконечность как признак недостижимой суммы
21. В чём разница по памяти между мемоизацией и табуляцией? >> Мемоизация: $O(n)$ для кэша + $O(n)$ для стека вызовов; табуляция: $O(n)$ только для таблицы, без стека
22. Два подхода к ДП? >> Мемоизация (top-down) и табуляция (bottom-up)
23. Начальные значения в `fib_optimal` ? >> `prev=0, curr=1`
24. Что такое перекрывающиеся подзадачи? >> Одни и те же подзадачи возникают и вычисляются многократно при наивном подходе
25. Обновление в `fib_optimal` ? >> `prev, curr = curr, prev + curr`
26. `coin_change([1, 5, 10, 25], 36)` ? >> `3` – монеты $25 + 10 + 1$
27. Сложность задачи о монетах? >> $O(\text{amount} \times \text{len(coins)})$ по времени; $O(\text{amount})$ по памяти
28. Два признака применимости ДП? >> Оптимальная подструктура и перекрывающиеся подзадачи
29. Формула для задачи о лестнице? >> `ways(n) = ways(n-1) + ways(n-2)`
30. Что такое динамическое программирование? >> Техника решения задач разбивкой на перекрывающиеся подзадачи с кэшированием результатов для исключения повторных вычислений
31. Память стандартной табуляции Фибоначчи? >> $O(n)$
