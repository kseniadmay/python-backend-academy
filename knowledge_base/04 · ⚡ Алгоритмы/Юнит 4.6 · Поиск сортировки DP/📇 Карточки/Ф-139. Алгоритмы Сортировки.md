1. Как работает Insertion Sort? >> Берёт очередной элемент и вставляет его на правильное место в уже отсортированную левую часть
2. С чем сравнивают Insertion Sort? >> Сортировка карт в руке
3. Является ли Timsort стабильным? >> Да
4. Как работает Bubble Sort? >> Сравнивает соседние элементы и меняет местами если в неправильном порядке; максимум «всплывает» вправо за каждый проход
5. Является ли Selection Sort стабильным? >> Нет – перестановка может нарушить порядок равных элементов
6. Принцип Merge Sort? >> Разделяй и властвуй (divide and conquer): рекурсивно делить пополам, затем сливать
7. Является ли Quick Sort стабильным? >> Нет – перестановки нарушают относительный порядок равных элементов
8. Память Selection Sort? >> $O(1)$
9. Базовый случай рекурсии Merge Sort? >> `len(arr) <= 1`
10. Память Quick Sort в худшем случае? >> $O(n)$ – стек рекурсии деградирует до $n$ уровней при вырожденном pivot
11. Является ли Bubble Sort стабильным? >> Да – равные элементы не меняются местами
12. Сложность Insertion Sort в худшем случае? >> $O(n^2)$
13. Из чего состоит Timsort? >> Merge Sort + Insertion Sort: на малых подмассивах (run) применяет Insertion Sort, затем сливает через Merge Sort
14. Является ли Insertion Sort стабильным? >> Да – равные элементы не переставляются
15. Почему Merge Sort требует $O(n)$ памяти? >> Временные массивы для слияния двух подмассивов
16. Алгоритм сортировки в Python `sorted()` и `list.sort()` ? >> Timsort
17. Память Bubble Sort? >> $O(1)$
18. Что происходит с максимумом за один проход Bubble Sort? >> Всплывает в крайнюю правую позицию
19. Худший случай Quick Sort? >> $O(n^2)$ – при неудачном pivot (отсортированный, обратно-отсортированный или все равные элементы)
20. Главное преимущество Selection Sort? >> Минимальное количество перестановок – $O(n)$ ; полезно когда запись дорогостоящая
21. Память Timsort? >> $O(n)$
22. Принцип Selection Sort? >> Поиск минимума в неотсортированной части и его перемещение на текущую позицию
23. Сложность Insertion Sort для отсортированного массива? >> $O(n)$
24. В каком гибридном алгоритме используется Insertion Sort? >> Timsort
25. Сложность Selection Sort во всех случаях? >> $O(n^2)$ – всегда перебирает весь неотсортированный остаток
26. Сложность Timsort? >> $O(n \log n)$ в худшем случае; $O(n)$ для отсортированных данных
27. Зачем флаг `swapped` ? >> Для досрочного прерывания: если за проход не было ни одной перестановки – массив отсортирован
28. Когда Bubble Sort – $O(n)$ ? >> Массив уже отсортирован при наличии флага `swapped`
29. Что возвращает `partition` ? >> Финальный индекс опорного элемента после перераспределения
30. Сложность Merge Sort во всех случаях? >> $O(n \log n)$
31. Является ли Merge Sort стабильным? >> Да – порядок равных элементов сохраняется
32. Почему Quick Sort быстрее Merge Sort на практике? >> Лучшая локальность памяти (cache locality): работает in-place, меньше промахов кэша
33. Сложность Bubble Sort в среднем и худшем случае? >> $O(n^2)$
34. Средняя сложность Quick Sort? >> $O(n \log n)$
35. Для каких данных эффективен Insertion Sort? >> Маленькие и почти отсортированные массивы
36. Память Quick Sort в среднем? >> $O(\log n)$ – глубина стека рекурсии
37. Что такое pivot в Quick Sort? >> Опорный элемент, относительно которого делится массив: меньшие – левее, большие – правее
