1. Сложность `heappush` ? >> $O(\log n)$
2. Что находится в корне max-heap? >> Максимальное значение
3. Будет ли список отсортирован после `heapify` ? >> Нет – только удовлетворяет свойству кучи
4. Как изменяется высота кучи при росте $n$ ? >> $O(\log n)$
5. Можно ли использовать `heapq` для пользовательских объектов? >> Да, если определён `__lt__` ; или хранить кортеж `(priority, obj)` для избежания сравнения объектов
6. В чём разница между `heappushpop` и `heapreplace` ? >> `heappushpop(heap, item)` – сначала push, затем pop (можно на пустой); `heapreplace(heap, item)` – сначала pop, затем push (heap должна быть непустой); оба $O(\log n)$
7. Какой тип кучи реализует `heapq` по умолчанию? >> Min-heap
8. Что такое куча (heap)? >> Специализированное полное бинарное дерево, удовлетворяющее свойству кучи; хранится как массив
9. Как куча хранится в памяти? >> Как массив: для узла с индексом `i` – родитель `(i-1)//2` , дети `2i+1` и `2i+2`
10. Сложность поиска произвольного элемента в куче? >> $O(n)$
11. Функция для слияния отсортированных итерируемых? >> `heapq.merge()` – возвращает итератор без загрузки всего в память
12. Для чего наиболее эффективна куча? >> Нахождение и извлечение минимума или максимума за $O(\log n)$
13. Сложность `nlargest` и `nsmallest` ? >> $O(n \log k)$
14. Сложность `heapify` ? >> $O(n)$
15. Функция для $k$ наименьших элементов? >> `heapq.nsmallest(k, iterable)`
16. Сложность `heappop` ? >> $O(\log n)$
17. Как реализовать max-heap через `heapq` ? >> Хранить значения с отрицательным знаком: `heappush(heap, -val)` ; при извлечении инвертировать обратно
18. Функция для извлечения минимума? >> `heapq.heappop(heap)`
19. Функция для преобразования списка в кучу? >> `heapq.heapify()`
20. Почему поиск произвольного элемента $O(n)$ ? >> Куча частично упорядочена: гарантирует только отношение родитель-потомок, не полный порядок
21. Модуль Python для работы с кучами? >> `heapq`
22. Сложность `peek` через `heap[0]` ? >> $O(1)$
23. Как `heapq` сравнивает кортежи? >> Лексикографически – по первому элементу; при равенстве по второму и т.д.
24. Функция для добавления элемента в кучу? >> `heapq.heappush(heap, item)`
25. Для чего в алгоритме Дейкстры применяется куча? >> Выбор непосещённого узла с минимальным расстоянием за $O(\log V)$
26. Условие для каждого узла в min-heap? >> Значение узла ≤ значениям всех его дочерних узлов (рекурсивно)
27. Функция для $k$ наибольших элементов? >> `heapq.nlargest(k, iterable)`
28. Что находится в корне min-heap? >> Минимальное значение
29. Как посмотреть минимум без удаления? >> `heap[0]` – корень кучи всегда минимум
