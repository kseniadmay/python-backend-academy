1. Примеры самобалансирующихся деревьев? >> AVL-дерево и красно-чёрное дерево
2. Что такое вырожденное дерево? >> Каждый узел имеет не более одного ребёнка; дерево деградирует до связного списка
3. Порядок Post-order обхода? >> Левый → правый → корень
4. Куда идти при `target > node.val` ? >> В правое поддерево
5. Базовый случай рекурсии при обходе дерева? >> `if not node: return`
6. Что такое дерево? >> Иерархическая структура данных с одним корнем, без циклов и без родителей у корня
7. Глубина корня? >> 0
8. Максимум детей у узла бинарного дерева? >> Два – левый и правый
9. Сложность поиска в BST? >> $O(h)$ , где $h$ – высота дерева
10. Когда обрабатывается узел в Post-order? >> После рекурсивных вызовов
11. Что такое лист? >> Узел без дочерних элементов
12. Что такое корневой узел? >> Единственный узел без родителя
13. Что будет при вставке в BST строго по возрастанию? >> Дерево станет вырожденным (все узлы уходят вправо), поиск – $O(n)$
14. Сложность поиска в сбалансированном BST? >> $O(\log n)$
15. Где максимум в BST? >> Самый правый узел
16. Какая структура используется для Level-order обхода? >> `deque`
17. Куда идти при поиске если `target < node.val` ? >> В левое поддерево
18. Что такое высота узла? >> Максимальное расстояние от данного узла до листа в его поддереве
19. Порядок Pre-order обхода? >> Корень → левый → правый
20. Что такое глубина узла? >> Расстояние (число рёбер) от корня до данного узла
21. Какой обход BST даёт отсортированный порядок? >> In-order
22. Как называется обход уровень за уровнем? >> Level-order (BFS)
23. Когда обрабатывается узел в Pre-order? >> До рекурсивных вызовов
24. Основное свойство BST? >> Для каждого узла: все значения в левом поддереве меньше, в правом – больше; применяется рекурсивно
25. Когда дерево считается сбалансированным? >> Когда высота левого и правого поддерева каждого узла отличается не более чем на 1; высота ≈ $O(\log n)$
26. Порядок In-order обхода? >> Левый → корень → правый
27. Что возвращает `insert` при достижении пустого места? >> `TreeNode(val)` – новый узел
28. Сложность поиска в несбалансированном BST? >> $O(n)$ в худшем случае
29. Где минимум в BST? >> Самый левый узел
30. Три случая удаления узла из BST? >> 1) Нет детей – просто удалить; 2) Один ребёнок – заменить узел ребёнком; 3) Два ребёнка – заменить значением in-order преемника (наименьший в правом поддереве) и удалить преемника
31. Что такое высота дерева? >> Максимальное расстояние от корня до самого удалённого листа
