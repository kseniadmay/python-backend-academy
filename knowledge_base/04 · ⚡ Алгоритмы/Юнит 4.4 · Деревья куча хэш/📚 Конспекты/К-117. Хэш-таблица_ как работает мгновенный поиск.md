# ⚡ Хэш-таблица (Hash Table): устройство `dict` и `set`, коллизии и амортизация

> **Принцип прямого доступа (Direct Addressing)**:
> В списке поиск ключа требует перебора за $O(n)$.
> В **хэш-таблице (Hash Table)** ключ преобразуется функцией `hash()` в 64-битное число, а индекс слота вычисляется битовой маской `index = hash & mask`. Это даёт прямое чтение ячейки памяти за **$O(1)$ в среднем**!

---

## Цепочка преобразования ключа в индекс ячейки

Когда вы выполняете `d[key] = value` или проверяете `key in s`:
1. Вызывается `h = hash(key)` $\to$ возвращается 64-битное целое число.
2. Вычисляется индекс слота: `index = h & (table_size - 1)` (маска для степени двойки).
3. Проверяется слот `index`. Если ячейка занята, проверяется равенство `existing_key == key` (`__eq__`).
4. Возвращается или записывается значение за **$O(1)$ в среднем**.

```text
Путь ключа в хэш-таблице:

1. Ключ: "user_42"
   │
   ▼ hash("user_42")
2. 64-битный хэш
   │
   ▼ hash & (size - 1)
3. Индекс слота: 3
   │
   ▼
4. Бакет [3]: ("user_42", 950)
```

## Коллизии (Hash Collisions) и два метода их разрешения

Когда два разных ключа (`k1 != k2`) попадают в один индекс, возникает **коллизия (Collision)**:
- **Метод цепочек (Separate Chaining)**: каждая ячейка хранит связный список пар `(key, value)`. При поиске мы находим бакет за $O(1)$ и линейно проходим короткую цепочку.
- **Открытая адресация (Open Addressing)** — используется в CPython `dict` и `set`: все элементы хранятся в самом массиве таблицы. При занятости ячейки алгоритм зондирования (**Probing**) ищет следующую свободную ячейку. При удалении ставится метка-«надгробие» (**`DUMMY`**), чтобы не оборвать цепочку поиска.

```text
Компактный dict в CPython 3.7+:

1. Разреженная таблица (dk_indices):
   Слот:   0   1   2   3   4   5..7
   Индекс: -   0   -   2   1    -

2. Плотный массив (dk_entries):
   [0] hash=101 | key="alice" | val=10
   [1] hash=252 | key="bob"   | val=20
   [2] hash=83  | key="carol" | val=30
```

## Коэффициент заполнения (Load Factor) и контракт Хэшируемости

- **Load Factor ($\alpha = n / \text{buckets}$)**: в CPython `dict`, как только таблица заполняется на **$2/3$ ($\approx 0.66$)**, происходит реаллокация с удвоением размера и перехэшированием всех ключей за $O(n)$, чтобы поиск оставался **амортизированным $O(1)$**.
- **Контракт Хэшируемости (Hashable)**:
  Только объекты с неизменным хэшем и правилом `a == b ==> hash(a) == hash(b)` могут быть ключами `dict` и элементами `set`.
  - **Хэшируемые**: `int`, `str`, `float`, `bool`, `tuple` (если элементы хэшируемы).
  - **Нехэшируемые**: `list`, `dict`, `set` (`TypeError: unhashable type`).

## Паттерн Two Sum: мгновенный поиск дополнения через dict

Классическая задача: найти пару индексов с заданной суммой за один проход $O(n)$ вместо квадратичного перебора $O(n^2)$.

```python
def two_sum_hash(
    nums: list[int], target: int
) -> tuple[int, int] | None:
    """Two Sum: O(n) time / O(n) mem."""
    seen: dict[int, int] = {}
    for i, x in enumerate(nums):
        complement = target - x
        if complement in seen:
            return seen[complement], i
        seen[x] = i
    return None

ans = two_sum_hash([2, 11, 7, 15], target=9)
print("Two Sum O(n):", ans)
```

## Анатомия хэш-таблицы: учебная реализация методом цепочек

```python
class SimpleHashTable:
    """Учебная хэш-таблица со списками."""
    def __init__(
        self, capacity: int = 8
    ) -> None:
        self.capacity = capacity
        b = [[] for _ in range(capacity)]
        self.buckets: list[list] = b

    def _idx(self, key: str) -> int:
        return hash(key) % self.capacity

    def put(self, key: str, val: int) -> None:
        bucket = self.buckets[self._idx(key)]
        for i, (k, _) in enumerate(bucket):
            if k == key:
                bucket[i] = (key, val)
                return
        bucket.append((key, val))

    def get(self, key: str) -> int | None:
        bucket = self.buckets[self._idx(key)]
        for k, v in bucket:
            if k == key:
                return v
        return None

ht = SimpleHashTable(capacity=4)
ht.put("alpha", 100)
ht.put("beta", 200)
a = ht.get("alpha")
b = ht.get("beta")
print(f"Из таблицы: alpha={a}, beta={b}")
```
