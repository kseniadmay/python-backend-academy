## Прямой доступ по хэшу за O(1)

> **Вычисление адреса вместо перебора**: хэш-таблица не ищет элемент по одному — она мгновенно вычисляет номер ячейки по значению самого ключа.

- В обычном списке `list` поиск элемента требует линейного перебора за $O(n)$.
- В **хэш-таблице** (`dict`, `set`) функция `hash()` превращает ключ в число, а индекс слота находится битовой маской `hash & mask` за **$O(1)$ в среднем**.

---

## Цепочка преобразования ключа в индекс ячейки

При обращении `d[key]` или проверке `key in s` интерпретатор проходит четыре шага:

1. Вызывается `h = hash(key)` $\to$ возвращается 64-битное целое число.
2. Вычисляется индекс слота по маске степени двойки: `index = h & (table_size - 1)`.
3. Если ячейка занята, проверяется равенство ключей `existing_key == key` (`__eq__`).
4. Возвращается или записывается значение за **$O(1)$ в среднем**:

```text
Путь ключа в хэш-таблице:

1. Ключ: "user_42"
   │
   ▼ hash("user_42")
2. 64-битный хэш
   │
   ▼ hash & (size - 1)
3. Индекс слота: 3
   │
   ▼
4. Бакет [3]: ("user_42", 950)
```

## Коллизии и два метода их разрешения

Когда два разных ключа (`k1 != k2`) дают одинаковый индекс слота, возникает **коллизия**, которую решают одним из двух способов:

- **Метод цепочек (Separate Chaining)**: каждая ячейка хранит список пар `(key, value)`; найдя бакет за $O(1)$, алгоритм просматривает короткую цепочку.
- **Открытая адресация (Open Addressing)** — используется в CPython `dict` и `set`: при занятости слота зондирование (*Probing*) ищет следующую пустую ячейку, а удалённый элемент заменяется меткой **`DUMMY`**, чтобы не оборвать цепочку поиска.

В Python 3.7+ словарь хранит разреженную таблицу индексов `dk_indices` отдельно от плотного массива записей `dk_entries`, экономя память и сохраняя порядок вставки:

```text
Компактный dict в CPython 3.7+:

1. Индексы (dk_indices): [ - | 0 | - | 1 ]
2. Записи (dk_entries):
   [0] hash=101 | 'alice' | 10
   [1] hash=252 | 'bob'   | 20
```

## Коэффициент заполнения и контракт хэшируемости

Константное время доступа $O(1)$ в хэш-таблице обеспечивают коэффициент заполнения и контракт хэшируемости.

**1. Load Factor ($\alpha = n / \text{buckets}$):** в CPython `dict` при заполнении на **$2/3$ ($\approx 0.66$)** таблица расширяется вдвое и элементы перехэшируются за $O(n)$, сохраняя амортизированный **$O(1)$**.

**2. Контракт хэшируемости (`Hashable`):** ключами `dict` и элементами `set` могут быть только объекты с неизменным хэшем и законом `a == b ==> hash(a) == hash(b)`:

- **Хэшируемые**: `int`, `str`, `float`, `bool`, `tuple` (если все элементы внутри тоже хэшируемы).
- **Нехэшируемые**: `list`, `dict`, `set` (бросают `TypeError: unhashable type`).

## Паттерн Two Sum: поиск дополнения через `dict`

Классическая задача — найти пару индексов с суммой `target` за один проход $O(n)$ вместо квадратного перебора $O(n^2)$.

На каждом шаге сохраняем пройденные числа в словарь и за $O(1)$ проверяем, встречалось ли дополнение `target - x`:

```python
def two_sum_hash(
    nums: list[int], target: int
) -> tuple[int, int] | None:
    seen: dict[int, int] = {}
    for i, x in enumerate(nums):
        comp = target - x
        if comp in seen:
            return seen[comp], i
        seen[x] = i
    return None

ans = two_sum_hash([2, 11, 7, 15], target=9)
print('Индексы Two Sum:', ans)
# >>> Индексы Two Sum: (0, 2)
```

## Реализация хэш-таблицы методом цепочек

Чтобы закрепить работу корзин (`buckets`) и разрешение коллизий, соберём простую учебную хэш-таблицу поверх списка списков:

```python
class SimpleHashTable:
    def __init__(self, cap: int = 8) -> None:
        self.cap = cap
        self.buckets: list[list] = [
            [] for _ in range(cap)
        ]

    def _idx(self, key: str) -> int:
        return hash(key) % self.cap

    def put(self, key: str, val: int) -> None:
        bucket = self.buckets[self._idx(key)]
        for i, (k, _) in enumerate(bucket):
            if k == key:
                bucket[i] = (key, val)
                return
        bucket.append((key, val))

    def get(self, key: str) -> int | None:
        bucket = self.buckets[self._idx(key)]
        for k, v in bucket:
            if k == key:
                return v
        return None

ht = SimpleHashTable()
ht.put('apple', 100)
ht.put('apple', 200)
print(ht.get('apple'), ht.get('missing'))
# >>> 200 None
```
