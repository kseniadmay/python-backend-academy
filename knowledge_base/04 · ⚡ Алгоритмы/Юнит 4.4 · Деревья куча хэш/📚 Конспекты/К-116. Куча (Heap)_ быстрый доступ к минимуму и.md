# ⛰️ К-116. Бинарная куча (Binary Heap) и приоритетная очередь (`heapq`)

> **Ментальная модель — «Турнирная пирамида чемпиона»**:
> В отличие от дерева поиска (BST), где все элементы строго упорядочены слева направо, **Бинарная куча (Binary Heap)** поддерживает более слабое, но компактное правило: **родитель всегда не хуже своих детей**.
> В **Min-Heap** в самом верху пирамиды (`heap[0]`) гарантированно сидит **абсолютный минимум** всего набора! При этом куча настолько плотно уложена по уровням, что ей вообще не нужны объекты `Node` с указателями `left`/`right` — она хранится в обычном плоском массиве `list`!

---

## 1. Устройство бинарной кучи в плоском массиве

**Бинарная куча** — это **почти полное бинарное дерево (Complete Binary Tree)**, которое заполняется строго сверху вниз и слева направо.
Благодаря отсутствию «дырок» между узлами дерево идеально отображается на обычный массив `arr` с индексацией с `0`:
- **Корень (экстремум)**: `arr[0]`
- **Левый потомок узла `i`**: `2 * i + 1`
- **Правый потомок узла `i`**: `2 * i + 2`
- **Родитель узла `i`**: `(i - 1) // 2`

```text
Дерево Min-Heap (родитель <= детей):           Представление того же дерева в обычном list:

            [ 1 ] (i=0)                        Индекс:   0    1    2    3    4    5
           /     \                             Значение: [1,   3,   5,   7,   9,   8]
      (i=1)[ 3 ] [ 5 ](i=2)                              |    ^    ^
          /   \   /                                      +----+----+
       [ 7 ] [ 9 ][ 8 ]                                  дети i=0: 2*0+1=1, 2*0+2=2
      (i=3) (i=4)(i=5)
```

### Сложность операций в бинарной куче
- **Посмотреть минимум (`heap[0]`)**: **$O(1)$**.
- **Вставка (`heappush`)**: элемент добавляется в конец массива и «всплывает» вверх (`sift up`) по высоте дерева за **$O(\log n)$**.
- **Извлечение минимума (`heappop`)**: корень `heap[0]` забирается, на его место ставится последний элемент массива и «просеивается» вниз (`sift down`) за **$O(\log n)$**.
- **Построение кучи из готового списка (`heapify`)**: просеивание снизу вверх выполняется за **линейное время $O(n)$** (а не $O(n \log n)$!), так как большинство узлов находятся на нижних ярусах и просеиваются всего на 1–2 шага.

## 2. Модуль `heapq` в стандартной библиотеке Python

В Python модуль `heapq` реализует **Min-Heap** прямо поверх стандартного `list`:

| Функция `heapq` | Сложность | Описание |
| :--- | :--- | :--- |
| `heapq.heapify(lst)` | **$O(n)$** | Превращает существующий список `lst` в кучу `in-place` за линейное время |
| `heapq.heappush(heap, x)` | **$O(\log n)$** | Вставляет элемент `x` с сохранением инварианта кучи |
| `heapq.heappop(heap)` | **$O(\log n)$** | Удаляет и возвращает наименьший элемент (`heap[0]`) |
| `heapq.heappushpop(heap, x)` | **$O(\log n)$** | Быстрее раздельных `push` + `pop`: вставляет `x` и сразу извлекает минимум |
| `heapq.nlargest(k, iterable)` | **$O(n \log k)$** | Возвращает $k$ наибольших элементов, удерживая в памяти кучу размера всего $k$! |

### Как сделать Max-Heap в Python?
Поскольку `heapq` предоставляет только **Min-Heap**, для превращения её в **Max-Heap** числа при вставке **умножают на `-1`** (`heappush(h, -val)`), а при извлечении снова меняют знак (`-heappop(h)`). Для сложных объектов кладут кортеж `(-priority, item)`.

> **Junior vs Senior**:
> - **Junior**: Чтобы найти Топ-$10$ самых дорогих заказов из потока в $10\,000\,000$ записей, загружает все $10^7$ записей в память и делает `sorted(orders, reverse=True)[:10]`, тратя $O(n \log n)$ времени и гигабайты RAM.
> - **Senior**: Поддерживает **Min-Heap фиксированного размера $k = 10$** (`heapq.nlargest(10, stream)` или `heappushpop`): на самом верху кучи лежит «слабейший из текущей десятки лидеров». Любой элемент меньше него отбрасывается за $O(1)$, а общие затраты составляют **$O(n \log k)$ времени и $O(k)$ памяти**!

```python
import heapq

# 1. Построение Min-Heap за O(n) и работа с приоритетной очередью
nums = [15, 3, 9, 1, 22, 7]
heapq.heapify(nums)  # in-place за O(n)
print("После heapify(nums), минимум в nums[0]:", nums[0], "| массив кучи:", nums)

# 2. Эмуляция Max-Heap через инверсию знака (-x)
max_heap: list[int] = []
for score in [40, 100, 25, 85]:
    heapq.heappush(max_heap, -score)
top_score = -heapq.heappop(max_heap)
print("Извлечён максимум из Max-Heap:", top_score)

# 3. Поиск Top-K наибольших элементов за O(n log k) времени и O(k) памяти
def top_k_largest(stream: list[int], k: int) -> list[int]:
    min_heap = stream[:k]
    heapq.heapify(min_heap)
    for x in stream[k:]:
        if x > min_heap[0]:
            heapq.heapreplace(min_heap, x)  # вытесняем минимум из топ-k за O(log k)
    return sorted(min_heap, reverse=True)

print("Топ-3 наибольших числа:", top_k_largest([12, 5, 787, 1, 23, 90, 45, 600], k=3))
```
