# ⛰️ Бинарная куча (Binary Heap) и приоритетная очередь (`heapq`)

> **Ментальная модель — «Турнирная пирамида чемпиона»**:
> В отличие от дерева поиска (BST), где элементы строго упорядочены слева направо, **Бинарная куча (Binary Heap)** поддерживает более простое правило: **родитель всегда не хуже своих детей**.
> В **Min-Heap** на вершине пирамиды (`heap[0]`) гарантированно сидит **абсолютный минимум**! Куча настолько плотно уложена, что ей не нужны объекты `Node` с указателями — она хранится в обычном плоском массиве `list`!

---

## Устройство бинарной кучи в плоском массиве

Куча — это **почти полное бинарное дерево (Complete Binary Tree)**.
Благодаря отсутствию дырок дерево идеально отображается на обычный массив `arr` с индексацией с `0`:
- **Корень (экстремум)**: `arr[0]`
- **Левый потомок узла `i`**: `2 * i + 1`
- **Правый потомок узла `i`**: `2 * i + 2`
- **Родитель узла `i`**: `(i - 1) // 2`

```text
1. Дерево Min-Heap (родитель <= детей):
        [ 1 ] (i=0)
       /        [ 3 ]     [ 5 ] (i=2)
   /   \     /
 [ 7 ] [ 9 ][ 8 ]

2. Представление в виде массива:
   Индекс:   0   1   2   3   4   5
   Значение:[1,  3,  5,  7,  9,  8]
             │   ▲   ▲
             └───┴───┘
   Дети для i: left = 2i+1, right = 2i+2
```

### Сложность операций в куче
- **Посмотреть минимум (`heap[0]`)**: **$O(1)$**.
- **Вставка (`heappush`)**: добавление в конец и всплытие (`sift up`) за **$O(\log n)$**.
- **Извлечение минимума (`heappop`)**: корень забирается, на его место ставится хвост и просеивается вниз (`sift down`) за **$O(\log n)$**.
- **Построение кучи из готового списка (`heapify`)**: выполняется за **линейное время $O(n)$**!

## Модуль heapq: функции и трюк эмуляции Max-Heap

В Python модуль `heapq` реализует **Min-Heap** поверх обычного списка `list`:

| Функция `heapq` | Сложность | Описание |
| :--- | :--- | :--- |
| `heapq.heapify(lst)` | **$O(n)$** | Превращает список `lst` в кучу `in-place` |
| `heapq.heappush(heap, x)` | **$O(\log n)$** | Вставляет элемент с сохранением инварианта |
| `heapq.heappop(heap)` | **$O(\log n)$** | Извлекает наименьший элемент (`heap[0]`) |
| `heapq.heappushpop(h, x)` | **$O(\log n)$** | Вставляет `x` и сразу извлекает минимум |
| `heapq.nlargest(k, it)` | **$O(n \log k)$** | Возвращает $k$ наибольших элементов |

Для эмуляции **Max-Heap** числа умножают на `-1` при вставке (`heappush(h, -val)`) и возвращают знак при извлечении (`-heappop(h)`).

```python
import heapq

# 1. Построение Min-Heap за O(n)
nums = [15, 3, 9, 1, 22, 7]
heapq.heapify(nums)
print("Минимум в nums[0]:", nums[0], "| куча:", nums)

# 2. Max-Heap через умножение на -1
max_h: list[int] = []
for val in [40, 100, 25, 85]:
    heapq.heappush(max_h, -val)
print("Максимум из Max-Heap:", -heapq.heappop(max_h))
```

## Паттерн Top-K элементов: пирамида лидеров

```python
import heapq

def top_k_largest(stream: list[int], k: int) -> list[int]:
    """Поиск k наибольших элементов за O(n log k) времени и O(k) памяти."""
    min_heap = stream[:k]
    heapq.heapify(min_heap)
    for x in stream[k:]:
        if x > min_heap[0]:
            heapq.heapreplace(min_heap, x)
    return sorted(min_heap, reverse=True)

data = [12, 5, 787, 1, 23, 90, 45, 600]
print("Топ-3 числа:", top_k_largest(data, k=3))
```
