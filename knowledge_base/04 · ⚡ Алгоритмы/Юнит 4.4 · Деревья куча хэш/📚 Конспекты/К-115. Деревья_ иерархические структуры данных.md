# 🌳 Деревья (Trees): бинарное дерево, обходы (DFS/BFS) и дерево поиска (BST)

> **Ментальная модель — «Генеалогическое древо и игра Больше/Меньше»**:
> - **Дерево (Tree)** — связный ациклический граф с выделенной вершиной — **корнем (Root)**. Корень рисуют сверху, а **листья (Leaves)** — узлы без потомков — снизу.
> - **Бинарное дерево поиска (Binary Search Tree, BST)** — справочник с развилками: в каждом узле **все** ключи в левом поддереве строго меньше узла, а **все** ключи в правом поддереве — строго больше!

---

## Терминология и виды бинарных деревьев

- **Бинарное дерево (Binary Tree)** — дерево, где у каждого узла не более двух потомков: `left` и `right`.
- **Глубина узла (Depth)** — число рёбер от корня до этого узла.
- **Высота дерева (Height)** — максимальное число узлов от корня до самого дальнего листа.
- **Сбалансированное дерево (Balanced Tree — AVL, Red-Black)** — высоты поддеревьев любого узла отличаются не более чем на 1. Высота гарантированно равна **$h = O(\log n)$**.
- **Вырожденное дерево (Skewed Tree)** — превращается в связный список при вставке отсортированных данных (`1 -> 2 -> 3`), высота деградирует до **$h = O(n)$**!

```text
1. Сбалансированное BST (высота O(log n)):
        [ 8 ]  <-- Корень (Root)
       /     \
    [ 3 ]   [ 10 ]
    /   \        \
  [1]   [6]      [14] <-- Листья (Leaves)
2. Вырожденное BST (худший случай O(n)):
    [ 1 ]
       \
       [ 2 ]
          \
          [ 3 ]
```

## Четыре канонических обхода дерева (Tree Traversals)

Пусть дано дерево с корнем `8`, левым поддеревом `(3: 1, 6)` и правым `(10: -, 14)`:

| Вид обхода | Порядок обхода | Результат | Главное применение |
| :--- | :--- | :--- | :--- |
| **Pre-order (Прямой)** | **Корень** $\to$ Лево $\to$ Право | `8, 3, 1, 6, 10, 14` | Клонирование и сериализация |
| **In-order (Симметричный)** | Лево $\to$ **Корень** $\to$ Право | `1, 3, 6, 8, 10, 14` | В **BST** даёт **строго отсортированный список**! |
| **Post-order (Обратный)** | Лево $\to$ Право $\to$ **Корень** | `1, 6, 3, 14, 10, 8` | Подсчёт высоты, удаление узлов снизу вверх |
| **Level-order (BFS)** | По уровням (через `deque`) | `8 | 3, 10 | 1, 6, 14` | Кратчайший путь, послойная печать |

## Бинарное дерево поиска (BST): устройство и вставка

Инвариант **BST**: для каждого узла `val` левое поддерево содержит только значения `< val`, а правое — только `> val`.

        self, val: int,

        right: 'TreeNode | None' = None
    ) -> None:

        self.left = left
        self.right = right
