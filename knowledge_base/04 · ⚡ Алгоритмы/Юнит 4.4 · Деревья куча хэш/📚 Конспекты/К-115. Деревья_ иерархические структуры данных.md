## Ключевая концепция: генеалогическое древо и BST

> **Иерархия и поиск**: дерево растёт от корня (`Root`) вниз к листьям (`Leaves`), а бинарное дерево поиска упорядочивает ключи по правилу «меньше — влево, больше — вправо».

- **Дерево (Tree)** — связный ациклический граф с выделенным **корнем (Root)** сверху и **листьями (Leaves)** без потомков снизу.
- **Бинарное дерево поиска (Binary Search Tree, BST)** — в каждом узле **все** ключи левого поддерева строго меньше текущего, а **все** ключи правого поддерева — строго больше.

---

## Терминология и виды бинарных деревьев

- **Бинарное дерево (Binary Tree)** — дерево, где у каждого узла не более двух потомков: `left` и `right`.
- **Глубина узла (Depth)** — число рёбер от корня до этого узла.
- **Высота дерева (Height)** — максимальное число рёбер от корня до самого дальнего листа.
- **Сбалансированное дерево (Balanced Tree — AVL, Red-Black)** — высоты поддеревьев поддерживаются близкими к $O(\log n)$ (в AVL разница высот $\le 1$, в Red-Black — не более чем в 2 раза). Высота гарантированно равна **$h = O(\log n)$**.
- **Вырожденное дерево (Skewed Tree)** — превращается в связный список при вставке отсортированных данных (`1 -> 2 -> 3`), высота деградирует до **$h = O(n)$**!

```text
1. Сбалансированное BST (высота O(log n)):
        [ 8 ]  <-- Корень (Root)
       /     \
    [ 3 ]   [ 10 ]
    /   \        \
  [1]   [6]      [14] <-- Листья (Leaves)
2. Вырожденное BST (худший случай O(n)):
    [ 1 ]
       \
       [ 2 ]
          \
          [ 3 ]
```

## Четыре канонических обхода дерева (Tree Traversals)

Пусть дано дерево с корнем `8`, левым поддеревом `(3: 1, 6)` и правым `(10: -, 14)`:

| Вид обхода | Порядок обхода | Результат | Главное применение |
| :--- | :--- | :--- | :--- |
| **Pre-order (Прямой)** | **Корень** $\to$ Лево $\to$ Право | `8, 3, 1, 6, 10, 14` | Клонирование и сериализация |
| **In-order (Симметричный)** | Лево $\to$ **Корень** $\to$ Право | `1, 3, 6, 8, 10, 14` | В **BST** даёт **строго отсортированный список**! |
| **Post-order (Обратный)** | Лево $\to$ Право $\to$ **Корень** | `1, 6, 3, 14, 10, 8` | Подсчёт высоты, удаление узлов снизу вверх |
| **Level-order (BFS)** | По уровням (через `deque`) | `8 \| 3, 10 \| 1, 6, 14` | Кратчайший путь, послойная печать |

## Бинарное дерево поиска (BST): устройство и вставка

Инвариант **BST**: для каждого узла `val` левое поддерево содержит только значения `&lt; val`, а правое — только `&gt; val`.

```python
class TreeNode:
    def __init__(
        self, val: int,
        left: 'TreeNode | None' = None,
        right: 'TreeNode | None' = None
    ) -> None:
        self.val = val
        self.left = left
        self.right = right

def insert_bst(
    root: TreeNode | None, val: int
) -> TreeNode:
    if root is None:
        return TreeNode(val)

    # В BST меньшие уходят влево, большие
    # вправо
    if val < root.val:
        root.left = insert_bst(root.left, val)
    elif val > root.val:
        root.right = insert_bst(
            root.right,
            val,
        )
    return root

# Симметричный обход (Л-К-П) даёт сортировку

def inorder_dfs(
    root: TreeNode | None
) -> list[int]:
    if root is None:
        return []
    return (
        inorder_dfs(root.left)
        + [root.val]
        + inorder_dfs(root.right)
    )

bst_root: TreeNode | None = None
for v in [8, 3, 10, 1, 6, 14]:
    bst_root = insert_bst(bst_root, v)
print(
    "In-order обход BST:",
    inorder_dfs(bst_root),
)
# >>> In-order обход BST: [1, 3, 6, 8, 10, 14]
```

## Валидация BST и ловушка локальной проверки

```python
class TreeNode:
    def __init__(
        self, val: int,
        left: 'TreeNode | None' = None,
        right: 'TreeNode | None' = None
    ) -> None:
        self.val = val
        self.left = left
        self.right = right

def is_valid_bst(
    root: TreeNode | None,
    low: float = float("-inf"),
    high: float = float("inf")
) -> bool:
    if root is None:
        return True

    # Каждый узел проверяем по интервалу
    if not (low < root.val < high):
        return False
    return (
        is_valid_bst(root.left, low, root.val)
        and (
            is_valid_bst(
                root.right,
                root.val,
                high,
            )
        )
    )

valid_tree = TreeNode(
    8,
    TreeNode(3),
    TreeNode(10),
)
print("Valid:", is_valid_bst(valid_tree))
# >>> Valid: True
```

## Поуровневый обход дерева (Level-order BFS через deque)

В задачах на послойный обход используется очередь `collections.deque`: на каждом шаге длина очереди фиксирует точное число узлов текущего яруса.

```python
from collections import deque

class TreeNode:
    def __init__(
        self, val: int,
        left: 'TreeNode | None' = None,
        right: 'TreeNode | None' = None
    ) -> None:
        self.val = val
        self.left = left
        self.right = right

def level_order_bfs(
    root: TreeNode | None
) -> list[list[int]]:
    if root is None:
        return []
    levels: list[list[int]] = []

    # Очередь FIFO обходит дерево по уровням
    q: deque[TreeNode] = deque([root])
    while q:
        level_vals: list[int] = []

        # Фиксируем размер строго текущего
        # уровня
        for _ in range(len(q)):
            node = q.popleft()
            level_vals.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        levels.append(level_vals)
    return levels
```
