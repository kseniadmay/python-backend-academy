## Иерархия деревьев и инвариант BST

> **Корень и листья**: дерево растёт сверху от единственного корня (`Root`) к терминальным листьям (`Leaves`) без циклов, а бинарное дерево поиска упорядочивает ключи.

- **Дерево (Tree)** — связный ациклический граф с выделенным корнем сверху и узлами без потомков внизу.
- **Бинарное дерево поиска (BST)** — для каждого узла **все** ключи левого поддерева строго меньше текущего, а **все** ключи правого поддерева — строго больше.

---

## Терминология и вырождение бинарных деревьев

Ключевые метрики бинарного дерева (не более двух потомков `left` и `right` у каждого узла) определяют скорость поиска в нём:

- **Глубина узла (Depth)** — число рёбер от корня до узла; **высота дерева (Height)** — путь до самого дальнего листа.
- **Сбалансированное дерево (AVL, Red-Black)** — высоты поддеревьев близки, поэтому высота гарантированно $h = O(\log n)$.
- **Вырожденное дерево (Skewed)** — при вставке отсортированных ключей превращается в линейную цепочку с высотой $h = O(n)$:

```text
1. Сбалансированное BST:    2. Вырожденное:
        [ 8 ] (Root)            [ 1 ]
       /     \                     \
    [ 3 ]   [ 10 ]                 [ 2 ]
    /   \        \                    \
  [1]   [6]     [14] (Листья)         [ 3 ]
```

## Четыре канонических обхода дерева

Для дерева с корнем `8`, левым поддеревом `(3: 1, 6)` и правым `(10: -, 14)` порядок посещения узлов задаёт свойства результата:

| Вид обхода | Порядок обхода | Результат | Главное применение |
| :--- | :--- | :--- | :--- |
| **Pre-order (Прямой)** | **Корень** $\to$ Лево $\to$ Право | `8, 3, 1, 6, 10, 14` | Клонирование и сериализация |
| **In-order (Симметричный)** | Лево $\to$ **Корень** $\to$ Право | `1, 3, 6, 8, 10, 14` | В **BST** даёт **отсортированный список** |
| **Post-order (Обратный)** | Лево $\to$ Право $\to$ **Корень** | `1, 6, 3, 14, 10, 8` | Удаление узлов снизу вверх |
| **Level-order (BFS)** | По уровням через `deque` | `8 \| 3, 10 \| 1, 6, 14` | Кратчайший путь, послойный вывод |

## Бинарное дерево поиска: устройство и вставка

Инвариант **BST**: для каждого узла `val` левое поддерево содержит только значения `< val`, а правое — только `> val`.

При вставке ключ спускается влево или вправо до пустого места, а симметричный обход `inorder_dfs` собирает отсортированную последовательность:

```python
class TreeNode:
    def __init__(
        self, val: int, left=None, right=None
    ):
        self.val = val
        self.left = left
        self.right = right

def insert_bst(root, val: int):
    if root is None:
        return TreeNode(val)
    if val < root.val:
        root.left = insert_bst(root.left, val)
    elif val > root.val:
        root.right = insert_bst(
            root.right, val
        )
    return root

def inorder_dfs(root) -> list[int]:
    if root is None:
        return []
    return (
        inorder_dfs(root.left)
        + [root.val]
        + inorder_dfs(root.right)
    )

bst = None
for v in [8, 3, 10, 1, 6, 14]:
    bst = insert_bst(bst, v)

print('In-order BST:', inorder_dfs(bst))
# >>> In-order BST: [1, 3, 6, 8, 10, 14]
```

## Валидация BST и ловушка локальной проверки

Проверять в каждой вершине только прямых потомков (`left.val < root.val < right.val`) — частая ошибка.

Например, глубокий узел `7` в правом поддереве под `10` может оказаться меньше корня `8` и нарушить BST.

Поэтому при рекурсии сверху вниз пробрасывают допустимый интервал `(low, high)` от всех предков:

```python
class TreeNode:
    def __init__(
        self, val: int, left=None, right=None
    ):
        self.val = val
        self.left = left
        self.right = right

def is_valid_bst(
    root,
    low: float = float('-inf'),
    high: float = float('inf'),
) -> bool:
    if root is None:
        return True
    if not (low < root.val < high):
        return False
    left_ok = is_valid_bst(
        root.left, low, root.val
    )
    right_ok = is_valid_bst(
        root.right, root.val, high
    )
    return left_ok and right_ok

bad_tree = TreeNode(
    8,
    TreeNode(3),
    TreeNode(10, left=TreeNode(7)),
)
print('Валидно ли:', is_valid_bst(bad_tree))
# >>> Валидно ли: False
```

## Поуровневый обход дерева (BFS через `deque`)

Для обхода по ярусам используют очередь `collections.deque`: в начале каждой итерации `len(q)` фиксирует точное число узлов текущего уровня:

```python
from collections import deque

class TreeNode:
    def __init__(
        self, val: int, left=None, right=None
    ):
        self.val = val
        self.left = left
        self.right = right

def level_order_bfs(root) -> list[list[int]]:
    if root is None:
        return []
    levels: list[list[int]] = []
    q = deque([root])
    while q:
        cur: list[int] = []
        for _ in range(len(q)):
            node = q.popleft()
            cur.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        levels.append(cur)
    return levels

tree = TreeNode(8, TreeNode(3), TreeNode(10))
print('По уровням:', level_order_bfs(tree))
# >>> По уровням: [[8], [3, 10]]
```
