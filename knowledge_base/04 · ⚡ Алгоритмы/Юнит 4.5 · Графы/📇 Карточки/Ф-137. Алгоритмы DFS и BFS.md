1. Что будет в `visited` после завершения DFS? >> Все узлы, достижимые из начальной точки
2. Почему `visited` – это `set` ? >> Проверка наличия за $O(1)$
3. Структура данных для итеративного DFS? >> Стек ( `stack` )
4. Что инициализирует очередь в BFS? >> Начальный узел (или несколько узлов при multi-source BFS)
5. Что проверяется на равенство `end` в BFS пути? >> Последний узел текущего пути: `path[-1] == end`
6. Порядок preorder в DFS? >> Корень → левый → правый
7. Три применения DFS? >> Поиск пути, топологическая сортировка, обнаружение циклов
8. Как DFS помечает узел посещённым? >> Добавляет в множество `visited`
9. Память BFS по максимальной ширине уровня $w$ ? >> $O(w)$ – в очереди одновременно хранятся все узлы одного уровня
10. Когда помечать узел посещённым в итеративном DFS? >> Два подхода: при извлечении из стека (безопасно, но один узел может добавляться несколько раз) или при добавлении в стек (эффективнее – исключает дубли в стеке)
11. Что такое multi-source BFS? >> BFS, стартующий одновременно из нескольких узлов; используется когда источников несколько (например, расстояние до ближайшего из множества целей)
12. Начальное значение очереди в BFS для поиска пути? >> `deque([[start]])` – очередь путей; каждый элемент – список узлов от старта до текущего
13. Для каких графов BFS ищет кратчайший путь? >> Для невзвешенных; в взвешенных используется Дейкстра
14. Почему DFS не гарантирует кратчайший путь? >> Углубляется в одну ветку не сравнивая длины альтернативных маршрутов
15. Что выполняет роль стека в рекурсивном DFS? >> Стек вызовов (call stack)
16. Метод для извлечения из очереди в BFS? >> `popleft()` из `deque`
17. Что возвращает BFS при нахождении цели? >> Текущий путь от `start` до `end` – гарантированно кратчайший по числу рёбер
18. Память DFS по высоте дерева $h$ ? >> $O(h)$ – максимальная глубина стека равна высоте дерева
19. Что завершает цикл `while stack` ? >> Стек становится пустым – все достижимые узлы обработаны
20. Как называется возврат к предыдущему узлу в DFS? >> Backtrack
21. Цель обхода по уровням в BFS? >> Посещение всех узлов на расстоянии $k$ перед узлами на расстоянии $k+1$
22. Применение BFS для поиска изолированных групп? >> Поиск связных компонент – запускать BFS из каждого непосещённого узла
23. Главное отличие DFS от BFS при поиске пути? >> BFS гарантирует кратчайший путь (по числу рёбер); DFS находит любой доступный путь
24. Применение DFS для перебора вариантов? >> Backtracking – перебор с откатом
25. Откуда извлекается узел в итеративном DFS? >> С вершины стека: `stack.pop()`
