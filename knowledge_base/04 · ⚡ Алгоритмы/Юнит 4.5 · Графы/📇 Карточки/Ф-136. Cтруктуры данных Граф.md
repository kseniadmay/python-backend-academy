1. Что такое неориентированный граф? >> Граф с рёбрами без направления – связь между вершинами симметрична
2. Какая структура Python используется для списка смежности? >> `dict` , где ключ – вершина, значение – список соседей
3. Что такое DFS? >> Depth-First Search – поиск в глубину
4. Структура данных для BFS? >> `deque` – $O(1)$ для добавления и удаления с обоих концов
5. Сложность BFS? >> $O(V + E)$ – каждая вершина и каждое ребро обрабатываются по одному разу
6. Для чего используется DFS? >> Топологическая сортировка, поиск путей, обнаружение циклов, обход компонент связности
7. Что такое ориентированный граф? >> Граф с направленными рёбрами – каждое ребро имеет направление (стрелку)
8. Применение графов в картографии? >> Поиск оптимальных маршрутов (Dijkstra, A*)
9. Тип данных `visited` ? >> `set` – $O(1)$ для проверки и добавления
10. Что означает `1` в матрице смежности? >> Наличие ребра
11. Для чего используется `visited` при обходе графа? >> Отслеживание посещённых вершин для избежания зацикливания
12. Ключевое отличие графа от дерева? >> В графе допустимы циклы и несколько путей между вершинами; в дереве нет
13. Как хранятся веса во взвешенном списке смежности? >> Список кортежей `(сосед, вес)` : `{'A': [('B', 5), ('C', 2)]}`
14. Когда предпочесть BFS, а когда DFS? >> BFS – для кратчайшего пути в невзвешенном графе; DFS – для топологической сортировки, поиска всех путей, обнаружения циклов
15. Что такое граф? >> Множество вершин (V) и соединяющих их рёбер (E)
16. Применение графов в социальных сетях? >> Моделирование связей между людьми (подписки, друзья)
17. Как реализуется DFS? >> Рекурсией или итеративно через явный стек ( `stack.append` )
18. Что такое ребро? >> Элемент графа, соединяющий две вершины
19. Что такое взвешенный граф? >> Граф, где каждому ребру назначен вес (расстояние, стоимость, время)
20. Что находит BFS в графе без весов? >> Кратчайший путь по количеству рёбер
21. Что означает `0` в матрице смежности? >> Отсутствие ребра
22. Самый распространённый способ представления графа? >> Список смежности (Adjacency List)
23. Что такое BFS? >> Breadth-First Search – поиск в ширину
24. Какова сложность по памяти матрицы смежности? >> $O(V^2)$ – хранит все возможные пары вершин
25. Как в `dict` представлены связи `{'A': ['B', 'C']}` ? >> `A` – вершина, `['B', 'C']` – список её соседей
26. Когда удобна матрица смежности? >> Для плотных графов и быстрой проверки наличия ребра $O(1)$
27. Стратегия DFS? >> Идёт вглубь до упора, затем возвращается назад (backtracking)
28. Почему список смежности лучше для разреженных графов? >> Хранит только существующие рёбра: $O(V + E)$ памяти против $O(V^2)$ у матрицы
29. Применение графов в разработке ПО? >> Управление зависимостями пакетов; топологическая сортировка определяет порядок установки
30. Что такое DAG? >> Directed Acyclic Graph – ориентированный граф без циклов; используется для топологической сортировки
31. Принцип BFS? >> Обход уровень за уровнем; сначала все соседи текущего узла, затем соседи соседей
32. Сложность DFS? >> $O(V + E)$
