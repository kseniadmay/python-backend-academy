1. Что такое неориентированный граф? >> Граф с рёбрами без направления – связь между вершинами симметрична
2. Какая структура Python используется для списка смежности? >> `dict`, где ключ – вершина, значение – список соседей
3. В чём заключается алгоритм обхода графа в глубину (Depth-First Search, DFS)? >> Depth-First Search – поиск в глубину
4. Структура данных для BFS? >> `deque` – $O(1)$ для добавления и удаления с обоих концов
5. Какова временная сложность алгоритма обхода графа в ширину (BFS) в терминах количества вершин V и рёбер E? >> $O(V + E)$ – каждая вершина и каждое ребро обрабатываются по одному разу
6. Для чего используется DFS? >> Топологическая сортировка, поиск путей, обнаружение циклов, обход компонент связности
7. Что такое ориентированный граф? >> Граф с направленными рёбрами – каждое ребро имеет направление (стрелку)
8. Какая задача на графах решается картографическими сервисами при поиске оптимального автомобильного маршрута? >> Поиск оптимальных маршрутов (Dijkstra, A*)
9. Какую структуру данных оптимальнее всего использовать для коллекции `visited` при обходе графа для проверки за $O(1)$? >> `set` – $O(1)$ для проверки и добавления
10. Что означает `1` в матрице смежности? >> Наличие ребра
11. Для чего используется `visited` при обходе графа? >> Отслеживание посещённых вершин для избежания зацикливания
12. Ключевое отличие графа от дерева? >> В графе допустимы циклы и несколько путей между вершинами; в дереве нет
13. Как хранятся веса во взвешенном списке смежности? >> Список кортежей `(сосед, вес)`: `{'A': [('B', 5), ('C', 2)]}`
14. Когда предпочесть BFS, а когда DFS? >> BFS – для кратчайшего пути в невзвешенном графе; DFS – для топологической сортировки, поиска всех путей, обнаружения циклов
15. Что представляет собой абстрактная структура данных «граф» в теории алгоритмов? >> Множество вершин (V) и соединяющих их рёбер (E)
16. Как концепция графов применяется в архитектуре социальных сетей для моделирования взаимосвязей пользователей? >> Моделирование связей между людьми (подписки, друзья)
17. С помощью каких двух структурных подходов (рекурсия со стеком вызовов или явный стек) реализуется алгоритм DFS? >> Рекурсией или итеративно через явный стек (`stack.append`)
18. Какую роль выполняет ребро (edge) в ориентированных и неориентированных графах? >> Элемент графа, соединяющий две вершины
19. Что такое взвешенный граф? >> Граф, где каждому ребру назначен вес (расстояние, стоимость, время)
20. Что находит BFS в графе без весов? >> Кратчайший путь по количеству рёбер
21. Что означает `0` в матрице смежности? >> Отсутствие ребра
22. Самый распространённый способ представления графа? >> Список смежности (Adjacency List)
23. В чём заключается алгоритм обхода графа в ширину (Breadth-First Search, BFS)? >> Breadth-First Search – поиск в ширину
24. Какова сложность по памяти матрицы смежности? >> $O(V²)$ – хранит все возможные пары вершин
25. Как в `dict` представлены связи `{'A': ['B', 'C']}`? >> `A` – вершина, `['B', 'C']` – список её соседей
26. Когда удобна матрица смежности? >> Для плотных графов и быстрой проверки наличия ребра $O(1)$
27. Каков базовый порядок исследования вершин при поиске в глубину (DFS)? >> Идёт вглубь до упора, затем возвращается назад (backtracking)
28. Почему список смежности лучше для разреженных графов? >> Хранит только существующие рёбра: $O(V + E)$ памяти против $O(V²)$ у матрицы
29. Как структуры данных на графах используются в пакетных менеджерах для управления зависимостями библиотек? >> Управление зависимостями пакетов; топологическая сортировка определяет порядок установки
30. Что представляет собой направленный ациклический граф (Directed Acyclic Graph, DAG) и где он применяется в бэкенд-системах? >> Directed Acyclic Graph – ориентированный граф без циклов; используется для топологической сортировки
31. Какую структуру данных (очередь FIFO) использует алгоритм BFS для поуровневого обхода вершин графа? >> Обход уровень за уровнем; сначала все соседи текущего узла, затем соседи соседей
32. Какова временная сложность алгоритма обхода графа в глубину (DFS) в терминах количества вершин V и рёбер E? >> $O(V + E)$
