# 🕸️ К-118. Графы (Graphs): виды графов, список смежности и матрица смежности

> **Ментальная модель — «Карта авиарейсов и подписок в соцсети»**:
> - **Дерево** — это жёсткая иерархия «начальник $\to$ подчинённый» без петель.
> - **Граф (Graph $G = (V, E)$)** снимает все ограничения: города — это **вершины (Vertices / Nodes, $V$)**, а дороги или авиарейсы между ними — **рёбра (Edges, $E$)**. Дороги могут быть с двусторонним движением (**неориентированный граф**), с односторонним движением (**ориентированный граф** — например, подписка в соцсети или зависимости пакетов `pip`), а также иметь стоимость или длину в километрах (**взвешенный граф**).

---

## 1. Классификация графов

1. **Неориентированный (Undirected Graph)** vs **Ориентированный (Directed Graph / Digraph)**:
   - В неориентированном графе ребро $(u, v)$ симметрично: если из $A$ есть дорога в $B$, то из $B$ есть та же дорога в $A$.
   - В ориентированном графе ребро $u \to v$ имеет направление (стрелку).
2. **Невзвешенный (Unweighted)** vs **Взвешенный (Weighted)**:
   - Во взвешенном графе каждому ребру сопоставлено число $w(u, v)$ — вес (расстояние, задержка сети, стоимость).
3. **Циклический** vs **Ациклический ориентированный граф (DAG — Directed Acyclic Graph)**:
   - **DAG** — ориентированный граф без циклов. Именно так устроены пайплайны задач в Airflow/GitLab CI, граф коммитов Git и зависимости таблиц при миграциях БД!

---

## 2. Два главных способа хранения графа в памяти

Пусть граф содержит $V$ вершин и $E$ рёбер:

```text
Ориентированный граф:          1) Список смежности (Adjacency List):     2) Матрица смежности (Adjacency Matrix):
                                  0: [1, 2]                                    0  1  2  3
   (0) ---> (1)                   1: [3]                                    0 [0, 1, 1, 0]
    |        |                    2: [3]                                    1 [0, 0, 0, 1]
    v        v                    3: []                                     2 [0, 0, 0, 1]
   (2) ---> (3)                                                             3 [0, 0, 0, 0]
```

### Сравнение способов представления графа

| Критерий | Список смежности (`dict[int, list[int]]`) | Матрица смежности (`list[list[int]]` $V \times V$) | Список рёбер (`list[tuple[int, int]]`) |
| :--- | :--- | :--- | :--- |
| **Затраты памяти (Space)** | **$O(V + E)$** (экономно для разреженных графов) | **$O(V^2)$** (даже если рёбер почти нет!) | **$O(E)$** |
| **Перебор всех соседей вершины $u$** | **$O(\text{deg}(u))$** (только реальные соседи!) | **$O(V)$** (приходится сканировать всю строку из $V$ нулей) | $O(E)$ |
| **Проверка «есть ли ребро $(u, v)$?»** | $O(\text{deg}(u))$ (или **$O(1)$** для `dict[int, set[int]]`) | **$O(1)$** (`matrix[u][v] == 1`) | $O(E)$ |
| **Когда применять?** | **95% реальных задач** (дорожные сети, соцсети, веб-графы, где $E \ll V^2$) | Плотные графы ($E \approx V^2$) с малым числом вершин ($V \le 1000$) | Входной формат данных, алгоритм Краскала (MST) |

> **Junior vs Senior**:
> - **Junior**: Создаёт матрицу смежности $V \times V$ для графа из $100\,000$ пользователей соцсети, мгновенно получая `MemoryError` ($10^5 \times 10^5 = 10^{10}$ ячеек $\approx 80$ ГБ памяти!), либо забывает при построении **неориентированного** графа добавить обратное ребро `graph[v].append(u)`.
> - **Senior**: По умолчанию использует **список смежности** на базе `collections.defaultdict(list)` (занимает всего $O(V + E)$ памяти), чётко различает направленные (`u -> v`) и двунаправленные (`u <-> v`) рёбра, а для взвешенного графа хранит кортежи `(neighbor, weight)`.

```python
from collections import defaultdict

def build_adjacency_list(
    edges: list[tuple[str, str]], directed: bool = False
) -> dict[str, list[str]]:
    """Строит список смежности за O(V + E) по времени и памяти."""
    graph: dict[str, list[str]] = defaultdict(list)
    for u, v in edges:
        graph[u].append(v)
        if not directed:
            graph[v].append(u)
        else:
            graph.setdefault(v, [])  # гарантируем присутствие стоков (вершин без исходящих рёбер)
    return dict(graph)

road_edges = [("Москва", "Тверь"), ("Тверь", "СПб"), ("Москва", "Тула")]
undirected_map = build_adjacency_list(road_edges, directed=False)
directed_dag = build_adjacency_list([("auth", "db"), ("api", "auth"), ("api", "cache")], directed=True)

print("Неориентированный граф дорог (соседи Москвы):", undirected_map["Москва"])
print("Ориентированный граф зависимостей сервисов (DAG):", directed_dag)
```
