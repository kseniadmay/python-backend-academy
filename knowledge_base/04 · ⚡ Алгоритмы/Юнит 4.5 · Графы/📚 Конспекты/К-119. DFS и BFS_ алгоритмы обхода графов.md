# 🧭 К-119. Алгоритмы обхода графов: DFS (в глубину), BFS (в ширину) и Дейкстра

> **Ментальная модель — «Искатель в лабиринте vs Круги на воде»**:
> - **DFS (Depth-First Search — Поиск в глубину)** — исследователь с клубком ниток в лабиринте: он выбирает один коридор и идёт по нему до самого тупика, после чего возвращается на последнюю развилку (**Backtracking**) и пробует следующую дверь.
> - **BFS (Breadth-First Search — Поиск в ширину)** — камень, брошенный в воду: волна сначала одновременно накрывает всех соседей на расстоянии **1 шага**, затем всех на расстоянии **2 шагов**, затем **3 шагов**. Поэтому первый же момент, когда волна BFS коснулась цели, гарантированно даёт **кратчайший путь по числу рёбер**!

---

## 1. Сравнение DFS, BFS и алгоритма Дейкстры

```text
Порядок обхода графа от вершины A:
         [ A ]
        /     \
     [ B ]   [ C ]
     /   \       \
  [ D ] [ E ]   [ F ]

- DFS (в глубину, уходим до листа):   A -> B -> D -> E -> C -> F  (Стек / Рекурсия)
- BFS (в ширину, строго по слоям):    A -> B -> C -> D -> E -> F  (Очередь collections.deque)
```

| Характеристика | **DFS (Поиск в глубину)** | **BFS (Поиск в ширину)** | **Алгоритм Дейкстры (Dijkstra)** |
| :--- | :--- | :--- | :--- |
| **Базовая структура данных** | **Стек (`list` или рекурсия)** — LIFO | **Очередь (`collections.deque`)** — FIFO | **Приоритетная очередь (`heapq`)** — Min-Heap |
| **Временная сложность** | **$O(V + E)$** | **$O(V + E)$** | **$O((V + E) \log V)$** |
| **Пространственная сложность** | **$O(V)$** (`visited` + стек до глубины $V$) | **$O(V)$** (`visited` + очередь ширины слоя) | **$O(V)$** (словарь `dist` + куча) |
| **Находит ли кратчайший путь?** | **Нет** (находит *любой* путь, не обязательно кратчайший) | **Да, в невзвешенном графе** (минимум рёбер) | **Да, во взвешенном графе с весами $\ge 0$** |
| **Главные задачи** | Поиск циклов, связность, **топологическая сортировка**, острова на матрице | Кратчайший путь в лабиринте, число рукопожатий, поуровневый обход | Навигатор дорог с километражем, маршрутизация пакетов в сети |

## 2. Критическая роль множества `visited`

В отличие от дерева, в графе могут быть **циклы и двусторонние рёбра** (`A <-> B`). Без сохранения уже посещённых вершин в `visited: set` любой обход мгновенно уйдёт в бесконечный цикл `A -> B -> A -> B...`!

> **Junior vs Senior**:
> - **Junior**: В алгоритме BFS добавляет вершину в `visited` только **при извлечении** из очереди (`u = queue.popleft(); visited.add(u)`). Из-за этого одна и та же вершина с 50 входящими рёбрами может быть добавлена в очередь **50 раз** до того, как до неё дойдёт ход!
> - **Senior**: В BFS помечает соседнюю вершину `visited.add(nxt)` **в момент добавления в очередь** (`queue.append(nxt)`), гарантируя, что каждая вершина попадёт в `deque` ровно один раз. А для взвешенных графов с неотрицательными весами заменяет `deque` на `heapq` (алгоритм Дейкстры).

```python
from collections import deque
import heapq

# 1. BFS: поиск кратчайшего пути (по числу пересадок) в невзвешенном графе за O(V + E)
def shortest_path_bfs(graph: dict[str, list[str]], start: str, goal: str) -> list[str] | None:
    if start == goal:
        return [start]
    visited: set[str] = {start}
    queue: deque[tuple[str, list[str]]] = deque([(start, [start])])
    while queue:
        vertex, path = queue.popleft()
        for neighbor in graph.get(vertex, []):
            if neighbor not in visited:
                new_path = path + [neighbor]
                if neighbor == goal:
                    return new_path
                visited.add(neighbor)  # помечаем СРАЗУ при добавлении в очередь!
                queue.append((neighbor, new_path))
    return None

# 2. DFS: подсчёт числа компонент связности за O(V + E)
def count_connected_components(graph: dict[str, list[str]]) -> int:
    visited: set[str] = set()
    components = 0

    def dfs(u: str) -> None:
        visited.add(u)
        for v in graph.get(u, []):
            if v not in visited:
                dfs(v)

    for node in graph:
        if node not in visited:
            components += 1
            dfs(node)
    return components

# 3. Алгоритм Дейкстры: кратчайшие расстояния во взвешенном графе (веса >= 0) через Min-Heap
def dijkstra(weighted_graph: dict[str, list[tuple[str, int]]], start: str) -> dict[str, int]:
    distances: dict[str, int] = {node: float("inf") for node in weighted_graph}  # type: ignore[misc]
    distances[start] = 0
    pq: list[tuple[int, str]] = [(0, start)]  # (текущее_расстояние, вершина)

    while pq:
        cur_dist, u = heapq.heappop(pq)
        if cur_dist > distances[u]:
            continue  # пропускаем устаревшую запись в куче
        for v, weight in weighted_graph[u]:
            new_dist = cur_dist + weight
            if new_dist < distances[v]:
                distances[v] = new_dist
                heapq.heappush(pq, (new_dist, v))
    return distances

city_graph = {
    "A": ["B", "C"],
    "B": ["A", "D", "E"],
    "C": ["A", "F"],
    "D": ["B"],
    "E": ["B", "F"],
    "F": ["C", "E"],
}
print("Кратчайший путь BFS от A до F:", shortest_path_bfs(city_graph, "A", "F"))
print("Число компонент связности:", count_connected_components(city_graph))

roads = {
    "A": [("B", 10), ("C", 3)],
    "B": [("D", 2)],
    "C": [("B", 4), ("D", 8)],
    "D": [],
}
print("Кратчайшие расстояния Дейкстры от A (через C->B->D дешевле, чем напрямую!):", dijkstra(roads, "A"))
```
