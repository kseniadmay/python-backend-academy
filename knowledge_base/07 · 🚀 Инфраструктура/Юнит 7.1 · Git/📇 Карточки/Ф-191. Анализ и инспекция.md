1. Как вывести историю коммитов, где каждый коммит занимает одну строку? >> `git log --oneline`
2. Как просмотреть полный контекст коммита, найденного через `git blame` ? >> `git show <hash>` ; показывает сообщение коммита, автора, дату и полный diff
3. Как отфильтровать коммиты по автору? >> `git log --author="Alice"` ; поддерживает частичное совпадение и регулярные выражения
4. Как просмотреть изменения только в одном файле через `git diff` ? >> `git diff -- file.py`
5. Как ограничить `git blame` диапазоном строк с 20 по 40? >> `git blame -L 20,40 users.py`
6. Как просмотреть историю коммитов, затрагивавших конкретный файл `file.py` ? >> `git log -- file.py` ; `--` отделяет имя ветки/коммита от пути к файлу
7. Как сравнить два конкретных коммита? >> `git diff abc1234 def5678`
8. Какая опция `git log` визуализирует структуру веток ASCII-графикой? >> `--graph` ; обычно используется в связке: `git log --oneline --graph --all`
9. Как просмотреть staged-изменения в конкретном файле? >> `git diff --staged -- config.json`
10. Что означает хэш `00000000` в выводе `git blame` ? >> Строка изменена в рабочей директории и ещё не закоммичена
11. Как вывести полную построчную историю файла `users.py` ? >> `git blame users.py`
12. Для чего используется `git blame` ? >> Показывает построчно, кто, когда и каким коммитом изменил каждую строку файла; используется для поиска автора изменения
13. Как просмотреть изменения, уже добавленные в staging area? >> `git diff --staged` (синоним: `git diff --cached` )
14. Как ограничить вывод `git log` последними 10 коммитами? >> `git log -10`
15. Как вывести последние 5 коммитов автора Bob в одну строку? >> `git log --author="Bob" --oneline -5`
16. Какая команда используется для просмотра истории коммитов? >> `git log`
17. Что показывает `git log main..feature` ? >> Коммиты, которые есть в `feature` , но отсутствуют в `main` ; удобно перед merge для проверки того, что войдёт
18. Для чего используется `--` (два тире) в командах `git log` и `git diff` ? >> Для явного отделения ссылок (ветки, хэши) от путей к файлам; предотвращает неоднозначность, когда имя файла совпадает с именем ветки
19. Как увидеть различия текущего рабочего дерева с состоянием 3 коммита назад? >> `git diff HEAD~3`
20. Как сравнить состояние кода между двумя ветками? >> `git diff main feature/auth`
21. Верно ли, что `git diff --staged` и `git diff --cached` делают одно и то же? >> Да, это полные синонимы
22. Что делает `git diff HEAD~1 HEAD` ? >> Показывает разницу между последним и предпоследним коммитом
23. Что выведет `git diff` без аргументов, если все изменения уже в staging? >> Ничего; `git diff` сравнивает рабочую директорию с индексом, а не с последним коммитом – распространённая ловушка
24. Что делает флаг `-w` в `git blame` ? >> Игнорирует изменения, связанные только с пробелами; помогает найти содержательного автора строки, а не того, кто лишь отформатировал код
25. Как найти коммиты, в сообщении которых содержится слово `fix` ? >> `git log --grep="fix"`
26. Как увидеть историю коммитов с 1 января 2024 года, затрагивающих папку `src/` ? >> `git log --since="2024-01-01" -- src/`
27. Какая команда показывает незафиксированные изменения, ещё не добавленные в индекс? >> `git diff` ; без аргументов сравнивает рабочую директорию с индексом
28. Как найти коммиты из `feature` , которых ещё нет в `origin/master` ? >> `git log origin/master..feature`
29. Как отфильтровать коммиты начиная с определённой даты? >> `git log --since="2024-01-01"` ; можно комбинировать с `--until="2024-12-31"`
