1. Что, помимо актуального состояния файлов, скачивает `git clone` ? >> Всю историю коммитов и все ветки репозитория
2. Что делает `git pull` ? >> Загружает изменения из удалённого репозитория и применяет их к текущей ветке; по умолчанию – через `git fetch` + `git merge`
3. Что произойдёт при `git pull origin main` , если текущая ветка отличается от `main` ? >> Git скачает изменения из `origin/main` и сольёт их с текущей веткой через merge-коммит (если не указан `--rebase` )
4. Чем `git pull --rebase` отличается от обычного `git pull` ? >> Вместо merge-коммита создаётся линейная история: локальные коммиты перекладываются поверх обновлённой удалённой ветки
5. Что делает команда `git commit -am "message"` ? >> Автоматически индексирует все изменения в уже отслеживаемых файлах и создаёт коммит; эквивалентно `git add -u && git commit -m`
6. Какой флаг команды `git commit` используется для указания сообщения коммита? >> `-m "сообщение"`
7. Что делает `git commit --amend` ? >> Заменяет последний коммит новым: позволяет изменить сообщение и/или добавить проиндексированные изменения; меняет SHA коммита
8. Что такое индекс (Index) в Git? >> Синоним staging area; структура данных, хранящая снимок файлов, подготовленных для следующего коммита
9. Что делает флаг `-u` (он же `--set-upstream` ) в `git push` ? >> Устанавливает связку между локальной веткой и удалённой; после этого достаточно вводить просто `git push` без указания remote и ветки
10. Для чего используется команда `git add` ? >> Для добавления изменений из рабочей директории в staging area (индекс) – подготовки к коммиту
11. Что делает `git pull --rebase` ? >> Выполняет `git fetch` , затем переносит локальные коммиты поверх полученных через `git rebase` ; сохраняет линейную историю
12. Как отправить ветку `feature/auth` на удалённый сервер? >> `git push origin feature/auth`
13. Комбинацией каких двух команд является `git pull` ? >> `git fetch` + `git merge` (по умолчанию)
14. Что такое shallow-клон? >> Клон репозитория с усечённой историей; создаётся флагом `--depth N` , где N – количество последних коммитов; ускоряет клонирование больших репозиториев в CI
15. Почему `git commit --amend` опасно использовать после `git push` ? >> Он переписывает историю: SHA коммита меняется, и последующий push потребует `--force` , что перезапишет историю в удалённом репозитории и сломает работу других участников
16. Какая команда Git создаёт локальную копию удалённого репозитория? >> `git clone <url>`
17. Для чего используется команда `git push` ? >> Для отправки локальных коммитов в удалённый репозиторий
18. Почему `git push --force-with-lease` безопаснее, чем `--force` ? >> Перед перезаписью проверяет, не появились ли в удалённой ветке новые коммиты от других участников; если появились – отказывает в push, предотвращая потерю чужих изменений
19. Что такое staging area в Git? >> Промежуточная зона (индекс) между рабочей директорией и историей коммитов; позволяет точно контролировать, что войдёт в следующий коммит
20. Как добавить в индекс один конкретный файл `file.py` ? >> `git add file.py`
21. Какая команда индексирует все изменения в текущей директории? >> `git add .`
22. Что означает команда `git push origin main` ? >> Отправка коммитов текущей локальной ветки в ветку `main` удалённого репозитория `origin`
23. Какова основная функция команды `git commit` ? >> Фиксация содержимого staging area в локальную историю репозитория в виде нового коммита
24. Что делает флаг `-p` в команде `git add` ? >> Запускает интерактивный патч-режим: позволяет выбирать отдельные hunks (части файла) для добавления в индекс
25. Для каких файлов не сработает флаг `-a` в `git commit -am` ? >> Для новых (untracked) файлов – они не отслеживаются Git и не попадут в индекс автоматически
26. Какая опция `git clone` позволяет скачать только последний коммит без полной истории? >> `--depth 1`
27. Как называется удалённый репозиторий по умолчанию в командах `git push` / `git pull` ? >> `origin` – имя, которое `git clone` автоматически присваивает исходному удалённому репозиторию
28. Как клонировать удалённый репозиторий в папку с конкретным именем `my-folder` ? >> `git clone <url> my-folder`
29. Что делает `git fetch` в рамках `git pull` ? >> Скачивает новые данные из удалённого репозитория в локальные remote-tracking ветки без слияния с текущей веткой
30. Как добавить в staging area все изменения внутри директории `src/` ? >> `git add src/`
