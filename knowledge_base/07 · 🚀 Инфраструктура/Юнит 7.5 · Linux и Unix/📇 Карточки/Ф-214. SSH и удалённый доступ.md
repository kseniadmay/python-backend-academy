1. Что такое SSH? >> Протокол для безопасного удалённого подключения к серверу; шифрует весь трафик между клиентом и сервером, а не только пароль
2. Что такое SCP? >> Secure Copy – утилита для безопасного копирования файлов через SSH
3. Как подключиться к серверу, настроенному как `Host myserver` в `~/.ssh/config` ? >> `ssh myserver` ; SSH подставит все параметры из блока автоматически
4. Что означают флаги `-avz` в команде `rsync` ? >> `-a` – архивный режим (сохраняет права, симлинки, даты); `-v` – подробный вывод; `-z` – сжатие при передаче
5. Где должен находиться публичный ключ для успешной аутентификации? >> В файле `~/.ssh/authorized_keys` на целевом сервере
6. Как пробросить локальный порт `5432` на порт `5432` сервера? >> `ssh -L 5432:localhost:5432 user@server.com` ; после этого можно подключаться к БД через `localhost:5432`
7. В чём основное отличие `rsync` от `scp` ? >> `rsync` передаёт только изменившиеся части файлов (дельта-синхронизация), экономя трафик и время; `scp` всегда копирует файл целиком
8. Как загрузить локальный файл `file.txt` в `/tmp/` на сервере? >> `scp file.txt user@server.com:/tmp/`
9. Что означает `localhost` в команде `ssh -L 8080:localhost:80` ? >> `localhost` здесь – адрес относительно самого сервера; трафик с локального порта `8080` будет перенаправлен на порт `80` сервера
10. Где хранится публичный ключ `ed25519` ? >> `~/.ssh/id_ed25519.pub`
11. Для чего в `ssh-keygen` используется флаг `-t` ? >> Указывает алгоритм шифрования; `ed25519` предпочтительнее устаревшего `rsa`
12. Какое правило безопасности применимо к приватному ключу? >> Никогда не передавать никому и не публиковать; компрометация приватного ключа означает компрометацию всех серверов, где установлен соответствующий публичный ключ
13. Какие параметры задаются в блоке `Host` файла `~/.ssh/config` ? >> `Host` – алиас; `HostName` – реальный IP или домен; `User` – имя пользователя; `Port` – порт; `IdentityFile` – путь к приватному ключу
14. Почему аутентификация по ключу безопаснее парольной? >> Приватный ключ никогда не передаётся по сети; даже при перехвате трафика злоумышленник не получит секрет; пароль же можно подобрать брутфорсом
15. Как синхронизировать локальную папку `./code/` с удалённой `/app/` ? >> `rsync -avz ./code/ user@server.com:/app/`
16. Как скачать файл с сервера в текущую директорию? >> `scp user@server.com:/var/log/app.log ./`
17. Какой порт SSH использует по умолчанию? >> `22` (стандартный TCP-порт демона `sshd`)
18. Что такое SSH-туннель (Local Forwarding)? >> Проброс локального порта через зашифрованный SSH-канал на порт удалённого сервера; позволяет работать с удалёнными сервисами как с локальными
19. Как подключиться к серверу по SSH? >> `ssh user@server.com`
20. Как сгенерировать пару SSH-ключей типа ed25519? >> `ssh-keygen -t ed25519 -C "dev@example.com"`
21. Как выполнить команду на удалённом сервере без открытия интерактивной сессии? >> `ssh user@server.com "команда"` ; например `ssh user@server.com "docker ps"`
22. Какой флаг `scp` используется для копирования директорий? >> `-r` (recursive — рекурсивное копирование каталога со всем его содержимым)
23. Как автоматически скопировать публичный ключ на сервер? >> `ssh-copy-id user@server.com`
24. Как указать нестандартный порт при подключении по SSH? >> `ssh -p 2222 user@server.com`
25. Где хранится приватный ключ `ed25519` по умолчанию? >> `~/.ssh/id_ed25519`
26. Для чего используется SSH-туннель на практике? >> Доступ к базе данных или внутреннему сервису, закрытому для внешних соединений; например, подключение к PostgreSQL на продакшене через локальный клиент
27. Для чего в `ssh-keygen` используется флаг `-C` ? >> Добавляет комментарий к публичному ключу (обычно email); помогает идентифицировать ключ в `authorized_keys`
28. Где хранится пользовательский конфиг SSH для алиасов? >> `~/.ssh/config`
