1. Что делает параметр `push: true` в `docker/build-push-action` ? >> Автоматически отправляет собранный образ в registry после сборки
2. Какие утилиты отвечают за форматирование кода и сортировку импортов? >> `black` – форматирует код; `isort` – сортирует импорты; в пайплайне запускаются с флагом `--check` (без правок)
3. Какая утилита проверяет код Python на соответствие PEP 8? >> `flake8`
4. Что означает `environment: staging` в GitHub Actions? >> Привязывает job к логическому окружению; GitHub отображает историю деплоев и позволяет настроить protection rules (например, обязательное ревью)
5. Для чего используется `--exclude=migrations/` в настройках линтера? >> Исключает автогенерированные файлы миграций Django из проверки; их стиль не контролируется разработчиком
6. В чём суть этапа lint? >> Статический анализ исходного кода на наличие ошибок и соответствие стилю без его выполнения
7. Что такое пайплайн (pipeline) в CI/CD? >> Автоматизированная последовательность шагов от коммита кода до его развёртывания в продакшене: lint → test → build → deploy
8. Какая утилита генерирует XML-отчёт о покрытии кода? >> `pytest-cov` с параметром `--cov-report=xml`
9. Что проверяет флаг `--cov-fail-under=80` в `pytest` ? >> Завершает с ошибкой, если покрытие кода тестами ниже 80%; блокирует пайплайн
10. Для чего используется `docker/login-action@v2` ? >> Авторизует раннер в Docker Registry перед push или pull образа
11. Для чего в команде деплоя используется флаг `-T` ( `docker-compose exec -T` )? >> Отключает выделение псевдо-терминала (TTY); без него команда зависает в CI-окружении, где TTY недоступен
12. Для чего в `flake8` используется флаг `--max-line-length=100` ? >> Устанавливает максимально допустимую длину строки в 100 символов вместо дефолтных 79
13. Почему для тега Docker-образа рекомендуется использовать хэш коммита ( `$GITHUB_SHA` )? >> Обеспечивает уникальность тега и трассируемость: можно точно определить, из какого коммита собран образ (Artifact Traceability)
14. Почему медленные интеграционные тесты ставят в конец пайплайна? >> Чтобы не тратить время на них, если код уже не прошёл быстрые проверки линтера или юнит-тестов
15. Зачем в задании `test` описывается блок `services: postgres` ? >> Автоматически поднимает контейнер с PostgreSQL, необходимый для интеграционных тестов
16. Для чего используется `parallel: matrix` в CI? >> Для параллельного запуска задач на разных версиях окружения (например, Python 3.10, 3.11, 3.12); гарантирует совместимость
17. Как обеспечивается безопасность секретов в GitHub Actions? >> Через механизм Secrets ( `${{ secrets.TOKEN }}` ); значения маскируются в логах и не передаются в форкнутые PR
18. Что является результатом этапа build? >> Готовый к деплою артефакт: Docker-образ, бинарник или пакет
19. Для чего используется `actions/checkout@v4` в GitHub Actions? >> Клонирует репозиторий на виртуальную машину раннера; без этого шага код недоступен
20. Что происходит с пайплайном, если один из шагов завершается ошибкой? >> Последующие шаги не выполняются; пайплайн помечается как failed
21. Зачем кэшировать зависимости (например, `pip install` ) в CI? >> Исключает повторную загрузку одних и тех же пакетов; значительно ускоряет пайплайн
22. Почему важно разделять окружения staging и production? >> Staging позволяет финально проверить работоспособность в условиях, близких к боевым, до выпуска для пользователей
23. Что проверяет `mypy` в пайплайне? >> Корректность аннотаций типов в Python-коде; работает без запуска кода (статически)
24. Почему рекомендуется использовать `@v4` вместо `@latest` для actions? >> `@latest` может сломать пайплайн при выходе новой мажорной версии; конкретный тег обеспечивает воспроизводимость
25. Что означает параметр `needs: lint` в задании `test` ? >> Задание `test` начнёт выполнение только после успешного завершения задания `lint` ; создаёт явную зависимость между jobs
26. Каков правильный порядок шагов при обновлении сервиса на сервере через SSH? >> `docker pull` (скачать новый образ) → `docker-compose up -d` (перезапустить контейнеры) → `python manage.py migrate` (применить миграции)
