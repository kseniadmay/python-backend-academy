1. В каком параметре конфигурации Flask указывается строка подключения к БД? >> `SQLALCHEMY_DATABASE_URI` ; пример: `postgresql://user:pass@localhost/mydb`
2. Роль `blueprints/` в структуре Flask-проекта? >> Разделение логики на модули (пользователи, заказы, авторизация); каждый blueprint – независимый модуль с маршрутами
3. Как инициализировать Flask-SQLAlchemy при паттерне Application Factory? >> `db = SQLAlchemy()` в `extensions.py` ; `db.init_app(app)` внутри `create_app()`
4. Для чего Flask-Migrate? >> Управление миграциями через Alembic, интегрированный с Flask; отслеживает изменения моделей
5. Что делает `db.Column(db.Integer, primary_key=True)` ? >> Создаёт целочисленный первичный ключ; автоинкремент включён по умолчанию
6. Основные команды Flask-Migrate? >> `flask db init` – инициализация; `flask db migrate -m "msg"` – создание миграции; `flask db upgrade` – применение; `flask db downgrade` – откат; `flask db history` – история; `flask db current` – текущая версия
7. Правда ли, что `db.session.add()` сразу сохраняет данные в БД? >> Нет; данные попадают в БД только после `db.session.commit()`
8. Зачем выносить `db = SQLAlchemy()` в отдельный файл `extensions.py` ? >> Чтобы импортировать `db` в моделях без импорта самого приложения; предотвращает circular imports
9. Что такое Flask-SQLAlchemy? >> Расширение, интегрирующее SQLAlchemy с Flask; упрощает настройку, управление сессиями и определение моделей
10. Что такое `first_or_404()` ? >> Комбинация `filter` + `first` ; вызывает 404 при отсутствии результата
11. Как подключить Flask-Migrate в Application Factory? >> `migrate = Migrate()` в `extensions.py` ; `migrate.init_app(app, db)` в `create_app()`
12. Зачем `SQLALCHEMY_TRACK_MODIFICATIONS = False` ? >> Отключает систему событий SQLAlchemy; экономит ресурсы; по умолчанию вызывает предупреждение
13. Что означает `nullable=False` в `db.Column` ? >> Запрещает `NULL` ; SQL-ограничение `NOT NULL`
14. Что делает `db.session.rollback()` ? >> Отменяет все незафиксированные изменения; возвращает сессию к состоянию до начала транзакции
15. Что вернёт `User.query.filter_by(email='a@b.com').first()` при отсутствии записи? >> `None`
16. Что произойдёт, если приложение завершится ошибкой до `commit()` ? >> Изменения не сохранятся; произойдёт неявный откат
17. Типичная структура Flask-проекта по файлам? >> `run.py` – точка входа; `__init__.py` – `create_app()` ; `extensions.py` – `db` , `migrate` ; `models.py` – модели; `config.py` – конфигурация; `blueprints/` – маршруты; `templates/` – HTML; `static/` – CSS/JS; `migrations/` – скрипты миграций
18. Чем `get_or_404(id)` отличается от `get(id)` ? >> `get_or_404` возвращает 404 если запись не найдена; `get` возвращает `None`
19. От какого класса наследуются модели в Flask-SQLAlchemy? >> `db.Model`
20. Как просмотреть SQL миграции без применения? >> `flask db upgrade --sql`
