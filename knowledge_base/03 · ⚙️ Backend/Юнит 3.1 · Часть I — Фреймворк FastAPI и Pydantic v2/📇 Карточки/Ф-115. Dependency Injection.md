4. Что произойдёт с сессией БД если во время эндпоинта произойдёт ошибка? >> Сессия закроется в блоке `finally` функции `get_db`

13. Что произойдёт если передать `limit=150` при ограничении `le=100` ? >> FastAPI вернёт `422 Unprocessable Entity`
14. Для чего `OAuth2PasswordBearer` принимает `tokenUrl` ? >> Указывает URL для получения токена клиентом
15. Автоматически ли FastAPI разрешает вложенные зависимости? >> Да – любой глубины вложенности
16. В чем разница между статус-кодами 401 Unauthorized и 403 Forbidden в контексте API? >> `403 Forbidden`
17. Что произойдёт если зависимость на уровне роутера выбросит `HTTPException` ? >> Выполнение эндпоинта прервётся; клиент получит ответ с ошибкой
18. Как реализовать вложенную зависимость (Sub-dependency) для проверки прав администратора в FastAPI? >> Принимает аргумент `Annotated[User, Depends(get_current_user)]`
19. Какую функцию выполняет Depends() в сигнатурах эндпоинтов FastAPI? >> Указывает FastAPI что параметр является зависимостью, которую нужно разрешить перед вызовом функции
20. Как называется механизм FastAPI для автоматического разрешения внешних компонентов? >> Dependency Injection (внедрение зависимостей)
21. В чём преимущество `Annotated` при объявлении зависимостей? >> Совмещает объявление типа и метаданных зависимости ( `Depends` ) в одной переменной
22. Что возвращает `get_current_user` при успешной проверке токена? >> Объект пользователя ( `current_user` )
23. Может ли одна функция зависимости использовать несколько `Depends` ? >> Да
24. Что проверяет `le=100` в `Query` ? >> Значение не может превышать 100

30. Может ли синхронная функция использоваться как зависимость через `Depends` ? >> Да – FastAPI поддерживает и синхронные, и асинхронные зависимости

34. Зачем в `get_db` используется `yield` вместо `return` ? >> Чтобы приостановить функцию после передачи сессии и вернуться для её закрытия
