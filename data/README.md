# 💾 Хранилище данных и снимков прогресса (Data Hub)

В этой директории сохраняются локальные снимки пользовательского прогресса, очереди синхронизации и баг-репорты платформы **Python Backend Academy**.

---

## Файлы директории

| Файл | Описание |
|---|---|
| `progress_sync.json` | Локальный снимок синхронизации прогресса: решённые задачи IDE, накопленный XP, стрик, статус прохождения карточек SRS и активный урок. Используется сервером `scripts/server.js` в режиме локальной разработки (при отсутствии переменной `DATABASE_URL`). |
| `user_history_snapshot.json` | Таймлайн активности пользователя: хронология прохождения тем, отправки решений и сессий интервального повторения. |
| `user_feedback_queue.json` | Очередь замечаний и предложений по мобильному интерфейсу, отправляемых через REST API (`POST /api/bug-report`). |

---

## Архитектура хранения

1. **Режим разработки (по умолчанию)**:
   - Данные сериализуются в локальные JSON-файлы с атомарной записью через временные файлы (`.tmp -> .json`) для предотвращения повреждения при внезапном завершении процесса.
2. **Продакшен-режим (Облако / Render / Neon)**:
   - При наличии переменной окружения `DATABASE_URL` сервер `scripts/server.js` автоматически подключается к PostgreSQL (таблица `academy_progress_sync`) с защитой от сетевых конфликтов версий (HTTP 409 Conflict).
