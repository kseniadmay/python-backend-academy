# 💾 Хранилище данных платформы (`data/`)

В этой директории находятся канонические нормализованные данные обучающего контента, а также локальные снимки пользовательского прогресса и очередей обратной связи.

---

## 📁 Структура каталога

### 1. Канонический контент (`data/content/`)
Нормализованные JSON-базы, используемые FastAPI-сервисом и клиентским API:
- `manifest.json` — метаданные 7 модулей платформы, эшелонов и общего дерева навыков
- `notes.json` — 238 канонических конспектов микрообучения
- `cards.json` — 287 колод карточек интервального повторения SRS
- `tasks.json` — 401 задача с тест-кейсами и валидацией

### 2. Пользовательский прогресс и очереди
| Файл | Описание |
|---|---|
| `progress_sync.json` | Локальный снимок синхронизации: решённые задачи IDE, накопленный XP, стрик, статус карточек SRS и активный урок |
| `user_history_snapshot.json` | Таймлайн активности пользователя: хронология прохождения тем и сессий интервального повторения |
| `user_feedback_queue.json` | Очередь замечаний и предложений, отправляемых через REST API (`POST /api/v1/feedback`) |

---

## 🛡️ Архитектура хранения

1. **Режим разработки (по умолчанию)**:
   - Данные сериализуются в локальные JSON-файлы с атомарной записью через временные файлы (`.tmp -> .json`) для предотвращения повреждения при внезапном завершении процесса.
2. **Продакшен-режим (Облако / Render / Neon)**:
   - При наличии переменной окружения `DATABASE_URL` сервис автоматически подключается к PostgreSQL с оптимистичной блокировкой и защитой от сетевых конфликтов версий (HTTP 409 Conflict).
