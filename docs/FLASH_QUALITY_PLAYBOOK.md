## 2. Инструменты и рельсы безопасности

1. **Единый аудитор качества**:
   - Быстрый L1+L2 без вызова LLM:  
     `python scripts/quality_gate.py --tier 1 --no-llm`
   - Полный L1+L2+L3 через встроенный воркфлоу (`run_workflow` на `scripts/quality_gate_workflow.py`):  
     `Args: {"tier": "1", "model": "flash", "skills": "1.1.1,1.1.2,...", "force": false}`
   - Кэш SHA-256 хэшей хранится в `data/quality_ledger.json`, детальный отчёт — в `data/quality_report.md`.
2. **Единый синхронизатор (`scripts/sync_content.py`)**:
   - Не пишите самодельные регулярки/патчеры для `standards/standards.html`!
   - Редактируйте `knowledge_base/` и `data/content/{notes.json,cards.json,tasks.json}`, а для рубежных тестов — временный JSON `{ "unit_id": { ... } }`, после чего запускайте:
     - `python scripts/sync_content.py --notes К-001,К-002`
     - `python scripts/sync_content.py --decks Ф-005,Ф-092`
     - `python scripts/sync_content.py --tasks 92,350`
     - `python scripts/sync_content.py --unit-tests temp_ut.json`
   - Скрипт сам экранирует `</script` через `safe_js_json` и делает побайтовую копию `standards/standards.html` ➔ `academy.html`.
3. **Обязательная проверка после каждой пачки правок**:
   - `python scripts/audit_content_acceptance.py --tier 1 --strict`
   - `python scripts/quality_gate.py --skills <пачка> --no-llm --strict`

## 3. Порядок работ в 4 волны

### Волна А. Рентген Эшелона 1 (L1 + L2 + L3)
- Прогоните оставшиеся 60 навыков Эшелона 1 через `run_workflow` (`scripts/quality_gate_workflow.py`, `model: "flash"`) пачками по **10–15 навыков** (например, по одному треку/юниту за раз).
- Результат автоматически сохранится в `data/quality_ledger.json` и `data/quality_report.md`.

### Волна Б. Быстрые детерминированные правки (по L1 + отчёту)
1. Починить все **7** случаев вырезанных `<...>` (экранировать через `&lt;...&gt;` в HTML и проверить в Markdown).
2. Заменить все **47** заглушек I/O Flow в `data/content/tasks.json` на конкретные вход/выход задачи.
3. Переписать все **72** шаблонных `hint` в `data/content/tasks.json` в **4-уровневую лестницу Сократа** (без слива готового кода на шагах 1–3).
4. Удалить копипаст очистки Redis `r._store` из `tests` не-Redis задач.

### Волна В. Санация 18 перекошенных рубежных тестов
- Для каждого из 18 юнитов (`1.1..7.1` из списка выше):
  - Равномерно распределить индекс `correct` по позициям `0..3` (не более ~30–40% на один индекс).
  - Выровнять длину вариантов ответа (медиана верных / медиана дистракторов `< 1.8x`), заменить шуточные/абсурдные дистракторы на правдоподобные инженерные заблуждения.
  - Проверить в `explain`, что объясняется физика «почему», а не пересказывается верный вариант.
  - Загрузить через `python scripts/sync_content.py --unit-tests <file.json>`.

### Волна Г. Практика IDE, Конспекты ↔ Карточки и финал `61 / 61 PASS`
1. По `data/quality_report.md` доработать проблемные задачи: контракты в `desc`, edge-cases в `tests`, строки кода `≤ 46` символов под мобильный 390px экран, 0 `r._store` мусора.
2. Закрыть разрывы *Zero Surprises* в конспектах и убрать смысловые дубли в колодах (ориентир — эталон `1.5.3`: `К-039`, `Ф-055`, `Ф-056`, `#92`, `#350`).
3. Синхронизировать через `scripts/sync_content.py` и перепрогнать `quality_gate_workflow.py` (SHA-256 кэш проверит только изменённые навыки) до результата **`61 / 61 PASS`**.
