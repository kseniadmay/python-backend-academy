## 1. Глобальный лейаут, Сайдбар, Шапка и Навигация

### 1.1. Критический баг: Наложение плавающей кнопки «🐞 Замечание» (`.bug-fab-btn`)
- **Проблема**: Кнопка с классом `.bug-fab-btn` имеет фиксированное позиционирование `position: fixed; right: 16px; bottom: 18px` (на десктопе) и `bottom: 74px; right: 12px` (на мобильных).
  - На мобильных экранах (390×844) эта кнопка **физически перекрывает интерактивные элементы**:
    - В `#/cards` она ложится прямо поверх кнопки оценки карточки «2 · Трудно (+2 XP)» (см. скриншот `12_mob_flashcards.png`).
    - В `#/practice` и `#/mock` она перекрывает заголовок задачи и кнопки запроса наводки (скриншоты `10_mob`, `11_mob`).
    - На дашборде в светлой теме она закрывает текст третьей темы списка (скриншот `14_mob`).
- **Предложение по улучшению**:
  1. **Убрать плавающую кнопку из фиксированного слоя поверх контента на мобильных устройствах**. Перенести вызов фиксации замечания внутрь шапки (компактная иконка `🐞` рядом с переключателем темы `☀️/🌙`) либо добавить её 6-м пунктом в контекстное меню/сайдбар.
  2. Если оставлять плавающий FAB, сделать его полупрозрачным микро-значком (32×32px, `opacity: 0.4`, при наведении/тапе `opacity: 1`), который автоматически прячется при скролле вниз и появляется при скролле вверх.
  3. Для `#/cards`, `#/practice` и `#/mock` задать на контейнере динамический отступ справа снизу (`padding-right: 54px` или отключать FAB на экранах с полноэкранными кнопками действий).

### 1.2. Оверлей мобильной нижней панели (`.tabbar`) на контент (Safe Area Inset)
- **Проблема**: В `#/cards` кнопки «3 · Хорошо» и «4 · Легко» наполовину срезаются нижней панелью навигации (скриншот `12_mob_flashcards.png`). На современных смартфонах с жестовой полосой (Home Indicator) это приводит к ложным свайпам и невозможности нажать нижний ряд.
- **Предложение по улучшению**:
  - Добавить во все мобильные контейнеры просмотров (`#view-root`, `.card-study-view`, `.ide-container`):
    ```css
    padding-bottom: calc(76px + env(safe-area-inset-bottom, 16px));
    ```
  - Обеспечить, чтобы контент скроллился с запасом, не прилипая вплотную к таббару.

### 1.3. Сайдбар на десктопе: 15 монолитных пунктов без иерархии
- **Проблема**: В левом меню 15 пунктов идут сплошной вертикальной лентой: Дашборд, Python, Web, Backend, Алгоритмы, БД, Архитектура, Инфраструктура, Собеседование, Карта, IDE, Карточки, Справочник, Песочница, Микро-шаг. При высоте экрана 900px сайдбар выглядит перегруженным (скриншот `01_desk_dark_dashboard.png`).
- **Предложение по улучшению**:
  - Сгруппировать навигацию по 3 визуальным блокам с тонкими волосковыми заголовками:
    1. **Обучение**: `Дашборд`, `7 Модулей (выпадающий/аккордеонный список)`, `Карта навыков`.
    2. **Тренажёры**: `Практика IDE (401)`, `3D Карточки (286)`, `Собеседование (Mock)`.
    3. **Инструменты**: `Справочник (Docs)`, `Песочница Python`.
  - Модули 01–07 свернуть в элегантный аккордеон с суммарным прогресс-баром.

### 1.4. Грамматика счётчика стрика в подвале сайдбара
- **Проблема**: Отображается надпись `1 дней подряд` (скриншот `01_desk`).
- **Предложение по улучшению**:
  - Внедрить универсальный хелпер склонения русских числительных:
    ```javascript
    function pluralize(n, one, two, five) {
      const mod10 = n % 10, mod100 = n % 100;
      if (mod100 >= 11 && mod100 <= 19) return `${n} ${five}`;
      if (mod10 === 1) return `${n} ${one}`;
      if (mod10 >= 2 && mod10 <= 4) return `${n} ${two}`;
      return `${n} ${five}`;
    }
    // pluralize(state.streak, 'день', 'дня', 'дней') -> "1 день подряд", "3 дня подряд"
    ```

### 2.2. Карточка Кокона Фокуса («✨ Фокус сейчас · 4 минуты»)

### 2.4. Скрытые модули и статистика под спойлером (`<details class="cocoon-details">`)

- **Предложение по улучшению**:

## 3. Студия конспектов и Ридер микро-шагов

### 3.1. Проблема пустого пространства (Empty Canvas Void) на десктопе
- **Проблема**: При открытии микро-шага на десктопе (`04_desk_skill_1_1_1.png`) в режиме фокуса карточка занимает всего ~180px сверху, а оставшиеся 720px экрана представляют собой сплошную пустоту.
- **Предложение по улучшению**:
  - Внедрить для десктопа **Двухколоночный расклад (Split View)**:
    - **Левая колонка (60%)**: Поток конспекта с плавным Scroll-Reveal кусочков и богатой типографикой.
    - **Правая колонка (40%)**: Интерактивная «Лаборатория закрепления» (живой редактор для быстрой проверки разобранной строчки кода, контекстная флеш-карточка по текущему правилу и мини-шпаргалка ключевых терминов).
  - Это превращает пустой ридер в полноценную учебную студию профессионального уровня.

### 3.2. Визуализация структур данных и архитектурных концепций
- **Проблема**: В теоретических конспектах структуры данных описываются текстовыми списками (см. `shot_lesson_chunks_reveal_390x844.png`: `int`, `float`, `str`, `list`, `tuple`). Нет графических схем памяти.
- **Предложение по улучшению**:
  - Добавить стилизованные интерактивные **SVG/HTML-виджеты структур памяти CPython**:
    - Для `list`: массив указателей на PyObject с разделением на заголовок `ob_refcnt`, `ob_type`, `ob_size`, `allocated` и ячейки буфера.
    - Для `dict`: компактная хэш-таблица (массив индексов + плотная таблица записей `hash | key | value`).
    - Для сравнения списков и срезов: подсветка создания нового массива ссылок vs мутация на месте.

### 3.3. Блоки контраста собеседований (Junior vs Senior)
- **Проблема**: В некоторых конспектах примеры кода Junior vs Senior идут друг за другом обычными блоками без цветового зонирования.
- **Предложение по улучшению**:
  - В соответствии с навыком `visual-pedagogical-audit`, оформить контраст в две выразительные карточки:
    - ❌ **Ответ Junior**: деликатная полупрозрачная бордовая подложка `rgba(107, 29, 47, 0.08)`, волосковая граница, бейдж «Типичная ошибка на скрининге», указание скрытой сложности $O(n^2)$.
    - 🌟 **Ответ Senior**: деликатная полупрозрачная изумрудная подложка `rgba(20, 90, 70, 0.08)`, волосковая граница, бейдж «Архитектурный стандарт», аргументация с точки зрения памяти и потокобезопасности.

### 3.4. Навигатор конспектов внутри темы (`Навигация по теме (К-001)`)
- **Проблема**: Внизу кусочка находится выпадающий список «Навигация и вкладки (К-001) Конспекты (3) ▾». Нажатие на него требует лишнего действия.
- **Предложение по улучшению**:
  - Заменить на фиксированную внизу экрана или плавающую панель с хлебными крошками и кнопками «Предыдущий шаг» / «Следующий шаг», дополненную индикатором прочитанности (хлебные крошки `К-001 (1/7) • К-002 • К-003`).

## 4. Интегрированный тренажёр кода и IDE

### 4.1. Перегруженность фильтрами на мобильных устройствах
- **Проблема**: В `#/practice` на мобильном экране (скриншот `10_mob_practice_ide.png`) вертикально выстроены 5 селекторов подряд:
  1. `Все эшелоны (1-4)`
  2. `Все уровни (🥚 1 .. 👑 7)`
  3. `Все модули (401)`
  4. `Все статусы`
  5. Поле поиска по названию
  6. Длинный селект выбора конкретной задачи.
  В результате они занимают **весь первый экран**, вытесняя условие задачи и редактор кода за пределы видимости!
- **Предложение по улучшению**:
  - Свернуть фильтры на мобильных в горизонтальный скроллируемый ряд чипсов (Chips bar): `[🚨 Эшелон 1] [🥚 Ур. 1-2] [🐍 Python] [Не решено]`.
  - Добавить кнопку-фильтр с бейджем активных фильтров, открывающую аккуратную нижнюю шторку (Bottom Sheet) для тонкой настройки.
  - Селектор задачи заменить на компактный свайпер «Задача #240 из 401 ‹ ›» с быстрым поиском по номеру.

### 4.2. Эргономика мобильного ввода кода (Виртуальная инструментальная панель)
- **Проблема**: Стандартная клавиатура смартфона прячет спецсимволы (`:`, `_`, `[`, `]`, `{`, `}`, `(`, `)`, `"`, `'`, `=`, `->`) на третьем экране клавиатуры, а клавиша `Tab` (4 пробела) на мобильных отсутствует вовсе. Написание кода на телефоне превращается в мучение.
- **Предложение по улучшению**:
  - Добавить над редактором кода **липкую плавающую панель быстрых символов Python (Accessory Bar)**:
    - Кнопки: `Tab (4 сп)`, `:`, `_`, `( )`, `[ ]`, `{ }`, `def`, `return`, `self`, `in`, `==`.
    - Нажатие кнопки мгновенно вставляет символ в позицию курсора с сохранением фокуса.

### 4.3. Подсветка синтаксиса и номера строк в редакторе
- **Проблема**: Сейчас поле ввода представляет собой стилизованный `textarea` без номеров строк и динамической подсветки синтаксиса при наборе (скриншот `05_desk_practice_ide.png`).
- **Предложение по улучшению**:
  - Интегрировать ультралёгкий оверлей номеров строк слева (gutter с нумерацией строк, синхронизированный со скроллом `textarea`).
  - Добавить мягкую подсветку парных скобок и текущей строки.

### 4.4. Статус тестирования и анимация запуска
- **Проблема**: При нажатии «Запустить pytest (Ctrl+Enter)» происходит пауза в 200–500 мс (работа Brython). Если код сложный, пользователь не видит состояния выполнения.
- **Предложение по улучшению**:
  - Анимировать кнопку во время исполнения (шиммер-эффект, спиннер `⏳ Тестирование...`).
  - При успехе — мягкая изумрудная пульсация (`@keyframes correct-pulse`) и всплывающий бейдж `✓ 4/4 тестов пройдено (+15 XP)`.
  - При ошибке — подсветка строки с ошибкой в редакторе с цитатой AssertionError и кнопкой «Спросить подсказку 1-го уровня».

## 5. Симулятор собеседования (`#/mock`)

### 5.1. Визуализация 20-минутного таймера Live-Coding
- **Проблема**: Таймер отображается простыми статичными зелёными цифрами `20:00` (скриншот `06_desk_mock_interview.png`).
- **Предложение по улучшению**:
  - Добавить **Круговой SVG-индикатор обратного отсчёта**:
    - Плавное движение кольца по мере убывания времени.
    - Динамическая цветовая индикация:
      - `20:00 – 10:00`: Спокойный изумрудный (`--emerald`).
      - `10:00 – 03:00`: Фокусирующий янтарный (`--amber`).
      - `< 03:00`: Предупреждающий бордовый (`--bordeaux`) с мягким пульсирующим мерцанием на последних 60 секундах.
    - Звуковой мягкий тик на последней минуте (с возможностью отключения).

### 5.2. Интерактивный диалог Сократического интервьюера
- **Проблема**: Кнопка «Запросить наводку интервьюера (0/4)» выдаёт подсказку в блок текста, не создавая атмосферы реального диалога с техническим лидом.
- **Предложение по улучшению**:
  - Оформить блок подсказок в виде **Интерфейса живого технического интервью (Chat Stream UI)**:
    - Аватар интервьюера: `🎙️ Tech Lead (Яндекс / Тинькофф)`.
    - Реплики появляются в пузырях сообщений с печатной анимацией (typing effect).
    - Каждая наводка строго соблюдает регламент Mastery Learning (Уровень 0: открытый вопрос → Уровень 1: концептуальный намёк → Уровень 2: псевдокод шагов → Уровень 3: абстрактная сигнатура).
    - Счётчик подсказок: «Использовано подсказок: 1/4 (Оценка раунда: Strong Junior)».

### 5.3. Вкладка поведенческого интервью (STAR)
- **Проблема**: Вкладка STAR менее проработана визуально по сравнению с Live-Coding секцией.
- **Предложение по улучшению**:
  - Добавить интерактивную форму с 4 карточками-шагами матрицы STAR:
    - **S** (Situation / Ситуация): «Какой был контекст проекта и технический стек?»
    - **T** (Task / Задача): «Какая стояла архитектурная проблема или дедлайн?»
    - **A** (Action / Действие): «Что конкретно предприняли именно вы как бэкендер?»
    - **R** (Result / Результат): «Какие метрики улучшились (RPS, латентность p99, RAM)?»
  - Таймер на ответ (2 минуты на самопрезентацию по правилу питча).

## 6. Центр 3D Флеш-карточек (`#/cards`)

### 6.1. Физика 3D-переворота карточки (Tactile Flip)
- **Проблема**: Текущий переворот карточки происходит быстро и плоско.
- **Предложение по улучшению**:
  - Реализовать честный 3D-переворот с пружинящей физикой:
    ```css
    .card-scene { perspective: 1200px; }
    .card-object {
      transition: transform 0.45s cubic-bezier(0.34, 1.56, 0.64, 1);
      transform-style: preserve-3d;
    }
    .card-object.is-flipped {
      transform: rotateY(180deg);
    }
    .card-face {
      backface-visibility: hidden;
      -webkit-backface-visibility: hidden;
    }
    .card-face--back {
      transform: rotateY(180deg);
    }
    ```
  - Добавить динамический световой градиент (глянцевый блик/шейдинг), который перемещается по поверхности карточки во время поворота.

### 6.2. Мобильные жесты свайпа (Swipe Ergonomics)
- **Проблема**: На смартфонах управлять карточками кнопками внизу неудобно, особенно когда кнопки перекрыты таббаром.
- **Предложение по улучшению**:
  - Подключить обработчики Touch Events (`touchstart`, `touchmove`, `touchend`):
    - **Тап по карточке**: Переворот (Вопрос ↔ Ответ).
    - **Свайп вправо**: Оценка «4 · Легко» (карточка улетает вправо с зелёным свечением).
    - **Свайп влево**: Оценка «1 · Снова» (карточка улетает влево с красным свечением).
    - **Свайп вверх**: «3 · Хорошо».
  - Тактильная виброотдача через `navigator.vibrate([10])` при фиксации свайпа.

### 6.3. Индикатор прогресса колоды
- **Проблема**: Отображается только сухой текст «Карточка 1 из 19».
- **Предложение по улучшению**:
  - Добавить сегментированный микро-прогресс-бар сверху карточки (как в Instagram/Telegram Stories): 19 тонких полосок, где просмотренные карточки закрашиваются изумрудным или янтарным в зависимости от оценки.

## 7. Карта навыков и Эшелоны собеседования (`#/map`)

### 7.1. Баг наложения процентов на бейджи эшелонов (`08_desk_skill_tree_map.png`)

### 7.2. Визуализация дерева зависимостей и графа навыков
- **Проблема**: В текущей версии ветки навыков представлены плоскими карточками в колонках с простыми вертикальными линиями-разделителями.

## 9. Анти-прокрастинационный контур, Звук и Микро-геймификация

### 9.1. Интеграция таймера Помодоро на всех экранах
- **Проблема**: Таймер Помодоро (15/25 мин) спрятан внутри дашборда и не виден, когда ученик переходит в чтение конспектов или решение задач.

    - При клике — всплывающее микро-меню (Пауза / Сброс / Перерыв 5 мин).

### 9.2. Звуковая обратная связь через Web Audio API (Zero Dependencies)
- **Проблема**: Интерфейс полностью беззвучный. При решении сложных задач и карточек отсутствует аудиальное подкрепление дофаминового цикла.
- **Предложение по улучшению**:
  - Создать ультралёгкий встроенный аудио-синтезатор на чистом Web Audio API (0 внешних mp3-файлов, работает 100% оффлайн):
    ```javascript
    const SoundFx = {
      ctx: null,
      getCtx() {
        if (!this.ctx) this.ctx = new (window.AudioContext || window.webkitAudioContext)();
        return this.ctx;
      },
      playSuccess() { // Приятный двухтональный аккорд
        const ctx = this.getCtx();
        const now = ctx.currentTime;
        [523.25, 659.25, 783.99].forEach((freq, i) => { // C5, E5, G5
          const osc = ctx.createOscillator();
          const gain = ctx.createGain();
          osc.frequency.setValueAtTime(freq, now + i * 0.08);
          gain.gain.setValueAtTime(0.08, now + i * 0.08);
          gain.gain.exponentialRampToValueAtTime(0.001, now + i * 0.08 + 0.35);
          osc.connect(gain); gain.connect(ctx.destination);
          osc.start(now + i * 0.08); osc.stop(now + i * 0.08 + 0.35);
        });
      },
      playFlip() { // Мягкий щелчок переворота карточки
        const ctx = this.getCtx();
        const osc = ctx.createOscillator();
        const gain = ctx.createGain();
        osc.frequency.setValueAtTime(800, ctx.currentTime);
        osc.frequency.exponentialRampToValueAtTime(200, ctx.currentTime + 0.04);
        gain.gain.setValueAtTime(0.05, ctx.currentTime);
        gain.gain.exponentialRampToValueAtTime(0.001, ctx.currentTime + 0.04);
        osc.connect(gain); gain.connect(ctx.destination);
        osc.start(); osc.stop(ctx.currentTime + 0.04);
      }
    };
    ```
  - В сайдбар или шапку добавить переключатель `🔊 Звук: Вкл/Выкл` (по умолчанию выключен или мягкий).

### 9.3. Анимация разлёта очков XP (+10 XP Particle Burst)
- **Проблема**: При нажатии кнопки «Понятно, дальше (+10 XP)» число XP в шапке просто мгновенно меняется цифрой.

  - Одновременно запускать кратковременную пульсацию бейджа очков в шапке.

## 10. Цветовая гармония (60/30/10), Типографика и Доступность

### 10.1. Тонкая настройка Светлой Темы (Ephemeral Warm Parchment)
- **Проблема**:
  - На скриншотах `02_desk_light_dashboard.png` и `14_mob_light_dashboard.png` фон `#faf8f5` тёплый и приятный, однако карточки имеют границы одинаковой монотонной серой прозрачности, а розовая кнопка собеседования диссонирует с изумрудным фокусом.
- **Предложение по улучшению**:
  - Привести светлую тему в строгое соответствие правилу 60/30/10:
    - **60% Фон**: пергаментный тёплый `#faf8f5`.
    - **30% Поверхности**: полупрозрачные молочные плашки `rgba(255, 255, 255, 0.88)` с размытием `backdrop-filter: blur(20px)` и волосковой границей `rgba(15, 23, 42, 0.06)`.
    - **10% Акцентный треугольник**:
      - Изумруд `--emerald: #145a46` (основное целевое действие, правильные ответы, выполненные юниты).
      - Янтарь `--amber: #d97706` (текущий фокус, стрик, предупреждения).
      - Бордо `--bordeaux: #6b1d2f` (собеседования, ошибки, критические ловушки).
  - Заменить плоские заливки второстепенных кнопок на волосковые полупрозрачные тинты (Translucent Washes).

### 10.2. Доступность для слабовидящих и контрастность WCAG AAA
- **Проблема**: Некоторые серые подписи («Конспект 7 коротких микро-шагов...», мета-данные карточек) используют цвет `--ink-muted: #64748b` или `#94a3b8`, который на светлом фоне даёт контраст около 4.2:1 (на грани стандарта WCAG AA, но ниже WCAG AAA 7:1).
- **Предложение по улучшению**:
  - Для второстепенного текста в светлой теме поднять контраст до `#334155` (контраст > 8.5:1 к `#faf8f5`), обеспечив 100% соответствие WCAG AAA.
  - Убедиться, что все интерактивные кнопки имеют видимый фокус-аутлайн при навигации с клавиатуры (`:focus-visible { outline: 2px solid var(--emerald); outline-offset: 2px; }`).

### 10.3. Проверка инвариантов чистоты заголовков
- **Проверка**: В текущем HTML заголовок страницы равен `<title>Academy · Python Backend</title>`. Черновые названия тем («Глубокая осень», «Deep Autumn») в видимом UI отсутствуют, что полностью соответствует правилу чистоты.
