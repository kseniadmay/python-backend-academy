## 🎯 Ключевые архитектурные инварианты

1. **Единый фокус входа (`#/`) + Путь обучения (`#/path`)**: точка комфортного старта на дашборде без нулей и карта прогресса по кривой Безье (`../DESIGN.md § 6.2`).
2. **Один главный CTA**: ровно одно спокойное целевое действие в стиле Изумрудного стекла (`../DESIGN.md § 6.1`).
3. **Mastery Learning**: непрерывная цепь бусин и интервальное повторение SRS без штрафующих таймеров.
4. **Zero-Keyboard Scaffolding**: быстрые чипы и 4 подсказки Сократа для мобильной эргономики.
5. **100% Byte-Exact Sync**: побайтовое соответствие `academy.html` и канонического эталона `standards/standards.html`.
