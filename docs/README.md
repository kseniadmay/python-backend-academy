## 🎯 Ключевые архитектурные инварианты

1. **Home = Journey**: Тропа обучения — главный экран и смысловой центр приложения.
2. **Single Dominant CTA**: Ровно одно главное целевое действие на первом экране без визуального шума.
3. **Mastery Learning**: Фокус на освоении материала, интервальное повторение SRS без штрафующих таймеров.
4. **Zero-Keyboard Scaffolding**: Быстрые чипы-токены и интерактивные подсказки для мобильной эргономики.
5. **100% Byte-Exact Sync**: Побайтовое соответствие `academy.html` и канонических эталонов `Эталоны/Эталоны.html`.
