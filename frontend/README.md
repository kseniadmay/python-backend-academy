# 🎨 Модульный фронтенд (`frontend/`)

Декомпозированные компоненты пользовательского интерфейса, стилевая система и клиентские адаптеры платформы **Python Backend Academy**.

---

## 📁 Структура фронтенда

```text
frontend/
├── css/
│   ├── components/       # Изолированные CSS-компоненты (cards, ide, reader, sidebar, trail)
│   ├── base.css          # Базовый сброс и глобальная типографика
│   ├── glassmorphism.css # Эффекты матового стекла и глубина палитры «Вечерний Обсидиан»
│   ├── main.css          # Главная точка сборки CSS
│   └── variables.css     # CSS Custom Properties (цветовая палитра 60/30/10, токены)
├── dist/                 # Скомпилированные ассеты (bundle.css)
├── js/
│   ├── api.js            # Клиентский слой взаимодействия с FastAPI Content API
│   └── state.js          # Реактивный клиентский стейт-менеджер прогресса
└── index.html            # Модульная страница интерфейса
```

---

## 🛠️ Сборка стилей

Сборка бандла `dist/bundle.css` выполняется автоматически в мастер-пайплайне сборки:
```bash
python scripts/build.py
```
