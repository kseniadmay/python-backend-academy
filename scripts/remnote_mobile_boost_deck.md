# 📇 Мобильный буст: Карточки RemNote (Django ORM & FastAPI)

## 🐍 Django ORM & Models (Active Recall)

- Для предотвращения проблемы N+1 при связях ForeignKey и OneToOne в Django используется метод {{select_related()}}.
- Для оптимизации запросов со связями ManyToManyField и обратными ForeignKeys в Django используется метод {{prefetch_related()}}.
- Чтобы выполнить атомарное обновление счетчика в базе данных без race condition, в Django применяют {{F('field_name')}}.
- Для построения сложных фильтров с условием OR или NOT в Django ORM используется объект {{Q()}}.
- Метод QuerySet для проверки наличия хотя бы одной записи без загрузки всех объектов в память: {{queryset.exists()}}.
- Метод QuerySet, возвращающий список словарей вместо объектов моделей: {{values()}}.
- Метод QuerySet, возвращающий список кортежей значений: {{values_list(..., flat=True)}}.
- Чтобы выполнить добавление вычисляемого поля (например, COUNT связанных записей), используется метод {{annotate()}}.
- Чтобы сгруппировать данные и отфильтровать по агрегированному значению, аналог HAVING в Django реализуется через цепочку {{values().annotate().filter()}}.
- Для оборачивания группы операций в транзакцию базы данных в Django используется контекстный менеджер {{transaction.atomic()}}.
- Чтобы отложить загрузку тяжелых текстовых полей модели до прямого обращения, применяется метод {{defer('field_name')}}.
- Чтобы загрузить строго определенный перечень полей модели, используется метод {{only('field_name')}}.

## ⚡ FastAPI & Pydantic v2 (Active Recall)

- В FastAPI для объявления обязательного query-параметра достаточно указать аннотацию типа без {{значения по умолчанию}} (например `q: str`).
- Чтобы сделать параметр пути валидируемым целым числом больше нуля, используется {{Path(..., gt=0)}}.
- Базовый класс для создания схем валидации запросов и ответов в Pydantic: {{BaseModel}}.
- Декоратор Pydantic v2 для валидации конкретного поля модели: {{@field_validator('field_name')}}.
- Механизм внедрения зависимостей (Dependency Injection) в аргументы функций FastAPI задается через {{Depends(dependency_function)}}.
- Для выполнения фоновых задач после отправки HTTP-ответа клиенту в эндпоинт инжектируется объект класса {{BackgroundTasks}}.
- Исключение, прерывающее выполнение запроса и возвращающее понятную HTTP-ошибку клиенту: {{HTTPException(status_code=..., detail=...)}}.
- Статус-код HTTP, который автоматически возвращает FastAPI при ошибке валидации входных данных Pydantic: {{422 Unprocessable Entity}}.
- Для загрузки файлов как потока байтов в память или во временный файл используется тип {{UploadFile}} вместо bytes.
- Модель ответа и фильтрация выходных полей эндпоинта настраиваются через параметр декоратора {{response_model=...}}.
- Чтобы объявить роут, принимающий статус 201 Created при успешном создании ресурса, в декораторе указывают {{status_code=status.HTTP_201_CREATED}}.
