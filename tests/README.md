# 🧪 Автотесты и верификационный сьют платформы

В этой директории расположен сквозной набор автотестов, предотвращающий возникновение регрессий и проверяющий соблюдение утверждённых канонических эталонов интерфейса **Python Backend Academy**.

---

## Состав тестов

| Файл | Описание |
|---|---|
| `test_bugs_regression.js` | Главный регрессионный сьют из 80 проверок (`Bugs 1..80`): проверяет AST-валидность сниппетов Python, структуру флешкарт RemNote, корректность разметки формул, отсутствие синтаксических ошибок в конспектах и 100% идентичность `academy.html` каноническому файлу `Эталоны/Эталоны.html`. |
| `test_pravki_spec.js` | Спецификация 5 канонических эталонов интерфейса: 1. Экран конспекта и ридера теории; 2. Интерактивные флешкарты SRS; 3. Экран тренажёра практики со сплит-вью; 4. Модальное окно рубежного теста; 5. Сохранение десктопного сайдбара. |

---

## Запуск тестов

```bash
# Запуск регрессионного сьюта (80 тестов + канонические эталоны)
node tests/test_bugs_regression.js

# Запуск спецификации канонических эталонов
node tests/test_pravki_spec.js

# Запуск через общий мастер-конвейер
python verify_all.py --quick
```
