# 🏆 Канонические эталоны интерфейса платформы (Single Source of Truth)

Директория `Эталоны/` является единственным утверждённым источником правды для визуального стиля, эргономики и механики платформы **Python Backend Academy**.

## Состав эталонов

### 1. `эталон_конспект_теория.png` — Экран конспекта и ридера теории
- **Сайдбар слева**: остаётся полностью видимым на десктопе, обеспечивая непрерывную навигацию и контроль дневной активности.
- **Топбар эшелона**:
  - Прогресс эшелона: `Эшелон 1 · 35% готовности к скринингу` с прогресс-баром.
  - Бейдж дневного XP: `⚡ +55 XP за сутки`.
  - Кнопки: `📖 Справка` (ссылка на инженерный справочник) и `🎧 Озвучить` (вызов аудио-компаньона).
- **Иерархия заголовков**:
  - Серый надзаголовок юнита (например, `Базовый синтаксис`).
  - Крупный заголовок темы навыка (`Структуры данных Python: list, dict, set`).
- **Непрерывный трекер 13 точек (Continuous Atomic Dots)**:
  - Центрированная цепь: пройденные зелёные точки, текущая белая точка с ореолом, будущие серые точки, завершающий ромб рубежного теста.
- **Контент теории**:
  - Чистая типографика без лишних обёрток, сфокусированная на микро-шаге.
  - Интерактивный запуск Python-сниппетов.
- **Single Dominant Action**:
  - Широкая изумрудная кнопка `Понятно, дальше (+10 XP) ➔`.

### 2. `Запись 2026-10-14 203339.mp4` — Видео-эталон интерактивных карточек
- **Файл**: `Эталоны/Запись 2026-10-14 203339.mp4` (7.2 сек, 1920×954, 30 fps).
- **Раскадровка**: `Эталоны/video_frames/frame_001.png` .. `frame_014.png`.
- **Поведение и состояния**:
  1. **Над карточкой**: номер текущей карточки `Карточка 1 из 19` и бейдж `Интервальное повторение`.
  2. **Карточка**: карточка со скруглёнными углами и изумрудной рамкой (`border: 1px solid rgba(16, 185, 129, 0.4)`).
  3. **Шапка карточки**: бейдж `Вопрос` / `Ответ` слева и кнопка-чип `💡 Шпаргалка` справа.
  4. **Состояние 1 (Вопрос)**:
     - Текст вопроса с подсветкой ключевых слов кода.
     - Кнопки внизу: `← Назад`, по центру широкая изумрудная кнопка `Показать ответ (Пробел)`, справа `Дальше →`.
  5. **Состояние 2 (Ответ)**:
     - При клике на карточку или нажатии `Пробел` / кнопку `Показать ответ`:
     - Карточка плавно переворачивается, бейдж меняется на `Ответ`, отображается ответ на вопрос.
     - Вместо кнопки «Показать ответ» раскрывается панель 4 кнопок интервального повторения (SRS):
       - `Снова` (темная с фиолетовым акцентом)
       - `Трудно (+2 XP)` (рубиновая с каймой)
       - `Хорошо (+5 XP)` (янтарно-коричневая)
       - `Легко (+10 XP)` (ярко-изумрудная залитая кнопка).

### 3. `эталон_практика_задача.png` — Экран задачи и тренажёра практики
- **Сайдбар слева**: открыт и доступен.
- **Топбар эшелона и трекер 13 точек**: сохраняются в едином ритме со страницей теории и карточек.
- **Двухколоночный Split-View**:
  - **Левая колонка**:
    - Бейдж задачи: `Задача #20  🥚 Уровень 1` ... `1 из 5`.
    - Текст условия задачи.
    - Блок **⚡ ПОТОК ДАННЫХ (I/O FLOW)**:
      `ВХОД (ORIGINAL): [1, 2, 3, 4, 5] ➔ ОЖИДАНИЕ (РЕЗУЛЬТАТ): [5, 4, 3, 2, 1]`
    - Блок **📐 АНАТОМИЯ СТРУКТУРЫ / СРЕЗА**:
      Интерактивная диаграмма индексов с ячейками `[ 1 ][ 2 ][ 3 ][ 4 ][ 5 ]`, прямыми `0..4` и обратными `-5..-1`.
    - Блок **💡 НАСТАВНИК СОКРАТ**:
      Счётчик `Уровень скаффолдинга: 0 / 4` и кнопка `Получить наводку без готового кода ➔`.
  - **Правая колонка (Редактор кода)**:
    - Виртуальная панель чипсов быстрых вставок над редактором (`[::-1]`, `original[::-1]`, `reversed_list`, `Tab ➔`, `:`, `_`).
    - Полнофункциональный редактор Python с номерами строк.
    - Подсказки горячих клавиш: `Ctrl + Enter Запустить тесты`, `Tab Отступ`.
    - Кнопка сброса `↺` и широкая изумрудная кнопка `▷ Проверить решение +15 XP (Ctrl+Enter)`.

  - Заголовок: `Готовы начать тест?`.

  - Вторичная кнопка: `Пропустить`.
  - Опция с тумблером (toggle switch): `Показывать разбор после ответа`.
  - Чекбокс: `Всегда открывать тест без этой модалки`.
  - Сноска: `Это можно изменить в «⚙ Настройки платформы»`.
